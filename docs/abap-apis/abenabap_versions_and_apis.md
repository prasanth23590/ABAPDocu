# ABAP APIs

ABAP supports two main programming paradigms:

- [ABAP Cloud](../abap-glossary/abenabap_cloud_glosry.md)

- [Classic ABAP](../abap-glossary/abenclassic_abap_glosry.md)

While in classic ABAP there is unrestricted access to the [ABAP technology](../abap-glossary/abenabap_techno_glosry.md), in ABAP Cloud there are restrictions regarding ABAP language versions and access to APIs explained in the following topics.

- [ABAP Language Versions](abenabap_language_versions.md)

- [Release Contracts](release-contracts/abenabap_release_contracts.md)

- [Released APIs](released-apis/abenabap_api_release.md)
