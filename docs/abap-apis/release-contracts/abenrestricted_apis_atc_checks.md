# Contract Checks for Released APIs

A set of [ATC](../../abap-glossary/abenatc_glosry.md) checks is shipped with SAP Basis that [ATC](../../abap-glossary/abenatc_glosry.md) checks shipped by SAP that check if [released APIs](../../abap-glossary/abenreleased_api_glosry.md) fulfill the rules of their [release contracts](../../abap-glossary/abenrelease_contract_glosry.md).

The following topics display the [KTD](../../abap-glossary/abenktd_glosry.md) documentation of these checks. The consistency checks are relevant for rules regarding the prerequisites for release and the compatibility checks are relevant for the stability rules after release.

- [Consistency Checks for Released APIs](abenrestricted_apis_atc_consi.md)

- [Compatibility Checks for Released APIs](abenrestricted_apis_atc_compa.md)
