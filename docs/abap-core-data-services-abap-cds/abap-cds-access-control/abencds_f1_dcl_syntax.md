# ABAP CDS - DCL Statements

The data control language CDS DCL in ABAP CDS follows the [general CDS syntax rules](../abap-cds-syntax/abencds_general_syntax_rules.md) and comprises the following statements for the definition of [CDS roles](../../abap-glossary/abencds_role_glosry.md) and [CDS access policies](../../abap-glossary/abencds_access_policy_glosry.md) in [DCL source code](../../abap-glossary/abendcl_source_code_glosry.md):

- [`DEFINE ROLE`](abencds_f1_define_role.md)

- [`DEFINE ACCESSPOLICY`](abencds_f1_define_accesspolicy.md)

## Hints

- The [DCL source code](../../abap-glossary/abendcl_source_code_glosry.md) for CDS access control has its own editor in [`ADT`](../../abap-glossary/abenadt_glosry.md), which is documented there.

- The names of the items of DCL source code for [CDS roles](../../abap-glossary/abencds_role_glosry.md) and [CDS access policies](../../abap-glossary/abencds_access_policy_glosry.md) are in the same namespace.
