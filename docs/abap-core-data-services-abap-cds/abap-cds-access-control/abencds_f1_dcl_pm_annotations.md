# CDS DCL - DEFINE PFCG_MAPPING, pfcg_mapping_annot

## Syntax

``` abap
... @annotation ...  
```

[`annotation`](../abap-cds-annotations/abencds_annotations.md)

## Description

Specifies an [annotation](../../abap-glossary/abencds_annotation_glosry.md) [`annotation`](../abap-cds-annotations/abencds_annotations_syntax.md) as a PFCG mapping annotation in front of the statement [`PFCG_MAPPING`](abencds_f1_define_pfcg_mapping.md) in the definition of a [CDS PFCG mapping](../../abap-glossary/abencds_pfcg_mapping_glosry.md). The character `@` must be placed in front of the name `annotation` of the annotation.

The following [ABAP annotations](../../abap-glossary/abenabap_annotation_glosry.md) can be specified for `annotation`. No other annotations can be specified.

- EndUserText Annotations

  - [`EndUserText.label`](../abap-cds-annotations/abencds_924137870_anno.md)
