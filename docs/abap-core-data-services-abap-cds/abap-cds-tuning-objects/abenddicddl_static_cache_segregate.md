# CDS DDL - DEFINE STATIC CACHE, SEGREGATE CACHE DATA

## Syntax

``` abap
... 
[SEGREGATE CACHE DATA BY filter_cond] 
...  
```

## Description

Filtering cached data can be done with the optional statement `SEGREGATE CACHE DATA`.
