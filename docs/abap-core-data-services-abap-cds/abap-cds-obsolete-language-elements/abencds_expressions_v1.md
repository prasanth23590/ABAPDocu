# CDS DDL - DDIC-Based View, Expressions

## Syntax

``` abap
... arith_expr 
  | aggr_expr 
  | case_expr 
  | cast_expr 
  | func...  
```

[`arith_expr`](abencds_arithmetic_expression_v1.md) · [`aggr_expr`](abencds_aggregate_functions_v1.md) · [`case_expr`](abencds_case_expression_v1.md) · [`cast_expr`](abencds_cast_expression_v1.md) · [`func`](abencds_builtin_functions_v1.md)

## Description

CDS DDL expressions are expressions that can be specified in a CDS DDL operand position of a [CDS DDIC-based view (obsolete)](../../abap-glossary/abencds_v1_view_glosry.md).

The following CDS DDL expressions exist:

- [Arithmetic expressions](abencds_arithmetic_expression_v1.md)

- [Aggregate expressions](abencds_aggregate_functions_v1.md)

- [Case distinctions](abencds_case_expression_v1.md)

- [Cast expressions](abencds_cast_expression_v1.md)

- [Calls of built-in CDS functions](abencds_builtin_functions_v1.md)
