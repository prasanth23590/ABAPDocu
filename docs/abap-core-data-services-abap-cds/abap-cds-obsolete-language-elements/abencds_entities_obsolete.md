# Obsolete CDS Entities

- [CDS DDIC-based Entities](abencds_ddic_entity.md): CDS DDIC-based entities are obsolete and as a consequence, CDS DDIC-based views (obsolete), representing a sub-category of CDS DDIC-based entities, are obsolete. Accessing a [CDS-managed DDIC view](../../abap-glossary/abencds_mngdddic_view_glosry.md), which is created for each CDS DDIC-based view (obsolete), is [obsolete](abencds_access_obsolete.md) as well.

- [CDS Propagated Buffer (Obsolete)](abencds_propagate_buffer.md): CDS propagated buffers are obsolete, as there are no longer any performance gains to be had by using them. It is not advised to use these.
