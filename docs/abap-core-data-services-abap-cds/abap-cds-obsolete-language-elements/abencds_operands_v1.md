# CDS DDL - DDIC-Based View, Elementary CDS Operands

## Syntax

``` abap
... literal 
  | field 
  | $parameters.pname 
  | $session.vname ...  
```

[`literal`](abencds_literal_v1.md) · [`field`](abencds_field_v1.md) · [`$parameters.pname`](abencds_parameter_v1.md) · [`$session.vname`](abencds_session_variable_v1.md)

## Description

Specifies a literal [`literal`](abencds_literal_v1.md), a field [`field`](abencds_field_v1.md), a parameter [`$parameters.pname`](abencds_parameter_v1.md), or a session variable [`$session.vname`](abencds_session_variable_v1.md) as an elementary [CDS operand](../../abap-glossary/abencds_operand_glosry.md) in a CDS DDL operand position.
