## yearQuarter

### Short Description

The value of the annotated field encodes a fiscal year and quarter as a string following the logical pattern YYYYQ consisting of five digits. The last digit represents the fiscal quarter in the year.

### Example

The string matches the regex pattern (\[1-9\]{3,}\|0\[0-9\]{3})\[1-4\]
