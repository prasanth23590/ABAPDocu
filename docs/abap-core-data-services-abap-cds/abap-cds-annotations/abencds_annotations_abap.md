# ABAP CDS - ABAP Annotations

ABAP annotations are [SAP annotations](../../abap-glossary/abensap_annotation_glosry.md) that are evaluated by the ABAP runtime framework. The following sections show the [annotation syntax](../../abap-glossary/abencds_annotation_syntax_glosry.md):

- [ABAP annotation syntax](abencds_annotations_abap_tables.md)

The detailed meanings of the ABAP annotations is documented for the corresponding [scope](abencds_annotations_scopes.md) in this documentation.

## Hint

An ABAP annotation can also be evaluated by frameworks of other software components.
