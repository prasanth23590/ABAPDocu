## Annotation Documentation

## AbapCatalog

Technical settings of a CDS entity.

## sqlViewName

Name of the CDS-managed DDIC view (obsolete) of a DDIC-based CDS view.

## Annotation Value

Character string with a maximum of 16 characters consisting of letters, numbers and underscores and that starts with a namespace prefix.
