# ABAP CDS - Framework-Specific Annotations

Framework-specific annotations are [SAP annotations](../../abap-glossary/abensap_annotation_glosry.md) that define the technical and semantic properties of CDS objects that are required by specific software components, such as `ODATA`, `UI`, and Analytics. The following sections show the [annotation syntax](../../abap-glossary/abencds_annotation_syntax_glosry.md):

- [Framework-specific annotation syntax](abencds_annotations_frmwrk_tables.md)

The documentation [CDS Annotations](https://help.sap.com/docs/ABAP_Cloud/f055b8bf582d4f34b91da667bc1fcce6/130e02a697e14bf8b05dd6672c56250b?version=sap_cross_product_abap) describes the meaning of framework-specific annotations, which SAP framework is evaluated by these annotations, and their allowed values.

## Hint

When using the framework-specific annotations, note the corresponding established rules. Otherwise error messages can occur during framework-specific checks.
