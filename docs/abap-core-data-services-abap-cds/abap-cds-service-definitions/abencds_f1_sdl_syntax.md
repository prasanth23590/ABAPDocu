# ABAP CDS - SDL for Service Definitions

A [CDS service definition](../../abap-glossary/abencds_service_definition_glosry.md) in ABAP CDS is created using the data definition language [CDS SDL](../../abap-glossary/abencds_sdl_glosry.md) in [SDL source code](../../abap-glossary/abensdl_source_code_glosry.md). CDS SDL complies with the [general CDS syntax rules](../abap-cds-syntax/abencds_general_syntax_rules.md) and contains the following language element for service definitions:

- [`DEFINE SERVICE`](abensrvd_define_service.md)

## Hints

- The [SDL source code](../../abap-glossary/abensdl_source_code_glosry.md) of service definitions has its own editor in [ADT](../../abap-glossary/abenadt_glosry.md), which is documented there.
