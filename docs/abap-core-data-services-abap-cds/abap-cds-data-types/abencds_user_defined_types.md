# ABAP CDS - User-Defined Data Types

A [CDS user-defined type](../../abap-glossary/abencds_user_defined_type_glosry.md) is defined as a [CDS object](../../abap-glossary/abencds_object_glosry.md) in [ABAP CDS](../../abap-glossary/abenabap_cds_glosry.md). CDS user-defined types can be used as [global types](../../abap-glossary/abenglobal_type_glosry.md).

The following CDS user-defined types are available:

- [CDS simple types](../abap-cds-data-definitions/abencds_simple_types.md) for defining [elementary data types](../../abap-glossary/abenelementary_data_type_glosry.md).

- [CDS enumerated types](../abap-cds-data-definitions/abencds_enumeration_types.md) for defining [enumerated types](../../abap-glossary/abenenum_type_glosry.md).

For details, see the topic [ABAP CDS - Type Definitions](../abap-cds-data-definitions/abencds_tdl.md).
