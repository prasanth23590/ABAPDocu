# ABAP CDS - Data Types

ABAP CDS provides a set of [CDS built-in data types](../../abap-glossary/abencds_built_in_type_glosry.md). Custom data types can be defined as [CDS user-defined types](../../abap-glossary/abencds_user_defined_type_glosry.md). [CDS generic types](../../abap-glossary/abencds_generic_type_glosry.md) cover a range of CDS built-in data types and can be used like a placeholder that allows for different built-in data types.

- [ABAP CDS - Built-In Data Types](abencds_overview_builtin_types.md)

- [ABAP CDS - User-Defined Data Types](abencds_user_defined_types.md)

- [ABAP CDS - Generic Data Types](abenddic_generic_types.md)

## More Information

For further details on data types in ABAP CDS, see [*Data Types in ABAP CDS*](https://help.sap.com/docs/ABAP_Cloud/aaae421481034feab3e71dd9e0f643bf/f04708ca02d345e18fecbbd9a1eb9eb7?version=sap_cross_product_abap) in the ABAP Data Models guide on SAP Help Portal.
