# ABAP CDS - Amounts and Quantities

In [ABAP CDS](../../abap-glossary/abenabap_cds_glosry.md), a special handling for amounts and quantities is implemented. [ABAP CDS amount fields](../../abap-glossary/abencds_amount_field_glosry.md) and [ABAP CDS quantity fields](../../abap-glossary/abencds_quantity_glosry.md) are similar to [DDIC currency fields](../../abap-glossary/abenddic_currency_field_glosry.md) and [DDIC quantity fields](../../abap-glossary/abenddic_quantity_glosry.md), but more data types are possible.

In [CDS view entities](../../abap-glossary/abencds_v2_view_glosry.md), the [currency key](../../abap-glossary/abencurrency_key_glosry.md) and [unit key](../../abap-glossary/abenunit_glosry.md) reference is respected in [expressions](../abap-cds-data-definitions/abencds_expressions_v2.md), [comparisons](../abap-cds-data-definitions/abencds_cond_expr_types_v2.md), [`UNION` views](../abap-cds-data-definitions/abencds_union_v2.md), and [`INTERSECT` views](../abap-cds-data-definitions/abencds_intersect_v2.md). Moreover, a special data type is available: the [calculated quantity with calculated unit reference](abencds_calculated_quantity.md).
