# ABAP CDS - Syntax

The syntax of the [CDS DDL](../../abap-glossary/abencds_ddl_glosry.md) and the [CDS DCL](../../abap-glossary/abencds_dcl_glosry.md) in ABAP CDS comprises elements of the general [SQL](../../abap-glossary/abensql_glosry.md) [DDL](../../abap-glossary/abenddl_glosry.md) and [DCL](../../abap-glossary/abendcl_glosry.md) and also makes it possible to define annotations and CDS associations. The syntax and semantics basically match the general [CDS](../../abap-glossary/abencds_glosry.md) concept.
