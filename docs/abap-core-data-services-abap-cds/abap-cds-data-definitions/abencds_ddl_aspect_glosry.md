# CDS DDL aspect

[CDS](../abencds_glossary.md)

## Definition

A [CDS object](../../abap-glossary/abencds_object_glosry.md) defined in [ABAP CDS](../../abap-glossary/abenabap_cds_glosry.md) that defines reusable components for [CDS entities](../../abap-glossary/abencds_entity_glosry.md). A [CDS aspect](abencds_aspects.md) is defined using the syntax [`DEFINE ASPECT`](abencds_define_aspect.md). An aspect can be included in one or more [CDS data definitions](../../abap-glossary/abencds_data_definition_glosry.md) by a [CDS aspect binding](../../abap-glossary/abencds_ddl_aspect_binding_glosry.md).
