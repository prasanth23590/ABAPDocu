- [CDS view entities](abencds_v2_views.md)

- [CDS Aspects](abencds_aspects.md)

- [CDS table functions](abencds_table_functions.md)

Each section first gives an overview of the concept, describes client handling and table buffering for the respective entity, and then describes the associated CDS DDL statement and all possible additions.

## Hint

After activation, a CDS entity can be changed into another type of CDS entity. How this works and all possible type changes are described in topic [ABAP CDS - Changing the Type of a CDS Entity](abencds_transitions.md).
