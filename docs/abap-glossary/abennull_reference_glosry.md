# null reference

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Initial value](abeninitial_value_glosry.md) of a [reference variable](abenreference_variable_glosry.md). The null reference does not point to an [object](abenobject_glosry.md) and can be assigned to any reference variable. [Data objects](abendata_object_glosry.md) accessed using the null reference generally produce an [uncatchable exception](abenuncatchable_exception_glosry.md). Method calls using the null reference produce a [catchable exception](abencatchable_exception_glosry.md).
