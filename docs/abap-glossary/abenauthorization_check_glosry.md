# authorization check

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Checks whether the current [ABAP user](abenabap_user_glosry.md) has a specific [authorization](abenauthorization_glosry.md). For each [authorization field](abenauthorization_field_glosry.md) of an [authorization object](abenauthorization_object_glosry.md), the system checks a value against the corresponding entries in the [user master record](abenuser_master_record_glosry.md). [Check indicators](abencheck_indicator_glosry.md) control whether an authorization check takes place. Authorization checks are either implicit when programs are called, or explicit when the [ABAP statement](abenabap_statement_glosry.md) [`AUTHORITY-CHECK`](../abap-programming-language/abap-authorizations/abapauthority-check.md) is used.
