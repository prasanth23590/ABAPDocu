# relational database

[General](abenabap_glossary.md)

## Definition

[Database](abendatabase_glosry.md) whose data is managed according to the [relational data model](abenrelational_data_model_glosry.md), that is, in [database tables](abendatabase_table_glosry.md). Further objects such as [views](abenview_glosry.md) can be created to access the data. These objects are organized in [database schemas](abendatabase_schema_glosry.md). The objects are generally defined and accessed using [SQL](abensql_glosry.md).
