# hierarchy attribute

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

A component of the tabular result set of a [hierarchy function](abenhierarchy_function_glosry.md) that contains hierarchy-specific information for each row. When a [ABAP SQL hierarchy](abensql_hierarchy_glosry.md) is accessed in [ABAP SQL](abenabap_sql_glosry.md), the hierarchy attributes can be included in the result set as [hierarchy columns](abenhierarchy_column_glosry.md) of [hierarchy nodes](abenhierarchy_node_glosry.md). The hierarchy attributes can be used to define elements of the CDS hierarchy can be used in the definition of a [CDS hierarchy](abencds_hierarchy_glosry.md).
