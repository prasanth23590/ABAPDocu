# BOPF-managed RAP BO provider

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The part of the [RAP BO provider](abenrap_bo_provider_glosry.md) that provides the [transactional buffer](abentransactional_buffer_glosry.md) for [BOPF-based RAP BOs](abenrap_bopf_bo_glosry.md).
