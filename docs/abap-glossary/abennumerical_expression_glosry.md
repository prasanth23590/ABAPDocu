# numeric expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Represents a numeric value. A numeric expression is a [constructor expression](abenconstructor_glosry.md), [arithmetic expression](abenarithmetic_expression_glosry.md), [table expression](abentable_expression_glosry.md), or a [function](abenfunction_glosry.md) whose return value has a [numeric data type](abennumeric_data_type_glosry.md).
