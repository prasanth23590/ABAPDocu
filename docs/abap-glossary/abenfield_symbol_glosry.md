# field symbol

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Symbolic name for a [data object](abendata_object_glosry.md) to which actual memory areas can be assigned at program runtime. A field symbol can be used as a placeholder for a data object at an operand position. A field symbol is [typed](abentyping_glosry.md) either generically or completely. Field symbols are declared using the statement [`FIELD-SYMBOLS`](../abap-programming-language/abap-declarations/abapfield-symbols.md) or the [declaration operator](abendeclaration_operator_glosry.md) [`FIELD-SYMBOL`](../abap-programming-language/abap-declarations/abenfield-symbol_inline.md); memory areas are assigned to them using [`ASSIGN`](../abap-programming-language/abap-processing-internal-data/abapassign.md).
