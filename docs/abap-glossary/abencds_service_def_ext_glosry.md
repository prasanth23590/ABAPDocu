# CDS service definition extension

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A transportable extension of a [CDS service definition](abencds_service_definition_glosry.md) using the [CDS SDL](abencds_sdl_glosry.md) statement [`EXTEND SERVICE`](../abap-core-data-services-abap-cds/abap-cds-service-definitions/abensrvd_extend_service.md). A CDS service definition extension can add further entities to an existing CDS service definition without modifying the original service definition.
