# calculation type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Property of an [arithmetic expression](abenarithmetic_expression_glosry.md) depending on the [numeric data types](abennumeric_data_type_glosry.md) involved. The calculation type determines the calculation rule used to evaluate an arithmetic expression. There are different rules for the possible calculation types `i`, `int8`, `p`, `decfloat34`, and `f`.
