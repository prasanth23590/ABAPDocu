# floating point arithmetic

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Calculation with [floating point numbers](abenfloating_point_number_glosry.md). It is executed directly on the [host computer](abenhost_computer_glosry.md) of the current [AS instance](abenas_instance_glosry.md). Either [binary floating point arithmetic](abenbinfloat_arith_glosry.md) or [decimal floating point arithmetic](abendecfloat_arith_glosry.md).
