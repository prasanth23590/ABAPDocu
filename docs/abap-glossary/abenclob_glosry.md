# CLOB

[General](abenabap_glossary.md)

## Definition

Short for Character Large Object. Name for a [database field](abendatabase_field_glosry.md) with the data type [`STRING`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md) or the result of an [SQL expression](../abap-programming-language/abap-database-access/abapsql_expr.md) that returns the data type [`STRING`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md).
