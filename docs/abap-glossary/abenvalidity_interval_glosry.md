# validity interval

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

The time interval that is assigned to each [hierarchy node](abenhierarchy_node_glosry.md) of a [temporal SQL hierarchy](abentemporal_hierarchy_glosry.md). The validity interval is the intersection of the validity interval of the [ancestor node](abenancestor_node_glosry.md) and the [period](abenperiod_glosry.md) of the current node.
