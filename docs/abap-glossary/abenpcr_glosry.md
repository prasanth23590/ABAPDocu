# parent-child relationship

[General](abenabap_glossary.md)

## Definition

PCR for short. A parent-child relationship is a directed [hierarchy edge](abenhierarchy_edge_glosry.md) between two [hierarchy nodes](abenhierarchy_node_glosry.md) that defines the type of the nodes. A hierarchy node with outbound edges is a [parent node](abenparent_node_glosry.md). A hierarchy node with inbound edges is a [child node](abenparent_node_glosry.md). A hierarchy node with no inbound edges is a [root node](abenroot_node_glosry.md) or an [orphan node](abenorphan_node_glosry.md). A hierarchy node with no outbound edges is a [leaf node](abenleaf_node_glosry.md).
