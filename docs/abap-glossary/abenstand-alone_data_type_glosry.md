# standalone data type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

A [data type](abendata_type_glosry.md) that is defined using the statement [`TYPES`](../abap-programming-language/abap-declarations/abaptypes.md) in an [ABAP program](abenabap_program_glosry.md), as a data type of the [ABAP Dictionary](abenabap_dictionary_glosry.md) or as a [CDS entity](abencds_entity_glosry.md). See also [bound data type](abenbound_data_type_glosry.md).
