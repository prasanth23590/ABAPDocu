# CDS to-parent association

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A specialized [CDS association](abencds_association_glosry.md) in [ABAP CDS](abenabap_core_data_services_glosry.md) that is defined in the [child entity](abenchild_entity_glosry.md) and points to the [parent entity](abenparent_entity_glosry.md) using the syntax statement [`ASSOCIATION TO PARENT`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_to_parent_assoc_v2.md). In combination with the [to-child association](abento_child_association_glosry.md), they define a [CDS composition](abencds_composition_glosry.md) relationship. The CDS compositions are the basis for the [CDS composition tree](abencds_composition_tree_glosry.md) of a [RAP business object](abenrap_bo_glosry.md).
