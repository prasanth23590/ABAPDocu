# RAP global feature control

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A kind of [feature control](abenrap_feature_control_glosry.md) that defines access restrictions independently of the state of a [BO entity instance](abenrap_bo_entity_inst_glosry.md). Global feature control can be defined for [operations](abenrap_bo_operation_glosry.md) only.
