# generic data type

[General](abenabap_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) that does not set all properties of a [data object](abendata_object_glosry.md). Generic data types can only be used for the [typing](abentyping_glosry.md) of [formal parameters](abenformal_parameter_glosry.md) and [field symbols](abenfield_symbol_glosry.md). A generic data type is either a [generic ABAP type](abengeneric_abap_type_glosry.md) or a [table type](abentable_type_glosry.md) with no [primary table key](abenprimary_table_key_glosry.md) or an incomplete one.
