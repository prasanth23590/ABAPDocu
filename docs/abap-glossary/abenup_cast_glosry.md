# upcast

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Also referred to as a widening cast. [Assignment](abenassignment_glosry.md) between [reference variables](abenreference_variable_glosry.md), where the [static type](abenstatic_type_glosry.md) of the target variables is more general or identical to the static type of the source variables. An upcast does not have to be performed explicitly. See [downcast](abendown_cast_glosry.md).
