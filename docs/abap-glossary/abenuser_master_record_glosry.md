# user master record

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

A user master record must exist that a user can [log on](abenlogon_glosry.md) to an [AS ABAP](abenas_abap_glosry.md). The record determines which actions an [ABAP user](abenabap_user_glosry.md) with a certain [user name](abenuser_name_glosry.md) is allowed to execute and which [authorizations](abenauthorization_glosry.md) are granted. Default settings, such as [format settings](abenformat_setting_glosry.md) for [character strings](abencharacter_string_glosry.md) are also recorded in the user master record.
