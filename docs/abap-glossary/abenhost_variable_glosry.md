# host variable

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

ABAP [data object](abendata_object_glosry.md) specified in an operand position of an [ABAP SQL](../abap-programming-language/abap-database-access/abenabap_sql_host_variables.md) statement. The ABAP data object can be a [variable](abenvariable_glosry.md) or a [constant](abenconstant_glosry.md) (see [host constant](abenhost_constant_glosry.md)). In ABAP SQL, a host variable must be prefixed with the [escape character](abenescape_character_glosry.md) `@`.
