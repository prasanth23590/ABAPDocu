# hash key

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Unique [table key](abentable_key_glosry.md) of an [internal table](abeninternal_table_glosry.md), in which the assignment to the table lines is managed using a [hash algorithm](abenhash_algorithm_glosry.md). A hash key is the [primary table key](abenprimary_table_key_glosry.md) of a [hashed table](abenhashed_table_glosry.md) and can be assigned to every type of internal table as a [secondary table key](abenprimary_table_key_glosry.md). During access to an internal table using a hash key, the response time is constant, regardless of the number of table entries.
