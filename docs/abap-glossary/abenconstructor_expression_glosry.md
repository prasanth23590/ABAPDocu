# constructor expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A constructor expression uses a [constructor operator](abenconstructor_operator_glosry.md) to create a result for a specified [type](abentype_glosry.md) and constructs its content.
