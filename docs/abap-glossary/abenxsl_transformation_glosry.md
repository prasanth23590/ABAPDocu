# XSL transformation

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Program written in [XSLT](abenxslt_glosry.md) to transform [XML](abenxml_glosry.md) data. XSL transformations of the [repository](abenrepository_glosry.md) using the statement [`CALL TRANSFORMATION`](../abap-programming-language/abap-data-interchange-formats/abapcall_transformation.md). Implicit [serializations](abenserialization_glosry.md) and [deserializations](abendeserialization_glosry.md) allow the direct transformation of ABAP data into XML formats and vice versa.
