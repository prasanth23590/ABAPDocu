# SAP HANA

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

SAP HANA is a platform for SAP In-Memory Computing based on the [SAP HANA database](abenhana_database_glosry.md). If an SAP HANA database is used as the [standard database](abenstandard_db_glosry.md) of an [AS ABAP](abenas_abap_glosry.md), ABAP programs can use [ABAP SQL](abenabap_sql_glosry.md) to access SAP HANA directly.
