# BDEF extension

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [repository object](abenrepository_object_glosry.md) that extends a [RAP behavior definition](abencds_behavior_definition_glosry.md).

There are the following types of BDEF extensions:

- [base BDEF extensions](abenrap_base_bdef_ext_glosry.md)

- [BDEF projection extensions](abenrap_projec_bdef_ext_glosry.md)

- [abstract BDEF extensions](abenrap_abs_bdef_ext_glosry.md)

It is possible to extend a BDEF extension with further BDEF extensions. This is referred to as [extension layering](abenrap_ext_layering_glosry.md).
