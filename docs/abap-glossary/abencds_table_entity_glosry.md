# CDS table entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS persistent entity](abencds_sql_entity_glosry.md) that defines a [database table](abendatabase_table_glosry.md) in ABAP CDS. A table entity is defined as a [CDS data definition](abencds_data_definition_glosry.md) using the statement [`DEFINE TABLE ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_table_entities.md).
