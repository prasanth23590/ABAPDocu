# SAP S/4HANA Cloud Private Edition

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Cloud version of [SAP S/4HANA](abensap_s4hana_glosry.md) based on the [ABAP Platform](abenabap_platform_glosry.md) of SAP S/4HANA. Partner and customer developments can either use the [ABAP Cloud](abenabap_cloud_glosry.md) or the [classic ABAP](abenclassic_abap_glosry.md) paradigm. For ABAP Cloud the [SAP S/4HANA Cloud ABAP environment](abens4_hana_cloud_abap_env_glosry.md) (aka [embedded Steampunk](abenembedded_steampunk_glosry.md)) can be used. See also [SAP S/4HANA Cloud Public Edition](abensap_s4hana_cpub_glosry.md).
