# analytical selection

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Also called restricted measure. An analytical selection is an element of a [CDS analytical projection view](abencds_analytical_pv_glosry.md) that is newly added in the projection layer. A selection is defined by means of a [selection-related case expression](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_case_expression_apv.md).
