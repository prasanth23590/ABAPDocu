# root node set

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

The set of [hierarchy nodes](abenhierarchy_node_glosry.md) of a [ABAP SQL hierarchy](abensql_hierarchy_glosry.md) that are determined by their start condition. The elements of the root node set are [root nodes](abenroot_node_glosry.md).
