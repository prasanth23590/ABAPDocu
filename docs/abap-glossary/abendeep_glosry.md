# deep

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Property of a [data type](abendata_type_glosry.md) in which the content of its [data object](abendata_object_glosry.md) is either a [reference](abenreference_glosry.md) that points to the actual content ([reference variables](abenreference_variable_glosry.md)), or is addressed internally using references ([internal tables](abeninternal_table_glosry.md), [strings](abenstring_glosry.md), and [boxed components](abenboxed_component_glosry.md)). See also [flat](abenflat_glosry.md).
