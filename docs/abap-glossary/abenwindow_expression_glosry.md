# window expression

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

In [ABAP SQL](abenabap_sql_glosry.md), a window expression uses [`OVER`](../abap-programming-language/abap-database-access/abapselect_over.md) to define a subset of the result set of a [query](abenwindow_function_glosry.md) and applies a [window function](abenwindow_function_glosry.md) to it.
