# RAP reuse service

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A RAP reuse service is a [reuse service](abenreuse_service_glosry.md) that is natively integrated in [RAP](abenrap_glosry.md). For example, [RAP change documents](abenrap_change_documents_glosry.md) are a RAP reuse service.
