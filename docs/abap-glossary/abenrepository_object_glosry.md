# repository object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Repository objects are development objects in the [ABAP repository](abenabap_repository_glosry.md) such as [ABAP programs](abenabap_program_glosry.md), [classes](abenclass_glosry.md), [CDS entities](abencds_entity_glosry.md), [dictionary objects](abendictionary_object_glosry.md), or [CDS objects](abencds_object_glosry.md). They are maintained [ABAP development tools for Eclipse (ADT)](abenadt_glosry.md). The names of repository objects are stored in upper case. Each repository object is assigned to a [package](abenpackage_glosry.md).
