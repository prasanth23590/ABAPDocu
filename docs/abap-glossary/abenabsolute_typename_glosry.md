# absolute type name

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Type name](abentype_name_glosry.md), constructed as a path in a [character string](abencharacter_string_glosry.md), that uniquely specifies the [context](abenobj_context_glosry.md) of a [data type](abendata_type_glosry.md), a [class](abenclass_glosry.md), or an [interface](abenoo_intf_glosry.md), and which can be used in dynamic type specifications. See also [relative type name](abenrelative_type_name_glosry.md).
