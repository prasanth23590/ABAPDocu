# CDS-Based Enterprise Search

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

The ABAP-CDS-specific version of the [SAP Enterprise Search](abensap_enterprisesearch_glosry.md) technology. It is based on [CDS view entities](abencds_v2_view_glosry.md) in the backend. These view entities are annotated with [framework-specific annotations](abenfrmwrk_annotation_glosry.md) from the [`EnterpriseSearch`](../abap-core-data-services-abap-cds/abap-cds-annotations/abencds_enterprisesearch_f.md) domain. The annotations define search capabilities and they also trigger the generation of a [CDS-based search connector](abencds_search_connector_glosry.md). CDS-based enterprise search provides enhanced search capabilities in SAP Fiori launchpad.
