# locale

[General](abenabap_glossary.md)

## Definition

Part of the [text environment](abentext_environment_glosry.md). Defines the language-specific and country-specific characteristics of characters, such as the sort sequence or the uppercase/lowercase conversion. Local properties are defined in a library independent of the operating system.
