# DDIC database table

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Database table defined in the [ABAP Dictionary](abenabap_dictionary_glosry.md) as an [ABAP-managed database object](abenabap_dictionary_glosry.md). Each database table has a unique [primary index](abenprimary_index_glosry.md) and can have additional [secondary indexes](abensecondary_index_glosry.md). [Foreign key dependencies](abenforeign_key_dependency_glosry.md) can exist between individual DDIC database tables. A DDIC database table is generally defined as a [transparent table](abentransparent_table_glosry.md) in the [database](abendatabase_glosry.md) of the AS ABAP. All DDIC database tables defined in ABAP Dictionary can be referenced as a [data type](abendata_type_glosry.md) like [DDIC structures](abenddic_structure_glosry.md) and can be accessed using [ABAP SQL](abenabap_sql_glosry.md).
