# canonical JSON representation

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Format of [JSON](abenjson_glosry.md) data that is created during the [serialization](abenserialization_glosry.md) of ABAP data by the [identity transformation](abenid_trafo_glosry.md) and that is a prerequisite for a [deserialization](abendeserialization_glosry.md) using identity transformations. The short name is [asJSON](abenasjson_glosry.md).
