# ABAP SQL indicator

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

[Substructure](abensubstructure_glosry.md) or component with a [byte field type](abenbyte_field_type_glosry.md) that can be used either in read statements as a [null indicator](abennull_indicator_glosry.md) or in write statements as a [set indicator](abenset_indicator_glosry.md). In read statements, the indicators can store information while in write statements, indicators can be used to mark columns for change. ABAP SQL indicators can be created as [indicator structures](abenindicator_structure_glosry.md).
