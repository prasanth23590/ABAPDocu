# subquery

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

[ABAP SQL query](abenasql_query_glosry.md) that is used in an [ABAP SQL](abenabap_sql_glosry.md) statement for subqueries. Subqueries are possible in [SQL conditions](abensql_cond_glosry.md), for the definition of a [common table expression](abencommon_table_expression_glosry.md) after [`WITH`](../abap-programming-language/abap-database-access/abapwith.md), or as a [data source](../abap-programming-language/abap-database-access/abapinsert_from_select.md) of an [`INSERT`](../abap-programming-language/abap-database-access/abapinsert_dbtab.md) or [`MODIFY`](../abap-programming-language/abap-database-access/abapmodify_dbtab.md) statement.
