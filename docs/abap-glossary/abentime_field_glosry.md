# time field

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data object](abendata_object_glosry.md) of [time type](abentime_type_glosry.md) [`t`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_date_time.md) for storing a character-like [time](abenday_time_glosry.md). Valid values have the format *hhmmss*. The internal representation takes place in the [character representation](abenchar_representation_glosry.md) of the current [code page](abencodepage_glosry.md). For assignments, data objects with [numeric data types](abennumeric_data_type_glosry.md) and for calculations, the content of the time field is converted to the number of seconds since 00:00:00.
