# base BDEF

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Synonym for projected BDEF. [RAP behavior definition](abencds_behavior_definition_glosry.md) that serves as a basis for projections. It can be of [BDEF implementation type](abencds_bdef_impl_type_glosry.md) [managed](abenmanaged_rap_bo_glosry.md) or [unmanaged](abenunmanaged_rap_bo_glosry.md).
