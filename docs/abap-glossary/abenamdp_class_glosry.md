# AMDP class

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [AMDP](../abap-programming-language/abap-database-access/abenamdp_glossary.md)

## Definition

[Global class](abenglobal_class_glosry.md) with one or more [tag interfaces](abentag_interface_glosry.md) `IF_AMDP_MARKER_ ...` for [ABAP Managed Database Procedures](abenabap_managed_db_proc_glosry.md). An AMDP class can contain [AMDP methods](abenamdp_method_glosry.md) for different [database systems](abendatabase_system_glosry.md).
