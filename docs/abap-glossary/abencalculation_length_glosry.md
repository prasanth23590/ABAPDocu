# calculation length

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Property of a [bit expression](abenbit_expression_glosry.md) depending on the [byte-like data types](abenbyte_like_data_object_glosry.md) involved. The calculation length is the length in which the operands of the expression are processed.
