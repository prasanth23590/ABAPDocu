# unnamed data object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data object](abendata_object_glosry.md) that cannot be addressed by a name. Unnamed data objects are [literals](abenabap_literal_glosry.md) and [anonymous data objects](abenanonymous_data_object_glosry.md).
