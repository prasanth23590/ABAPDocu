# checkpoint

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Superordinate term for [assertions](abenassertion_glosry.md), [breakpoints](abenbreakpoint_glosry.md), or [logpoints](abenlogpoint_glosry.md). The statements [`ASSERT`](../abap-programming-language/abap-program-maintenance/abapassert.md), `BREAK-POINT`, and `LOG-POINT` for defining checkpoints are not operative but equip the program for test purposes. Inactive checkpoints are ignored during program execution.
