# iXML Library for ABAP Cloud

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Global [classes](abenglobal_class_glosry.md) that are accessible via [interfaces](abenoo_intf_glosry.md) for handling [XML](abenxml_glosry.md) documents in [DOM](abendom_glosry.md) representation. The *integrated* iXML Library provides services such as an XML parser, an XML renderer, and reads and writes to the DOM. The interfaces of the iXML Library for ABAP Cloud start with the prefix `IF_IXML_CORE`.
