# global interface

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Interface](abenoo_intf_glosry.md) that is defined as a [global type](abenglobal_type_glosry.md). Global interfaces are declared in the [interface pools](abeninterface_pool_glosry.md) and are marked as such there using the addition `PUBLIC` of the statement [`INTERFACE`](../abap-programming-language/abap-declarations/abapinterface.md). An interface pool cannot contain anything except for a global interface.
