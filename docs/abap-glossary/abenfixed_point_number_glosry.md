# fixed point number

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Number with a fixed number of [decimal places](abendecimal_place_glosry.md). In ABAP, fixed point numbers are implemented using [packed numbers](abenpacked_number_glosry.md) where a sequence of digits contains a decimal separator at a position defined by a [packed number type](abenpacked_number_type_glosry.md).
