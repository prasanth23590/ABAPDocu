# UTC time stamp

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [General](abenabap_glossary.md)

## Definition

[Time stamp](abentime_stamp_glosry.md) referring to the [UTC](abenutc_glosry.md) reference time. The time stamps of the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) are UTC time stamps, but as [POSIX time stamps](abenposix_timestamp_glosry.md) they do not support [leap seconds](abenleap_second_glosry.md).
