# RAP BO instance

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A specific data set of a [BO composition tree](abencds_composition_tree_glosry.md). A BO instance at least consists of one [RAP BO root entity](abenrap_bo_root_entity_glosry.md) instance. Furthermore, it includes all [entity instances](abenrap_bo_entity_inst_glosry.md) with a compositional relationship to the root entity instance.
