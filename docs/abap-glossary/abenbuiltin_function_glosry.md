# built-in function

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A predefined function in ABAP, ABAP SQL, and ABAP CDS.

- In ABAP, built-in functions can be used as [expressions](abenexpression_glosry.md) in [certain operand positions](../abap-programming-language/abap-operands/abenoperands_expressions.md). [Numeric functions](abenmathematical_funktion_glosry.md), [string functions](abenstring_function_glosry.md), [table functions](abentable_function_glosry.md), and [byte chain functions](abenbyte_chain_function_glosry.md) that have a return value of the corresponding data type can be distinguished. [Description functions](abendescription_function_glosry.md) that provide information on data objects, are also available. The names of the built-in functions are a subset of the [reserved names](abenabap_word_glosry.md). For further details, see the topic [Built-In Functions](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_functions.md).

- For ABAP SQL, [built-in functions](../abap-programming-language/abap-database-access/abensql_builtin_func.md) are part of the [SQL expressions](abensql_expression_glosry.md).

- For built-in functions in ABAP CDS, see the topic [CDS built-in function](abencds_builtin_func_glosry.md).

[Actual parameters](abenactual_parameter_glosry.md) passed to the [formal parameters](abenformal_parameter_glosry.md) of built-in functions are called also called [arguments](abenargument_glosry.md) of the function.
