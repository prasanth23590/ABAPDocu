# ABAP development tools for Eclipse

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

ADT for short. Eclipse-based tools for editing [repository objects](abenrepository_object_glosry.md) of the [ABAP Repository](abenabap_repository_glosry.md) and their components.
