# foreign key

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

One or more columns of a [DDIC database table](abenddic_db_table_glosry.md) ([foreign key table](abenforeign_key_table_glosry.md)) that are [primary keys](abenprimary_key_glosry.md) of another database table ([check table](abencheck_table_glosry.md)).
