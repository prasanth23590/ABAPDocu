# CDS analytical measure field

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An analytical measure field is a field of an [analytical cube view](abencds_analytical_cube_glosry.md) or an [analytical dimension view](abencds_anal_dim_view_glosry.md) that contains measurable data. In other words, an analytical measure field can be any field that contains quantifiable data that can be calculated, for example, the total price of all sales order positions.
