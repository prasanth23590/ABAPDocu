# released API

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Repository object](abenrepository_object_glosry.md) or part of an repository object that is released for access in [ABAP Cloud](abenabap_cloud_glosry.md). A released API is based on two classifications:

- A [release contract](abenrelease_contract_glosry.md) that governs changes to released APIs.

- Visibility for a [restricted ABAP language version](abenrestricted_version_glosry.md).
