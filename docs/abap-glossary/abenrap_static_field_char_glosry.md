# RAP static field characteristic

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

[Field characteristic](abenrap_field_char_glosry.md) that defines usage restrictions for a [RAP BO field](abenrap_bo_field_glosry.md) independently of the state of a [RAP BO entity instance](abenrap_bo_entity_inst_glosry.md). For example, [read-only](abenread_only_rap_bo_field_glosry.md) and [mandatory](abenmandatory_rap_bo_field_glosry.md) are static field characteristics.
