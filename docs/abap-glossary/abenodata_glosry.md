# OData

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [General](abenabap_glossary.md)

## Definition

Short for Open Data Protocol. OData is a standardized protocol for defining and consuming [RESTful](abenrestful_glosry.md) APIs. [SAP Gateway](abensap_gateway_glosry.md) provides such APIs for [AS ABAP](abenas_abap_glosry.md).
