# RAP action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO non-standard operation](abenrap_nstandard_operation_glosry.md) that modifies the state of a [RAP BO entity instance](abenrap_bo_entity_inst_glosry.md).

There are different types or RAP actions:

- [RAP factory actions](abenrap_factory_action_glosry.md)

- [RAP non-factory actions](abenrap_non_fac_action_glosry.md)
