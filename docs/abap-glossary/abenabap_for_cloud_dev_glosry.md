# ABAP for Cloud Development

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Restricted ABAP language version](abenrestricted_version_glosry.md) with restricted language scope and restricted access to [released APIs](abenreleased_api_glosry.md). In ABAP for Cloud Development, [client isolation](abenclient_isolation_glosry.md) is enforced. ABAP for Cloud Development is the [ABAP language version](abenabap_version_glosry.md) for [ABAP Cloud](abenabap_cloud_glosry.md).
