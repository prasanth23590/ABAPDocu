# mesh type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) of a [mesh](abenmesh_glosry.md). Special [structured type](abenstructured_type_glosry.md) that contains only [table types](abentable_type_glosry.md) with structured [line types](abenrow_type_glosry.md) as [components](abenstructure_component_glosry.md) that can be linked using [mesh associations](abenmesh_association_glosry.md).
