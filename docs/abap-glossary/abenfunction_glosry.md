# function

[General](abenabap_glossary.md)

## Definition

A function calculates a [return value](abenreturn_value_glosry.md) from one or more [actual parameters](abenactual_parameter_glosry.md) or [arguments](abenargument_glosry.md). Functions can be specified as [expressions](abenexpression_glosry.md) or part of expressions in [operand positions](abenoperand_position_glosry.md).
