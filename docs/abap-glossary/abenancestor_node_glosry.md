# ancestor node

[General](abenabap_glossary.md)

## Definition

The ancestor nodes of a [child node](abenchild_node_glosry.md) in a [hierarchy](abenhierarchy_glosry.md) are its [parent nodes](abenparent_node_glosry.md), their parent nodes, and so on.
