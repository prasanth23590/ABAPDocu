# RAP runtime framework

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Part of the [RAP framework](abenrap_framework_glosry.md) that is provided by the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) for consuming [RAP business objects](abenrap_bo_glosry.md) from outside [AS ABAP](abenas_abap_glosry.md) or from [ABAP programs](abenabap_program_glosry.md). In order to handle open protocols such as [OData](abenodata_glosry.md) when a RAP BO is exposed as a [business service](abenbusiness_service_glosry.md), the RAP runtime framework involves components of [SAP Gateway](abensap_gateway_glosry.md). In order to control the runtime behavior of a RAP business object, the RAP runtime framework uses [SADL](abensadl_glosry.md) as an orchestration framework. [ABAP EML](abenabap_eml_glosry.md) statements that are used to access RAP BOs from inside an ABAP program, also trigger processes in the RAP runtime framework.
