# DDIC append view

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Object in [ABAP Dictionary](abenabap_dictionary_glosry.md) with which a [DDIC database view](abendatabase_view_glosry.md) can be enhanced without modification by adding additional fields of its base tables.
