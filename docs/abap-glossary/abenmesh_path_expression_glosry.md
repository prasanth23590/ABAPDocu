# mesh path expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A standalone specification of a [mesh path](abenmesh_path_glosry.md) in an [operand position](abenoperand_position_glosry.md) for which the same rules apply as for a [table expression](abentable_expression_glosry.md).
