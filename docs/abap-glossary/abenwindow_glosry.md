# window

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

In [ABAP SQL](abenabap_sql_glosry.md), a window is a subset of the result set of a [query](abenasql_query_glosry.md) defined by a [window expression](abenwindow_expression_glosry.md) to whose rows a [window function](abenwindow_function_glosry.md) is applied.
