# logical operator

[General](abenabap_glossary.md)

## Definition

[Operator](abenoperator_glosry.md) in a [logical expression](abenlogical_expression_glosry.md). Either a [Boolean operator](abenboolean_operator_glosry.md) for the association or negation of logical expressions or a [relational operator](abenrel_operator_glosry.md) for [relational expressions](abenrelational_expression_glosry.md).
