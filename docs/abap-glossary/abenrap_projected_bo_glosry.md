# RAP base BO

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP business object](abenrap_bo_glosry.md) that is used as a basis of a [RAP projection BO](abenrap_projection_bo_glosry.md). It can be of [BDEF implementation type](abencds_bdef_impl_type_glosry.md) [managed](abenmanaged_rap_bo_glosry.md) or [unmanaged](abenunmanaged_rap_bo_glosry.md).
