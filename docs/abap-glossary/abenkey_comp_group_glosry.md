# RAP BO instance key component group

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [component group](abencomponent_group_glosry.md) in [BDEF derived types](abenrap_derived_type_glosry.md) that contains primary key fields of a [RAP BO instance](abenrap_bo_instance_glosry.md): [`%key`](../abap-rap-business-objects/abap-for-rap-business-objects/abapderived_types_key.md), [`%tky`](../abap-rap-business-objects/abap-for-rap-business-objects/abapderived_types_tky.md), [`%pky`](../abap-rap-business-objects/abap-for-rap-business-objects/abapderived_types_pky.md).
