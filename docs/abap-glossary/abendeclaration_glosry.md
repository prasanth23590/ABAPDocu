# declaration

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Defines the properties of local program entities. [Data types](abendata_type_glosry.md), [data objects](abendata_object_glosry.md), [classes](abenclass_glosry.md), [interfaces](abenoo_intf_glosry.md), and [field symbols](abenfield_symbol_glosry.md) can be declared. Declarations are made either with [declaration statements](abendeclaration_statement_glosry.md) or as [inline declarations](abeninline_declaration_glosry.md) using [declaration expressions](abendeclaration_expression_glosry.md). The declared unit is visible statically as soon as it is declared and is valid throughout the entire [context](abenobj_context_glosry.md).
