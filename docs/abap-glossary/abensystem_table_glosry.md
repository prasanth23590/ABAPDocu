# system table

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Client-independent](abenclient_independent_glosry.md) [DDIC database table](abenddic_db_table_glosry.md) without a [client column](abenclient_column_glosry.md). A system table contains data that is not specific for a client and that is generally only processed by [system programs](abensystem_program_glosry.md).
