# static type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) of a [reference variable](abenreference_variable_glosry.md) ([reference type](abenreference_type_glosry.md)). It determines the [objects](abenobject_glosry.md) a reference variable can point to. For [object reference variables](abenobject_refer_variable_glosry.md), the static type is a [class](abenclass_glosry.md) or an [interface](abenoo_intf_glosry.md). For [data reference variables](abendata_reference_variable_glosry.md), the static type is a data type. The static type is always more general than or the same as the [dynamic type](abendynamic_type_glosry.md).
