# current client

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

The current client of a [user session](abenuser_session_glosry.md) is the [client](abenclient_glosry.md) whose [client ID](abenclient_identifier_glosry.md) was specified during [logon](abenlogon_glosry.md).
