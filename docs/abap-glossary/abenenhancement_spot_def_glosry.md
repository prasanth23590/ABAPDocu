# enhancement spot element definition

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Part of the definition of an explicit [enhancement option](abenenhancement_point_glosry.md). An enhancement spot element definition must be assigned to at least one [enhancement spot](abenenhancement_spot_glosry.md).
