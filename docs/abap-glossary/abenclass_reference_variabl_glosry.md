# class reference variable

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Object reference variable](abenobject_refer_variable_glosry.md) whose [static type](abenstatic_type_glosry.md) is a [class](abenclass_glosry.md). A class reference variable can be used to access all visible components of an object.
