# return code

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Numeric value that is placed in the [system field](abensystem_field_glosry.md) [`sy-subrc`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abensystem_fields.md) for many [ABAP statements](abenabap_statement_glosry.md) when the statement is executed. The value 0 usually indicates a successful completion.
