# AMDP procedure implementation

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [AMDP](../abap-programming-language/abap-database-access/abenamdp_glossary.md)

## Definition

[AMDP method](abenamdp_method_glosry.md) without [return value](abenreturn_value_glosry.md) that is indicated by [`BY DATABASE PROCEDURE`](../abap-programming-language/abap-database-access/abapmethod_by_db_proc.md) in the [implementation part](abenimplementation_part_glosry.md) of the class. In an AMDP procedure implementation, [AMDP procedures](abenamdp_procedure_glosry.md) are implemented in a database-specific language as [ABAP Managed Database Procedures](abenabap_managed_db_proc_glosry.md). AMDP procedure implementations are called in ABAP just like regular methods and passed to the database system and executed here. See also [AMDP function implementation](abenamdp_procedure_glosry.md).
