# SAP HANA database

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

The SAP HANA database is the in-memory database of [SAP HANA](abensap_hana_glosry.md). It is the only database that is supported as the [standard database](abenstandard_db_glosry.md) of an [AS ABAP](abenas_abap_glosry.md).
