# client dependency

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Property of a [SQL data source](abensql_data_source_glosry.md). A SQL data source can be [client-dependent](abenclient_dependent_glosry.md) or [client-independent](abenclient_independent_glosry.md). When accessing a client-dependent SQL data source in [ABAP SQL](abenabap_sql_glosry.md), an implicit [client handling](abenclient_handling_glosry.md) takes place.
