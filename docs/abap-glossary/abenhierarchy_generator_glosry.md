# hierarchy generator

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

A [hierarchy function](abenhierarchy_function_glosry.md) in [ABAP SQL](abenabap_sql_glosry.md) that creates a [ABAP SQL hierarchy](abensql_hierarchy_glosry.md) either as a [parent-child-based hierarchy](abenpc_based_hiera_glosry.md) or a [level-based hierarchy](abenlevel_based_hiera_glosry.md).
