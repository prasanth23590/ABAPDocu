# sibling node

[General](abenabap_glossary.md)

## Definition

Sibling nodes are all [child nodes](abenchild_node_glosry.md) of a [hierarchy](abenhierarchy_glosry.md) that have the same [parent node](abenparent_node_glosry.md).
