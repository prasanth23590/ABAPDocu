# operand

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [General](abenabap_glossary.md)

## Definition

A component of an [ABAP statement](abenabap_statement_glosry.md) or of a [CDS data definition](abencds_data_definition_glosry.md) at an [operand position](abenoperand_position_glosry.md). An operand can be an [elementary operand](abenelementary_operand_glosry.md) or an [expression](abenexp_glosry.md).

There are different types of operands:

- [ABAP operands](abenabap_operand_glosry.md)

- [CDS operands](abencds_operand_glosry.md)
