# ABAP language element

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP keyword](abenabap_keyword_glosry.md) or combination of an ABAP keyword with one or more following [ABAP words](abenabap_word_glosry.md) or [ABAP operands](abenabap_operand_glosry.md). An ABAP language element uniquely describes the semantics of an [ABAP statement](abenabap_statement_glosry.md). Examples of different ABAP language elements are `GET BIT`, `GET TIME`, `DELETE itab`, or `DELETE dbtab`. ABAP language elements can be enhanced using [ABAP language element additions](abenabap_language_elmnt_add_glosry.md).
