# reference type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A reference type describes [reference variables](abenreference_variable_glosry.md), that is, the [data objects](abendata_object_glosry.md) that contain [references](abenreference_glosry.md). See also [static type](abenstatic_type_glosry.md).
