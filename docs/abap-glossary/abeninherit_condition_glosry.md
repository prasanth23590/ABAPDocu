# inheritance condition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Part of an [access condition](abenaccess_condition_glosry.md) in a [CDS role](abencds_role_glosry.md) that inherits conditions from another [CDS role](abencds_role_glosry.md) or a different [CDS entity](abencds_entity_glosry.md).
