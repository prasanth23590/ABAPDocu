# RAP dynamic field characteristic

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [field characteristic](abenrap_field_char_glosry.md) that defines usage restrictions for a [RAP BO field](abenrap_bo_field_glosry.md) depending on the state of a [RAP BO entity instance](abenrap_bo_entity_inst_glosry.md). For example, a field can be dynamically defined as [read-only](abenread_only_rap_bo_field_glosry.md), [mandatory](abenmandatory_rap_bo_field_glosry.md), or without restrictions.
