# RAP early save phase

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The early phase of the [RAP save sequence](abenrap_save_seq_glosry.md) that covers the [RAP saver methods](abenabp_saver_method_glosry.md) [`finalize`](../abap-rap-business-objects/abap-for-rap-business-objects/abensaver_finalize.md), [`check_before_save`](../abap-rap-business-objects/abap-for-rap-business-objects/abensaver_check_before_save.md) and [`cleanup_finalize`](../abap-rap-business-objects/abap-for-rap-business-objects/abapsaver_class_cleanup_finalize.md) methods.
