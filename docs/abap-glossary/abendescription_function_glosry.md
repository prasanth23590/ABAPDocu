# description function

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Built-in function](abenbuiltin_function_glosry.md) that returns properties of [data objects](abendata_object_glosry.md). There are [description functions for character-like](../abap-programming-language/abap-processing-internal-data/abendescriptive_functions.md), [table-like](../abap-programming-language/abap-processing-internal-data/abenitab_functions.md), and [byte-like](../abap-programming-language/abap-processing-internal-data/abendescriptive_functions_binary.md) arguments.
