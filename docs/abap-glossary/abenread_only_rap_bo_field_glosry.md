# read-only RAP BO field

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [field](abenrap_bo_field_glosry.md) in a [RAP BO](abenrap_bo_glosry.md) that is defined as read-only in the [behavior definition](abencds_behavior_definition_glosry.md). Changes to this field are only allowed by the [RAP BO provider](abenrap_bo_provider_glosry.md) in local mode.
