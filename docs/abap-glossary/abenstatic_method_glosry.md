# static method

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Method](abenmethod_glosry.md) of a [class](abenclass_glosry.md) declared using [`CLASS-METHODS`](../abap-programming-language/abap-declarations/abapclass-methods.md) that can be used independently of a class [instance](abeninstance_glosry.md). Static methods can only access [static attributes](abenstatic_attribute_glosry.md) and [static events](abenstatic_event_glosry.md) of their own class.
