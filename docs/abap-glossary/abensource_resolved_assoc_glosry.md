# source-resolved association

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Also known as [foreign key association](abenforeign_key_assoc_glosry.md). An [association](abencds_association_glosry.md) relationship in which the [foreign key](abenforeign_key_glosry.md) is stored in the [association source](abenassociation_source_glosry.md) entity.
