# RAP business event for side effects

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP business event](abenrap_entity_event_glosry.md) that is defined with the syntax addition [`for side effects`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_event_side_effect.md). A RAP business event for side effects is defined to be used exclusively as a trigger for an [event-driven side effect](abenrap_event_sideef_glosry.md).
