# structural fragment view

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Fragment View for short. Splits [structures](abenstructure_glosry.md) into [alignment gaps](abenalignment_gap_glosry.md), [character-like](abencharlike_data_object_glosry.md) and [byte-like](abenbyte_like_data_object_glosry.md) areas, [numeric data objects](abennumeric_data_object_glosry.md), [strings](abenstring_glosry.md), [time stamp fields](abentimestamp_field_glosry.md), [reference variables](abenreference_variable_glosry.md), and [internal tables](abeninternal_table_glosry.md).
