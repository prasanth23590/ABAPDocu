# RAP runtime engine

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Processor that handles the consumption of [RAP queries](abenrap_query_glosry.md) and [RAP BOs](abenrap_bo_glosry.md). There is the [RAP query engine](abenrap_query_engine_glosry.md) for non-transactional consumption and the [RAP transactional engine](abenrap_transac_engine_glosry.md) for transactional consumption.
