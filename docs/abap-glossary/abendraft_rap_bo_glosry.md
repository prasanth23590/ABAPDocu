# draft-enabled RAP business object

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO](abenrap_bo_glosry.md) that supports [RAP draft handling](abenrap_draft_handling_glosry.md). A RAP BO is draft-enabled with the RAP BDL syntax addition [`with draft`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_with_draft.md) or [`with collaborative draft`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_with_coll_draft.md).
