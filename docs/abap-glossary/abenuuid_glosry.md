# UUID

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [General](abenabap_glossary.md)

## Definition

Short for Universal Unique Identifier. Universally unique identifier that is generated in accordance with [OSF standards](http://www.opengroup.org/onlinepubs/9629399/apdxa.htm) from the system time stamp and the network address. In ABAP, a UUID can be created using the [system class](abensystem_class_glosry.md) `CL_SYSTEM_UUID` and the [SQL function](abensql_function_glosry.md) [`UUID`](../abap-programming-language/abap-database-access/abensql_uuid.md).
