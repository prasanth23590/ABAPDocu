# deserialization

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Transformation of [XML](abenxml_glosry.md) data or [JSON](abenjson_glosry.md) data to ABAP data objects. Performed either by calling an [XSLT program](abenxsl_transformation_glosry.md) or a [Simple Transformation](abensimple_transformation_glosry.md). If use [XSLT](abenxslt_glosry.md) is used, the result of the transformation (in XML) must be a [canonical XML representation](abencanonical_xml_represent_glosry.md) (([asXML](abenasxml_glosry.md)).
