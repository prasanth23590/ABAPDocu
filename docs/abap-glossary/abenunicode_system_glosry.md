# Unicode system

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Single code page system](abensingle_codepage_system_glosry.md) in which characters are encoded in a [Unicode character representation](abenunicode_char_represent_glosry.md). The [system code page](abensystem_codepage_glosry.md) of a Unicode system is [UTF-16](abenutf16_glosry.md) with platform-dependent [byte order](abenbyte_order_glosry.md) of which the ABAP programming language supports the subset covered by [UCS-2](abenucs2_glosry.md).
