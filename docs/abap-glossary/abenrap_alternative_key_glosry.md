# BDEF alternative key

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A user-defined BDEF key. User-defined BDEF keys exist in addition to the [primary key](abenprimary_key_glosry.md) of the underlying CDS data model and to the predefined [secondary table keys](abensecondary_table_key_glosry.md) for [BDEF derived types](abenrap_derived_type_glosry.md). There are two types of BDEF alternative keys:

- [BDEF pure key](abenrap_pure_key_glosry.md)

- [BDEF secondary key](abenrap_secondary_key_glosry.md)

BDEF alternative keys are used, for example, to define the signature of a [RAP key function](abenrap_key_function_glosry.md).
