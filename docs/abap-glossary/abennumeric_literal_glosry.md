# numeric literal

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [General](abenabap_glossary.md)

## Definition

A [literal](abenabap_literal_glosry.md) that has a [numeric data type](abennumeric_data_type_glosry.md) and whose characters represent a numeric value.

- In general ABAP, numeric literals are [untyped literals](abenuntyped_literal_glosry.md).

- In [ABAP SQL](abenabap_sql_glosry.md) and [ABAP CDS](abenabap_cds_glosry.md), numeric literals can be [typed literals](abentyped_literal_glosry.md) or [untyped literals](abenuntyped_literal_glosry.md).
