# RESTful

[General](abenabap_glossary.md) [RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Programming models and their services, APIs, and protocols are called RESTful if they meet the [REST](abenrest_glosry.md) principles. See also [ABAP RESTful Application Programming Model](abenarap_glosry.md).
