# authorization object

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

A [repository object](abenrepository_object_glosry.md) that is the basis of [authorizations](abenauthorization_glosry.md). An authorization object consists of up to ten [authorization fields](abenauthorization_field_glosry.md). The combination of authorization fields that represent data and activities is used for [authorization assignments](abenauthorization_assign_glosry.md). Authorization objects are grouped in authorization object classes.
