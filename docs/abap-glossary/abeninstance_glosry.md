# instance

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Concrete occurrence of an abstract [type](abentype_glosry.md). The instance of a [data type](abendata_type_glosry.md) is a [data object](abendata_object_glosry.md). The instance of a [class](abenclass_glosry.md) is often simply described as an object. See also [instantiation](abeninstantiation_glosry.md).
