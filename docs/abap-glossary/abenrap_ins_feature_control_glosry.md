# RAP instance feature control

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A kind of [feature control](abenrap_feature_control_glosry.md) that defines access restrictions for a [field](abenrap_bo_field_glosry.md) or an [operation](abenrap_bo_operation_glosry.md). It can be static or dynamic.
