# static constructor

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Constructor](abenconstructor_glosry.md) that is declared as a [static method](abenstatic_method_glosry.md) under the name [`class_constructor`](../abap-programming-language/abap-abap-objects/abenconstructor.md) in the [public](abenpublic_glosry.md) [visibility section](abenvisibility_section_glosry.md) of a [class](abenclass_glosry.md). It is called automatically prior to the first use of the class in an [internal session](abeninternal_session_glosry.md).
