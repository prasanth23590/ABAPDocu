# byte-like data type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) that allows access to the unencoded bytes of [byte chains](abenbyte_chain_glosry.md). These data types are [byte field types](abenbyte_field_type_glosry.md) and [byte string types](abenbyte_string_type_glosry.md). The associated [generic data type](abengeneric_data_type_glosry.md) is [`xsequence`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
