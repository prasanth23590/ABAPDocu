# flat

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Property of a [data type](abendata_type_glosry.md), where the content of its [data objects](abendata_object_glosry.md) represents the actual work data. All [elementary data types](abenelementary_data_type_glosry.md) except [`string`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_character.md) and [`xstring`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_byte.md) are flat. See also [deep](abendeep_glosry.md).
