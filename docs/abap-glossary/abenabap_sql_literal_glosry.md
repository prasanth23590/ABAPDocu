# ABAP SQL literal

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

An [ABAP literal](abenabap_literal_glosry.md) used in [ABAP SQL](abenabap_sql_glosry.md). In contrast to general ABAP, in ABAP SQL, both [typed literals](abentyped_literal_glosry.md) and [untyped literal](abenuntyped_literal_glosry.md) are available.
