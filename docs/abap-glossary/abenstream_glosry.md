# stream

[General](abenabap_glossary.md)

## Definition

Sequential succession of data records, the end of which cannot be predicted. A stream is either a [reader stream](abenreader_stream_glosry.md) or a [writer stream](abenwriter_stream_glosry.md) and therefore always has exactly one [stream direction](abenstream_direction_glosry.md). Furthermore, a distinction is made between the [binary stream](abenbinary_stream_glosry.md) and [character stream](abencharacter_stream_glosry.md). Multiple streams with matching properties can be combined into one stream. In ABAP, streams are implemented using [instances](abeninstance_glosry.md) of special [classes](abenclass_glosry.md). The transfer of streams is called [streaming](abenstreaming_glosry.md).
