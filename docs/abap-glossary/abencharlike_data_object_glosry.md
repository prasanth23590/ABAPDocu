# character-like data object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data object](abendata_object_glosry.md) that can be interpreted as character-like if its content is appropriate. Besides data objects with [character-like data types](abencharlike_data_type_glosry.md) or [date types](abendate_type_glosry.md) and [time types](abendate_type_glosry.md), [structures](abenstructure_glosry.md) with purely [flat](abenflat_glosry.md) character-like [structure components](abenstructure_component_glosry.md) can also be character-like in many [operand positions](abenoperand_position_glosry.md).
