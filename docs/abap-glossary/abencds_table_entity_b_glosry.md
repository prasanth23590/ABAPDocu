# CDS table entity buffer

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS entity buffer](abencds_entity_buffer_glosry.md) that defines the kind of [table buffering](abentable_buffering_glosry.md) for a [CDS table entity](abencds_table_entity_glosry.md). Defined using the statement [`DEFINE TABLE ENTITY BUFFER`](../abap-core-data-services-abap-cds/abap-cds-tuning-objects/abencds_define_view_entity_buffer.md).
