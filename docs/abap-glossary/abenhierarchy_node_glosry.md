# hierarchy node

[General](abenabap_glossary.md)

## Definition

Hierarchy nodes are the objects of a [hierarchy](abenhierarchy_glosry.md) linked using [hierarchy edges](abenhierarchy_edge_glosry.md). Hierarchy nodes can be [root nodes](abenroot_node_glosry.md), [parent nodes](abenparent_node_glosry.md), [child nodes](abenparent_node_glosry.md), [leaf nodes](abenleaf_node_glosry.md), [orphan nodes](abenorphan_node_glosry.md), [sibling nodes](abensibling_node_glosry.md), [descendant nodes](abendescendant_node_glosry.md), and [ancestor nodes](abenancestor_node_glosry.md).
