# predicative method call

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Call of a [functional method](abenfunctional_method_glosry.md) as the only [ABAP operand](abenabap_operand_glosry.md) of a [relational expression](abenrelational_expression_glosry.md). The result of the relational expression is true if the result of the [functional method call](abenfunctional_method_call_glosry.md) is not initial. See also [predicate method](abenpredicate_method_glosry.md).
