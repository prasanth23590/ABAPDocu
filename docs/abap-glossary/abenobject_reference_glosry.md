# object reference

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Reference](abenreference_glosry.md) that points to an [instance](abeninstance_glosry.md) of a [class](abenclass_glosry.md). An non-initial object reference is always a [heap reference](abenheap_reference_glosry.md). See also [weak reference](abenweak_reference_glosry.md).
