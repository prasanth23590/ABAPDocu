# fuzzy search index

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Index](abenindex_glosry.md) of the [SAP HANA database](abenhana_database_glosry.md) that database that provides fast error-tolerant text search, where a query returns records even when the search term contains additional or missing characters or other types of spelling errors. The [ABAP Dictionary](abenabap_dictionary_glosry.md) allows fuzzy search indexes to be created for [DDIC database tables](abenddic_db_table_glosry.md).
