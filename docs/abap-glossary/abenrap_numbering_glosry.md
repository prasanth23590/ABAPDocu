# RAP numbering

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A concept that deals with setting values for primary key fields of [RAP BO entity instances](abenrap_bo_entity_inst_glosry.md).

The following numbering concepts are available:

- [early numbering](abenrap_early_numbering_glosry.md)

- [external numbering](abenrap_ext_numbering_glosry.md)

- [internal numbering](abenrap_int_numbering_glosry.md)

- [late numbering](abenrap_late_numbering_glosry.md)
