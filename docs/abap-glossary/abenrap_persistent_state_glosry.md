# RAP persistent state

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The state of a [business object](abenrap_bo_glosry.md) or its [instances](abenrap_bo_instance_glosry.md) as it is on the [persistent database table](abenrap_persistent_table_glosry.md).
