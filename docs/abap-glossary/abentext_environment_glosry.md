# text environment

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

The text environment is part of the [language settings](abenlanguage_setting_glosry.md) of an [ABAP program](abenabap_program_glosry.md) and consists of a [text environment language](abentext_env_langu_glosry.md), the [system code page](abensystem_codepage_glosry.md), and a [locale](abenlocale_glosry.md). All programs of an [internal session](abeninternal_session_glosry.md) have a common text environment.
