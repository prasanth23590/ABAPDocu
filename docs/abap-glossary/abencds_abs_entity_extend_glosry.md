# CDS abstract entity extension

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS entity extension](abencds_entity_extend_glosry.md) of a [CDS abstract entity](abencds_abstract_entity_glosry.md). A CDS abstract entity extension can be used to add elements to an abstract entity without making any modifications to the original entity. It is defined using the statement [`EXTEND ABSTRACT ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_extend_abstract_entity.md).
