# dictionary DDL

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Data definition language ([DDL](abenddl_glosry.md)) of the [ABAP Dictionary](abenabap_dictionary_glosry.md) for the definition of [ABAP-managed database objects](abenabap_managed_db_object_glosry.md) in the [ABAP development tools for Eclipse (ADT)](abenadt_glosry.md). Dictionary DDL contains language elements for [structures](abenstructure_glosry.md), [append structures](abenappend_structure_glosry.md), [DDIC database tables](abenddic_db_table_glosry.md) and [HANA tuning objects](abenhana_tuning_object_glosry.md). Dictionary DDL is based on the syntax of [CDS DDL](abencds_ddl_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md).
