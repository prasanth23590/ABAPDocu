# instance constructor

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Constructor](abenconstructor_glosry.md) declared under the name [`constructor`](../abap-programming-language/abap-abap-objects/abenconstructor.md) as an [instance method](abeninstance_method_glosry.md) of a [class](abenclass_glosry.md), and which is automatically called when the class is [instantiated](abeninstantiation_glosry.md) and after the [object](abenobject_glosry.md) is created.
