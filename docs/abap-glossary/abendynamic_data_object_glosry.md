# dynamic data object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data object](abendata_object_glosry.md) for which all properties apart from the memory consumption are statically determined by the [data type](abendata_type_glosry.md). Dynamic data objects are [strings](abenstring_glosry.md) and [internal tables](abeninternal_table_glosry.md). They belong to the [deep data objects](abendeep_glosry.md). Structures that contain dynamic components are also dynamic data objects. All other data objects, except for [boxed components](abenboxed_component_glosry.md), are [static data objects](abenstatic_data_object_glosry.md). When dynamic data objects are accessed, [value semantics](abenvalue_semantics_glosry.md) apply.
