# logpoint

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

In an [ABAP program](abenabap_program_glosry.md), a logpoint is defined statically as an unconditional [checkpoint](abencheckpoint_glosry.md) using the statement `LOG-POINT`, or dynamically in the [ABAP development tools for Eclipse (ADT)](abenadt_glosry.md). When an active logpoint is reached, a log entry is created. A static logpoint must be assigned to a [checkpoint group](abencheckpoint_group_glosry.md) when it is created. This group controls its [activation](abenactivatable_checkpoint_glosry.md).
