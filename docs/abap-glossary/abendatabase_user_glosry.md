# database user

[General](abenabap_glossary.md)

## Definition

Person or system logged on to a [database system](abendatabase_system_glosry.md) using a [database user name](abendatabase_user_name_glosry.md). When the database is accessed using the [database connections](abendatabase_connection_glosry.md) of an [AS ABAP](abenas_abap_glosry.md), the database user is a [work process](abenwork_process_glosry.md) that implicitly accesses the [database schema](abendatabase_schema_glosry.md) assigned to the user name of the connection.
