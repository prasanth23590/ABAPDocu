# BDEF extension header

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The part of a [BDEF extension](abenrap_extension_glosry.md) that includes the first one to three lines of [BDL source code](abenbdl_source_code_glosry.md). It starts with&#x00A0; [`extension`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_extensibility_managed_unm.md) and may additionally define an implementation class and enable BDEF privileged mode.
