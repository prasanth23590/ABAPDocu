# ABAP annotation

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[SAP annotation](abensap_annotation_glosry.md) that can be specified in [CDS source code](abencds_source_code_glosry.md) and that is evaluated by the ABAP Core Data Services framework, namely the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) itself. Any other [CDS annotations](abencds_annotation_glosry.md) are [framework-specific annotations](abenfrmwrk_annotation_glosry.md) and must be evaluated by their own frameworks.
