# work area

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Description for a [data object](abendata_object_glosry.md) that is particularly useful when working with [internal tables](abeninternal_table_glosry.md) or [DDIC database tables](abenddic_db_table_glosry.md) as a source for changing operations or as a target for reading operations.
