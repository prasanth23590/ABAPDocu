# private

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Term in [ABAP Objects](abenabap_objects_glosry.md). A private [component](abenclass_component_glosry.md) of a [class](abenclass_glosry.md) can be accessed only by the class itself and its [friends](abenfriend_glosry.md), which also only can create [objects](abenobject_glosry.md) of a class with private instances. The private [visibility section](abenvisibility_section_glosry.md) of a class is declared in its [declaration part](abendeclaration_part_glosry.md) using the statement [`PRIVATE SECTION`](../abap-programming-language/abap-declarations/abapprivate.md).
