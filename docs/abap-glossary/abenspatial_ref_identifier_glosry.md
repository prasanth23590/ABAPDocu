# spatial reference identifier

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md) [General](abenabap_glossary.md)

## Definition

SRID for short. An identifier that specifies a [spatial reference system](abenspatial_ref_system_glosry.md). The default value for the identifier of the spatial reference system is 0 and indicates a Cartesian coordinate system, i.e. 2D geometries.
