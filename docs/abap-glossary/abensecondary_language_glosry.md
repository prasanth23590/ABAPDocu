# secondary language

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

The secondary language is used for [messages](abenmessage_glosry.md), [text pools](abentext_pool_glosry.md), and translatable [CDS annotations](abencds_annotation_glosry.md) if the desired language is not found.
