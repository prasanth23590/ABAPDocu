# writer stream

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[data stream](abendata_stream_glosry.md) that is connected to a [streaming data sink](abenstreaming_data_sink_glosry.md) The direction of a writer stream always goes toward the data sink. In a writer stream data can only be written.
