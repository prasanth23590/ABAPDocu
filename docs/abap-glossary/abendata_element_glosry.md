# DDIC data element

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Repository object](abenrepository_object_glosry.md) in the [ABAP Dictionary](abenabap_dictionary_glosry.md) that defines an [elementary data type](abenelementary_data_type_glosry.md) or a [reference type](abenreference_type_glosry.md). In addition to [technical type properties](abentechnical_type_prpt_glosry.md), it specifies the semantic meaning of a ([database](abendatabase_field_glosry.md)) [field](abenfield_glosry.md) (e.g., the header for tabular representations or documentation text). Properties such as [data type](abendata_type_glosry.md), length, and so on, are defined directly in the data element or are copied from a [DDIC domain](abendomain_glosry.md).
