# enumerated variable

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Variable](abenvariable_glosry.md) with an [enumerated type](abenenum_type_glosry.md). An enumerated variable is a variable [enumerated object](abenenumerated_object_glosry.md) and can only contain the corresponding [enumerated values](abenenumerated_value_glosry.md).
