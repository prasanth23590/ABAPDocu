# casting

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Handling of a [data object](abendata_object_glosry.md) by assuming a specific [data type](abendata_type_glosry.md). Explicit casting is possible in the statement [`ASSIGN`](../abap-programming-language/abap-processing-internal-data/abapassign.md) with the addition [`ASSIGNING`](../abap-programming-language/abap-processing-internal-data/abapread_table_outdesc.md) when processing internal tables, for some assignments of [actual parameters](abenactual_parameter_glosry.md) to [formal parameters](abenformal_parameter_glosry.md), and as a [downcast](abendown_cast_glosry.md) or [upcast](abenup_cast_glosry.md) in the [assignments](abenassignment_glosry.md) between [reference variables](abenreference_variable_glosry.md). An implicit casting sometimes takes place when handling [operands](abenoperand_glosry.md) in certain [operand positions](abenoperand_position_glosry.md).
