# character-like expression position

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Character-like](abencharlike_position_glosry.md) [read position](abenread_position_glosry.md) in which, in addition to a [character-like data object](abencharlike_data_object_glosry.md), a [character-like expression](abencharlike_expression_glosry.md) can also be specified.
