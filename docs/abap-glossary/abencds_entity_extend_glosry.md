# CDS entity extension

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A transportable extension of a [CDS entity](abencds_entity_glosry.md). A CDS entity extension can be used to add elements and/or clauses to a CDS entity without making any modifications to the original entity.

There are currently four different statements that can be used to extend a CDS entity in [CDS DDL](abencds_ddl_glosry.md):

- [`EXTEND VIEW ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_extend_view_entity.md): [CDS view entity extension](abencds_view_entity_extend_glosry.md) for a [CDS view entity](abencds_v2_view_glosry.md) or a [CDS projection view](abencds_projection_view_glosry.md).

- [`EXTEND CUSTOM ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_extend_custom_entity.md) [CDS custom entity extension](abencds_cus_entity_extend_glosry.md) for a [CDS custom entity](abencds_custom_entity_glosry.md).

- [`EXTEND ABSTRACT ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_extend_abstract_entity.md) [CDS abstract entity extension](abencds_abs_entity_extend_glosry.md) for a [CDS abstract entity](abencds_abstract_entity_glosry.md).

- [`EXTEND VIEW`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_extend_view.md) [CDS DDIC-based view extension](abencds_view_extend_glosry.md) for a [CDS DDIC-based view (obsolete)](abencds_v1_view_glosry.md).
