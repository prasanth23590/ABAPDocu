# streaming

[General](abenabap_glossary.md)

## Definition

The sequential and segmental transfer of data or the transfer of [streams](abenstream_glosry.md). Streaming is intended for all possible resources and is currently implemented for [LOBs](abenlob_glosry.md) in ABAP SQL, [strings](abenstring_glosry.md), and [internal tables](abeninternal_table_glosry.md).
