# subroutine

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Obsolete [procedure](abenprocedure_glosry.md) that can be defined in any [ABAP program](abenabap_program_glosry.md) (except [class pools](abenclass_pool_glosry.md), and [interface pools](abeninterface_pool_glosry.md)), however, can only be implemented outside [classes](abenclass_glosry.md) between the statements [`FORM`](../abap-programming-language/abap-obsolete-language-elements/abapform.md) and [`ENDFORM`](../abap-programming-language/abap-obsolete-language-elements/abapform.md). The statement [`PERFORM`](../abap-programming-language/abap-calling-and-exiting-program-units/abapperform.md) can be used to call the subroutines of an [ABAP program](abenabap_program_glosry.md) and of any other programs.
