# BAdI context object

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Instance](abeninstance_glosry.md) of a [class](abenclass_glosry.md) that implements the [tag interface](abentag_interface_glosry.md) `IF_BADI_CONTEXT`. This tag interface can be implemented by any class. [References](abenreference_glosry.md) to BAdI context objects can be used in the statement [`GET BADI`](../abap-programming-language/abap-enhancements/abapget_badi.md) to specify a context for [object plug-ins](abenobject_plugin_glosry.md).
