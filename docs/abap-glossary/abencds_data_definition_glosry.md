# CDS data definition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A definition or extension of a [CDS entity](abencds_entity_glosry.md) using [language elements](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_f1_ddl_syntax.md) of the [CDS DDL](abencds_ddl_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md) in [DDL source code](abenddl_source_code_glosry.md). A CDS data definition might also contain [DQL](abendql_glosry.md) parts that define the data retrieval. For example, the DQL statement `SELECT` is embedded in [CDS DDL](abencds_ddl_glosry.md) for [CDS views](abencds_view_glosry.md).
