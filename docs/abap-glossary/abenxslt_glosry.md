# XSLT

[General](abenabap_glossary.md)

## Definition

Short for Extensible Stylesheet Language Transformation, see [www.w3.org/TR/xslt](http://www.w3.org/TR/xslt). XSLT allows the conversion of [XML](abenxml_glosry.md) formats into any other XML formats. The [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) contains the [SAP XSLT processor](abenxslt_processor_glosry.md) for the execution of [XSL transformations](abenxsl_transformation_glosry.md).
