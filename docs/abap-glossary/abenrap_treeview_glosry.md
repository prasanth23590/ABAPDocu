# treeview

[General](abenabap_glossary.md) [RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

In the context of the [ABAP RESTful Application Programming Model](abenarap_glosry.md), a treeview visualizes data modeled by a [CDS hierarchy](abencds_hierarchy_glosry.md) e.g. by using a SAP Fiori Elements treetable. A treeview can be read-only or editable.
