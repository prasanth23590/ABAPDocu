# classified API

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

An API (for example, methods of classes and interfaces, and function modules) with special classifications. These classifications are typically included as type definitions, start with `IF_ABAP_TX_...` and define specific [transactional contracts](abentransactional_contract_glosry.md). In the context of the [controlled SAP LUW](abencontrolled_sap_luw_glosry.md), the classifications are used to specify that the functionality encapsulated by the API is only used in [transactional phases](abentr_phase_glosry.md) where allowed.
