# uncatchable exception

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Exception](abenexception_glosry.md) that is not assigned to an [exception class](abenexception_class_glosry.md) and that cannot be handled in the program by [`TRY - CATCH - ENDTRY`](../abap-programming-language/abap-program-flow-logic/abaptry.md). Uncatchable exceptions are raised by the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) and are usually a response to error situations that cannot be handled properly in the program. An uncatchable exception always produces a [runtime error](abenruntime_error_glosry.md).
