# LOB handle component

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

[Reference type](abenreference_type_glosry.md) or [reference variable](abenreference_variable_glosry.md) in a [LOB handle structure](abenlob_handle_structure_glosry.md). The [static type](abenstatic_type_glosry.md) of such a component must be less specific or the same as the [class](abenclass_glosry.md) of a [LOB handle](abenlob_handle_glosry.md) and must contain the [interface](abenoo_intf_glosry.md) `IF_ABAP_DB_LOB_HANDLE`.
