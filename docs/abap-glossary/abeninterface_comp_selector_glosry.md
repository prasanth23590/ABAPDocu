# interface component selector

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Character `~`. An [interface component](abeninterface_component_glosry.md) `comp` of an [interface](abenoo_intf_glosry.md) `intf` can be addressed in an implementing [class](abenclass_glosry.md) or a [compound interface](abencompound_interface_glosry.md) via `intf~comp`.
