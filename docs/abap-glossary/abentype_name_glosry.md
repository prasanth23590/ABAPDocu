# type name

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Name of a [type](abentype_glosry.md). In a program, only the [relative type name](abenrelative_type_name_glosry.md) is known and statically usable. An [absolute type name](abenabsolute_typename_glosry.md) can be used to specify dynamic types.
