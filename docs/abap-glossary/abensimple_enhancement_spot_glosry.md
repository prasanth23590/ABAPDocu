# simple enhancement spot

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Reference to a set of [enhancement spot element definitions](abenenhancement_spot_def_glosry.md). A simple enhancement spot can occur independently or as a component of a [composite enhancement spot](abencomp_enhancement_spot_glosry.md).
