# standard table

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Table category](abentable_category_glosry.md) of an [internal table](abeninternal_table_glosry.md) that is managed using a [primary table index](abenprimary_table_index_glosry.md) and that has no unique [primary table key](abenprimary_table_key_glosry.md). When a standard table is accessed using its primary table key, it is searched linearly. [Secondary table keys](abensecondary_table_key_glosry.md) can be defined for more efficient key access to standard tables. The associated [generic data type](abengeneric_data_type_glosry.md) is [`[standard] table`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
