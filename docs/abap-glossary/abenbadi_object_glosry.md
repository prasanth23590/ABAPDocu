# BAdI object

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Instance of a [BAdI](abenbadi_glosry.md). BAdI objects are addressed exclusively using [BAdI reference variables](abenbadi_reference_variable_glosry.md) in which a [BAdI reference](abenbadi_reference_glosry.md) was set using [`GET BADI`](../abap-programming-language/abap-enhancements/abapget_badi.md). A BAdI object acts as a handle for the calls of [BAdI methods](abenbadi_method_glosry.md) and contains references to the [object plug-ins](abenobject_plugin_glosry.md) created based on filter specifications. From a technical point of view, BAdI objects are [instances](abeninstance_glosry.md) of [BAdI classes](abenbadi_class_glosry.md).
