# database connection

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Connection of an [AS ABAP](abenas_abap_glosry.md) to a [database system](abendatabase_system_glosry.md). A database connection defines the address of the database system, the [database user](abendatabase_user_glosry.md), and therefore the [database schema](abendatabase_schema_glosry.md) assigned to it. By default, the [database interface](abendatabase_interface_glosry.md) accesses the [standard AS ABAP database](abenstandard_db_glosry.md) using the [standard connection](abenstandard_db_connection_glosry.md) of the current [work process](abenwork_process_glosry.md). Optionally, database accesses can also be performed using [service connections](abenservice_connection_glosry.md) to the standard database. Up to 16 database connections can be opened for a single work process.
