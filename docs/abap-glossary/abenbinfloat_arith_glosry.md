# binary floating point arithmetic

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Calculation with [binary floating point numbers](abenbinfloat_glosry.md). Can produce rounding errors because floating point numbers are not represented internally using the decimal system.
