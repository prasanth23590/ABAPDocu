# ABAP-managed database object

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Database object](abendb_object_glosry.md) in the [standard database](abenstandard_db_glosry.md) of an [AS ABAP](abenas_abap_glosry.md) that is both managed and used by AS ABAP. Only ABAP should be used to access an ABAP-managed database object.
