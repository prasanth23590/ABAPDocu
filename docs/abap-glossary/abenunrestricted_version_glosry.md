# unrestricted ABAP language version

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP language version](abenabap_version_glosry.md) that is not restricted regarding the ABAP language scope and access to other repository objects. [Standard ABAP](abenstandard_abap_glosry.md) is unrestricted. See also [restricted ABAP language versions](abenrestricted_version_glosry.md).
