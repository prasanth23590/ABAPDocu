# decimal separator

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [General](abenabap_glossary.md)

## Definition

Separator between the integer part and fractional part of a [decimal number](abendecimal_number_glosry.md). Within an [ABAP program](abenabap_program_glosry.md), the [decimal point](abendecimal_point_glosry.md) is always used.
