# ABAP expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

An [expression](abenexp_glosry.md) in an [ABAP statement](abenabap_statement_glosry.md). Expressions can be, for example, calls of [built-in functions](abenbuiltin_function_glosry.md) or [functional method calls](abenfunctional_method_call_glosry.md), [declaration expressions](abendeclaration_position_glosry.md), [logical expressions](abenlogical_expression_glosry.md) constructed from [relational expressions](abenrelational_expression_glosry.md), [constructor expressions](abenconstructor_expression_glosry.md), [table expressions](abentable_expression_glosry.md), and [calculation expressions](abencalculation_expression_glosry.md). See also [SQL Expression](abensql_expression_glosry.md).
