# CDS virtual element

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An element in the element list of a [CDS DDL aspect](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_ddl_aspect_glosry.md) or a [projection view](abencds_projection_view_glosry.md). In projection views, this element is not included in the [projected entity](abencds_pv_projected_entity_glosry.md). Virtual elements are not persistent on the database, but calculated during runtime, usually in [ABAP classes](abenclass_glosry.md). In order to fill and analyze the virtual elements of a projection view, special frameworks like the [RAP query engine](abenrap_query_engine_glosry.md) have to be involved.
