# CDS service definition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A CDS service definition is a [CDS object](abencds_object_glosry.md) that exposes [CDS entities](abencds_object_glosry.md) for a [business service](abenbs_glosry.md). A CDS service definition is defined by the [CDS SDL](abencds_sdl_glosry.md) language elements of [ABAP CDS](abenabap_cds_glosry.md) in [`SDL` source code](abensdl_source_code_glosry.md).
