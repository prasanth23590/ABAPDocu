# secondary table index

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Table index](abentable_index_glosry.md) for the administration of [sorted](abensorted_key_glosry.md) [secondary table keys](abensecondary_table_key_glosry.md). A secondary table index of a non-unique key is not updated immediately for each line insertion or deletion in an [internal table](abeninternal_table_glosry.md); it is only updated when the internal table is accessed via the associated secondary key.
