# text pool

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Component of an [ABAP program](abenabap_program_glosry.md) that contains the [text elements](abentext_element_glosry.md) of the program. Multiple text pools can be defined in various languages for a program.
