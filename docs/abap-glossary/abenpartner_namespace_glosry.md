# partner namespace

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Predefined [namespace](abennamespace_glosry.md) for [repository objects](abenrepository_object_glosry.md) created in partner development systems. Names have `J` as the first character. These names can be used in partner systems, if no [prefix namespace](abenprefix_name_space_glosry.md) is available.
