# CDS system function

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS function](abencds_function_glosry.md) delivered as part of the [ABAP technology](abenabap_techno_glosry.md) that implements basic functionality. Currently, SAP delivers [analytical scalar functions](abencds_ana_scalar_glosry.md) and [SQL-based scalar functions](abencds_sql_scalar_glosry.md) as system functions. System functions are classified with the [C1 contract](abenc1_contract_glosry.md) for use internally in the system.
