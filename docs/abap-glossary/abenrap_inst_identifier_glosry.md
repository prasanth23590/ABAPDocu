# RAP instance identifier

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [structure](abenstructure_glosry.md) that uniquely identifies a [RAP BO instance](abenrap_bo_instance_glosry.md). It consists of the primary key fields and all relevant [derived type](abenrap_derived_type_glosry.md) components, for example `%is_draft`, `%pid`. The instance identifier is represented by the component groups `%tky` or `%pky`.

See also: [RAP input identifier](abenrap_input_identifier_glosry.md).
