# decimal number

[General](abenabap_glossary.md)

## Definition

Number in the decimal numbering system. It consists of [places](abenplace_glosry.md), which can contain the decimal numbers 0-9, and can also contain a [decimal separator](abendecimal_point_separat_glosry.md) and a leading plus/minus sign.
