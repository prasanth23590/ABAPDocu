# object type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Description of an [object](abenobject_glosry.md) in [ABAP Objects](abenabap_objects_glosry.md). Either a [class](abenclass_glosry.md) for the entire object or [interface](abenoo_intf_glosry.md) for a part of an object. The associated [generic data type](abengeneric_data_type_glosry.md) is [`object`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md). Object types are either defined as [program global type](abenprogram_global_type_glosry.md) in an [ABAP program](abenabap_program_glosry.md) or as a [global type](abenglobal_type_glosry.md) in the [class library](abenclass_library_glosry.md).
