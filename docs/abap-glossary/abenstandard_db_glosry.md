# standard database

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Central database of an [AS ABAP](abenas_abap_glosry.md). A [standard connection](abenstandard_db_connection_glosry.md) to the standard database always exists for each [work process](abenwork_process_glosry.md) of an AS ABAP. Only a [SAP HANA database](abenhana_database_glosry.md) is supported as a standard database.
