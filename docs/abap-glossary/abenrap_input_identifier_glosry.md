# RAP input identifier

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [structure](abenstructure_glosry.md) that is imported into implementation methods in the [ABAP behavior pool](abenbehavior_pool_glosry.md). It consists of all components that are relevant to identify one [instance](abenrap_bo_entity_inst_glosry.md) for the current method.

An input identifier can either be the [instance identifier](abenrap_inst_identifier_glosry.md) or the [content identifier](abenrap_cont_identifier_glosry.md), or both.
