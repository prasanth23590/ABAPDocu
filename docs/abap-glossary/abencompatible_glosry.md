# compatible

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Except for [reference variables](abenreference_variable_glosry.md), two non-[generic data types](abengeneric_data_type_glosry.md) are compatible if all their [technical properties](abentechnical_type_prpt_glosry.md) are the same. Any [data type](abendata_type_glosry.md) is compatible with a generic data type if the generic data type includes its technical properties. [Data objects](abendata_object_glosry.md) are compatible if their data types are compatible. Compatibility is the basis for checking the [typing](abentyping_glosry.md). In an [assignment](abenassignment_glosry.md) or [comparison](abencomparison_glosry.md) of compatible data objects, no conversion takes place.
