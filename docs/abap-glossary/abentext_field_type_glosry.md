# text field type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Character-like data type](abencharlike_data_type_glosry.md) for storing [character strings](abencharacter_string_glosry.md) of fixed length. The associated [built-in ABAP type](abenbuiltin_abap_type_glosry.md) is [`c`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_character.md). The [built-in DDIC types](abenbuiltin_ddic_type_glosry.md) are [`CHAR`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md) and [`LCHR`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md). The internal representation takes place in the [character representation](abenchar_representation_glosry.md) of the current [code page](abencodepage_glosry.md). A [data object](abendata_object_glosry.md) of a text field type is a [text field](abentext_field_glosry.md).
