# RAP behavior extension body

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A part of an [entity behavior extension](abenrap_behavior_extension_glosry.md) that is defined within curly brackets after the statement [`extend behavior for`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_extend_beh.md). The entity behavior extension body can define [new extension elements](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_new_elem_ext.md), such as extension determinations, extension validations, and extension actions. It may also [extend existing elements](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_ext_elem_ext.md), such as RAP type mapping, and determine actions.
