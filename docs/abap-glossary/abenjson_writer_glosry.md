# JSON writer

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

There are two kinds of JSON writers:

- [Instance](abeninstance_glosry.md) of a [class](abenclass_glosry.md) of the [JSON Library](abenjson_library_glosry.md) that implements the [interface](abenoo_intf_glosry.md) `IF_JSON_WRITER`.

- [XML writer](abenxml_writer_glosry.md) that writes [JSON](abenjson_glosry.md) data. A JSON writer expects input for [JSON-XML](abenjson_xml_glosry.md) and uses it to create the JSON data.
