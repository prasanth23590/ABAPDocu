# grouping function

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Aggregate function](abenaggregate_function_glosry.md) for [`GROUPING SETS`](../abap-programming-language/abap-database-access/abapgrouping_sets_clause.md) in a [query](abenasql_query_glosry.md). The result of the grouping function `GROUPING` indicates whether a specific column was part of the aggregation. The return value of the grouping function is 0 for the column that was not involved in the aggregation or 1 for the column that was involved in the aggregation.
