# text string literal

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [General](abenabap_glossary.md)

## Definition

A [character literal](abencharacter_literal_glosry.md) of the [text string](abentext_string_type_glosry.md) type [`string`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_character.md).

- In general ABAP, text string literals are [untyped literals](abenuntyped_literal_glosry.md) delimited by backquotes.

- In [ABAP SQL](abenabap_sql_glosry.md) and [ABAP CDS](abenabap_cds_glosry.md), text string literals can be [typed literals](abentyped_literal_glosry.md) or [untyped literals](abenuntyped_literal_glosry.md).
