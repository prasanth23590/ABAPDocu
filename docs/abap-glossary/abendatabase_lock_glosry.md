# database lock

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Physical [locks](abenlock_glosry.md) for rows in [database tables](abendatabase_table_glosry.md), imposed by the [database system](abendatabase_system_glosry.md). A database lock persists until the end of the current [database LUW](abendatabase_luw_glosry.md).
