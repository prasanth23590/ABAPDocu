# DDIC currency field

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Component of a [DDIC structure](abenddic_structure_glosry.md), or [DDIC database table](abenddic_db_table_glosry.md) of type `CURR` defined in the [ABAP Dictionary](abenabap_dictionary_glosry.md). It is used for entering an amount in a particular currency. The content of a currency field is interpreted as an integer in the smallest units of the currency. A currency field must be linked with a [currency key](abencurrency_key_glosry.md) of a structure, database table, or view that specifies the currency and number of decimal places.
