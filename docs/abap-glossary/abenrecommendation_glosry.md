# RAP recommendation

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Input assistance that proposes field values for [input fields](abeninput_field_glosry.md) in a RAP application on an SAP Fiori UI, based on the user input and interaction history.

RAP recommendations can be implemented using generative AI or using deterministic rules in the [behavior pool](abenbehavior_pool_glosry.md) of the [RAP business object](abenrap_bo_glosry.md). In SAP Fiori, a RAP recommendation is exposed as a recommendation pattern of type input assistance.
