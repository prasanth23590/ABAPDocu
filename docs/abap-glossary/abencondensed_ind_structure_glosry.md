# condensed indicator structure

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Special [indicator structure](abenindicator_structure_glosry.md) that is not a [substructure](abensubstructure_glosry.md) but the last component of a structure with a [byte field type](abenbyte_field_type_glosry.md). Here, the individual bits of the [byte field](abenbyte_field_glosry.md) serve as indicators for the preceding components.
