# chained method call

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A [chaining](abenchaining_glosry.md) in which multiple [functional methods](abenfunctional_method_glosry.md) or [constructor expressions](abenconstructor_expression_glosry.md) are linked via [component selectors](abencomponent_selector_glosry.md). The [return values](abenreturn_value_glosry.md) of the individual methods are references to the next methods. A chained method call can either be executed as a [functional method call](../abap-programming-language/abap-calling-and-exiting-program-units/abapcall_method_functional.md) or as a [standalone statement](../abap-programming-language/abap-calling-and-exiting-program-units/abapcall_method_static_short.md).
