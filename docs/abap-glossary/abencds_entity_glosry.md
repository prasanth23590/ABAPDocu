# CDS entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS object](abencds_object_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md). A CDS entity is defined in a [CDS data definition](abencds_data_definition_glosry.md) using the [CDS DDL](abencds_ddl_glosry.md) of ABAP CDS in [DDL source code](abenddl_source_code_glosry.md). A CDS entity is defined when it is activated. Within CDS, a CDS entity can access other entities. Currently, there are the following CDS entities available:

- [CDS table entities](abencds_table_entity_glosry.md)

- [CDS view entities](abencds_v2_view_glosry.md)

- [CDS projection views](abencds_projection_view_glosry.md)

- [CDS table functions](abencds_table_function_glosry.md)

- [CDS external entities](abencds_external_entity_glosry.md)

- [CDS hierarchies](abencds_hierarchy_glosry.md)

- [CDS custom entities](abencds_custom_entity_glosry.md)

- [CDS abstract entities](abencds_abstract_entity_glosry.md)

- [CDS DDIC-based entities](abencds_ddic_based_entity_glosry.md).

In [ABAP programs](abenabap_program_glosry.md), a CDS entity can be used as a [global type](abenglobal_type_glosry.md) and [ABAP SQL](abenabap_sql_glosry.md) read statements can be used to access CDS entities.

CDS entities that are [writable database objects](abenwritable_db_obj_glosry.md) can be used in ABAP SQL read access for inserting, modifying, or deleting data on the database.
