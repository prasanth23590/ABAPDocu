# enhancement

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Addition to a [repository object](abenrepository_object_glosry.md) that is managed by the ABAP Enhancement Framework and changes its behavior without modification. An enhancement can be made by creating [enhancement implementation elements](abenenhancement_impl_elem_glosry.md) for explicitly defined or implicitly available [enhancement options](abenenhancement_point_glosry.md). Enhancements are switchable using the [Switch Framework](abenswitch_framework_glosry.md).
