# SQL data source

[General](abenabap_glossary.md)

## Definition

[DDIC database table](abenddic_db_table_glosry.md), [CDS entity](abencds_entity_glosry.md) or other resource such as a [common table expression](abencommon_table_expression_glosry.md), a [SQL path expression](abensql_path_expression_glosry.md), a [ABAP SQL hierarchy](abensql_hierarchy_glosry.md), a [table function](abentable_function_glosry.md), or an [internal table](abeninternal_table_glosry.md) from which a [query](abenasql_query_glosry.md) in [ABAP SQL](abenabap_sql_glosry.md) or [ABAP CDS](abenabap_cds_glosry.md) takes its data.
