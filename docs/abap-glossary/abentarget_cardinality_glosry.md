# target cardinality

[General](abenabap_glossary.md)

## Definition

The [cardinality](abencardinality_glosry.md) of a [join](abenjoin_glosry.md) or [association](abenassociation_glosry.md) can consist of a [source cardinality](abensource_cardinality_glosry.md) and a target cardinality. The target cardinality describes the number of matching entries for the entries of the original data source. For example, a target cardinality of many means that each record of the original data source has multiple matching entries in the joined data source.
