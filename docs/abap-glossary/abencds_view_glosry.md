# CDS view

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS entity](abencds_entity_glosry.md) defined in a [CDS data definition](abencds_data_definition_glosry.md) that implements a [view](abenview_glosry.md). There are three types of CDS views:

- [CDS view entity](abencds_v2_view_glosry.md) defined by [`DEFINE VIEW ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_view_entity.md).

- [CDS projection view](abencds_projection_view_glosry.md) defined by [`DEFINE VIEW ENTITY AS PROJECTION`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_view_as_projection.md).

- [CDS DDIC-based view (obsolete)](abencds_v1_view_glosry.md) defined by [`DEFINE VIEW`](../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_define_view_v1.md).

Read access on a CDS view is possible using [ABAP SQL](abenabap_sql_glosry.md) or from other CDS entities.
