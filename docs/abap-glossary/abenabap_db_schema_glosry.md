# ABAP database schema

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Database schema](abendatabase_schema_glosry.md) of the [standard database](abenstandard_db_glosry.md) assigned to the [database user name](abendatabase_user_name_glosry.md) used for database accesses to an [AS ABAP](abenas_abap_glosry.md) via the [standard connection](abenstandard_db_connection_glosry.md).
