# RAP late numbering

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [numbering concept](abenrap_numbering_glosry.md) in which key values are assigned during the [RAP save sequence](abenrap_save_seq_glosry.md).

The final key value is only assigned in the [RAP saver method](abenabp_saver_method_glosry.md) [`adjust_numbers`](../abap-rap-business-objects/abap-for-rap-business-objects/abensaver_adjust_numbers.md).&#x00A0;
