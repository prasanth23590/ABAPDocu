# replacement object

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

A replacement object is a [CDS view](abencds_view_glosry.md) that can be specified for a [DDIC database table](abenddic_db_table_glosry.md) or a [DDIC database view](abendatabase_view_glosry.md). In case of a read access using [ABAP SQL](abenabap_sql_glosry.md), the replacement object is addressed instead of the original object.
