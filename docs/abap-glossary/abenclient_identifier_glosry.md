# client ID

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Three-digit ID of a [client](abenclient_glosry.md) that specifies the [current client](abencurrent_client_glosry.md) when [logging on](abenlogon_glosry.md) to [AS ABAP](abenas_abap_glosry.md). In [application tables](abenapplication_table_glosry.md), [client-dependent](abenclient_dependent_glosry.md) data is indicated by the client ID stored in the [client column](abenclient_column_glosry.md).
