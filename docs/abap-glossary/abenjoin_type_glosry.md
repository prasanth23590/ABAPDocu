# join type

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

The join type determines, together with the [join conditions](abenjoin_condition_glosry.md) of a [join expression](abenjoin_expression_glosry.md), how the rows of its result set are combined from its [SQL data sources](abensql_data_source_glosry.md). [ABAP SQL](abenabap_sql_glosry.md) and [ABAP CDS](abenabap_cds_glosry.md) support [inner joins](abeninner_join_glosry.md), [outer joins](abenouter_join_glosry.md) ([left](abenleft_outer_join_glosry.md) and [right](abenright_outer_join_glosry.md)), and [cross joins](abencross_join_glosry.md).
