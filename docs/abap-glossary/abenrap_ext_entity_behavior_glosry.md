# RAP extension entity behavior

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Node extension for short. A component of a [BDEF extension](abenrap_extension_glosry.md) that defines the behavior for an extension node. Extension entity behavior is defined using [`define behavior for`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_define_beh_extend.md).&#x00A0;The extension node must be added to the current RAP BO's data model via [RAP data model extensions](abenrap_data_model_ext_glosry.md).
