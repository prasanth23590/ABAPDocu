# database system

[General](abenabap_glossary.md)

## Definition

System for storing large amounts of data in a [database](abendatabase_glosry.md). Besides the database, a database system consists of a database management system that manages the database and offers access to the data via a programming interface ([SQL](abensql_glosry.md) for [relational databases](abenrelational_database_glosry.md)).
