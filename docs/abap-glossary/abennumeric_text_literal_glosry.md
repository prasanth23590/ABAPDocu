# numeric text literal

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [General](abenabap_glossary.md)

## Definition

A [literal](abenabap_literal_glosry.md) that contains [numeric text](abennumeric_text_glosry.md) and has the length of the specified characters. The data type is [`n`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_character.md) or [`NUMC`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md).

- Not available in general ABAP.

- In [ABAP SQL](abenabap_sql_glosry.md), numeric text literals are available as [untyped literals](abenuntyped_literal_glosry.md).

- In [ABAP CDS](abenabap_cds_glosry.md), numeric text literals can be [typed literals](abentyped_literal_glosry.md) or [untyped literals](abenuntyped_literal_glosry.md).
