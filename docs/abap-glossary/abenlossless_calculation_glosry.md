# lossless calculation

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Arithmetic](abenarithmetic_expression_glosry.md) calculation where no rounding occurs. The [lossless operator](abenlossless_operator_glosry.md) [`EXACT`](../abap-programming-language/abap-processing-internal-data/abenconstructor_expression_exact.md) can be used to check whether a calculation is lossless.
