# JSON-XML

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

SAP-specific representation of [JSON](abenjson_glosry.md) data in [XML](abenxml_glosry.md) format. [JSON readers](abenjson_reader_glosry.md) and [JSON writers](abenjson_writer_glosry.md) use JSON-XML to [parse](../abap-programming-language/abap-data-interchange-formats/abenabap_json_sxml.md) and [render](../abap-programming-language/abap-data-interchange-formats/abenabap_json_sxml.md) JSON data.
