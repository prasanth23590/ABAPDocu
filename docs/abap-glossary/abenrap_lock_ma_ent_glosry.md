# RAP lock master entity

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO entity](abenrap_bo_entity_glosry.md) that is locked on each locking request of one of its [lock dependent entities](abenrap_lock_dep_ent_glosry.md). On each locking request the lock master and all its lock dependent entities are locked.
