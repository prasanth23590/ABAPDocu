# session variable

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A global variable of a [database system](abendatabase_system_glosry.md) that contains information about the current context. The [SAP HANA database](abenhana_database_glosry.md) has special ABAP-specific session variables whose content matches the value of certain [ABAP system fields](abensystem_field_glosry.md) when accessed from ABAP. In [CDS views](abencds_view_glosry.md), these ABAP-specific session variables can be accessed on all supported platforms.
