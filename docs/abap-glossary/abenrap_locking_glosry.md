# RAP locking

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A locking mechanism that is based on the SAP lock concept. It uses lock function modules for [pessimistic concurrency control](abenpessimist_conc_control_glosry.md).
