# CDS custom entity extension

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS entity extension](abencds_entity_extend_glosry.md) of a [CDS custom entity](abencds_custom_entity_glosry.md). A CDS custom entity extension can be used to add elements to a custom entity without making any modifications to the original entity. It is defined using the statement [`EXTEND CUSTOM ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_extend_custom_entity.md).
