# delayed update

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Procedure to create or update unique [secondary table keys](abensecondary_table_key_glosry.md) of [internal tables](abeninternal_table_glosry.md). After a modifying operation using [field symbols](abenfield_symbol_glosry.md) or [data references](abendata_reference_glosry.md), unique secondary table keys are not updated immediately; instead they are updated the next time the internal table is accessed. See also [direct update](abendirect_update_glosry.md) and [lazy update](abenlazy_update_glosry.md).
