# client handling

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [AMDP](../abap-programming-language/abap-database-access/abenamdp_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Processing of the application data of a [client](abenclient_glosry.md). When accessing [client-dependent](abenclient_dependent_glosry.md) [DDIC database tables](abenddic_db_table_glosry.md) or [views](abenview_glosry.md), [ABAP SQL](abenabap_sql_glosry.md) statements use [implicit client](../abap-programming-language/abap-database-access/abenabap_sql_client_handling.md) handling, which by default accesses the [current client](abencurrent_client_glosry.md). The client handling of [AMDP methods](abenamdp_method_glosry.md) can be defined with special [AMDP options](../abap-programming-language/abap-database-access/abapmethods_amdp_options_client.md).
