# class pool

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP program](abenabap_program_glosry.md) that contains the definition of one [global class](abenglobal_class_glosry.md) and is loaded when the class is used. In addition to the global class, a class pool can contain further [local classes](abenlocal_class_glosry.md), that are defined in a [CCDEF include](abenccdef_glosry.md), [CCIMP include](abenccimp_glosry.md), or a [test include](abentest_include_glosry.md).
