# ABAP tuning object

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Synonym for app-server tuning object. A [tuning object](abentuning_object_glosry.md) that defines the technical settings for a [CDS entity](abencds_entity_glosry.md) on [AS ABAP](abenas_abap_glosry.md). ABAP tuning objects are defined as [CDS objects](abencds_object_glosry.md) in [CDS source code](abencds_source_code_glosry.md). Currently, there are the following ABAP tuning objects:

- [CDS entity buffers](abencds_entity_buffer_glosry.md)
