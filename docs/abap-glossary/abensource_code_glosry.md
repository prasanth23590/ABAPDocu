# source code

[General](abenabap_glossary.md)

## Definition

Textual representation of programs or other [repository objects](abenrepository_object_glosry.md). For example, [ABAP source code](abenabap_source_code_glosry.md) for [ABAP programs](abenabap_program_glosry.md), [CDS source code](abencds_source_code_glosry.md) for [CDS objects](abencds_object_glosry.md), or [transformation source code](abentrafo_source_code_glosry.md) for [XSLT programs](abenxslt_program_glosry.md) and [Simple Transformations](abensimple_transformation_glosry.md).
