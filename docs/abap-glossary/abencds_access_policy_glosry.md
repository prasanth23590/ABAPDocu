# CDS access policy

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Framework defined in the [DCL](abendcl_glosry.md) of the [ABAP Core Data Services](abenabap_core_data_services_glosry.md) using [`DEFINE ACCESSPOLICY`](../abap-core-data-services-abap-cds/abap-cds-access-control/abencds_f1_define_accesspolicy.md). Currently, only one CDS access policy is used as a frame for the definition of exactly one [PFCG mapping](abencds_pfcg_mapping_glosry.md).
