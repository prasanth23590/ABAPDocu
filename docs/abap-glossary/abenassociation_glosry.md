# association

[General](abenabap_glossary.md)

## Definition

Relationship between [association sources](abenassociation_source_glosry.md) and [association targets](abenassociation_target_glosry.md) defined by conditions.

An association can be [source-resolved](abensource_resolved_assoc_glosry.md) or [target-resolved](abentarget_resolved_assoc_glosry.md), depending on the location of the foreign key field.
