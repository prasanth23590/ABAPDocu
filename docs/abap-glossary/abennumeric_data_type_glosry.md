# numeric data type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) whose [data objects](abendata_object_glosry.md) contain numeric values in platform-dependent encoding. These data types are [integer type](abeninteger_type_glosry.md), [packed number type](abenpacked_number_type_glosry.md), [decimal floating pointing number type](abendecfloat_type_glosry.md) and [binary floating pointing number type](abenbinfloat_type_glosry.md). The corresponding [generic data type](abengeneric_data_type_glosry.md) is [`numeric`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
