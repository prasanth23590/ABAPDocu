# SAP LUW

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Interrelated sequence of programming units, the execution of which can be distributed across several [work processes](abenwork_process_glosry.md). However, their database changes are processed within a single [database LUW](abendatabase_luw_glosry.md).

The [controlled SAP LUW](abencontrolled_sap_luw_glosry.md) is an extension to the SAP LUW.
