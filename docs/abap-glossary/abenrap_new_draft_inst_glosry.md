# RAP new draft instance

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [draft instance](abenrap_draft_instance_glosry.md) that is produced by a [create operation](abenrap_create_operation_glosry.md) with the [draft indicator](abenrap_draft_indicator_glosry.md) set to *true*. The data of new draft instances is not yet persisted on the active database table and there is no corresponding active instance available.

See also: [RAP edit draft instance](abenrap_edit_draft_inst_glosry.md)
