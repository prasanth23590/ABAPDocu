# managed RAP business object

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Managed RAP BO for short. A provisioning type of the [business object behavior](abenrap_bo_behavior_glosry.md) of a [RAP BO](abenrap_bo_glosry.md). The [transactional buffer](abentransactional_buffer_glosry.md) of a managed RAP BO is provided by the [managed RAP BO provider](abenmanaged_rap_bo_prov_glosry.md). The implementation can partly be provided by an [unmanaged RAP BO provider](abenunmanaged_rap_bo_prov_glosry.md) in an [ABAP behavior pool](abenbehavior_pool_glosry.md).
