# comparison expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Relational expression](abenrelational_expression_glosry.md) that combines two or more [operands](abenoperand_glosry.md) using a [comparison operator](abencomp_operator_glosry.md) in accordance with certain [comparison rules](abencomparison_rule_glosry.md).
