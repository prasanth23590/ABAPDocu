# RAP saver class

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

[Local class](abenlocal_class_glosry.md) in a [CCIMP include](abenccimp_glosry.md) of an [ABAP behavior pool (ABP)](abenbehavior_pool_glosry.md) for implementing [RAP saver methods](abenabp_saver_method_glosry.md) that are called during the [save sequence](abenrap_save_seq_glosry.md).
