# period

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

The time interval whose limits are defined by the content of the columns of a [temporal SQL hierarchy](abentemporal_hierarchy_glosry.md). These columns are defined when the [ABAP SQL hierarchy](abensql_hierarchy_glosry.md) is created.
