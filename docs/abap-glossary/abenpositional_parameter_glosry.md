# positional parameter

[General](abenabap_glossary.md)

## Definition

A [formal parameter](abenformal_parameter_glosry.md) to which an [actual parameter](abenactual_parameter_glosry.md) is passed according to its position in the calling statement. See also [keyword parameter](abenkeyword_parameter_glosry.md).
