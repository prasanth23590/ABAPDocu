# CDS parameter

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An input parameter of a [CDS object](abencds_object_glosry.md). A CDS parameter can be defined, for example, in the parameter list of a [CDS data definition](abencds_data_definition_glosry.md) or of a [CDS scalar function definition](abencds_dsfd_glosry.md). When a CDS object with parameters is used in another CDS object or in an [ABAP SQL statement](abenabap_sql_glosry.md), actual parameters must be assigned to their CDS parameters.
