# key table

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Superordinate term for [sorted tables](abensorted_table_glosry.md) and [hashed tables](abenhashed_table_glosry.md), in which the [primary table key](abenprimary_table_key_glosry.md), unlike [standard tables](abenstandard_table_glosry.md), has its own stable administration that allows optimized access.
