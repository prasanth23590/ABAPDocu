# member loop

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Loop at the members of a group in a [group loop](abengroup_loop_glosry.md) introduced using the statement [`LOOP AT GROUP`](../abap-programming-language/abap-processing-internal-data/abaploop_at_group.md).
