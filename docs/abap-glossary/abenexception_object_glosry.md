# exception object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Instance](abeninstance_glosry.md) of an [exception class](abenexception_class_glosry.md). Is created when a [catchable exception](abencatchable_exception_glosry.md) is raised and contains information on the exception situation. Can be propagated across call levels.
