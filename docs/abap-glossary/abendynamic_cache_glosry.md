# DDIC dynamic cache

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[SAP HANA tuning object](abenhana_tuning_object_glosry.md) defined using the statement [`DEFINE DYNAMIC CACHE`](../abap-dictionary-ddic/ddic-tuning-objects/abenddicddl_define_dynamic_cache.md) in [DDIC DDL](abenddic_dcl_glosry.md). A DDIC dynamic cache can improve performance when a view is accessed repeatedly. At the same time, a dynamic cache guarantees up-to-date data.

A DDIC dynamic cache is integrated into [ABAP Dictionary](abenabap_dictionary_glosry.md) as a wrapper for an SAP HANA dynamic result cache.
