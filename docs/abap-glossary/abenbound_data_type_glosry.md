# bound data type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) that only exists as a property of a [data object](abendata_object_glosry.md). A bound data type has a [technical type name](abentechnical_type_name_glosry.md) that can be retrieved as part of an [absolute type name](abenabsolute_typename_glosry.md) by [RTTI](abenrun_time_type_identific_glosry.md). See also [standalone data type](abenstand-alone_data_type_glosry.md).
