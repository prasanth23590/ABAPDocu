# convertible

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Two different [data types](abendata_type_glosry.md) are convertible if a [conversion rule](abenconversion_rule_glosry.md) applies to them. Two [data objects](abendata_object_glosry.md) are convertible if their data types are convertible and their content allows the corresponding conversion. Data objects of [compatible](abencompatible_glosry.md) data types are assigned to each other without a conversion.
