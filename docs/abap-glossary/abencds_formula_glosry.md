# analytical formula

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An analytical formula is an element of a [CDS analytical projection view](abencds_analytical_pv_glosry.md) that is added as a new element in the projection layer and performs a calculation.
