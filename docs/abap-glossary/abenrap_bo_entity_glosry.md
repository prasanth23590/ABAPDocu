# RAP BO entity

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Also RAP BO node. A [CDS entity](abencds_entity_glosry.md) for which behavior is defined in a [RAP behavior definition](abencds_behavior_definition_glosry.md) of a [RAP BO](abenrap_bo_glosry.md).
