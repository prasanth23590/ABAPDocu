# CDS association

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An [association](abenassociation_glosry.md) of [ABAP CDS](abenabap_cds_glosry.md). Associations define [join](abenjoin_glosry.md) relationships between [association sources](abenassociation_source_glosry.md) and [association targets](abenassociation_target_glosry.md). CDS associations can be defined for [CDS view entities](abencds_v2_view_glosry.md), [CDS DDIC-based views (obsolete)](abencds_v1_view_glosry.md), [CDS projection views](abencds_projection_view_glosry.md), [CDS custom entities](abencds_custom_entity_glosry.md), and [CDS abstract entities](abencds_abstract_entity_glosry.md) using the addition `ASSOCIATION` in the [CDS DDL](abencds_ddl_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md). They can be evaluated in [CDS DDL](abencds_ddl_glosry.md), [CDS DCL](abencds_dcl_glosry.md), and in [ABAP SQL](abenabap_sql_glosry.md) using [SQL path expressions](abensql_path_expression_glosry.md). [To-child associations](abento_child_association_glosry.md) and [to-parent associations](abento_parent_association_glosry.md) are specialized associations that together build a [CDS composition](abencds_composition_glosry.md) relationship for the [CDS composition tree](abencds_composition_tree_glosry.md) of a [RAP business object](abenrap_bo_glosry.md).
