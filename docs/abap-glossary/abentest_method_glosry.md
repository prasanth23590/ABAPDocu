# test method

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Special [instance method](abeninstance_method_glosry.md) of a [test class](abentest_class_glosry.md) in which a test is implemented. Test methods are defined using the addition [`FOR TESTING`](../abap-programming-language/abap-program-maintenance/abapmethods_testing.md) of the statement [`METHODS`](../abap-programming-language/abap-declarations/abapmethods.md), and called during a [test run](abentest_run_glosry.md) of the [ABAP Unit](abenabap_unit_glosry.md) tool.
