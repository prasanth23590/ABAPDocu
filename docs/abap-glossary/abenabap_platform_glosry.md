# ABAP Platform

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Name for the [ABAP technology](abenabap_techno_glosry.md) shipped as a basis of [SAP S/4HANA](abensap_s4hana_glosry.md) and [SAP S/4HANA Cloud Private Edition](abensap_s4hana_cpriv_glosry.md). The release numbering of an ABAP Platform is based on the respective SAP S/4HANA release. An ABAP Platform supports the programming paradigm [classic ABAP](abenclassic_abap_glosry.md) but programming according to the rules of [ABAP Cloud](abenabap_cloud_glosry.md) is also possible and encouraged.
