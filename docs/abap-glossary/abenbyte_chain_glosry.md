# byte chain

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [General](abenabap_glossary.md)

## Definition

String or sequence of bytes. Content of any data object. However, direct access to the bytes of a byte chain is possible only in [byte-like data objects](abenbyte_like_data_object_glosry.md), or by using appropriately typed [field symbols](abenfield_symbol_glosry.md).
