# instance attribute

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Attribute](abenattribute_glosry.md) of a [class](abenclass_glosry.md) that is declared using [`DATA`](../abap-programming-language/abap-declarations/abapdata.md). Instance attributes are only valid in the [context](abenobj_context_glosry.md) of an [instance](abeninstance_glosry.md) of the class. The content of the instance attributes determines the state of the [objects](abenobject_glosry.md) of a class.
