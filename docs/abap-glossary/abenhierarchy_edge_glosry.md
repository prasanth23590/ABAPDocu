# hierarchy edge

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [General](abenabap_glossary.md)

## Definition

The relationship between the [hierarchy nodes](abenhierarchy_node_glosry.md) of a [hierarchy](abenhierarchy_glosry.md). The hierarchy edges in [ABAP SQL hierarchies](abensql_hierarchy_glosry.md) created by a [hierarchy generator](abenhierarchy_generator_glosry.md) in [ABAP SQL](abenabap_sql_glosry.md) or in a [CDS hierarchy](abencds_hierarchy_glosry.md) are [parent-child relationships](abenpcr_glosry.md).
