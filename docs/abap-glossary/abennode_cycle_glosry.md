# node cycle

[General](abenabap_glossary.md)

## Definition

A node cycle occurs in a [hierarchy](abenhierarchy_glosry.md) for a [child node](abenchild_node_glosry.md) that is also one of the preceding [parent nodes](abenparent_node_glosry.md) or its own parent node.
