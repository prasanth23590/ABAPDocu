# null value

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A special value returned by a [database](abendatabase_glosry.md) to indicate an undefined value or result. There are no special null values in ABAP.
