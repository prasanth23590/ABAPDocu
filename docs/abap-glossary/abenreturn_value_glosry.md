# return value

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

The result of [functional methods](abenfunctional_method_glosry.md), [built-in functions](abenbuiltin_function_glosry.md), and [CDS scalar functions](abencds_scalar_function_glosry.md).

- In the [ABAP language](abenabala_glosry.md), the result of functional methods is the [formal parameter](abenformal_parameter_glosry.md) defined by the addition [`RETURNING`](../abap-programming-language/abap-declarations/abapmethods_functional.md) of the statement [`[CLASS-]`](../abap-programming-language/abap-declarations/abapclass-methods.md)[`METHODS`](../abap-programming-language/abap-declarations/abapmethods.md).

- in [ABAP CDS](abenabap_cds_glosry.md), the result of a CDS scalar function whose data type is defined after the addition [`RETURNS`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_scalar_function.md).
