# parent-child-based hierarchy

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

An [ABAP SQL hierarchy](abensql_hierarchy_glosry.md) that is generated from a [parent-child relationship](abenpcr_glosry.md). A parent-child-based hierarchy is based on a [SQL data source](abensql_data_source_glosry.md) that exposes a [hierarchy association](abenhierarchy_association_glosry.md) that defines the parent-child relationship between columns of the data source. [ABAP SQL](abenabap_sql_glosry.md) can access parent-child-based hierarchies generated by a [CDS hierarchy](abencds_hierarchy_glosry.md), by the [hierarchy generator](abenhierarchy_generator_glosry.md) using the addition [`CHILD TO PARENT ASSOCIATION`](../abap-programming-language/abap-database-access/abenselect_hierarchy_gen_assoc.md), or by a [CTE hierarchy](abencte_hierarchy_glosry.md).
