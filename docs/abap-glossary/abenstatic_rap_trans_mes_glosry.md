# RAP static transition message

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [transition message](abenrap_trans_mes_glosry.md) that refers to a [RAP BO entity](abenrap_bo_entity_glosry.md), but not to a specific [instance](abenrap_bo_entity_inst_glosry.md). Unlike a [RAP instance transition message](abeninstance_rap_trans_mes_glosry.md), it does not contain a key reference.
