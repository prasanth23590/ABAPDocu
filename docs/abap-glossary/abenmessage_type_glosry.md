# message type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Must be specified when the statement [`MESSAGE`](../abap-programming-language/abap-text-repositories/abapmessage.md) is used to send a [message](abenmessage_glosry.md). The possible message types are [information message](abeninformation_message_glosry.md), [status message](abenstatus_message_glosry.md), [error message](abenerror_message_glosry.md), [warning](abenwarning_glosry.md), [termination message](abentermination_message_glosry.md), and [exit message](abenexit_message_glosry.md).
