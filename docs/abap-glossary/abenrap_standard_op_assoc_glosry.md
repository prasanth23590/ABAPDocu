# RAP standard operation for associations

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

[Operation for associations](abenrap_operation_assoc_glosry.md) that provides canonical behavior along an [association path](abencds_association_path_glosry.md) from an [association source](abenassociation_source_glosry.md) to an [association target](abenassociation_target_glosry.md). [Create-by-association](abenrap_cba_operation_glosry.md) and [read-by-association](abenrap_rba_operation_glosry.md) are standard operations for associations.
