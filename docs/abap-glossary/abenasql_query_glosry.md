# ABAP SQL query

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

[Database query](abendb_query_glosry.md) that is implemented in [ABAP SQL](abenabap_sql_glosry.md) with the [DQL](abendql_glosry.md) language element `SELECT`. The [clauses and additions](../abap-programming-language/abap-database-access/abenselect_clauses.md) of `SELECT` define the result set returned by the database. &#x200E;See [main query](abenmainquery_glosry.md) and [subquery](abensubquery_glosry.md).
