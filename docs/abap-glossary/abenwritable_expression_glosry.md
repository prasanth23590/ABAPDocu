# writable expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Expression representing an operand that can be written to. Writable expressions are certain [constructor expressions](abenconstructor_expression_glosry.md) using [`NEW`](../abap-programming-language/abap-creating-objects-and-values/abennew_constructor_params_class.md) and [`CAST`](../abap-programming-language/abap-processing-internal-data/abenconstructor_expression_cast.md) or [table expressions](abentable_expression_glosry.md). A writable expression can be specified in a [result position](abenresult_position_glosry.md).
