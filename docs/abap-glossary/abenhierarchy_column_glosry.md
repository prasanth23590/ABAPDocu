# hierarchy column

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

A column of the result set of an [ABAP SQL](abenabap_sql_glosry.md) [query](abenasql_query_glosry.md) on a [ABAP SQL hierarchy](abensql_hierarchy_glosry.md) or on a [hierarchy navigator](abenhierarchy_navigator_glosry.md) containing a [hierarchy attribute](abenhierarchy_attribute_glosry.md). A hierarchy column must first be specified explicitly in the [`SELECT`](../abap-programming-language/abap-database-access/abapselect_list.md) list before it can be included in the result set.
