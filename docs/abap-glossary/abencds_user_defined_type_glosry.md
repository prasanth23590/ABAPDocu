# CDS user-defined type

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS object](abencds_object_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md). CDS user-defined types can be used for typing, casting, and as operands of expressions in [CDS entities](abencds_entity_glosry.md) and in other [CDS objects](abencds_object_glosry.md) and in ABAP after the addition `TYPES`. A CDS user-defined type can be enriched with metadata using [CDS annotations](abencds_annotation_glosry.md). Currently, the following CDS user-defined types are available:

- [CDS simple type](abencds_simple_type_glosry.md)

- [CDS enumerated type](abencds_enum_type_glosry.md)
