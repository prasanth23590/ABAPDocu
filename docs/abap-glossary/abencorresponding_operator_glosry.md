# component operator

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Constructor operator](abenconstructor_operator_glosry.md) [`CORRESPONDING`](../abap-programming-language/abap-processing-internal-data/abenconstructor_expr_corresponding.md) for component by component assignments between [structures](abenstructure_glosry.md) or between [internal tables](abeninternal_table_glosry.md) in [operand positions](abenoperand_position_glosry.md). By default, the mapping between the [structure components](abenstructure_component_glosry.md) is based on identical names and can also be defined using mapping rules.
