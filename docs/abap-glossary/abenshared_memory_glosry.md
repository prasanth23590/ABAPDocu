# shared memory

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Memory area of an [AS instance](abenas_instance_glosry.md) in which the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) stores programs, program data, buffers, and so on.
