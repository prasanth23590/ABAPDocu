# host computer

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Computer on which the current [AS instance](abenas_instance_glosry.md) is instantiated. The name of the current host computer can be read from the [system field](abensystem_field_glosry.md) `sy-host`.
