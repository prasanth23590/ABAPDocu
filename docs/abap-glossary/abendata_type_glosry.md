# data type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [General](abenabap_glossary.md)

## Definition

Property of a [data object](abendata_object_glosry.md). ABAP interprets the content of a data object in accordance with its data type. Data types exist either as [bound](abenbound_data_type_glosry.md) data types as a property of data objects or as [standalone](abenstand-alone_data_type_glosry.md) data types. Standalone data types can be defined globally in the [ABAP Dictionary](abenabap_dictionary_glosry.md) or in [ABAP CDS](abenabap_cds_glosry.md). Data types defined with [`TYPES`](../abap-programming-language/abap-declarations/abaptypes.md) in an [ABAP program](abenabap_program_glosry.md) can be either local or global. The latter is true for non-private data types of [classes](abenclass_glosry.md) and [interfaces](abenoo_intf_glosry.md). The [generic data type](abengeneric_data_type_glosry.md) of all data types is [`data`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
