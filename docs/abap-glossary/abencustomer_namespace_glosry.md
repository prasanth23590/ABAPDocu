# customer namespace

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Predefined [namespace](abennamespace_glosry.md) for [repository objects](abenrepository_object_glosry.md) created in non-SAP and non-partner development systems. Names have `Y` or `Z` as the first character. These names have to be used in non-SAP and non-partner systems, if no [prefix namespace](abenprefix_name_space_glosry.md) is available.
