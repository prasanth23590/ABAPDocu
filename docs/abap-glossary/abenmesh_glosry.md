# mesh

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Instance of a [mesh type](abenmesh_type_glosry.md). Special [structure](abenstructure_glosry.md) whose [components](abenstructure_component_glosry.md) described as [mesh nodes](abenmesh_node_glosry.md) are exclusively [internal tables](abeninternal_table_glosry.md) that can be joined using [mesh associations](abenmesh_association_glosry.md).
