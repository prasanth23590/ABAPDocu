# database rollback

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

End of a [database LUW](abendatabase_luw_glosry.md) in which all modifying database operations are undone until the beginning of the LUW. In an [AS ABAP](abenas_abap_glosry.md), database rollbacks are triggered implicitly, as well as by explicit requests.
