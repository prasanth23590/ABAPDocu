# set indicator

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

[ABAP SQL indicator](abenabap_sql_indicator_glosry.md) in a [work area](abenwork_area_glosry.md) or an [internal table](abeninternal_table_glosry.md). The components of a set indicator indicate the columns of a [DDIC database table](abenddic_db_table_glosry.md) to be changed using the [`UPDATE`](../abap-programming-language/abap-database-access/abapupdate.md) statement.
