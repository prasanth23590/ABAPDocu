# relational operator

[General](abenabap_glossary.md)

## Definition

Superordinate term for [comparison operators](abencomp_operator_glosry.md) and [predicate operators](abenpredicate_operator_glosry.md). Relational operators occur in [relational expressions](abenrelational_expression_glosry.md). Relational operators belong to the [logical operators](abenlogical_operator_glosry.md).
