# AMDP function

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [AMDP](../abap-programming-language/abap-database-access/abenamdp_glossary.md)

## Definition

[Database function](abendatabase_function_glosry.md) of the [SAP HANA database](abenhana_database_glosry.md) that is implemented in an [AMDP function implementation](abenamdp_function_method_glosry.md) of an [AMDP class](abenamdp_class_glosry.md) and is replicated from there to the [database system](abendatabase_system_glosry.md). There are [AMDP table functions](abenamdp_table_function_glosry.md) or [AMDP scalar functions](abenamdp_scalar_function_glosry.md). See also [AMDP procedure](abenamdp_procedure_glosry.md).
