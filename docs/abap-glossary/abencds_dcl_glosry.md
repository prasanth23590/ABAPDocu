# CDS DCL

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Data control language ([DCL](abendcl_glosry.md)) of [ABAP CDS](abenabap_cds_glosry.md) used to define [CDS roles](abencds_role_glosry.md) and [CDS access policies](abencds_access_policy_glosry.md) in [DCL source code](abendcl_source_code_glosry.md) in [CDS access control](abencds_access_control_glosry.md).
