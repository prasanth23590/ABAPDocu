# structured type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) of a [structure](abenstructure_glosry.md). It contains other data types as [structure components](abenstructure_component_glosry.md). A named structured type is either defined as a [DDIC structure](abenddic_structure_glosry.md), a [CDS entity](abencds_entity_glosry.md) or inside an [ABAP program](abenabap_program_glosry.md) using the statement [`TYPES BEGIN OF`](../abap-programming-language/abap-declarations/abaptypes_struc.md).
