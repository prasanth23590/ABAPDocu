# table reduction

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Creates the content of a [data object](abendata_object_glosry.md) by evaluating one or more [internal tables](abeninternal_table_glosry.md) using [table iterations](abentable_iteration_glosry.md) with [iteration expressions](abeniteration_expression_glosry.md) in a [constructor expression](abenconstructor_expression_glosry.md) with the [reduction operator](abenreduce_operator_glosry.md) [`REDUCE`](../abap-programming-language/abap-program-flow-logic/abenconstructor_expression_reduce.md). This usually reduces the content of the internal table to a less complex data object.
