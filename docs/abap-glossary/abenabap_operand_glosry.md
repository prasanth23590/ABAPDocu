# ABAP operand

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A syntax element of an [ABAP statement](abenabap_statement_glosry.md) at an [operand position](abenoperand_position_glosry.md). At [read](abenread_position_glosry.md) and [write positions](abenwrite_position_glosry.md), [data objects](abendata_object_glosry.md) or [expressions](abenexpression_glosry.md) can be specified. Besides that there are other operand positions, where types, callable units or other external resources such as [CDS entities](abencds_entity_glosry.md) or [DDIC database tables](abenddic_db_table_glosry.md) can be specified as operands.
