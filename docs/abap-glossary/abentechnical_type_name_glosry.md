# technical type name

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Internal name of a of a [data type](abendata_type_glosry.md) that only exists as a [bound data type](abenbound_data_type_glosry.md) of a [data object](abendata_object_glosry.md). A technical type name can be part of an [absolute type name](abenabsolute_typename_glosry.md) and retrieved by [RTTI](abenrun_time_type_identific_glosry.md). [RTTI](abenrun_time_type_identific_glosry.md). In the ABAP language version [ABAP for Cloud Development](abenabap_for_cloud_dev_glosry.md) it cannot be used in dynamic type specifications.
