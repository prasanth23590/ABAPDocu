# enhancement implementation

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

A [repository object](abenrepository_object_glosry.md) used for the administration of [enhancements](abenenhancement_glosry.md) of other repository objects. Enhancement implementations are components of a hierarchical tree structure of which the branches represent [composite](abencomp_enhancement_impl_glosry.md) enhancement implementations, and the leaves are [simple enhancement implementations](abensimple_enhancement_impl_glosry.md).
