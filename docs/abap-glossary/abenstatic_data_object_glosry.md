# static data object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data object](abendata_object_glosry.md) for which all attributes, including memory use, are specified statically by the [data type](abendata_type_glosry.md). Apart from [reference variables](abenreference_variable_glosry.md), all static data objects are [flat](abenflat_glosry.md). See also [dynamic data object](abendynamic_data_object_glosry.md).
