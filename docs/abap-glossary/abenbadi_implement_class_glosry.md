# BAdI implementation class

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Global [class](abenclass_glosry.md) that implements one or more [BAdI interfaces](abenbadi_interface_glosry.md) and therefore also their [BAdI methods](abenbadi_method_glosry.md). BAdI implementation classes are the main components of [BAdI implementations](abenbadi_implementation_glosry.md), and their instances act as [object plug-ins](abenobject_plugin_glosry.md) for functional [enhancements](abenenhancement_glosry.md) of ABAP programs. A BAdI implementation class that is not part of a BAdI implementation is not linked to an [enhancement implementation](abenenhancement_impl_glosry.md). The latter can be used, for example, as fallback BAdI implementation classes of [BAdIs](abenbadi_glosry.md).
