# vertex

[General](abenabap_glossary.md)

## Definition

Stores [graph](abengraph_glosry.md) data in combination with [edges](abenedge_glosry.md). A vertex can be considered as a node in a network. One vertex is denoted as the source and the other as the target. An edge connects two vertices. Vertices can have any number of [attributes](abenattribute_glosry.md). An attribute consists of a name that is associated with a [data type](abendata_type_glosry.md) and a value.
