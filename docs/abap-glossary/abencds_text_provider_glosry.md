# CDS text provider view

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS entity](abencds_entity_glosry.md) whose [primary key](abenprimary_key_glosry.md) consists of multiple [key fields](abenkey_field_glosry.md), one of which is of data type [`LANG`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md) and length 1. A text provider view typically contains one or more text fields for which translations in different languages are maintained. A text provider view can serve as an [association target](abenassociation_target_glosry.md) for a [CDS text association](abencds_text_association_glosry.md).
