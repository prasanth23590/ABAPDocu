# instance method

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Method](abenmethod_glosry.md) of a [class](abenclass_glosry.md) declared using [`METHODS`](../abap-programming-language/abap-declarations/abapmethods.md), which can only be used in an [instance](abeninstance_glosry.md) of the class. Instance methods can access all [attributes](abenattribute_glosry.md) and [events](abenevent_glosry.md) of their class.
