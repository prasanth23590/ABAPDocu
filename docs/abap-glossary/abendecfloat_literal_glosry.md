# decimal floating point literal

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [General](abenabap_glossary.md)

## Definition

A [numeric literal](abennumeric_literal_glosry.md) of a [decimal floating point type](abendecfloat_type_glosry.md).

- Not available in general ABAP.

- In [ABAP SQL](abenabap_sql_glosry.md) and [ABAP CDS](abenabap_cds_glosry.md), decimal floating point literals are available as [typed literals](abentyped_literal_glosry.md).
