# writable database object

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

A [repository object](abenrepository_object_glosry.md) that allows modifying data on the database.

- In [ABAP CDS](abenabap_cds_glosry.md), [CDS table entities](abencds_table_entity_glosry.md), [writable CDS view entities](abenwritable_v2_glosry.md), and [writable CDS external entities](abenwritable_ee_glosry.md) allow for the modification of data with the [ABAP SQL](abenabap_sql_glosry.md) statements [`INSERT`](../abap-programming-language/abap-database-access/abapinsert_dbtab.md), [`UPDATE`](../abap-programming-language/abap-database-access/abapupdate.md), [`MODIFY`](../abap-programming-language/abap-database-access/abapmodify_dbtab.md), and [`DELETE`](../abap-programming-language/abap-database-access/abapdelete_dbtab.md).

- In [ABAP Dictionary](abenabap_dictionary_glosry.md), [DDIC database tables](abenddic_db_table_glosry.md) allow data change operations.
