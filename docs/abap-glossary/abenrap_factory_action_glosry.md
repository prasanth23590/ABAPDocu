# RAP factory action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP action](abenrap_action_glosry.md) that creates new [RAP BO entity instances](abenrap_bo_entity_inst_glosry.md) where you can add functionality to the create process, for example, retrieving BO-specific default values. In contrast to a [non-factory action](abenrap_non_fac_action_glosry.md), the [BDEF derived type](abenrap_derived_type_glosry.md) of a factory action contains a [`%cid`](../abap-rap-business-objects/abap-for-rap-business-objects/abapderived_types_cid.md) component.
