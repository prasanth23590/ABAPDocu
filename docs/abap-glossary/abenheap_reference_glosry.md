# heap reference

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Reference](abenreference_glosry.md) to an [object](abenobject_glosry.md) or part of an object in the [heap](abenheap_glosry.md). A heap reference keeps an object alive. See also [stack reference](abenstack_reference_glosry.md).
