# elementary data type

[General](abenabap_glossary.md)

## Definition

A scalar [data type](abendata_type_glosry.md) of fixed or variable length that is neither [structured](abenstructured_type_glosry.md), nor a [table type](abentable_type_glosry.md) or a [reference type](abenreference_type_glosry.md).

- In ABAP, user-defined elementary data types are based on the [built-in ABAP types](abenbuiltin_abap_type_glosry.md).

- In [ABAP Dictionary](abenabap_dictionary_glosry.md), user-defined elementary data types are represented as [DDIC data elements](abendata_element_glosry.md) that are based on elementary built-in dictionary types.

- In [ABAP CDS](abenabap_cds_glosry.md), user-defined elementary data types are represented as [CDS simple types](abencds_simple_type_glosry.md) that are based on elementary built-in dictionary types.

An [enumerated type](abenenum_type_glosry.md) is a special kind of an elementary data type that can be defined by users in ABAP and in ABAP CDS.
