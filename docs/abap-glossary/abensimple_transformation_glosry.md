# Simple Transformation

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

ST for short. SAP-specific programming language for transformations between [XML](abenxml_glosry.md) formats and ABAP data and vice versa. [Serializations](abenserialization_glosry.md) and [deserializations](abendeserialization_glosry.md) can be carried out using ST. Simple Transformations are called using the statement [`CALL TRANSFORMATION`](../abap-programming-language/abap-data-interchange-formats/abapcall_transformation.md).
