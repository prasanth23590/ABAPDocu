# database hint

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [General](abenabap_glossary.md)

## Definition

An extension of the SQL standard that tells a [database system](abendatabase_system_glosry.md) or the [ABAP SQL in-memory engine](abenabap_sql_inmemeng_glosry.md) how to execute an access. Database hints are usually dependent on the database system and its release. In [ABAP SQL](abenabap_sql_glosry.md), database hints can be specified using the addition [`%_HINTS`](../abap-programming-language/abap-database-access/abenabap_sql_db_hints.md). In [ABAP CDS](abenabap_cds_glosry.md), the annotation [`Consumption.dbHints`](../abap-core-data-services-abap-cds/abap-cds-annotations/abencds_710938603-_anno.md) can be used.
