# RAP draft handling

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A concept in RAP that allows the content of the [transactional buffer](abentransactional_buffer_glosry.md) to be stored in intermediate storages ([draft tables](abendraft_table_glosry.md)) in order to allow transactions to expand over different [ABAP sessions](abenabap_session_glosry.md). Introduced by the keyword [`with draft`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_with_draft.md) or [`with collaborative draft`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_with_coll_draft.md) in the [behavior definition header](abencds_bdef_header_glosry.md) of a [RAP behavior definition](abencds_behavior_definition_glosry.md).
