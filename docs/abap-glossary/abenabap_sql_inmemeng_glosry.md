# ABAP SQL in-memory engine

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

Part of the [ABAP SQL engine](abenabap_sql_engine_glosry.md) for processing [ABAP SQL](abenabap_sql_glosry.md) statements which [read](../abap-programming-language/abap-database-access/abenabap_sql_reading.md) tabular data in the memory of an [AS ABAP](abenas_abap_glosry.md). The ABAP SQL in-memory engine is used by ABAP SQL when accessing the [table buffer](abentable_buffer_glosry.md) or when [internal tables](abeninternal_table_glosry.md) are specified in the [`FROM`](../abap-programming-language/abap-database-access/abapselect_itab.md) clause. The ABAP SQL in-memory engine supports a large subset of ABAP SQL but there are also some restrictions.
