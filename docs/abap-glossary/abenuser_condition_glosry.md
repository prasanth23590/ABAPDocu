# user condition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Part of an [access condition](abenaccess_condition_glosry.md) in a [CDS role](abencds_role_glosry.md) that compares an element of a [CDS entity](abencds_entity_glosry.md) with the current [user name](abenuser_name_glosry.md).
