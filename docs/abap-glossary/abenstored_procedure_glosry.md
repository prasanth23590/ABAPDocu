# stored procedure

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Database procedure](abendatabase_procedure_glosry.md). Procedural [database object](abendb_object_glosry.md) that can be implemented and called depending on the platform. A stored procedure generally combines sequences of multiple [SQL](abensql_glosry.md) statements and contains additional instructions for controlling the sequence. [ABAP-managed](abenabap_managed_db_object_glosry.md) stored procedures are [AMDP procedures](abenamdp_procedure_glosry.md) and [AMDP functions](abenamdp_function_glosry.md).
