# CDS SQL query

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [database query](abendb_query_glosry.md) that is implemented in the [CDS DDL](abencds_ddl_glosry.md) as a part of the definition of a [view entity](abencds_v2_view_glosry.md) using the SQL language element [`SELECT`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_select_statement_v2.md). The clauses and additions of `SELECT` define the result set returned by the database. &#x200E;
