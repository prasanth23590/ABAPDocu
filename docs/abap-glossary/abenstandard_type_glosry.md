# standard type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Complete data type](abencomplete_data_type_glosry.md) used for [generically typed](abengeneric_typing_glosry.md) [field symbols](abenfield_symbol_glosry.md) or [formal parameters](abenformal_parameter_glosry.md) if their data type is required for compilation, or if a `LIKE` reference is made to a generic field symbol, to which no memory area is assigned. Different standard types are defined for replacement parameters of optional formal parameters, generically typed field symbols, and for [inline declarations](abeninline_declaration_glosry.md), where they depend on the current statement.
