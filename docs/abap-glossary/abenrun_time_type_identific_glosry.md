# Runtime Type Identification

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

RTTI for short. Determination of [data types](abendata_type_glosry.md) during program runtime. Implemented using description methods in [type description classes](abentype_class_glosry.md). Constitutes [RTTS](abenrun_time_type_services_glosry.md) together with [RTTC](abenrun_time_type_creation_glosry.md).
