# DDIC domain

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Repository object](abenrepository_object_glosry.md) in the [ABAP Dictionary](abenabap_dictionary_glosry.md) that describes the properties of [DDIC data elements](abendata_element_glosry.md), such as [data type](abendata_type_glosry.md) or value range. A domain can be linked with any number of data elements.
