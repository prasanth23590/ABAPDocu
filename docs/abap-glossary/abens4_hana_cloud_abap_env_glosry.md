# SAP S/4HANA Cloud ABAP environment

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Restricted [ABAP development environment](abenabap_dev_envir_glosry.md) (aka [embedded Steampunk](abenembedded_steampunk_glosry.md)) for customer developments in [SAP S/4HANA Cloud Public Edition](abensap_s4hana_cpub_glosry.md), [SAP S/4HANA Cloud Private Edition](abensap_s4hana_cpriv_glosry.md) and [SAP S/4HANA](abensap_s4hana_glosry.md). The developments are governed by the restricted rules of [ABAP Cloud](abenabap_cloud_glosry.md). See also [SAP BTP ABAP environment](abensap_btp_abap_env_glosry.md) (aka [Steampunk](abensteampunk_glosry.md)).
