# weak reference

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Reference to an [object](abenobject_glosry.md) of a [class](abenclass_glosry.md) that is ignored when the [Garbage Collector](abengarbage_collector_glosry.md) is executed, unlike [object references](abenobject_reference_glosry.md) in [reference variables](abenreference_variable_glosry.md). An object that is only pointed to by weak references is deleted by the Garbage Collector.
