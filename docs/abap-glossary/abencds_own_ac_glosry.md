# RAP full authorization context

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP authorization context](abencds_auth_con_glosry.md) that serves as a container for [authorization objects](abenauthorization_object_glosry.md). Specified using the syntax [`define own authorization context`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_def_own_auth_context.md). A full authorization context documents the authorization objects used in the implementation of the RAP BO in question.
