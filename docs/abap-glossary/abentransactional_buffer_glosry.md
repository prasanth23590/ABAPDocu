# RAP transactional buffer

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Storage where the data that is used during one [RAP transaction](abenrap_luw_glosry.md) is kept. It includes the [RAP BO instance](abenrap_bo_instance_glosry.md) that are being worked on.

A distinction is drawn between the following kinds of transactional buffer:

- [managed transactional buffer](abenmanaged_trans_buff_glosry.md) for [managed RAP BOs](abenmanaged_rap_bo_glosry.md).

- [unmanaged transactional buffer](abenunmanaged_trans_buff_glosry.md) for [unmanaged RAP BOs](abenunmanaged_rap_bo_glosry.md).
