# CDS annotation syntax

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Syntax for specifying a [CDS annotation](abencds_annotation_glosry.md) in [CDS source code](abencds_source_code_glosry.md). The CDS annotation syntax is fixed and the [CDS annotation definition](abencds_anno_definition_glosry.md) specifies further rules for the use of the respective annotation.
