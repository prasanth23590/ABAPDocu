# control structure

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Means of structuring a [processing block](abenprocessing_block_glosry.md) in [statement blocks](abenstatement_block_glosry.md). Possible control structures are [sequence](abensequence_glosry.md), [branch](abenbranch_glosry.md), and [loop](abenloop_glosry.md) as well as special control structures for exception handling. Control structures can be nested, so that statement blocks can contain other control structures.
