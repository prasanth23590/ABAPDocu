# time stamp

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md) [General](abenabap_glossary.md)

## Definition

Combined [date](abendate_glosry.md)/[time](abentime_glosry.md) specification for determining a point in time. Time stamps of the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) are [POSIX time stamps](abenposix_timestamp_glosry.md) independent of time zone. They are represented in a [time stamp field](abentimestamp_field_glosry.md) with the [time stamp type](abentimestamp_field_glosry.md) [`utclong`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_date_time.md) or as [time stamps in packed numbers](../abap-programming-language/abap-processing-internal-data/abentime_stamps_packed.md) whose data type is defined using the [DDIC data elements](abendata_element_glosry.md) `TIMESTAMP` or `TIMESTAMPL` from the [ABAP Dictionary](abenabap_dictionary_glosry.md).
