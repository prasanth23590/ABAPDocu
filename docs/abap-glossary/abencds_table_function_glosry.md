# CDS table function

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS persistent entity](abencds_sql_entity_glosry.md) defined using [`DEFINE TABLE FUNCTION`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_f1_define_table_function.md) in a [CDS data definition](abencds_data_definition_glosry.md). Each CDS table function is linked with an [AMDP table function](abenamdp_table_function_glosry.md) in which it is implemented using [SQLScript](abensql_script_glosry.md). A CDS table function returns a tabular result set.
