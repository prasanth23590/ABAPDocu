# unit key

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Component of a [DDIC structure](abenddic_structure_glosry.md), or [DDIC database table](abenddic_db_table_glosry.md) of type `UNIT` defined in the [ABAP Dictionary](abenabap_dictionary_glosry.md). A unit key can be linked to a [quantity field](abenquantity_glosry.md) of a structure, database table, or view. The unit key can contain a [unit ID](abenunit_id_glosry.md), and defines the unit for the quantity field.
