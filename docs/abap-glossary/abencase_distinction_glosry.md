# case distinction

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[Control structure](abencontrol_structure_glosry.md) with the [control statement](abencontrol_statement_glosry.md) [`CASE`](../abap-programming-language/abap-program-flow-logic/abapcase.md) or [`CASE TYPE OF`](../abap-programming-language/abap-program-flow-logic/abapcase_type.md), [condition expression](abenconditional_expression_glosry.md) with the [conditional operator](abenconditional_operator_glosry.md) [`SWITCH`](../abap-programming-language/abap-program-flow-logic/abenconditional_expression_switch.md), [`CASE`](../abap-programming-language/abap-database-access/abensql_case.md) expression in [ABAP SQL](abenabap_sql_glosry.md), or [`CASE`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_case_expression_v2.md) expression in [CDS DDL](abencds_ddl_glosry.md). In a case distinction, the value of an [operand](abenoperand_glosry.md) determines which of multiple source code sections is executed. In the ABAP language, there are only [simple case distinctions](abensimple_case_glosry.md). In ABAP CDS and ABAP SQL, there are [simple case distinctions](abensimple_case_glosry.md) and [complex case distinctions](abencomplex_case_glosry.md).
