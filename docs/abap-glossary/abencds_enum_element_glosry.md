# CDS enumerated element

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS element](abencds_element_glosry.md) that is typed with a [CDS enumerated type](abencds_enum_type_glosry.md). A CDS enumerated element can only contain one of the [enumerated values](abenenumerated_value_glosry.md) of the respective enumerated type.
