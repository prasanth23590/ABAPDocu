# time-stamp-like expression position

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Read position](abenread_position_glosry.md) in which a [time stamp field](abentimestamp_field_glosry.md), as well as an [expression](abencharlike_expression_glosry.md) can be specified whose result has a [time stamp type](abentimestamp_type_glosry.md).
