# instance component

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Superordinate term for [instance attributes](abeninstance_attribute_glosry.md), [instance events](abeninstance_event_glosry.md), and [instance methods](abeninstance_method_glosry.md). The instance components of a [class](abenclass_glosry.md) can only be addressed in [instances](abeninstance_glosry.md) of the class.
