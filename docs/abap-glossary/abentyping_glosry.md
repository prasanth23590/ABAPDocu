# typing

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Generic](abengeneric_typing_glosry.md) or [complete](abencomplete_typing_glosry.md) definition of a [data type](abendata_type_glosry.md) for [formal parameters](abenformal_parameter_glosry.md) or [field symbols](abenfield_symbol_glosry.md). Specifies in which operand positions a formal parameter or field symbol can be used and which type properties are used. When parameters are passed, it is checked whether the data type of the assigned [actual parameter](abenactual_parameter_glosry.md), or memory area is [compatible](abencompatible_glosry.md) with the typing.
