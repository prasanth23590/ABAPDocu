# binary floating point number

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Numeric data object](abennumeric_data_object_glosry.md) of ABAP or elementary object of the database with a [binary floating point number type](abenbinfloat_type_glosry.md). Due to the internal representation as binary fractions, not every decimal number within the type's value range can be represented exactly by a binary floating point number.
