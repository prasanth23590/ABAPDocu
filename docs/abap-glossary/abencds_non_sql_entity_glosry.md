# CDS transient entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS entity](abencds_entity_glosry.md) for which no [ABAP-managed database object](abenabap_managed_db_object_glosry.md) is created and which cannot be used in read access in [ABAP SQL](abenabap_sql_glosry.md) and ABAP CDS.

Currently, the following transient entities are available:

- [CDS custom entities](abencds_custom_entity_glosry.md)

- [CDS abstract entities](abencds_abstract_entity_glosry.md)

- [CDS analytical queries](abencds_analytic_query_glosry.md)

See also: [CDS persistent entity](abencds_sql_entity_glosry.md)
