# SQL service

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

A standardized protocol of the [Application Server ABAP](abenas_abap_glosry.md) providing SQL-level access to [ABAP-managed database objects](abenabap_managed_db_object_glosry.md), such as [CDS view entities](abencds_v2_view_glosry.md), for consumers outside the system. The SQL service can be accessed with the ODBC driver for ABAP using the [ODBC](abenodbc_glosry.md) protocol. It can be specified as a type of [service binding](abenservice_binding_glosry.md). With the SQL service, remote access to the database of AS ABAP is performed using the [ABAP SQL engine](abenabap_sql_engine_glosry.md) and (almost) all important ABAP SQL features are supported. The SQL service is also integrated with [SAP HANA Smart Data Access](abensap_hana_sda_glosry.md), which enables the SAP HANA database to query data from remote data stores.
