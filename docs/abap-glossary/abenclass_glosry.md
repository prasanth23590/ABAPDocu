# class

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Template for [objects](abenobject_glosry.md) in [ABAP Objects](abenabap_objects_glosry.md). Defined with [`CLASS - ENDCLASS`](../abap-programming-language/abap-declarations/abapclass.md), either as a [global class](abenglobal_class_glosry.md) in a [class pool](abenclass_pool_glosry.md) or as a [local class](abenlocal_class_glosry.md) in almost any [ABAP program](abenabap_program_glosry.md). The definition of a class comprises a [declaration part](abendeclaration_part_glosry.md) for the declaration of the [class components](abenclass_component_glosry.md) and an [implementation part](abenimplementation_part_glosry.md) for the implementation of the [methods](abenmethod_glosry.md).
