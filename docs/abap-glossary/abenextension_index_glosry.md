# extension index

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Index](abenindex_glosry.md) of a [DDIC database table](abenddic_db_table_glosry.md) that is created as a separate [repository object](abenrepository_object_glosry.md). An extension index can be created to extend an existing database table without modifying the original object. During an upgrade, the extension index is automatically applied without any modification adjustment.
