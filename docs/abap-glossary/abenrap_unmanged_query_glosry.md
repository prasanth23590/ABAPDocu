# RAP unmanaged query

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An implementation type of the RAP query for which parts of the [RAP query engine](abenrap_query_engine_glosry.md) must be implemented in an [ABAP class](abenclass_glosry.md) that is referenced in a [CDS custom entity](abencds_custom_entity_glosry.md).
