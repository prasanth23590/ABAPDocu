# self-reference

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Object reference variable](abenobject_refer_variable_glosry.md) called [`me`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenme.md) that is predefined as a local [constant](abenconstant_glosry.md) in each [instance method](abeninstance_method_glosry.md). It always references the current [instance](abeninstance_glosry.md) in which the method is being executed. The static type of `me` is the [class](abenclass_glosry.md) in which the instance method is implemented.
