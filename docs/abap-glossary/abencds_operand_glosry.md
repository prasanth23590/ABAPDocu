# CDS operand

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A syntax element of a [CDS data definition](abencds_data_definition_glosry.md) at an operand position. Defined directly or as a [formal parameter](abenformal_parameter_glosry.md), [built-in function](abenbuiltin_function_glosry.md), or [expression](abenexpression_glosry.md). Operands can be combined with [operators](abenoperator_glosry.md) to form [expressions](abenexpression_glosry.md) that in turn can be listed at certain [operand positions](abenoperand_position_glosry.md).
