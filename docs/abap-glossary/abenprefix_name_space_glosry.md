# prefix namespace

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Namespace](abennamespace_glosry.md) for [repository objects](abenrepository_object_glosry.md) of SAP departments, SAP partners, and SAP customers that can be requested from SAP. The names of the repository objects of a prefix namespace are introduced with a [namespace prefix](abenname_space_prefix_glosry.md).
