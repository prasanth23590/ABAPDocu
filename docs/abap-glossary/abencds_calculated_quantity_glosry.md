# CDS calculated quantity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A component of a [CDS view entity](abencds_v2_view_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md). A calculated quantity is always the result of a calculation using [CDS amount](abencds_amount_field_glosry.md) and / or [CDS quantity fields](abencds_quantity_glosry.md). The DDIC data type is `DECFLOAT34`. An ABAP CDS calculated quantity must be linked with a [CDS calculated unit](abencds_calculated_unit_glosry.md) of the same CDS view entity that specifies a user-defined unit for the calculated quantity.
