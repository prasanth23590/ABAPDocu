# CDS-based search connector

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [search connector](abensearch_connector_glosry.md) that enables communication between an [ABAP system](abenabap_system_glosry.md) and the [SAP HANA database](abenhana_database_glosry.md) in the context of [CDS-based enterprise search](abencds_enterprisesearch_glosry.md).
