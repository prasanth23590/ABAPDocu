# parameter interface

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Interface](abenintf_gen_glosry.md) of a [procedure](abenprocedure_glosry.md). Consists of [formal parameters](abenformal_parameter_glosry.md) and specifies the possible [exceptions](abenexception_glosry.md) of the procedure.
