# table expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A table expression reads a line from an [internal table](abeninternal_table_glosry.md) and returns it as a result. [Mesh path expressions](abenmesh_path_expression_glosry.md) are a special form of table expressions that can be used in the same way as table expressions.
