# class component selector

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Characters `=>`. Each visible [static component](abenstatic_component_glosry.md) `comp` of a [class](abenclass_glosry.md) `class` can be addressed with `class=>comp`.
