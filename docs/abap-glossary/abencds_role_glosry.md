# CDS role

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS object](abencds_object_glosry.md) defined using the statement [`DEFINE ROLE`](../abap-core-data-services-abap-cds/abap-cds-access-control/abencds_f1_define_role.md) in a [DCL source code](abendcl_source_code_glosry.md) in the [CDS DCL](abencds_dcl_glosry.md) of [ABAP CDS](abenabap_cds_glosry.md). This object applies [CDS access control](abencds_access_control_glosry.md) based on [access conditions](abenaccess_condition_glosry.md) when [CDS persistent entities](abencds_sql_entity_glosry.md) are accessed using [ABAP SQL](abenabap_sql_glosry.md). The access conditions of a CDS role evaluate the classic [authorizations](abenauthorization_glosry.md) of the current user.
