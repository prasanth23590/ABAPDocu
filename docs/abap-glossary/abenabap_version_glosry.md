# ABAP language version

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Program property](abenprogram_property_glosry.md) that determines the language scope and the syntax rules of an [ABAP program](abenabap_program_glosry.md) and other [repository objects](abenrepository_object_glosry.md). See also [unrestricted](abenunrestricted_version_glosry.md) and [restricted ABAP language versions](abenrestricted_version_glosry.md).
