# ABAP release

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Release of [ABAP](abenabap_glosry.md) ([ABAP technology](abenabap_techno_glosry.md) including the [ABAP language](abenabala_glosry.md) and its other programming languages). The counting of the releases is done by release numbers such as 7.95, 7.96, 9.12, ... These release numbers are based on the technical release names of the associated software component `SAP_BASIS`. ABAP is not released standalone but is shipped together with SAP products such as [SAP BTP ABAP environment](abensap_btp_abap_env_glosry.md), [SAP S/4HANA Cloud Public Edition](abensap_s4hana_cpub_glosry.md) and [SAP S/4HANA](abensap_s4hana_glosry.md), [SAP S/4HANA Cloud Private Edition](abensap_s4hana_cpriv_glosry.md). These products have other release numbers that can be mapped to the ABAP releases. The releases of the underlying [ABAP kernel](abenkernel_glosry.md) are also counted differently and can also be mapped to the ABAP releases.
