# functional method

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Method](abenmethod_glosry.md) with exactly one [return value](abenreturn_value_glosry.md) declared using [`RETURNING`](../abap-programming-language/abap-declarations/abapmethods_functional.md) and any number of other [formal parameters](abenformal_parameter_glosry.md). Can be used in [functional method calls](abenfunctional_method_call_glosry.md).
