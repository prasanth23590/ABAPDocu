# CDS root entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The top [CDS entity](abencds_entity_glosry.md) of a [CDS composition tree](abencds_composition_tree_glosry.md). The addition `ROOT` must be specified in the definition of a root entity with [CDS DDL](abencds_ddl_glosry.md). A root entity can be part of exactly one [RAP BO](abenrap_bo_glosry.md). A CDS root entity is typically a [CDS parent entity](abenparent_entity_glosry.md) and it is typically used as a [RAP BO root entity](abenrap_bo_root_entity_glosry.md) in the context of the [ABAP RESTful Application Programming Model](abenarap_glosry.md).
