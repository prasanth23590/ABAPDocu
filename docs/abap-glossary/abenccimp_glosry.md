# CCIMP include

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An [include program](abeninclude_program_glosry.md) of a [class pool](abenclass_pool_glosry.md) that is included behind the [declaration part](abendeclaration_part_glosry.md) and in front of the [implementation part](abenimplementation_part_glosry.md) of the [global class](abenglobal_class_glosry.md). It can be edited in [ADT](abenadt_glosry.md) by navigating to *Local Types*. The internal name of the include program ends with `CCIMP`. See also [CCDEF include](abenccdef_glosry.md).
