# assignment

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Transfer of the value of a [data object](abendata_object_glosry.md), a [return value](abenreturn_value_glosry.md) or result of a [functional method](abenfunctional_method_glosry.md), a [built-in function](abenbuiltin_function_glosry.md), a [constructor expression](abenconstructor_expression_glosry.md), a [table expression](abentable_expression_glosry.md), or the result of a [calculation expression](abencalculation_expression_glosry.md) to a target data object. If the [data types](abendata_type_glosry.md) are [compatible](abencompatible_glosry.md), the content is copied unchanged. If they are incompatible and a suitable [conversion rule](abenconversion_rule_glosry.md) exists, the content is converted.
