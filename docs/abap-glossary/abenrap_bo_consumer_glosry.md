# RAP BO consumer

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A piece of software that consumes the implementation of a [RAP BO](abenrap_bo_glosry.md). A RAP BO consumer is either the [RAP transactional engine](abenrap_transac_engine_glosry.md) that handles requests from outside the [AS ABAP](abenas_abap_glosry.md) or an [ABAP program](abenabap_program_glosry.md) using [ABAP EML](abenabap_eml_glosry.md).
