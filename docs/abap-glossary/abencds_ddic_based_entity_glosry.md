# CDS DDIC-based entity (obsolete)

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS persistent entity](abencds_sql_entity_glosry.md) for which a [CDS-managed DDIC view (obsolete)](abencds_mngdddic_view_glosry.md) is created in the ABAP Dictionary alongside the CDS entity upon activation.

There is only one kind of DDIC-based entity available, namely [CDS DDIC-based views](abencds_v1_view_glosry.md).
