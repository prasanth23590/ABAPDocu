# value semantics

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Value semantics means that the referenced data object or the dereferenced [reference](abenreference_glosry.md) is used when accessing a [deep](abendeep_glosry.md) [data object](abendata_object_glosry.md). In ABAP, value semantics apply when accessing [dynamic data objects](abendynamic_data_object_glosry.md) and [field symbols](abenfield_symbol_glosry.md). See also [reference semantics](abenreference_semantics_glosry.md).
