# ABAP Dictionary

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Persistent storage for [data types](abendata_type_glosry.md) that are visible in all [repository objects](abenrepository_object_glosry.md). In particular, [DDIC database tables](abenddic_db_table_glosry.md) on the [standard database](abenstandard_db_glosry.md) that can be used in [ABAP programs](abenabap_program_glosry.md) and in [ABAP CDS](abenabap_cds_glosry.md) are defined in the ABAP Dictionary. [Dictionary objects](abendictionary_object_glosry.md) are maintained using the [ABAP development tools for Eclipse (ADT)](abenadt_glosry.md).
