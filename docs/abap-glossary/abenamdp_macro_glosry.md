# AMDP macro

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [AMDP](../abap-programming-language/abap-database-access/abenamdp_glossary.md)

## Definition

Syntax specified in the implementation of an [AMDP method](abenamdp_method_glosry.md) in [SQLScript](abensql_script_glosry.md), which is replaced by the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) when the [database procedure](abendatabase_procedure_glosry.md) is generated on the [database](abendatabase_glosry.md) in compliance with the assigned rules.
