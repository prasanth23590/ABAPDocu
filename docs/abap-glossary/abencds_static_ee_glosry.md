# static external entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS external entity](abencds_external_entity_glosry.md) that uses the addition `PROVIDED BY` to specify a [logical external schema](abencds_logical_schema_glosry.md) in its [data definition](abencds_data_definition_glosry.md). Static external entities can be used as data sources in [ABAP SQL](abenabap_sql_glosry.md) `SELECT` statements, in other [CDS entities](abencds_entity_glosry.md), and in [ABAP Managed Database Procedures](abenabap_managed_db_proc_glosry.md) (AMDP).
