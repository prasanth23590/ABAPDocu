# SAP namespace

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Namespace](abennamespace_glosry.md) for [repository objects](abenrepository_object_glosry.md) created in SAP's own development systems. There are no real restrictions for the names. To avoid namespace conflicts [prefix namespace](abenprefix_name_space_glosry.md) can be used. Internally at SAP, all names are checked using a cross-system table to ensure their uniqueness.
