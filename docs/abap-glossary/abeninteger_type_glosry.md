# integer type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Numeric data type](abennumeric_data_type_glosry.md) for storing [integer numbers](abeninteger_number_glosry.md) of different value ranges. The associated [built-in ABAP types](abenbuiltin_abap_type_glosry.md) are ([`b`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_numeric.md), [`s`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_numeric.md)), [`i`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_numeric.md), and [`int8`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_numeric.md). The [built-in DDIC types](abenbuiltin_ddic_type_glosry.md) are [`INT1`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md), [`INT2`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md), [`INT4`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md) and [`INT8`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md). The internal representation takes place in the integer representation of the current platform. A [data object](abendata_object_glosry.md) of an integer type is an [integer](abeninteger_glosry.md).
