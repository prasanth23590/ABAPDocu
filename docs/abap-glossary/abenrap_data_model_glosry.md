# RAP data model

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A part of a [RAP BO](abenrap_bo_glosry.md) that defines the data that is used in the RAP BO. It consists of [RAP BO entities](abenrap_bo_entity_glosry.md) that are related by a [CDS composition tree](abencds_composition_tree_glosry.md).
