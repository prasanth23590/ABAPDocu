# RAP event handler method

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A method that is declared and implemented in the [CCIMP include](abenccimp_glosry.md) of a [RAP event handler class](abenrap_event_handler_class_glosry.md). It is used to process logic that is implemented in this method when [RAP business events](abenrap_entity_event_glosry.md) are raised and consumed locally in the system in which they are raised.

RAP event handler methods are called asynchronously.
