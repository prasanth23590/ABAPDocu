# hierarchy node navigator

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

A [hierarchy navigator](abenhierarchy_navigator_glosry.md) that accesses specific [hierarchy nodes](abenhierarchy_node_glosry.md) in an ABAP [ABAP SQL hierarchy](abensql_hierarchy_glosry.md), such as [descendant nodes](abendescendant_node_glosry.md), [ancestor nodes](abenancestor_node_glosry.md), or [sibling nodes](abensibling_node_glosry.md).
