# decimal floating point number type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Numeric data type](abennumeric_data_type_glosry.md) for the decimal storage of numbers with mantissa and exponents. The associated [built-in ABAP types](abenbuiltin_abap_type_glosry.md) are [`decfloat16`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_numeric.md) and [`decfloat34`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_numeric.md). The [built-in DDIC types](abenbuiltin_ddic_type_glosry.md) are [`DECFLOAT16`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md), [`DF16_DEC`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md), [`DF16_RAW`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md), [`DECFLOAT34`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md), [`DF34_DEC`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md) and [`DF34_RAW`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md). The internal representation follows the standard IEEE-754-2008, where [decimal numbers](abendecimal_number_glosry.md) with 16 or 34 [places](abenplace_glosry.md) are accurately represented in the mantissa. A decimal floating point number has an additional [scaling](abenscale_glosry.md) property. A [data object](abendata_object_glosry.md) of a decimal floating point number type is a [decimal floating point number](abendecfloat_glosry.md).
