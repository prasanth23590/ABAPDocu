# ABAP programming model for SAP Fiori

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Obsolete programming model for SAP HANA-optimized Fiori apps based on the [AS ABAP](abenas_abap_glosry.md). Its successor is the [ABAP RESTful Application Programming Model (RAP)](abenarap_glosry.md).
