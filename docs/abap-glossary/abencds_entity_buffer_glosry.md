# CDS entity buffer

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An [ABAP tuning object](abenabap_tuning_object_glosry.md) that defines [table buffering](abentable_buffering_glosry.md) settings for [CDS entities](abencds_entity_glosry.md). The following types of CDS entity buffers are available:

- [CDS view entity buffer](abencds_view_entity_b_glosry.md)

- [CDS table entity buffer](abencds_table_entity_b_glosry.md)

- [CDS propagated buffer](abencds_prop_buffer_glosry.md)

Sometimes, *CDS entity buffer* is also used as a synonym for the area of the [table buffer](abentable_buffer_glosry.md) in the [shared memory](abenshared_memory_glosry.md) where data from CDS entities is buffered.
