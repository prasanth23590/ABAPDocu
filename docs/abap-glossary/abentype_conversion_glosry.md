# type conversion

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Converts the content of a [data object](abendata_object_glosry.md) according to the associated [conversion rules](abenconversion_rule_glosry.md). Type conversions occur implicitly in [assignments](abenassignment_glosry.md) between data objects with different [data types](abendata_type_glosry.md) or can be performed explicitly using the [conversion operator](abenconversion_operator_glosry.md) [`CONV`](../abap-programming-language/abap-creating-objects-and-values/abenconstructor_expression_value.md).
