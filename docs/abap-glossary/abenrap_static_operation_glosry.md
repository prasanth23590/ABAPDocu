# static RAP BO operation

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO operation](abenrap_bo_operation_glosry.md) that is not bound to any [RAP BO entity instance](abenrap_bo_entity_inst_glosry.md) but relates to the complete [RAP BO entity](abenrap_bo_entity_glosry.md). Defined using the optional addition [`static`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_static.md).
