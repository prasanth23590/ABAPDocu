# ABAP Doc comment

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Special [comment](abencomment_glosry.md) consisting of one or more [comment lines](abencomment_line_glosry.md), each of which is initiated by `"!`. ABAP Doc comments can precede [declarations](abendeclaration_glosry.md) and are used by [ABAP Doc](abenabap_doc_glosry.md) for their documentation.
