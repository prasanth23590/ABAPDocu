# generic ABAP type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Built-in](abenbuiltin_data_type_glosry.md) [generic data type](abengeneric_data_type_glosry.md). The generic ABAP types are: `any`, `any table`, `c`, `clike`, `csequence`, `data`, `decfloat`, `hashed table`, `index table`, `n`, `numeric`, `p`, `simple`, `sorted table`, `standard table`, `table`, `x`, `xsequence`, and `any structure [ containing ... ]`.
