# primary table index

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Table index](abentable_index_glosry.md) of [index tables](abenindex_table_glosry.md) ([standard tables](abenstandard_table_glosry.md) and [sorted tables](abensorted_table_glosry.md)). Every index table has a primary table index, administrated by the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md), which contains a unique line number for each table line. The primary table index of an index table is updated each time a line is added or deleted from an internal table.
