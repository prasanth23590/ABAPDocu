# RAP authorization context

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A container for [authorization objects](abenauthorization_object_glosry.md) that lists one or more authorization objects. There are different types of authorization contexts:

- [Full authorization context](abencds_own_ac_glosry.md)

- [Authorization context for disable](abencds_auth_context_glosry.md)

Optional component of a [RAP behavior definition](abencds_behavior_definition_glosry.md).
