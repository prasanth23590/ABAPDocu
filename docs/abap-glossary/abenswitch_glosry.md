# switch

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Repository object](abenrepository_object_glosry.md) that in the context of a [Switch Framework](abenswitch_framework_glosry.md) is determines whether another [repository object](abenrepository_object_glosry.md) or a component of a repository object is visible and used in a system. This also applies in particular to [enhancements](abenenhancement_glosry.md) of the ABAP Enhancement Framework. In most cases, extensions can be switched on whenever they are defined in a [package](abenpackage_glosry.md) to which a switch is assigned. A switch can have the status *on*, *off*, or *stand-by*. See also [conflict switch](abenconflict_switch_glosry.md).
