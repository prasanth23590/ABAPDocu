# binary XML

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

SAP-specific format for the binary storage of [XML](abenxml_glosry.md) data. In Binary XML, redundant information is suppressed, and [UTF-8](abenutf8_glosry.md) encoding is used, which leads to performance benefits when storing and transporting data. In [AS ABAP](abenas_abap_glosry.md), Binary XML occurs as one of the supported [formats](../abap-programming-language/abap-data-interchange-formats/abenabap_sxml_lib_formats.md) in the [sXML Library](../abap-programming-language/abap-data-interchange-formats/abenabap_sxml_lib.md).
