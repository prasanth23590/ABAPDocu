# simple case distinction

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [case distinction](abencase_distinction_glosry.md) that matches an operand to another operand specified in one or more `WHEN` clauses. Available in [ABAP CDS](abenabap_cds_glosry.md) and [ABAP SQL](abenabap_sql_glosry.md).
