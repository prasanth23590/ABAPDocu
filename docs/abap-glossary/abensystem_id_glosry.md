# system ID

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

SID for short. Identification or name of an [AS ABAP](abenas_abap_glosry.md) and therefore also the ID or name of the [ABAP system](abenabap_system_glosry.md). A system ID consists of three characters and is the content of the [system field](abensystem_field_glosry.md) [`sy-sysid`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abensystem_fields.md).
