# RAP key function

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A predefined [RAP function](abenrap_function_glosry.md) that is defined for a [BDEF alternative key](abenrap_alternative_key_glosry.md). It receives the values of an alternative key as input and returns the [entity instances](abenrap_bo_entity_inst_glosry.md) with matching values. Key functions are used, for example, to enable [read-by-association](abenrap_rba_operation_glosry.md) operations in RAP BOs with [cross-BO associations](abencds_cross_bo_assoc_glosry.md) involving RAP reuse objects.
