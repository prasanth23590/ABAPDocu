# streaming data sink

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Repository in which a writer [data stream](abendata_stream_glosry.md) stores its data in [streaming](abenstreaming_glosry.md). A streaming data sink can be an external resource such as a [LOB](abenlob_glosry.md) column of a [DDIC database table](abenddic_db_table_glosry.md) or an internal resource such as a [string](abenstring_glosry.md) or an [internal table](abeninternal_table_glosry.md). [Streaming](abenstreaming_glosry.md) is currently implemented for [DDIC database tables](abenddic_db_table_glosry.md), [strings](abenstring_glosry.md), and [internal tables](abeninternal_table_glosry.md).
