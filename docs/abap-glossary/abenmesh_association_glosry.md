# mesh association

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Association](abenassociation_glosry.md) of a [mesh](abenmesh_glosry.md). Property of a [mesh node](abenmesh_node_glosry.md) and therefore part of the [mesh type](abenmesh_type_glosry.md). Associates mesh nodes in [mesh paths](abenmesh_path_glosry.md).
