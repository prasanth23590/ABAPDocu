# Business Application Programming Interface

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

BAPI for short. A predefined interface to data and processes of an SAP application that is stored in the business object repository with the basic functions *Create Objects*, *Query Object Properties*, and *Change Object Properties*. BAPIs are implemented using remotely called [function modules](abenfunction_module_glosry.md) with the naming convention `BAPI_business_object_name_method_name` that are not allowed to lead a user dialog.
