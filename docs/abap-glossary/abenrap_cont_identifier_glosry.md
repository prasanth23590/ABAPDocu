# RAP content identifier

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP input identifier](abenrap_input_identifier_glosry.md) that uniquely identifies an operation on one [instance](abenrap_bo_entity_inst_glosry.md). The content identifier is reflected in the [derived type](abenrap_derived_type_glosry.md) component `%cid`. It identifies an instance during the consumption of [static operations](abenrap_static_operation_glosry.md) before the instance is identified by an [instance identifier](abenrap_inst_identifier_glosry.md).
