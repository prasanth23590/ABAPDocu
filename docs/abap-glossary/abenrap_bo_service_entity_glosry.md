# RAP BO service projection entity

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A component of a [RAP BO service projection](abenrap_bo_service_proj_glosry.md). It describes the [RAP data model](abenrap_data_model_glosry.md) that is included in the service projection. The RAP BO service projection entity is represented by a [CDS projection view](abencds_projection_view_glosry.md) with the provider contract [`TRANSACTIONAL_QUERY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_pv_provider_contract.md).
