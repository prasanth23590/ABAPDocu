# main annotation

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Also called root annotation. The [CDS annotation](abencds_annotation_glosry.md) defined after the statement `DEFINE ANNOTATION` in a [CDS annotation definition](abencds_annotation_glosry.md), or a name of an [annotation](abencds_annotation_glosry.md) specified on its own or in front of a period in the [annotation syntax](abencds_annotation_syntax_glosry.md). A main annotation can be structured using [subannotations](abensub_annotation_glosry.md).
