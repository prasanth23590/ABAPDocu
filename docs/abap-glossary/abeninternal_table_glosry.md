# internal table

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Dynamic data object](abendynamic_data_object_glosry.md) that consists of a sequence of lines of the same [data type](abendata_type_glosry.md). An internal table has a [table type](abentable_type_glosry.md) that specifies the [line type](abenrow_type_glosry.md), the [table category](abentable_category_glosry.md), and a [table key](abentable_key_glosry.md). The corresponding [generic data type](abengeneric_data_type_glosry.md) is [`any table`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
