# end of line comment

[General](abenabap_glossary.md)

## Definition

Section of a program line, following an [ABAP statement](abenabap_statement_glosry.md) or part of a statement, that is identified as a [comment](abencomment_glosry.md) by a double quotation mark (`"`).
