# Base64

[General](abenabap_glossary.md)

## Definition

Method for coding binary data into printable characters. Each byte is converted into a short character string whose characters are obtained from a record of 64 [code page](abencodepage_glosry.md)-independent [ASCII](abenascii_glosry.md) characters.
