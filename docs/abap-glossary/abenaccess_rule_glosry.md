# CDS access rule

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An access rule formulates an [access condition](abenaccess_condition_glosry.md) for a [CDS entity](abencds_entity_glosry.md) or guarantees open access in a [CDS role](abencds_role_glosry.md).
