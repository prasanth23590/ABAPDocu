# data reference

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Reference](abenreference_glosry.md) that points to a [data object](abendata_object_glosry.md) or a part of a data object. A non-initial data reference can be a [heap reference](abenheap_reference_glosry.md) or a [stack reference](abenstack_reference_glosry.md).
