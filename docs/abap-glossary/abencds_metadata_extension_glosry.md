# CDS metadata extension

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Short MDE. A [CDS object](abencds_object_glosry.md) of the [ABAP CDS](abenabap_cds_glosry.md) is defined in [`DDLX` source code](abenddlx_source_code_glosry.md) with [language elements](../abap-core-data-services-abap-cds/abap-cds-annotations/abencds_f1_ddlx_syntax.md) of the [CDS DDL](abencds_ddl_glosry.md). In a CDS metadata extension, [CDS annotations](abencds_annotation_glosry.md) are specified for a [CDS entity](abencds_entity_glosry.md) outside its [data definition](abencds_data_definition_glosry.md). A CDS metadata extension is always assigned to a layer such as industry, partner or customer.
