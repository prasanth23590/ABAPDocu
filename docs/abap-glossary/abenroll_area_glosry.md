# session memory

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Memory for the modifiable parts of a program in an [internal session](abeninternal_session_glosry.md). From the perspective of an ABAP program, the session memory can be divided into a [heap](abenheap_glosry.md) area and a [stack](abenstack_glosry.md) area. The non-modifiable parts of a program are stored in [PXA](abenpxa_glosry.md), which is referred to in the session memory.
