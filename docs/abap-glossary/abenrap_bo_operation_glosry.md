# RAP BO operation

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An operation of a [RAP BO](abenrap_bo_glosry.md). RAP BO operations are [CRUD](abencrud_glosry.md) operations, [non-standard operations](abenrap_nstandard_operation_glosry.md), the [lock operation](abenlock_operation_glosry.md), and [operations for associations](abenrap_operation_assoc_glosry.md). The implementation of a RAP BO operation implements the [RAP BO behavior](abenrap_bo_behavior_glosry.md) by accessing the [transactional buffer](abentransactional_buffer_glosry.md). A RAP BO can be accessed by using RAP operations. The parameters of a RAP BO method are mainly typed with special [BDEF derived types](abenrap_derived_type_glosry.md).
