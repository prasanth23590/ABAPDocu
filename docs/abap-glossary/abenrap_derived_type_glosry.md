# BDEF derived type

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The type of an internal table or structure that is derived by the [RAP framework](abenrap_framework_glosry.md) from the [RAP behavior definition](abencds_behavior_definition_glosry.md). Such internal tables and structures are used for the communication between [RAP BO consumers](abenrap_bo_consumer_glosry.md) and [RAP BO providers](abenrap_bo_provider_glosry.md). For that, the parameters of a method that implements [RAP BO behavior](abenrap_bo_behavior_glosry.md) are typed with BDEF derived types. In [ABAP programs](abenabap_program_glosry.md), BDEF derived types can be used to declare internal tables or structures to be passed to parameters of [RAP handler](abenabp_handler_class_glosry.md) and [saver classes](abenabp_saver_method_glosry.md).
