# SAP S/4HANA Cloud Public Edition

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

SAP S/4HANA Cloud for short. Cloud version of [SAP S/4HANA](abensap_s4hana_glosry.md). Partner and customer developments are governed by the [ABAP Cloud](abenabap_cloud_glosry.md) paradigm. For that the [SAP S/4HANA Cloud ABAP environment](abens4_hana_cloud_abap_env_glosry.md) (aka [embedded Steampunk](abenembedded_steampunk_glosry.md)) can be used. See also [SAP S/4HANA Cloud Private Edition](abensap_s4hana_cpriv_glosry.md).
