# SAP buffering

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Buffering of frequently used data in the [shared memory](abenshared_memory_glosry.md) buffers of an [AS ABAP](abenas_abap_glosry.md) [AS instance](abenas_instance_glosry.md). Includes [table buffering](abentable_buffering_glosry.md).
