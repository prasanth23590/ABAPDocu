# DOM

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Short for Document Object Model. Interface for accessing [XML](abenxml_glosry.md) documents that are based on an object-oriented tree-like representation of the documents in the memory, where each node is represented by an object. In ABAP, the [iXML Library](../abap-programming-language/abap-data-interchange-formats/abenabap_ixml_lib_cloud.md) can be used to process XML documents in DOM representation.
