# dictionary object

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

DDIC object for short. [Repository object](abenrepository_object_glosry.md) defined in [ABAP Dictionary](abenabap_dictionary_glosry.md). Examples of dictionary objects are global [data types](abendata_type_glosry.md), [DDIC database tables](abenddic_db_table_glosry.md).
