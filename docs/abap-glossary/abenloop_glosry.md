# loop

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Control structure](abencontrol_structure_glosry.md) that performs an [iteration](abeniteration_glosry.md). Consists of a [statement block](abenstatement_block_glosry.md) defined by the keywords [`DO` - `ENDDO`](../abap-programming-language/abap-program-flow-logic/abapdo.md), [`WHILE` - `ENDWHILE`](../abap-programming-language/abap-program-flow-logic/abapwhile.md), [`LOOP` - `ENDLOOP`](../abap-programming-language/abap-processing-internal-data/abaploop_at_itab.md), `PROVIDE` - `ENDPROVIDE`, [`SELECT` - `ENDSELECT`](../abap-programming-language/abap-database-access/abapselect.md) and that can be executed multiple times.
