# functional method call

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

An [expression](abenexpression_glosry.md) that calls a [functional method](abenfunctional_method_glosry.md) in a suitable [read position](abenread_position_glosry.md), where the [return value](abenreturn_value_glosry.md) of the method is used as an [ABAP operand](abenabap_operand_glosry.md).
