# RAP projection behavior definition

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

RAP projection BDEF or projection BDEF for short. A RAP projection behavior definition is a [RAP behavior definition](abencds_behavior_definition_glosry.md) of [implementation type](abencds_bdef_impl_type_glosry.md) `projection`. It is based on a [CDS transactional query](abencds_transactional_pv_glosry.md) and it projects a [base BDEF](abenrap_base_bdef_glosry.md).
