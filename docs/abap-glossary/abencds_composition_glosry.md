# CDS composition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A CDS composition consists of a [to-parent association](abento_parent_association_glosry.md) and a [to-child association](abento_child_association_glosry.md). A CDS composition defines an existential dependency between two entities, where the [child entity](abenchild_entity_glosry.md) cannot exist without the [parent entity](abenparent_entity_glosry.md).
