# search connector

[General](abenabap_glossary.md)

## Definition

A technology that enables communication between a data provider and an application by providing search access to a specific data source in a specific destination (logical system) or a list of destinations. Used, for example, in [SAP Enterprise Search](abensap_enterprisesearch_glosry.md).
