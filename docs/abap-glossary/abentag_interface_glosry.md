# tag interface

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Special predefined global interface. By implementing or including a tag interface, [classes](abenclass_glosry.md) or other [interfaces](abenoo_intf_glosry.md) are particularly tagged for the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md).
