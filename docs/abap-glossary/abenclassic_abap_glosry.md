# classic ABAP

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

ABAP development model for legacy solutions. Classic ABAP is based on the [ABAP technology](abenabap_techno_glosry.md) without restrictions regarding [ABAP language versions](abenabap_version_glosry.md), usage of tools or access to [repository objects](abenrepository_object_glosry.md). Classic ABAP is still supported by the [ABAP Platform](abenabap_platform_glosry.md) of [SAP S/4HANA](abensap_s4hana_glosry.md). See also [ABAP Cloud](abenabap_cloud_glosry.md).
