# ABAP Unit

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Test tool integrated into the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) that is used for checking the functions of code units in a program ([unit tests](abenunit_test_glosry.md)). Individual tests are implemented as [test methods](abentest_method_glosry.md) of local [test classes](abentest_class_glosry.md) in ABAP programs. The tests of one test class use the same [fixture](abenfixture_glosry.md). Global test classes can only be used in local test classes. The properties of a test can be specified in the definition of a local test class. Tests of multiple ABAP programs can be combined into [test tasks](abentest_task_glosry.md).
