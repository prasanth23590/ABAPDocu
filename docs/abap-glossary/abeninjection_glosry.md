# injection

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Test-friendly code located between the statements [`TEST-INJECTION`](../abap-programming-language/abap-program-maintenance/abaptest-injection.md) and [`END-TEST-INJECTION`](../abap-programming-language/abap-program-maintenance/abapend-test-injection.md) in a [method](abenmethod_glosry.md) of a [test class](abentest_class_glosry.md). Injections replace the associated [test seams](abentest_seam_glosry.md) when a [unit test](abenunit_test_glosry.md) is executed.
