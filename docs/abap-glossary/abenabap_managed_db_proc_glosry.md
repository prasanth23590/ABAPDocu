[ABAP Language](../abap-programming-language/abenabala_glossary.md) [AMDP](../abap-programming-language/abap-database-access/abenamdp_glossary.md)

AMDP for short. Class-based framework for managing and calling [stored procedures](abenstored_procedure_glosry.md) or [database procedures](abendatabase_procedure_glosry.md) as [AMDP procedures](abenamdp_procedure_glosry.md) in [AS ABAP](abenas_abap_glosry.md).
