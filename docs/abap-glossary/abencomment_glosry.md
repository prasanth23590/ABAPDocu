# comment

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Explanation inserted into the [ABAP source code](abenabap_source_code_glosry.md) that is ignored when the program is generated. Either a [comment line](abencomment_line_glosry.md) or an [line end comment](abenendline_comment_glosry.md). See also [pseudo comment](abenpseudo_comment_glosry.md).
