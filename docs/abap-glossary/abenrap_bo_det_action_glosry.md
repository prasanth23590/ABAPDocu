# RAP BO determine action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP action](abenrap_action_glosry.md) that executes [determinations](abenrap_determination_glosry.md) and [validations](abenrap_validation_glosry.md) on request. The implementation is provided by the [managed RAP BO provider](abenmanaged_rap_bo_prov_glosry.md).
