# client column

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

First column and [key field](abenkey_field_glosry.md) of [client-dependent](abenclient_dependent_glosry.md) [DDIC database tables](abenddic_db_table_glosry.md) or DDIC views of the type `CLNT` for storing the [client ID](abenclient_identifier_glosry.md). By default, [ABAP SQL](abenabap_sql_glosry.md) statements work with automatic [client handling](abenclient_handling_glosry.md). Database tables with a client column are generally [application tables](abenapplication_table_glosry.md) but can also contain administrative data. Database tables without a client column are called [system tables](abensystem_table_glosry.md).
