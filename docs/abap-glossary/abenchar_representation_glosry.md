# character representation

[General](abenabap_glossary.md)

## Definition

Binary encoding of characters. [Character sets](abencharacter_set_glosry.md) are assigned to a character representation using [code pages](abencodepage_glosry.md). The [Unicode character representations](abenunicode_char_represent_glosry.md) comprise all characters world-wide and can be encoded using one, two, or four bytes, depending on the [UTF](abenutf_glosry.md) representation.
