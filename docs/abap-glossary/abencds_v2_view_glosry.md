# CDS view entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [view](abenview_glosry.md) defined in [ABAP CDS](abencds_glosry.md) as a [CDS persistent entity](abencds_sql_entity_glosry.md) with the [CDS DDL](abencds_ddl_glosry.md) statement [`DEFINE VIEW ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_view_entity.md).
