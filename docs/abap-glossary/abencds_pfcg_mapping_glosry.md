# CDS PFCG mapping

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A PFCG mapping associates [CDS elements](abencds_element_glosry.md) with [authorization fields](abenauthorization_field_glosry.md). It is defined using [`DEFINE PFCG_MAPPING`](../abap-core-data-services-abap-cds/abap-cds-access-control/abencds_f1_define_pfcg_mapping.md) as part of a [CDS access policy](abencds_access_policy_glosry.md) and can be used in [PFCG conditions](abenpfcg_condition_glosry.md).
