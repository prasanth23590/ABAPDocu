# null indicator

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP SQL indicator](abenabap_sql_indicator_glosry.md) in a structured target area of an [ABAP SQL](abenabap_sql_glosry.md) [query](abenasql_query_glosry.md). The components or bits of a null indicator indicate which columns of the result set contain the [null value](abennull_value_glosry.md) and which do not.
