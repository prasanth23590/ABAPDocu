# string operator

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Combines two character-like [operands](abenabap_operand_glosry.md) in a [string expression](abenstring_expression_glosry.md). The only string operator currently possible is the [concatenation operator](abenconcatenation_operator_glosry.md) [`&&`](../abap-programming-language/abap-processing-internal-data/abenstring_operators.md), which concatenates the two operands into one string.
