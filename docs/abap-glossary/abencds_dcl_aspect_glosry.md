# CDS DCL aspect

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Object used for the definition of user-specific values and their use in the conditions of a [CDS role](abencds_role_glosry.md). Currently, the predefined aspects `pfcg_auth` and `user` are available, plus the user-defined aspects defined with [`DEFINE ASPECT`](../abap-core-data-services-abap-cds/abap-cds-access-control/abencds_f1_define_generic_aspect.md).
