# child node

[General](abenabap_glossary.md)

## Definition

A [hierarchy node](abenhierarchy_node_glosry.md) that inherits a [parent-child relationship](abenpcr_glosry.md) from a [parent node](abenparent_node_glosry.md). A child node can have multiple parent nodes. A child node is a [descendant node](abendescendant_node_glosry.md) of its parent nodes, their parent nodes, and so on. A hierarchy in which each child node has only one parent node is a [tree hierarchy](abentree_hierarchy_glosry.md), where a [root node](abenroot_node_glosry.md) is the origin of a tree.
