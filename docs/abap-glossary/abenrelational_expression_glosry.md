# relational expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [General](abenabap_glossary.md)

## Definition

[Expression](abenexpression_glosry.md) whose result is a [truth value](abentruth_value_glosry.md). Relational expressions include [comparison expressions](abencomparison_expression_glosry.md) and [predicates](abenpredicate_glosry.md). A single relational expression or multiple relational expressions combined using [Boolean operators](abenboolean_operator_glosry.md) form a [logical expression](abenlogical_expression_glosry.md) in ABAP.
