# CTE association

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

[Association](abenassociation_glosry.md) that is defined for a [common table expression](abencommon_table_expression_glosry.md) ([CTE](abencte_glosry.md)) and can be used in the [queries](abenasql_query_glosry.md) of its [`WITH`](../abap-programming-language/abap-database-access/abapwith.md) statement in [SQL path expressions](abensql_path_expression_glosry.md). A CTE association is defined in the definition of the common table expression using the addition [`WITH ASSOCIATIONS JOIN`](../abap-programming-language/abap-database-access/abapwith_associations_defining.md).
