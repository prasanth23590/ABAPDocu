# built-in data type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) that is provided in an [ABAP program](abenabap_program_glosry.md) by the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md). The built-in data types are [built-in ABAP types](abenbuiltin_abap_type_glosry.md), [generic ABAP types](abengeneric_abap_type_glosry.md), [built-in data types](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md) from [ABAP Dictionary](abenabap_dictionary_glosry.md), and [CDS built-in types](abencds_built_in_type_glosry.md). The names of the elementary and generic built-in ABAP types are a subset of the [reserved names](abenabap_word_glosry.md) (except for internal types `b` and `s`, which cannot be used directly in a program).
