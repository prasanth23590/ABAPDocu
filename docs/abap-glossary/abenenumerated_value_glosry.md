# enumerated value

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An enumerated value is an allowed value of an [enumerated variable](abenenumerated_variable_glosry.md) or a [CDS enumerated element](abencds_enum_element_glosry.md). The possible enumerated values are defined in the definition of the respective [enumerated type](abenenum_type_glosry.md) as the values of [enumerated constants](abenenumerated_constant_glosry.md) or of components of an [enumerated structure](abenenumerated_structure_glosry.md). The technical data type of an enumerated value is the [base type](abenbase_type_glosry.md) of the enumerated type.
