# object plug-in

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Object plug-ins are used to make modification-free functional [enhancements](abenenhancement_glosry.md) to ABAP programs. They are instances of [BAdI implementation classes](abenbadi_implement_class_glosry.md) and are administered by [BAdI objects](abenbadi_object_glosry.md). Object plug-ins are created when the [`GET BADI`](../abap-programming-language/abap-enhancements/abapget_badi.md) statement is executed and in accordance with the filter specifications.
