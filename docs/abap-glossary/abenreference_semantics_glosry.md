# reference semantics

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Reference semantics means that the [reference](abenreference_glosry.md) itself is used when accessing a [deep](abendeep_glosry.md) [data object](abendata_object_glosry.md). In ABAP, reference semantics apply to [assignments](abenassignment_glosry.md) and [comparisons](abencomparison_glosry.md) of [reference variables](abenreference_variable_glosry.md) but not when accessing [dynamic data objects](abendynamic_data_object_glosry.md) or [field symbols](abenfield_symbol_glosry.md). See also [value semantics](abenvalue_semantics_glosry.md).
