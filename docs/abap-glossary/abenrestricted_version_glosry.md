# restricted ABAP language version

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP language version](abenabap_version_glosry.md) that is restricted as follows:

- The ABAP language scope is limited.

- Access to other repository objects is restricted by [released APIs](abenreleased_api_glosry.md).

Restricted ABAP language versions are:

- [ABAP for Cloud Development](abenabap_for_cloud_dev_glosry.md)

- [ABAP for Key Users](abenabap_for_key_users_glosry.md)

[Standard ABAP](abenstandard_abap_glosry.md) is an [unrestricted ABAP language version](abenunrestricted_version_glosry.md).
