# enumerated type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Enum for short. An enumerated type is a [data type](abendata_type_glosry.md) that specifies a value set in addition to the actual type properties. Enumerated types can be defined in ABAP with [`TYPES BEGIN OF ENUM`](../abap-programming-language/abap-declarations/abaptypes_enum.md) or in [ABAP CDS](abenabap_cds_glosry.md) with [`DEFINE TYPE ENUM`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_enum_type.md).
