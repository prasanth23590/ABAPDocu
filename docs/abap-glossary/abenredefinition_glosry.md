# redefinition

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Term in [ABAP Objects](abenabap_objects_glosry.md). In a redefinition, an [instance method](abeninstance_method_glosry.md) in a [subclass](abensubclass_glosry.md) can be reimplemented without changing the [parameter interface](abenparameter_interface_glosry.md).
