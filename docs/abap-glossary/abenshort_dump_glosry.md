# short dump

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Error log that is displayed and stored after a [runtime error](abenruntime_error_glosry.md) or by a [runtime warning](abenruntime_warning_glosry.md). Stored short dumps can be called using the [ABAP dump analysis](abenabap_dump_analsyis_glosry.md) tool.
