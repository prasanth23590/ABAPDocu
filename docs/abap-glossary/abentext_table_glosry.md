# text table

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Special [foreign key table](abenforeign_key_table_glosry.md) whose [primary key](abenprimary_key_glosry.md) consists of the [foreign key](abenforeign_key_glosry.md), that is, the primary key of the [check table](abencheck_table_glosry.md) and a language key of the type [`LANG`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md). A text table contains language-dependent texts that are assigned to the lines of the check table.
