# window function

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

A function that is specified in front of the definition of a [window](abenwindow_glosry.md) in an [ABAP SQL](abenabap_sql_glosry.md) [window expression](abenwindow_expression_glosry.md) and that evaluates the rows of the window. A window function is either an [aggregate function](abenaggregate_function_glosry.md), a [ranking function](abenranking_function_glosry.md), or a [value function](abenvalue_function_glosry.md).
