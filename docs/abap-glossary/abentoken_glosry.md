# token

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Elementary component of an [ABAP statement](abenabap_statement_glosry.md), into which the compiler breaks down statements into tokens. Tokens are [ABAP words](abenabap_word_glosry.md), [ABAP operands](abenabap_operand_glosry.md), [operators](abenoperator_glosry.md), and certain special characters.
