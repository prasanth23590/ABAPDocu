# exception category

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Classification of [class-based exceptions](abenclass_based_exception_glosry.md) corresponding to the [superclasses](abensuperclass_glosry.md) of their [exception classes](abenexception_class_glosry.md). The exception category determines how the exceptions must be declared in [procedures](abenprocedure_glosry.md).
