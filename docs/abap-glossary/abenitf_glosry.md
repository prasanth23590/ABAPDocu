# Interchange Text Format

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

ITF for short. A SAP-specific markup language for system texts maintained in databases `DOKIL`, `DOKHL` and `DOKTL`. System texts written in ITF serve as API documentation for [repository objects](abenrepository_object_glosry.md) that can be maintained in the ABAP Workbench. ITF is also used by text management tools such as [SAPscript](https://help.sap.com/docs/ABAP_PLATFORM_NEW/872c7db8e8ad411c8c3364aceed6e2c1/4e16389db8294181e10000000a15822b) or the current [ABAP Keyword Documentation](../abenabap.md). Refer also to [KTD](abenktd_glosry.md) for system texts used for documenting repository objects that can be maintained in [ADT](abenadt_glosry.md) only.
