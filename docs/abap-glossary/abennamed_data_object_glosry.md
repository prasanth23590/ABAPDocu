# named data object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data object](abendata_object_glosry.md) that can be identified via a name. Named data objects are [constants](abenconstant_glosry.md), [variables](abenvariable_glosry.md), and [text symbols](abentext_symbol_glosry.md) and can be stored in the [stack](abenstack_glosry.md) or as [instance attributes](abeninstance_attribute_glosry.md) in the [heap](abenheap_glosry.md). See also [unnamed data object](abenunnamed_data_object_glosry.md).
