# RAP behavior

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The part of a [RAP BO](abenrap_bo_glosry.md) that describes the abilities of the RAP BO in question. It is defined in a [RAP behavior definition](abencds_behavior_definition_glosry.md) and implemented in the [RAP behavior implementation](abenbehavior_implement_glosry.md).
