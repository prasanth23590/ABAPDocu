# RAP data model extension

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An extension of the data model of a [RAP BO](abenrap_bo_glosry.md). May consist of [DDIC extensions](abenddic_extension_glosry.md) and [CDS entity extensions](abencds_entity_extend_glosry.md).
