# secondary index

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Index](abenindex_glosry.md) of [DDIC database tables](abenddic_db_table_glosry.md) defined in the [ABAP Dictionary](abenabap_dictionary_glosry.md) that can be created in addition to the [primary index](abenprimary_index_glosry.md). Creating secondary indexes can improve the performance when accessing databases that evaluate the indexes of the [database](abendatabase_glosry.md). A secondary index can be unique, but it does not have to be. A [secondary table index](abensecondary_table_index_glosry.md) can be assigned to [internal tables](abeninternal_table_glosry.md).
