# global temporary table

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

GTT for short. [Table category](../abap-dictionary-ddic/ddic-database-tables/abenddic_database_tables_tab_cat.md) of a [DDIC database table](abenddic_db_table_glosry.md) in the [ABAP Dictionary](abenabap_dictionary_glosry.md). A GTT is used to store temporary data that is deleted at the end of each [database LUW](abendatabase_luw_glosry.md). Only [ABAP SQL](abenabap_sql_glosry.md) should be used to access global temporary tables defined in the ABAP Dictionary.
