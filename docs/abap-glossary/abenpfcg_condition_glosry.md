# CDS PFCG condition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Part of an [access condition](abenaccess_condition_glosry.md) in a [CDS role](abencds_role_glosry.md) that uses an [authorization object](abenauthorization_object_glosry.md) to associate an element of a [CDS entity](abencds_entity_glosry.md) with the [authorizations](abenauthorization_glosry.md) of the current [ABAP user](abenabap_user_glosry.md).
