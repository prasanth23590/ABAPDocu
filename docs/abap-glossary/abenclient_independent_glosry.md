# client-independent

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [SQL data source](abensql_data_source_glosry.md) that is not [client-dependent](abenclient_dependent_glosry.md). Client-independent SQL data sources contain data that is not specific to a [client](abenclient_glosry.md) and should be accessed by [system programs](abensystem_program_glosry.md). See also [system table](abensystem_table_glosry.md).
