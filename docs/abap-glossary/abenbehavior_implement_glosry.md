# RAP behavior implementation

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A RAP behavior implementation implements the [unmanaged RAP BO provider](abenunmanaged_rap_bo_prov_glosry.md). The implementation takes place in local classes of an [ABAP behavior pool (ABP)](abenbehavior_pool_glosry.md).
