# character set

[General](abenabap_glossary.md)

## Definition

Defined set of characters, for example, [ASCII](abenascii_glosry.md), [Unicode](abenunicode_glosry.md). Character sets are mapped onto [character representations](abenchar_representation_glosry.md) via [code pages](abencodepage_glosry.md).
