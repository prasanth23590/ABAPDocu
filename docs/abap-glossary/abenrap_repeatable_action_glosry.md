# RAP repeatable operation

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

[RAP action](abenrap_action_glosry.md) or [RAP function](abenrap_function_glosry.md) that can be executed multiple times on the same [RAP BO entity instance](abenrap_bo_entity_inst_glosry.md) within the same [ABAP EML](abenabap_eml_glosry.md) or [OData](abenodata_glosry.md) request. The [BDEF derived type](abenrap_derived_type_glosry.md) of a repeatable operation contains a [`%cid`](../abap-rap-business-objects/abap-for-rap-business-objects/abapderived_types_cid.md) component and the [RAP response parameters](abenrap_response_param_glosry.md) are filled for each execution individually.
