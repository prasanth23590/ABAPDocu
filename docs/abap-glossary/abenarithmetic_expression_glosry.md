# arithmetic expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Formulation of an arithmetic calculation.

- In general ABAP, an [arithmetic expression](../abap-programming-language/abap-processing-internal-data/abapcompute_arith.md) is a [calculation expression](abencalculation_expression_glosry.md). It is assigned a [calculation type](abencalculation_type_glosry.md) that is used to execute the calculation. The result of an arithmetic expression is a numeric value that exists in the calculation type. Arithmetic expressions occur in the [read positions of specific statements](../abap-programming-language/abap-operands/abenoperands_expressions.md).

- In ABAP SQL, [arithmetic expressions](../abap-programming-language/abap-database-access/abensql_arith.md) are [SQL expressions](abensql_expression_glosry.md).

- In ABAP CDS, [arithmetic expressions](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_arithmetic_expression_v2.md) can be used in the `SELECT` list of CDS view entities.
