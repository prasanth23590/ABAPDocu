# CDS schema notation

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

CSN for short. Notation for compact representations of data models, such as data models defined with [ABAP CDS](abenabap_cds_glosry.md). SAP standard format for metadata exchange between data models of different technology stacks, for example between [ABAP CDS](abenabap_cds_glosry.md) and SAP Analytics Cloud (SAC).
