# authorization profile

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

A summary of multiple [authorizations](abenauthorization_glosry.md). An authorization can be assigned to multiple authorization profiles. Entering authorization profiles in the [user master record](abenuser_master_record_glosry.md) assigns [user names](abenuser_name_glosry.md) to authorizations.
