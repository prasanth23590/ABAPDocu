# entity behavior definition

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A component of a [CDS behavior definition](abencds_behavior_definition_glosry.md) (BDEF). A BDEF consists of a [header part](abencds_bdef_header_glosry.md) and at least one entity behavior definition, referring to a [RAP BO root entity](abenrap_bo_root_entity_glosry.md). Further entity behavior definitions referring to [child entities](abenchild_entity_glosry.md) are optional.
