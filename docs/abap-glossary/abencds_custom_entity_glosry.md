# CDS custom entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS transient entity](abencds_non_sql_entity_glosry.md) defined using [`DEFINE CUSTOM ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_f1_define_custom_entity.md) in a [CDS data definition](abencds_data_definition_glosry.md). A CDS custom entity allows developers to implement their own data retrieval using the [ABAP language](abenabala_glosry.md). The data retrieval is implemented by a method of an [ABAP class](../abap-programming-language/abap-declarations/abapclass.md) that is called when accessing the custom entity in a framework such as the [RAP query engine](abenrap_query_engine_glosry.md). Custom entities cannot be used in [ABAP SQL](abenabap_sql_glosry.md). In [RAP](abenrap_glosry.md), custom entities are used as the data model basis for [unmanaged queries](abenrap_unmanged_query_glosry.md).
