# CDS access control

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Implicit restriction applied to a selection of [CDS entities](abencds_entity_glosry.md) when accessing objects with [ABAP SQL](abenabap_sql_glosry.md) using [access conditions](abenaccess_condition_glosry.md) defined in [CDS roles](abencds_role_glosry.md). CDS access control is switched on by default for each [CDS view entity](abencds_v2_view_glosry.md), [CDS DDIC-based view (obsolete)](abencds_v1_view_glosry.md), and [CDS table function](abencds_table_function_glosry.md). It can be switched off for individual views and table functions using a view annotation or [table function annotation](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_f1_function_annotations.md).
