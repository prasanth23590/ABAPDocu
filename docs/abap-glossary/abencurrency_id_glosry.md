# currency code

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Content of a [currency key](abencurrency_key_glosry.md). Valid currency codes are defined in the database table `TCURC`. The database table `TCURX` contains the currency code for currencies whose number of decimal places is not two.
