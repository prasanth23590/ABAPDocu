# optimistic concurrency control

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Optimistic [concurrency control](abenrap_conc_control_glosry.md) enables transactional access to data by multiple users while avoiding inconsistencies by unintentional changes of already modified data. In [RAP](abenrap_glosry.md) this is ensured by using an [ETag field](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_etag.md) in the [RAP behavior definition](abencds_behavior_definition_glosry.md).
