# writable CDS view entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS view entity](abencds_v2_view_glosry.md) that allows modifying data on the database using the [ABAP SQL](abenabap_sql_glosry.md) [`INSERT`](../abap-programming-language/abap-database-access/abapinsert_dbtab.md), [`UPDATE`](../abap-programming-language/abap-database-access/abapupdate.md), [`MODIFY`](../abap-programming-language/abap-database-access/abapmodify_dbtab.md), and [`DELETE`](../abap-programming-language/abap-database-access/abapdelete_dbtab.md) operations. Defined using the statement [`WRITABLE`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_wrtbl_view_v2.md).
