# binary floating point number type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Numeric data type](abennumeric_data_type_glosry.md) used for the binary representation of numbers with mantissa and exponents. The associated [built-in ABAP type](abenbuiltin_abap_type_glosry.md) is [`f`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_numeric.md). The [built-in DDIC type](abenbuiltin_ddic_type_glosry.md) is [`FLTP`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md). The internal representation is in accordance with the norm IEEE-754 (double precision) by one bit for the plus/minus sign, 11 bits for the binary exponent, and 52 bits for the mantissa, whereby [decimal numbers](abendecimal_number_glosry.md) can be represented by 17 [places](abenplace_glosry.md). A [data object](abendata_object_glosry.md) of a binary floating point number type is a [binary floating point number](abenbinfloat_glosry.md).
