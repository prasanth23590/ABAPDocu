# join expression

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

The implementation of a [join](abenjoin_glosry.md) in [SQL](abensql_glosry.md) using the addition `JOIN`. Join expressions can be defined in [queries](abenasql_query_glosry.md), defined by the [`SELECT`](../abap-programming-language/abap-database-access/abapselect.md) statement of [ABAP SQL](abenabap_sql_glosry.md), the [`SELECT` statement in CDS view entities](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_select_statement_v2.md), or the [`SELECT` statement in CDS DDIC-based views (obsolete)](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_select_statement_v2.md).
