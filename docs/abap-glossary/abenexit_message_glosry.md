# exit message

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Message](abenmessage_glosry.md) of the [message type](abenmessage_type_glosry.md) *X*. Exit messages create a [database rollback](abendatabase_rollback_glosry.md) and terminate the running program with the [runtime error](abenruntime_error_glosry.md) `MESSAGE_TYPE_X`. The short text of the message can be found in the [short dump](abenshort_dump_glosry.md).
