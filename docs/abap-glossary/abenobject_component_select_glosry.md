# object component selector

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Character `->`. Also referred to as [instance component selector](abeninstance_comp_selector_glosry.md). Each visible [component](abencomponent_glosry.md) `comp` of a [data object](abendata_object_glosry.md) or an [instance](abeninstance_glosry.md) of a [class](abenclass_glosry.md) can be addressed using `ref->comp` if `ref` is a [reference variable](abenreference_variable_glosry.md) that refers to the object.
