# RAP entity behavior extension

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Short behavior extension. A component of a [BDEF extension](abenrap_extension_glosry.md) that extends the behavior of an existing RAP BO entity. An entity behavior extension is defined using [`extend behavior for EntityName`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_extend_beh.md).
