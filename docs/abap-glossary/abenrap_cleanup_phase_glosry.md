# RAP cleanup phase

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The final phase of the [RAP save sequence](abenrap_save_seq_glosry.md) in which the [`cleanup`](../abap-rap-business-objects/abap-for-rap-business-objects/abensaver_method_cleanup.md) [RAP saver method](abenabp_saver_method_glosry.md) is called.
