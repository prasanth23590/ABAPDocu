# global type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) or [object type](abenobject_type_glosry.md) that is visible as a [repository object](abenrepository_object_glosry.md) in the entire [AS ABAP](abenas_abap_glosry.md). Global data types are defined as [DDIC types](abenddic_type_glosry.md) in the [ABAP Dictionary](abenabap_dictionary_glosry.md) or as [CDS types](abencds_type_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md). Global object types are defined as [global classes](abenglobal_class_glosry.md) or as [global interfaces](abenglobal_interface_glosry.md) in the [class library](abenclass_library_glosry.md). All these global types share the same namespace. Besides these global types, data types defined in the public [visibility section](abenvisibility_section_glosry.md) of global classes or in global interfaces can also be used globally.
