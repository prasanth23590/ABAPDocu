# statement block

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Structural unit within [control structures](abencontrol_structure_glosry.md) that consists of one or more successive statements. The statements of a statement block are processed sequentially. Statement blocks can again contain control structures.
