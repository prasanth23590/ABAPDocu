# edge table

[General](abenabap_glossary.md)

## Definition

A table that stores a set of different [edges](abenedge_glosry.md). Among them, there are at least two additional columns that reference the key column of the [vertex table](abenvertex_table_glosry.md). One of the columns identifies the source [vertex](abenvertex_glosry.md), and the other identifies the target vertex of an [edge](abenedge_glosry.md).
