# pseudo reference

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

The identifier `super` that can be specified in the implementation of a redefined [instance method](abeninstance_method_glosry.md) or an [instance constructor](abeninstance_constructor_glosry.md) instead of a [reference variable](abenreference_variable_glosry.md) in order to call the implementation of the [method](abenmethod_glosry.md) to be called in the direct [superclass](abensuperclass_glosry.md).
