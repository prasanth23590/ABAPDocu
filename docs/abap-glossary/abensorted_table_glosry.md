# sorted table

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Table category](abentable_category_glosry.md) of an [internal table](abeninternal_table_glosry.md) that is managed using a [primary table index](abenprimary_table_index_glosry.md) and is always sorted according to its [primary table key](abenprimary_table_key_glosry.md). Sorting occurs according to the [comparison rules](../abap-programming-language/abap-program-flow-logic/abenlogexp_rules.md) for the data types of the key fields. The associated [generic data type](abengeneric_data_type_glosry.md) is [`sorted table`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
