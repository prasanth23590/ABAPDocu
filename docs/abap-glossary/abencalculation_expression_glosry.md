# calculation expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Calculates a value. Either an [arithmetic expression](abenarithmetic_expression_glosry.md), a [bit expression](abenbit_expression_glosry.md), or a [string expression](abenstring_expression_glosry.md). The three calculation expression types can be used simultaneously as operands of [relational expressions](abenrelational_expression_glosry.md), but they cannot be combined within a calculation expression.
