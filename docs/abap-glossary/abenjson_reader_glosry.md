# JSON reader

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

There are two kinds of JSON readers:

- [Instance](abeninstance_glosry.md) of a [class](abenclass_glosry.md) of the [JSON Library](abenjson_library_glosry.md) that implements the [interface](abenoo_intf_glosry.md) `IF_JSON_READER`.

- [XML reader](abenxml_reader_glosry.md) that accesses [JSON](abenjson_glosry.md) data. A JSON reader handles the JSON data internally like [JSON-XML](abenjson_xml_glosry.md).
