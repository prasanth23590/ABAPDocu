# component group

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Also [named include](abennamed_include_glosry.md). Group of [structure components](abenstructure_component_glosry.md) that are included from another [structure](abenstructure_glosry.md) under one name. The components can be addressed by this name.
