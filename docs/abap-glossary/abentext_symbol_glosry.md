# text symbol

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Named data object](abennamed_data_object_glosry.md) of an [ABAP program](abenabap_program_glosry.md) maintained as part of the [text elements](abentext_element_glosry.md) of the program and addressed in the program using the name `text-idf`.
