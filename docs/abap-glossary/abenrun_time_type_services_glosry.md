# Runtime Type Services

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

RTTS for short. Combination of [RTTC](abenrun_time_type_creation_glosry.md) and [RTTI](abenrun_time_type_identific_glosry.md) in a class hierarchy. The RTTS methods provide information on [data types](abendata_type_glosry.md) or [classes](abenclass_glosry.md) and [interfaces](abenoo_intf_glosry.md) of [objects](abenobject_glosry.md), or they create new data types as [type description objects](abentype_object_glosry.md). RTTS is implemented as a hierarchy of [type description classes](abentype_class_glosry.md) from which type description objects can be created.
