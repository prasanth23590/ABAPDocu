# prefix extension

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A prefix that is used in the context of [RAP BO extensions](abenrap_bo_extension_glosry.md) to refer to an element or [repository object](abenrepository_object_glosry.md) from a RAP BO extension. Examples: extension behavior, extension node, extension field.
