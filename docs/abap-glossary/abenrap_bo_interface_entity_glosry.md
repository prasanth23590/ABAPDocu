# RAP BO interface entity

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A component of a [RAP BO interface](abenrap_bo_interface_glosry.md). It describes the part of the [RAP data model](abenrap_data_model_glosry.md) that is included in the interface. A RAP BO interface entity is represented by a [CDS projection view](abencds_projection_view_glosry.md) with the provider contract [`TRANSACTIONAL_INTERFACE`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_pv_provider_contract.md).
