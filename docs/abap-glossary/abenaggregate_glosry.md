# aggregate

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

The result of an [aggregate function](abenaggregate_function_glosry.md). Can be determined using aggregate functions in an ABAP SQL [`SELECT`](../abap-programming-language/abap-database-access/abapselect.md) statement or in the [`SELECT`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_aggregate_functions_v2.md) list of a [CDS view entity](abencds_v2_view_glosry.md).
