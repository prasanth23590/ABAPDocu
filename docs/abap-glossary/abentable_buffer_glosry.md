# table buffer

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

An area in the [shared memory](abenshared_memory_glosry.md) for [table buffering](abentable_buffering_glosry.md). The table buffer is managed by the [database interface](abendatabase_interface_glosry.md) and when accessed by [ABAP SQL](abenabap_sql_glosry.md), tables in the table buffer are processed by the [ABAP SQL in-memory engine](abenabap_sql_inmemeng_glosry.md).
