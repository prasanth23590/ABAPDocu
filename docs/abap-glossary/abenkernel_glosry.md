# ABAP kernel

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Part of the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) which is primarily programmed in C/C++. In particular, [ABAP statements](abenabap_statement_glosry.md) are implemented by C functions in the ABAP kernel. When an ABAP statement is executed, the corresponding C functions or the ABAP kernel are called.
