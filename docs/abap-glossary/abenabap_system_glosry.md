# ABAP system

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Client-server system](abenclient_server_system_glosry.md) that is based on and provides [ABAP technology](abenabap_techno_glosry.md). It consists of:

- ABAP-specific components of the [presentation layer](abenpresentation_layer_glosry.md).

- [Application Server ABAP (AS ABAP)](abenas_abap_glosry.md)

- [ABAP database schema](abenabap_db_schema_glosry.md) of the [standard database](abenstandard_db_glosry.md) of the AS ABAP storing both [system programs](abensystem_program_glosry.md) and [system tables](abensystem_table_glosry.md), as well as [application programs](abenapplication_program_glosry.md) and [application tables](abenapplication_table_glosry.md).

The name of an ABAP system matches the [system ID](abensystem_id_glosry.md) of its AS ABAP.
