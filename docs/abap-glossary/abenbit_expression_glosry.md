# bit expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Formulation of a binary operation in a [calculation expression](abencalculation_expression_glosry.md). The result of a bit expression is a byte-like value. Bit expressions occur in [read positions of specific statements](../abap-programming-language/abap-operands/abenoperands_expressions.md).
