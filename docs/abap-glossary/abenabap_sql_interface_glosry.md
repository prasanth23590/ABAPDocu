# ABAP SQL interface

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

Part of the [database interface](abendatabase_interface_glosry.md) responsible for [ABAP SQL](abenabap_sql_glosry.md) statements. The ABAP SQL interface transforms ABAP SQL statements that access the [standard database](abenstandard_db_glosry.md) of an [AS ABAP](abenas_abap_glosry.md) to vendor-specific [SQL](abensql_glosry.md) and forwards the results to the [database system](abendatabase_system_glosry.md).
