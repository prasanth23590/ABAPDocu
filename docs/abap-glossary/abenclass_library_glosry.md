# class library

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

The class library consists of all [global](abenglobal_type_glosry.md) [object types](abenobject_type_glosry.md), namely of all [global classes](abenglobal_class_glosry.md) and [interfaces](abenglobal_interface_glosry.md).
