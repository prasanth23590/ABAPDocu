# CDS composition tree

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [tree hierarchy](abentree_hierarchy_glosry.md) of a [RAP business object](abenrap_bo_glosry.md) that consists of [parent entities](abenparent_entity_glosry.md) and [child entities](abenparent_entity_glosry.md) that are themselves defined using [CDS compositions](abencds_composition_glosry.md). The top parent entity of a CDS composition tree is the [root entity](abenroot_entity_glosry.md) which represents the business object.
