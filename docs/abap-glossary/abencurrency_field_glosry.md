# currency field

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

A currency field is linked to a [currency key](abencurrency_key_glosry.md) and it is used for entering an amount in a particular currency. Currency fields are available in [ABAP Dictionary](abenabap_dictionary_glosry.md) (DDIC) and in [ABAP CDS](abenabap_cds_glosry.md), but the possible data types and handling differs.
