# keyword parameter

[General](abenabap_glossary.md)

## Definition

A [formal parameter](abenformal_parameter_glosry.md) to which an [actual parameter](abenactual_parameter_glosry.md) is passed by specifying the formal parameter name in the calling statement. See also [positional parameter](abenpositional_parameter_glosry.md).
