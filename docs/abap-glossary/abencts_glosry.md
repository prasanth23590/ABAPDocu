# Change and Transport System

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Abbreviated to CTS. The Change and Transport System includes all [AS ABAP](abenas_abap_glosry.md) tools used to manage and transport [repository objects](abenrepository_object_glosry.md) and other objects between different [AS ABAP](abenas_abap_glosry.md) systems. A repository object is connected to CTS using its [package](abenpackage_glosry.md).
