# SAP Gateway

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Framework that makes it possible to access [AS ABAP](abenas_abap_glosry.md) using standardized open protocols such as [OData](abenodata_glosry.md). [Business services](abenbusiness_service_glosry.md) and [RAP business objects](abenrap_bo_glosry.md) based on the data and behavior modeled in [ABAP CDS](abenabap_cds_glosry.md) use SAP Gateway internally as part of the [RAP runtime framework](abenrap_runt_framework_glosry.md).
