# namespace prefix

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Prefix with five to ten characters that must contain a forward slash character (`/.../`) in the first and final place. The names of the [repository objects](abenrepository_object_glosry.md) of a [prefix namespace](abenprefix_name_space_glosry.md) are introduced by a namespace prefix.
