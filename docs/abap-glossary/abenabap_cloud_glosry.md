# ABAP Cloud

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

ABAP development model for state-of-the-art, cloud-ready and upgrade-stable solutions. Compared to [classic ABAP](abenclassic_abap_glosry.md), ABAP Cloud uses the [ABAP technology](abenabap_techno_glosry.md) with the following restrictions:

- The [ABAP language version](abenabap_version_glosry.md) is restricted to the [restricted ABAP language version](abenrestricted_version_glosry.md) [ABAP for Cloud Development](abenabap_for_cloud_dev_glosry.md).

- Access to other [repository objects](abenrepository_object_glosry.md) is restricted to APIs that are [released](abenreleased_api_glosry.md) for [ABAP for Cloud Development](abenabap_for_cloud_dev_glosry.md).

- Only [ABAP development tools for Eclipse (ADT)](abenadt_glosry.md) can be used. There is no access to SAP GUI.

The transactional programming model for ABAP Cloud is [RAP](abenrap_glosry.md).

ABAP Cloud is supported in all SAP products that are based on ABAP technology. It is fully or partly mandatory in

- [SAP BTP ABAP environment](abensap_btp_abap_env_glosry.md)

- [SAP S/4HANA Cloud Public Edition](abensap_s4hana_cpub_glosry.md)

- [SAP S/4HANA Cloud Private Edition](abensap_s4hana_cpriv_glosry.md)

On the [ABAP Platform](abenabap_platform_glosry.md) of [SAP S/4HANA](abensap_s4hana_glosry.md) it is available besides classic ABAP.
