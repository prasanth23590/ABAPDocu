# RAP additional save

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The save logic which can be added to [managed RAP BOs](abenmanaged_rap_bo_glosry.md) to enhance the default [save sequence](abenrap_save_seq_glosry.md). It can be applied to the complete [BO](abenrap_bo_glosry.md) by defining it in the [behavior definition header](abencds_bdef_header_glosry.md), or for an individual entity by defining it in the [behavior entity characteristics](abencds_entity_properties_glosry.md). It is implemented in the redefined [saver method](abenabp_saver_method_glosry.md) `save_modified`.
