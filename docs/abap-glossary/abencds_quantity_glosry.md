# CDS quantity field

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A component of a [CDS entity](abencds_entity_glosry.md) of data type `QUAN`, `DECFLOAT16`, `DECFLOAT34`, `DEC`, `FLTP`, `INT1`, `INT2`, or `INT4` in [ABAP CDS](abenabap_cds_glosry.md). It is used for entering a quantity in a particular unit. An ABAP CDS quantity field must be linked with a [unit key](abenunit_glosry.md) of the same CDS entity that specifies the unit of measurement and the number of decimal places.
