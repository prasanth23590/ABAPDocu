# event handler

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Method](abenmethod_glosry.md) that can handle an [event](abenevent_glosry.md) that was raised by [`RAISE EVENT`](../abap-programming-language/abap-calling-and-exiting-program-units/abapraise_event.md) in another method or in the same method. To ensure that an event handler handles a raised event, it must be registered with the statement [`SET HANDLER`](../abap-programming-language/abap-calling-and-exiting-program-units/abapset_handler.md).
