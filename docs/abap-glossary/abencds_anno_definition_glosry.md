# CDS annotation definition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Defines a [CDS annotation](abencds_annotation_glosry.md) as a [CDS object](abencds_object_glosry.md) using the statement `DEFINE ANNOTATION` in [`DDLA` source code](abenddla_source_code_glosry.md) in [CDS DDL](abencds_ddl_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md). A CDS annotation definition specifies the [CDS annotation syntax](abencds_annotation_syntax_glosry.md) that is to be used when the annotation is specified in [CDS source code](abencds_source_code_glosry.md).
