# enumerated constant

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A [constant](abenconstant_glosry.md) declared in the definition of an [enumerated type](abenenum_type_glosry.md) that contains an [enumerated value](abenenumerated_value_glosry.md) of the enumerated type.

In ABAP, an enumerated constant is a special [enumerated object](abenenumerated_object_glosry.md). See also [enumerated structure](abenenumerated_structure_glosry.md).

In ABAP CDS, an enumerated constant is a special [enumerated element](abencds_enum_element_glosry.md).
