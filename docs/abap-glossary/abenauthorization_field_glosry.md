# authorization field

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Smallest unit of an [authorization object](abenauthorization_object_glosry.md). An authorization field represents either data such as a [key field](abenkey_field_glosry.md) of a [DDIC database table](abenddic_db_table_glosry.md) or activities such as reading or changing. Activities are specified as abbreviations that are stored in the DDIC database table `TACT` and in `TACTZ` for customers.
