# elementary operand

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

An [operand](abenoperand_glosry.md) that is not an [expression](abenexp_glosry.md). The value of a elementary operand can be used directly and must not be evaluated.
