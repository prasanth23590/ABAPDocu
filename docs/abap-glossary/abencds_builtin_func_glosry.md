# CDS built-in function

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A predefined function in [ABAP CDS](abenabap_cds_glosry.md) that can be used in operand positions of [CDS entities](abencds_entity_glosry.md). ABAP CDS offers [numeric functions](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_sql_functions_numeric_v2.md), [string functions](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_sql_functions_character_v2.md), and [date and time functions](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_date_time_functions_v2.md) that have a return value of the corresponding data type. [Conversion functions](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_conversion_functions_v2.md) are available to perform conversions between data types.
