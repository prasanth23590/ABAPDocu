# CDS composition path

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A sequence of [CDS compositions](abencds_composition_glosry.md) that link the [CDS entities](abencds_entity_glosry.md) of a [CDS composition tree](abencds_composition_tree_glosry.md). CDS composition paths can be specified like [CDS association paths](abencds_association_path_glosry.md) in [SQL path expressions](abensql_path_expression_glosry.md).
