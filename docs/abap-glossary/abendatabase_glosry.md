# database

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [General](abenabap_glossary.md)

## Definition

System for storing and managing data between which logical dependencies exist. The data in the database of an [AS ABAP](abenas_abap_glosry.md) is stored on the [database server](abendatabase_server_glosry.md) and is managed by the [database system](abendatabase_system_glosry.md). See also [relational database](abenrelational_database_glosry.md).
