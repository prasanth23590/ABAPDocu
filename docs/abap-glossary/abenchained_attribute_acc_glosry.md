# chained attribute access

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Chaining](abenchaining_glosry.md) in which multiple [functional methods](abenfunctional_method_glosry.md) or [constructor expressions](abenconstructor_expression_glosry.md) are linked via [component selectors](abencomponent_selector_glosry.md). The [return values](abenreturn_value_glosry.md) or results of the individual methods or expressions are each references to the next methods, respectively, and the return value of the last method references an [attribute](abenattribute_glosry.md) that is used as an [ABAP operand](abenabap_operand_glosry.md). See also [chained identifiers](abenchained_name_glosry.md).
