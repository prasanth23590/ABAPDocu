# iteration expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Expression that executes an [iteration](abeniteration_glosry.md). An iteration expression is a subexpression of a [constructor expression](abenconstructor_expression_glosry.md) introduced using the [iteration operator](abeniteration_operator_glosry.md) [`FOR`](../abap-programming-language/abap-program-flow-logic/abenfor.md) and executes [conditional iterations](../abap-programming-language/abap-program-flow-logic/abenfor_conditional.md) or [table iterations](abentable_iteration_glosry.md).
