# RAP event-driven side effect

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP side effect](abenrap_side_effects_glosry.md) that is triggered by a [business event for side effects](abenrap_side_effct_event_glosry.md). The business event in question is defined to be used exclusively for a side effect with the syntax [`event MyEvent for side effects`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_event.md).
