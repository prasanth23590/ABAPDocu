# RAP managed draft provider

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A part of the [RAP BO provider](abenrap_bo_provider_glosry.md) that manages draft data on the [transactional buffer](abentransactional_buffer_glosry.md) during the [interaction phase](abenrap_int_phase_glosry.md) and provides [draft actions](abenrap_bo_draft_action_glosry.md) and the total ETag handling in draft-enabled [RAP BOs](abenrap_bo_glosry.md).
