# LOB handle

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

An object from one of the [system classes](abensystem_class_glosry.md) that support [streaming](../abap-programming-language/abap-database-access/abenabap_sql_streaming.md) and [locators](../abap-programming-language/abap-database-access/abenlocators.md) for [LOBs](abenlob_glosry.md) in [ABAP SQL](abenabap_sql_glosry.md). These classes all implement the [interface](abenoo_intf_glosry.md) `IF_ABAP_DB_LOB_HANDLE`. See also: [LOB Handle Structure](abenlob_handle_structure_glosry.md).
