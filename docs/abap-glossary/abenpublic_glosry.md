# public

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Term in [ABAP Objects](abenabap_objects_glosry.md). A public [component](abenclass_component_glosry.md) of a [class](abenclass_glosry.md) can be accessed at any point at which the class is known. In case of a public instantiation, [objects](abenobject_glosry.md) can be created at every point at which a class is known. The public [visibility section](abenvisibility_section_glosry.md) of a class is declared in its [declaration part](abendeclaration_part_glosry.md) using the statement [`PUBLIC SECTION`](../abap-programming-language/abap-declarations/abappublic.md).
