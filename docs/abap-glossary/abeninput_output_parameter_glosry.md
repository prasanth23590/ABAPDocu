# input/output parameter

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Formal parameter](abenformal_parameter_glosry.md) to which the value of an [actual parameter](abenactual_parameter_glosry.md) is passed at the time of the call. It can be changed during the call and is available in the actual parameter at the end of the call.
