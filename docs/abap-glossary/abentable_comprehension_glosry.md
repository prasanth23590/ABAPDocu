# table comprehension

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Creates the content of an [internal table](abeninternal_table_glosry.md) by evaluating one or more tables using [table iterations](abentable_iteration_glosry.md) with [iteration expressions](abeniteration_expression_glosry.md) within a [constructor expression](abenconstructor_expression_glosry.md) with the [instance operator](abeninstance_operator_glosry.md) [`NEW`](../abap-programming-language/abap-creating-objects-and-values/abennew_constructor_params_itab.md) or the [value operator](abenvalue_operator_glosry.md) [`VALUE`](../abap-programming-language/abap-creating-objects-and-values/abenvalue_constructor_params_itab.md).
