# iteration

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Repeated processing of a [statement block](abenstatement_block_glosry.md) in a [loop](abenloop_glosry.md) or an [expression](abenexpression_glosry.md) with an [iteration expression](abeniteration_expression_glosry.md).
