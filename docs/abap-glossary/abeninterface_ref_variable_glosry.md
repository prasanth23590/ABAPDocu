# interface reference variable

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Object reference variable](abenobject_refer_variable_glosry.md) of the [static type](abenstatic_type_glosry.md) of an [interface](abenoo_intf_glosry.md). An interface reference variable can be used to access the visible [interface components](abeninterface_component_glosry.md) of an object that exists in the corresponding interface. This applies to both dynamic and static access.
