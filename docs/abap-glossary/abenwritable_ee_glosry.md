# writable CDS external entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [dynamic external entity](abencds_dynamic_ee_glosry.md) that allows modifying data on an external database system using the [ABAP SQL](abenabap_sql_glosry.md) [`INSERT`](../abap-programming-language/abap-database-access/abapinsert_dbtab.md), [`UPDATE`](../abap-programming-language/abap-database-access/abapupdate.md), [`MODIFY`](../abap-programming-language/abap-database-access/abapmodify_dbtab.md), and [`DELETE`](../abap-programming-language/abap-database-access/abapdelete_dbtab.md) operations. It is defined using the statement [`WRITABLE`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_writable_ee.md) in the [CDS data definition](abencds_data_definition_glosry.md). An [ABAP SQL connection object](abenabap_sql_conn_obj_glosry.md) is required to establish a [service connection](abenservice_connection_glosry.md) and enable the [logical external schema](abencds_logical_schema_glosry.md) for write access.
