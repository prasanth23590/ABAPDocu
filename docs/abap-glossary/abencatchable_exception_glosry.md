# catchable exception

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Exception](abenexception_glosry.md) that can be handled in the program using the statements [`TRY - CATCH - ENDTRY`](../abap-programming-language/abap-program-flow-logic/abaptry.md) without causing a [runtime error](abenruntime_error_glosry.md). Catchable exceptions are based on [exception classes](abenexception_class_glosry.md) and are implemented by [exception objects](abenexception_object_glosry.md). A catchable exception is raised either by the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) or by the statement [`RAISE EXCEPTION`](../abap-programming-language/abap-program-flow-logic/abapraise_exception.md) in a program, or by the addition [`THROW`](../abap-programming-language/abap-program-flow-logic/abenconditional_expression_result.md) in a [conditional expression](abenconditional_expression_glosry.md).
