# initial memory requirement

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Property of a [table type](abentable_type_glosry.md) that affects the memory area allocated by the ABAP runtime framework for an [internal table](abeninternal_table_glosry.md) before the table is filled with lines. The initial memory requirement is not a [technical type property](abentechnical_type_prpt_glosry.md) and does not affect the [compatibility](abencompatible_glosry.md) of the table type.
