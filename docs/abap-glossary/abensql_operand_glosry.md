# SQL operand

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

Elementary operand in an [ABAP SQL statement](abenabap_sql_glosry.md). SQL operands are columns of [DDIC database tables](abenddic_db_table_glosry.md) or [views](abenview_glosry.md) defined in the [ABAP Dictionary](abenabap_dictionary_glosry.md), [host variables](abenhost_variable_glosry.md), or [host expressions](abenhost_expression_glosry.md).
