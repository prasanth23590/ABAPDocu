# table iteration

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Sequential evaluation of an [internal table](abeninternal_table_glosry.md). Either in a [loop](abenloop_glosry.md) introduced using [`LOOP AT`](../abap-programming-language/abap-processing-internal-data/abaploop_at_itab_variants.md) or `PROVIDE` or with the corresponding [variants](../abap-programming-language/abap-processing-internal-data/abenfor_itab.md) of an [iteration expression](abeniteration_expression_glosry.md).
