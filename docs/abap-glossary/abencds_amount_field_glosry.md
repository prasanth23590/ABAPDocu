# CDS amount field

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A component of a [CDS entity](abencds_entity_glosry.md) of data type `CURR`, `DECFLOAT34`, `DEC`, or `FLTP` in [ABAP CDS](abenabap_cds_glosry.md). It is used for entering an amount in a particular currency. The content of an amount field is interpreted as an integer in the smallest unit of the currency. An ABAP CDS amount field must be linked with a [currency key](abencurrency_key_glosry.md) of the same CDS entity that specifies the currency and the number of decimal places.
