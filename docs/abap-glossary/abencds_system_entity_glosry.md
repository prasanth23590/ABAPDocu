# CDS system entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS entity](abencds_entity_glosry.md) delivered with an [ABAP system](abenabap_system_glosry.md) that implements basic functionality, such as generating a series of integers (`SERIES_GENERATE_INTEGER`). It can be used as data source of other CDS entities or in [queries](abenasql_query_glosry.md) of [ABAP SQL](abenabap_sql_glosry.md).
