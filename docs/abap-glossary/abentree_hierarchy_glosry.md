# tree hierarchy

[General](abenabap_glossary.md)

## Definition

A [parent-child hierarchy](abenpcr_hierarchy_glosry.md), where each [parent-child relationship](abenpcr_glosry.md) is a one to many relationship whereas a child-parent relationship is one to one. A tree hierarchy has exactly one [root node](abenroot_node_glosry.md).
