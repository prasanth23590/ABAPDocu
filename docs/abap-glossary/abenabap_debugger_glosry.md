# ABAP Debugger

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Tool used to execute [ABAP programs](abenabap_program_glosry.md) line by line or section by section. This makes it possible to edit the content of [data objects](abendata_object_glosry.md) and to check the program logic. See also [breakpoint](abenbreakpoint_glosry.md).
