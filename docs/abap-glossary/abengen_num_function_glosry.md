# general numeric function

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Numeric function](abenmathematical_funktion_glosry.md) that expects a [numeric data object](abennumeric_data_object_glosry.md) as an argument. The [data type](abendata_type_glosry.md) of the argument determines the data type of the [return value](abenreturn_value_glosry.md) of the function.
