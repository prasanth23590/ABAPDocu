# data area

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Memory area of an [ABAP program](abenabap_program_glosry.md) in which data is stored. The data area covers a static area for [data objects](abendata_object_glosry.md) of fixed length and a dynamic area for data objects of variable length ([data types](abendata_type_glosry.md) [`string`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_complete.md), [`xstring`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_complete.md), and [internal tables](abeninternal_table_glosry.md)). The internal [references](abenreference_glosry.md) to the dynamic area are in the static area.
