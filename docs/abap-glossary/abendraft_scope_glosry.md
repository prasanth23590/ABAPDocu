# RAP draft scope

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A feature in [cross-BO scenarios](abencds_cross_bo_assoc_glosry.md) that enables consistent [draft management](abenrap_draft_handling_glosry.md) between [draft-enabled RAP business objects](abendraft_rap_bo_glosry.md). This means that multiple associated [business objects](abenbusiness_object_glosry.md) can be edited within a single [logical unit of work](abenluw_glosry.md).
