# alias name

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A name that is assigned as a substitute name to an element, an object, etc. The following alias names can be defined in ABAP:

- The statement [`ALIASES`](../abap-programming-language/abap-declarations/abapaliases.md) can be used to declare an alias name for an [interface component](abeninterface_component_glosry.md) in a [class](abenclass_glosry.md) or in a [compound interface](abencompound_interface_glosry.md).

- The addition [`ALIAS`](../abap-programming-language/abap-declarations/abaptypes_primary_key.md) can be used to specify an alias for the [primary table key](abenprimary_key_glosry.md) and [secondary table key](abensecondary_key_glosry.md) when declaring an [internal table](abeninternal_table_glosry.md).

- In [ABAP SQL](abenabap_sql_glosry.md), the addition `AS` can be used to define aliases for columns of the result set in a [`SELECT`](../abap-programming-language/abap-database-access/abapselect_list.md) list or for data sources in the [`FROM`](../abap-programming-language/abap-database-access/abapfrom_clause.md) clause.

- In [ABAP CDS](abenabap_cds_glosry.md), the addition `AS` can be used to define aliases for elements in the `SELECT` list or for [CDS associations](abencds_association_glosry.md).
