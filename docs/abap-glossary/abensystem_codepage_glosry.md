# system code page

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Code page](abencodepage_glosry.md) released for use on an [AS ABAP](abenas_abap_glosry.md). In the current release, each system is a [Unicode system](abenunicode_system_glosry.md), that is, a [single code page system](abensingle_codepage_system_glosry.md) with the system code page [UTF-16](abenutf16_glosry.md) with a platform-dependent [byte order](abenbyte_order_glosry.md). The programming language ABAP supports the subset [UCS-2](abenucs2_glosry.md) without [surrogates](abensurrogates_glosry.md). The system code page of a single code page system is always the code page of the [text environment](abentext_environment_glosry.md) of an [internal session](abeninternal_session_glosry.md).
