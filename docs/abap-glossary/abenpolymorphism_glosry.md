# polymorphism

[General](abenabap_glossary.md)

## Definition

In object-oriented programming, polymorphism means the ability to address differently implemented [methods](abenmethod_glosry.md) that belong to different [objects](abenobject_glosry.md) of different [classes](abenclass_glosry.md) with the same name and via the same interface.
