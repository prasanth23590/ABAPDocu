# CDS scalar function implementation reference

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[Repository object](abenrepository_object_glosry.md) that binds a [CDS scalar function](abencds_scalar_function_glosry.md) to a runtime environment. In case of an [SQL-based scalar function](abencds_sql_scalar_glosry.md), the scalar function implementation reference also specifies the [AMDP function implementation](abenamdp_function_method_glosry.md) that implements the scalar function in question.
