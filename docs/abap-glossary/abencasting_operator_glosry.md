# casting operator

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Operator](abenoperator_glosry.md) for executing a [downcast](abendown_cast_glosry.md) for [reference variables](abenreference_variable_glosry.md). Casting operators are the special [assignment operator](abenassignment_operator_glosry.md) [`?=`](../abap-programming-language/abap-processing-internal-data/abapmove_cast.md) and the [constructor operator](abenconstructor_operator_glosry.md) [`CAST`](../abap-programming-language/abap-processing-internal-data/abenconstructor_expression_cast.md).
