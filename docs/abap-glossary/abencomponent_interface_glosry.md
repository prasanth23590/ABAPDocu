# component interface

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Interface](abenoo_intf_glosry.md) included in a [compound interface](abencompound_interface_glosry.md) by an [`INTERFACES`](../abap-programming-language/abap-declarations/abapinterfaces.md) statement. A component interface can itself be a compound interface.
