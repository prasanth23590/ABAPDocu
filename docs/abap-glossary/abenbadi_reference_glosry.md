# BAdI reference

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Reference to a [BAdI object](abenbadi_object_glosry.md). BAdI references occur only as content of [BAdI reference variables](abenbadi_reference_variable_glosry.md). Technically, BAdI references are [object references](abenobject_reference_glosry.md) to [instances](abeninstance_glosry.md) of [BAdI classes](abenbadi_class_glosry.md).
