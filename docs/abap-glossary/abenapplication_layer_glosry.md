# application layer

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [General](abenabap_glossary.md)

## Definition

Software layer of a [client-server system](abenclient_server_system_glosry.md) that contains the application logic. [AS ABAP](abenas_abap_glosry.md) represents the application layer of an [ABAP system](abenabap_system_glosry.md) in which [ABAP programs](abenabap_program_glosry.md) are executed.
