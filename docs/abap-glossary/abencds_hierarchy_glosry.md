# CDS hierarchy

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS persistent entity](abencds_sql_entity_glosry.md) defined using [`DEFINE HIERARCHY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_f1_define_hierarchy.md) in a [CDS data definition](abencds_data_definition_glosry.md). A CDS hierarchy allows the retrieval of the nodes of hierarchical data. In [ABAP SQL](abenabap_sql_glosry.md) read statements, a CDS hierarchy can be accessed as a [ABAP SQL hierarchy](abensql_hierarchy_glosry.md). Additional [hierarchy columns](abenhierarchy_column_glosry.md) containing the [hierarchy attributes](abenhierarchy_attribute_glosry.md) are available.
