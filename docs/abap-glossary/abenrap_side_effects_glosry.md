# RAP side effect

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An optional part of a [RAP behavior definition](abencds_behavior_definition_glosry.md) that defines interdependencies among BO properties that trigger a reload of the affected properties on the user interface. Introduced by the keyword [`side effects`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_side_effects.md) in the [entity behavior body](abencds_entity_body_glosry.md) of a RAP behavior definition.
