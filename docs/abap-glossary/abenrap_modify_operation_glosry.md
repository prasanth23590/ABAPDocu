# RAP modify operation

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A synonym for [CUD operations](abencud_glosry.md). [RAP BO operation](abenrap_bo_operation_glosry.md) that changes data of a [RAP BO entity instance](abenrap_bo_entity_inst_glosry.md). [Create](abenrap_create_operation_glosry.md), [update](abenrap_update_operation_glosry.md), and [delete](abenrap_delete_operation_glosry.md) are RAP modify operations.
