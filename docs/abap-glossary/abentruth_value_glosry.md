# truth value

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [General](abenabap_glossary.md)

## Definition

A truth value is either true or false. In ABAP, truth values only occur as the result of [logical expressions](abenlogical_expression_glosry.md). [Data types](abendata_type_glosry.md) for [Boolean data objects](abenboolean_data_object_glosry.md) that can accept truth values are not supported. Instead, a truth value can be evaluated as the result of a [Boolean function](abenboole_function_glosry.md).
