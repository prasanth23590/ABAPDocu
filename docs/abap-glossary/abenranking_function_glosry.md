# ranking function

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

[Window function](abenwindow_function_glosry.md) that assigns a criterion for the ranking within the [window](abenwindow_glosry.md) for a line of a window on the result set of a [query](abenasql_query_glosry.md) in [ABAP SQL](abenabap_sql_glosry.md). The calculation is executed in the [database system](abendatabase_system_glosry.md).
