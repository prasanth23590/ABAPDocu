# CDS generic type

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[Built-in](abenbuiltin_data_type_glosry.md) [generic](abengeneric_data_type_glosry.md) [CDS type](abencds_type_glosry.md). The generic CDS types are: `any` and `numeric`. Generic CDS types can be used for the typing of parameters of [CDS scalar functions](abencds_scalar_function_glosry.md).
