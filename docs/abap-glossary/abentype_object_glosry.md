# type description object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Instance of a [type description class](abentype_class_glosry.md). Type description objects describe a [type](abentype_glosry.md). Type description objects are created using the static methods of the type description classes. The type description class and possible attributes of type description objects determine the [technical properties](abentechnical_type_prpt_glosry.md) of the type. [References](abenreference_glosry.md) to type description objects can be used, for example, after the addition `HANDLE` of the statements [`CREATE DATA`](../abap-programming-language/abap-creating-objects-and-values/abapcreate_data_handle.md) and [`ASSIGN`](../abap-programming-language/abap-processing-internal-data/abapassign_casting.md).
