# cardinality

[General](abenabap_glossary.md)

## Definition

In a [join](abenjoin_glosry.md) of two [SQL data sources](abensql_data_source_glosry.md), the cardinality expresses the relation between the rows of the data sources. Typical cardinalities are one-to-one (`1:1`), one-to-many (`1:n`), many-to-one (`n:1`), and many-to-many (`n:m`).
