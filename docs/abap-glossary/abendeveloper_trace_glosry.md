# developer trace

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Trace files on the [host computers](abenhost_computer_glosry.md) of an [AS ABAP](abenas_abap_glosry.md) that contain technical information for use in the event of an error.
