# reader stream

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Also referred to as [input stream](abeninput_stream_glosry.md). a [data stream](abendata_stream_glosry.md) that is connected to a [streaming data source](abenstreaming_data_source_glosry.md). The direction of a reader stream is always away from the data source. Data can only be read from a reader stream.
