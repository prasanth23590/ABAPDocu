# text environment language

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Language of the [text environment](abentext_environment_glosry.md) of the current [internal session](abeninternal_session_glosry.md). The text environment language is the content of the [system field](abensystem_field_glosry.md) [`sy-langu`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abensystem_fields.md). At the beginning of each internal session, it is the [logon language](abenlogon_language_glosry.md) and can be set explicitly with `SET LOCALE LANGUAGE`.
