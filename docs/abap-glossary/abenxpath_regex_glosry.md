# XPath regular expression

[General](abenabap_glossary.md)

## Definition

[Regular expression](abenregular_expression_glosry.md) using the syntax and semantics described under [Query 1.0 and XPath 2.0 Functions and Operators](https://www.w3.org/TR/xquery-operators/#regex-syntax). ABAP supports [XPath syntax](../abap-programming-language/abap-processing-internal-data/abenregex_xpath_syntax.md) for regular expressions by transforming them to [PCRE](abenpcre_glosry.md) internally. See also [PCRE regular expression](abenpcre_regex_glosry.md), [XSD regular expression](abenxsd_regex_glosry.md) and [POSIX regular expression](abenposix_regex_glosry.md) (obsolete).
