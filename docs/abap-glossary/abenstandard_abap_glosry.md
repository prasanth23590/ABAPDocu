# Standard ABAP

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Unrestricted ABAP language version](abenunrestricted_version_glosry.md) with unrestricted language scope and unrestricted access to [repository objects](abenrepository_object_glosry.md). For Standard ABAP, the [Unicode checks](abenunicode_check_glosry.md) are effective that are required in an [Unicode systems](abenunicode_system_glosry.md). Standard ABAP is the [ABAP language version](abenabap_version_glosry.md) for [classic ABAP](abenclassic_abap_glosry.md).
