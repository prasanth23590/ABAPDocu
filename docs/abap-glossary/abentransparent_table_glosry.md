# transparent table

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Table category](../abap-dictionary-ddic/ddic-database-tables/abenddic_database_tables_tab_cat.md) of a [DDIC database table](abenddic_db_table_glosry.md) in the [ABAP Dictionary](abenabap_dictionary_glosry.md) that has exactly one identically named instance with the same columns as the definition in the ABAP Dictionary. Besides using [ABAP SQL](abenabap_sql_glosry.md), the data of transparent tables can also be processed using [AMDP](abenamdp_glosry.md).
