# ABAP language element addition

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP word](abenabap_word_glosry.md) or combination of multiple ABAP words. A language element addition can be used in [ABAP statements](abenabap_statement_glosry.md) as an addition to a suitable [ABAP language element](abenabap_language_element_glosry.md). Examples of different ABAP language element additions are `WITH KEY` and `WITH TABLE KEY`.
