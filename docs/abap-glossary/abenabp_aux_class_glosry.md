# ABP auxiliary class

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [global class](abenglobal_class_glosry.md) that refers to a [RAP BO](abenrap_bo_glosry.md) and has extended access rights to the referenced RAP BO. Its primary purpose is to support implementation in an [ABAP behavior pool](abenbehavior_pool_glosry.md). This is accomplished by providing reusable methods and allowing developers to concurrently implement [RAP behavior](abenrap_behavior_glosry.md).
