# RAP BO entity instance

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Also RAP BO node instance. A specific data set of a [RAP BO entity](abenrap_bo_entity_glosry.md) that is identified by a key. During a [RAP transaction](abenrap_luw_glosry.md), a RAP BO entity instance is processed in the [RAP transactional buffer](abentransactional_buffer_glosry.md) during the [RAP interaction phase](abenrap_int_phase_glosry.md). Then it is saved to the database table during the [save sequence](abenrap_save_seq_glosry.md).
