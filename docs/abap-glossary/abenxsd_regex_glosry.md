# XSD regular expression

[General](abenabap_glossary.md)

## Definition

[Regular expressions](abenregular_expression_glosry.md) using the syntax and semantics described under [Regular expressions in XSD 1.0 and 1.1](https://www.w3.org/XML/2008/03/xsdl-regex/re.xml). ABAP supports [XSD syntax](../abap-programming-language/abap-processing-internal-data/abenregex_xsd_syntax.md) for regular expressions by transforming them to [PCRE](abenpcre_glosry.md) internally. See also [PCRE regular expression](abenpcre_regex_glosry.md), [XPath regular expression](abenxpath_regex_glosry.md) and [POSIX regular expression](abenposix_regex_glosry.md) (obsolete).
