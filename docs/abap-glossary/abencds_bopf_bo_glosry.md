# CDS-based BOPF business object

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

CDS-based BOPF BO for short. A [business object](abenbusiness_object_glosry.md) in the context of the [Business Object Processing Framework](abenbo_processing_fw_glosry.md) (BOPF). Built with the [ABAP programming model for SAP Fiori](abenabap_pm_for_fiori_glosry.md).
