# database object

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Object saved in a [database](abendatabase_glosry.md), such as a [database table](abendatabase_table_glosry.md), an [SQL view](abensql_view_glosry.md), or a [stored procedure](abenstored_procedure_glosry.md). [AS ABAP](abenas_abap_glosry.md) mainly uses [ABAP-managed database objects](abenabap_managed_db_object_glosry.md).
