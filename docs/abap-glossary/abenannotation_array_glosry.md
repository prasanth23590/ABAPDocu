# annotation array

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS annotation](abencds_annotation_glosry.md) defined with the addition `array of` in its [annotation definition](abencds_anno_definition_glosry.md). When an annotation array is specified in [annotation syntax](abencds_annotation_syntax_glosry.md), any number of similar elements are listed in square brackets [`[ ]`](../abap-core-data-services-abap-cds/abap-cds-annotations/abencds_annotations_syntax.md).
