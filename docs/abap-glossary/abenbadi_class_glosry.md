# BAdI class

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Specific global class that is created when a [BAdI](abenbadi_glosry.md) is defined and given the name of the BAdI as a [subclass](abensubclass_glosry.md) of the [abstract](abenabstract_glosry.md) global [class](abenclass_glosry.md) `CL_BADI_BASE`. BAdI classes are a part of the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) and, apart from being in the namespace of all global [types](abentype_glosry.md), they are not visible externally.
