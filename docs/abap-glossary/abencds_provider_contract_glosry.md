# CDS provider contract

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

In [ABAP CDS](abenabap_cds_glosry.md), a provider contract specifies the scenario in which a [CDS object](abencds_object_glosry.md) is used. Depending on the scenario, different rules apply to the definition of the object in question. Each provider contract imposes a different set of syntax checks.

Currently, the following CDS objects can have a provider contract:

- [CDS projection views](abencds_projection_view_glosry.md), see the topic [`PROVIDER CONTRACT`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_pv_provider_contract.md) for more details.

- [CDS service definition](abencds_service_definition_glosry.md), see the topic [`PROVIDER CONTRACTS`](../abap-core-data-services-abap-cds/abap-cds-service-definitions/abensrvd_provider_contract.md) for more details.
