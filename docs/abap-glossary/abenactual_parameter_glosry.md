# actual parameter

[General](abenabap_glossary.md)

## Definition

Operand whose content is passed to or from a [formal parameter](abenformal_parameter_glosry.md) when a callable unit, such as a [procedure](abenprocedure_glosry.md) or [function](abenfunction_glosry.md), is called. An actual parameter passed to a [built-in function](abenbuiltin_function_glosry.md) is also called [argument](abenargument_glosry.md) of the function.
