# pessimistic concurrency control

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Pessimistic [concurrency control](abenrap_conc_control_glosry.md) prevents simultaneous modification access to data on the database by more than one user. In [RAP](abenrap_glosry.md) this is ensured by the [RAP locking mechanism](abenrap_locking_glosry.md).
