# base BDEF extension

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A development object that extends a [RAP behavior definition](abencds_behavior_definition_glosry.md) of type [`managed`](abenmanaged_rap_bo_glosry.md) or [`unmanaged`](abenunmanaged_rap_bo_glosry.md) using the statement [`extension`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_extension_syntax.md).
