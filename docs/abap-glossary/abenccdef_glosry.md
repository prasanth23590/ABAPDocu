# CCDEF include

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Include program](abeninclude_program_glosry.md) of a [class pool](abenclass_pool_glosry.md) that is included in front of the [declaration part](abendeclaration_part_glosry.md) of the [global class](abenglobal_class_glosry.md). It can be edited in [ADT](abenadt_glosry.md) by navigating to *Class-Relevant Local Types*. The internal name of the include program ends with `CCDEF`. See also [CCIMP include](abenccimp_glosry.md).
