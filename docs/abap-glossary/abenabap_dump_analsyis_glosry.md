# ABAP Dump Analysis

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Tool for listing and analyzing [runtime errors](abenruntime_error_glosry.md) that occurred in [AS ABAP](abenas_abap_glosry.md) and that can be used to access the affiliated [short dumps](abenshort_dump_glosry.md).
