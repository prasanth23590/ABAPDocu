# packed number literal

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [General](abenabap_glossary.md)

## Definition

A [numeric literal](abennumeric_literal_glosry.md) of [packed number type](abenpacked_number_type_glosry.md).

- In general ABAP, packed number literals are [untyped literals](abenuntyped_literal_glosry.md).

- In [ABAP SQL](abenabap_sql_glosry.md) and [ABAP CDS](abenabap_cds_glosry.md), packed number literals can be [typed literals](abentyped_literal_glosry.md) or [untyped literals](abenuntyped_literal_glosry.md).
