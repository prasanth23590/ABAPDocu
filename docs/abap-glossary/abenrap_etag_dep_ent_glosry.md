# RAP ETag dependent entity

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO entity](abenrap_bo_entity_glosry.md) that uses the [ETag](abenrap_etag_glosry.md) field of another entity for [optimistic concurrency control](abenoptimistic_conc_control_glosry.md). Defined using the keyword [`etag dependent by _Assoc`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_etag.md).
