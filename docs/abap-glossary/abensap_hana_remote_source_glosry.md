# SAP HANA remote source

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

A named [database object](abendb_object_glosry.md) that contains the connection details for accessing an external system and the credentials to use it. An SAP HANA remote source uses a remote source adapter, such as [ODBC](abenodbc_glosry.md), to connect to a remote [SAP HANA database](abenhana_database_glosry.md), a non-SAP HANA database, or to the [SQL services](abenabap_sql_services_glosry.md) of a remote [AS ABAP](abenas_abap_glosry.md).
