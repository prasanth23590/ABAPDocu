# instance event

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Event](abenevent_glosry.md) of a [class](abenclass_glosry.md) declared using [`EVENTS`](../abap-programming-language/abap-declarations/abapevents.md). Instance events usually indicate status changes of [objects](abenobject_glosry.md).
