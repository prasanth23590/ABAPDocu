# write position

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Operand position](abenoperand_position_glosry.md) in which the [operand](abenabap_operand_glosry.md) is written to. There are [read/write positions](abenread_write_position_glosry.md), where an operand is read-accessed before writing and [write-only positions](abenwrite_only_position_glosry.md) where no read access occurs.
