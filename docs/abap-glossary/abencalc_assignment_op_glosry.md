# calculation assignment operator

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Operator for a [calculation assignment](abencalculation_assignment_glosry.md). The following calculation assignment operators are available: [addition assignment operator](abenadd_assignment_op_glosry.md) ([`+=`](../abap-programming-language/abap-processing-internal-data/abencalculation_assignments.md)), a [subtraction assignment operator](abensub_assignment_op_glosry.md) ([`-=`](../abap-programming-language/abap-processing-internal-data/abencalculation_assignments.md)), a [multiplication assignment operator](abenmult_assignment_op_glosry.md) ([`*=`](../abap-programming-language/abap-processing-internal-data/abencalculation_assignments.md)), a [division assignment operator](abendiv_assignment_op_glosry.md) ([`/=`](../abap-programming-language/abap-processing-internal-data/abencalculation_assignments.md)), or a [concatenation assignment operator](abenconcat_assignment_op_glosry.md) ([`&&=`](../abap-programming-language/abap-processing-internal-data/abencalculation_assignment_string.md)).
