# immutable variable

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Variable](abenvariable_glosry.md) that is declared with the [declaration operator](abendeclaration_operator_glosry.md) [`FINAL`](../abap-programming-language/abap-declarations/abenfinal_inline.md). This [inline declaration](abeninline_declaration_glosry.md) is the only [write position](abenwrite_position_glosry.md) within a context where a value can be assigned to an immutable variable.
