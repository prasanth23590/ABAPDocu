# function module

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Procedure](abenprocedure_glosry.md) that can only be implemented in [function pools](abenfunction_pool_glosry.md) and outside [classes](abenclass_glosry.md) between the statements [`FUNCTION`](../abap-programming-language/abap-program-structure/abapfunction.md) and [`ENDFUNCTION`](../abap-programming-language/abap-program-structure/abapendfunction.md). An [ABAP program](abenabap_program_glosry.md) can use the statement [`CALL FUNCTION`](../abap-programming-language/abap-calling-and-exiting-program-units/abapcall_function.md) to call each function module allowed by the [package concept](abenpackage_concept_glosry.md) externally.
