# literal

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [General](abenabap_glossary.md)

## Definition

The textual representation of a value in the [ABAP source code](abenabap_source_code_glosry.md) of an [ABAP program](abenabap_program_glosry.md) or in a [CDS object](abencds_object_glosry.md). There are [typed literals](abentyped_literal_glosry.md) and [untyped literals](abenuntyped_literal_glosry.md) available.
