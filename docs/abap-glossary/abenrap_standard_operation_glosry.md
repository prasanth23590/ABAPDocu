# RAP BO standard operation

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO operation](abenrap_bo_operation_glosry.md) that provides canonical transactional behavior for a [RAP BO](abenrap_bo_glosry.md). In a [managed RAP BO](abenmanaged_rap_bo_glosry.md), standard operations can be provided by the [managed RAP BO provider](abenmanaged_rap_bo_prov_glosry.md).

[Create](abenrap_create_operation_glosry.md), [read](abenrap_read_operation_glosry.md), [update](abenrap_update_operation_glosry.md), [delete](abenrap_delete_operation_glosry.md) ([CRUD](abencrud_glosry.md)) and [lock](abenlock_operation_glosry.md) are standard operations. [Actions](abenrap_action_glosry.md) and [functions](abenrap_function_glosry.md), in contrast, are [non-standard operations](abenrap_nstandard_operation_glosry.md). That means they are application-specific and user-implemented.
