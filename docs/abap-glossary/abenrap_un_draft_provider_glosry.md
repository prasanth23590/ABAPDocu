# RAP unmanaged draft provider

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Draft [provider](abenrap_bo_provider_glosry.md) of [BOs](abenrap_bo_glosry.md) with unmanaged draft. The [draft handling](abenrap_draft_handling_glosry.md) is implemented in the [ABAP behavior pool](abenbehavior_pool_glosry.md).
