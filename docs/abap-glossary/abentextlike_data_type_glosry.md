# text-like data type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) whose [data objects](abendata_object_glosry.md) contain texts. The corresponding [built-in data types](abenbuiltin_data_type_glosry.md) are [`c`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_character.md) and [`string`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_character.md). The corresponding [generic data type](abengeneric_data_type_glosry.md) is [`csequence`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
