# character-like data type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) whose [data objects](abendata_object_glosry.md) contain [characters](abencharacter_glosry.md) encoded according to the current [code page](abencodepage_glosry.md). The actual character-like data types are [text field type](abentext_field_type_glosry.md), [numeric text field type](abennumeric_text_field_type_glosry.md), and [text string type](abentext_string_type_glosry.md). [Date type](abendate_type_glosry.md) and [time type](abentime_type_glosry.md) are special character-like data types. The associated [generic data type](abengeneric_data_type_glosry.md) is [`clike`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
