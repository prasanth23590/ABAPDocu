# database procedure

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

General synonym for [stored procedure](abenstored_procedure_glosry.md). In [SAP HANA databases](abenhana_database_glosry.md) it is a name for an [SQLScript procedure](abensql_script_procedure_glosry.md) programmed in [SQLScript](abensql_script_glosry.md). Database procedures can be managed as [AMDP procedures](abenamdp_procedure_glosry.md) in the [ABAP Managed Database Procedures](abenabap_managed_db_proc_glosry.md) (AMDP). See also [database function](abendatabase_function_glosry.md).
