# UCS

[General](abenabap_glossary.md)

## Definition

Short for Universal Character Set. A 4-byte [character set](abencharacter_set_glosry.md), standardized in ISO-10646, that contains all other character sets. The `UCS` character set is currently identical to the [Unicode](abenunicode_glosry.md) character set; that is, no other characters than those contained in Unicode are currently defined. [Character representations](abenchar_representation_glosry.md) for the `UCS` character set are the [UTF](abenutf_glosry.md) representations [UCS-2](abenucs2_glosry.md) and UCS-4.
