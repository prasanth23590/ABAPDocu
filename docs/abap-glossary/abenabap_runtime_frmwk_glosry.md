# ABAP runtime framework

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Also called ABAP runtime environment. Hardware- and operating system-independent platform (virtual machine) of an [ABAP program](abenabap_program_glosry.md). Processes of the ABAP runtime framework control the execution of an ABAP program by calling the [processing blocks](abenprocessing_block_glosry.md) of the program. [ABAP statements](abenabap_statement_glosry.md) are implemented in the [ABAP kernel](abenkernel_glosry.md) of the ABAP runtime framework. The ABAP runtime framework is provided by the [Application Server ABAP](abenas_abap_glosry.md) and, therefore, [ABAP programs](abenabap_program_glosry.md) can only be executed in AS ABAP.
