# XML writer

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Instance](abeninstance_glosry.md) of a [class](abenclass_glosry.md) of the [sXML Library](abensxml_library_glosry.md) that implements the [interface](abenoo_intf_glosry.md) `IF_SXML_WRITER`. An XML writer enables the rendering of [XML](abenxml_glosry.md) in different [formats](../abap-programming-language/abap-data-interchange-formats/abenabap_sxml_lib_formats.md).
