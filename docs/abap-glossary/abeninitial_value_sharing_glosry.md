# initial value sharing

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

The status of a [boxed component](abenboxed_component_glosry.md) as long as it is processed by read access only. The [initial value](abeninitial_value_glosry.md) of all type-compliant boxed components of the same type is only stored once in each [AS instance](abenas_instance_glosry.md) in the [PXA](abenpxa_glosry.md).
