# Unicode character representation

[General](abenabap_glossary.md)

## Definition

[Character representation](abenchar_representation_glosry.md) defined for [Unicode](abenunicode_glosry.md). SAP supports the representations [UTF-8](abenutf8_glosry.md), [UTF-16](abenutf16_glosry.md), and [UTF-32](abenutf32_glosry.md), and the [byte order](abenbyte_order_glosry.md) can be platform-dependent. UTF-16 is the [system code page](abensystem_codepage_glosry.md) of a [Unicode system](abenunicode_system_glosry.md). The programming language ABAP supports the subset [UCS-2](abenucs2_glosry.md) without [surrogates](abensurrogates_glosry.md).
