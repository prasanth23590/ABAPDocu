# event

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

An event can trigger the processing of a [processing block](abenprocessing_block_glosry.md), without actually knowing the processing block.

Either a component of a [class](abenclass_glosry.md) or an [interface](abenoo_intf_glosry.md) declared using [`[CLASS-]`](../abap-programming-language/abap-declarations/abapclass-events.md)[`EVENTS`](../abap-programming-language/abap-declarations/abapevents.md), or an event of the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md). Events in classes trigger [event handlers](abenevent_handler_glosry.md).
