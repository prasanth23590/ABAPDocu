# ABAP enumerated type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Enumerated type](abenenum_type_glosry.md) in ABAP. An [enumerated variable](abenenumerated_variable_glosry.md) of an enumerated type can only accept the [enumerated values](abenenumerated_value_glosry.md) defined there that exist as the content of [enumerated constants](abenenumerated_constant_glosry.md) or components of an [enumerated structure](abenenumerated_structure_glosry.md). An enumerated type is defined with [`TYPES BEGIN OF ENUM`](../abap-programming-language/abap-declarations/abaptypes_enum.md).
