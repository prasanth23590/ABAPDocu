# ABAP SQL hierarchy

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

A tabular [SQL data source](abensql_data_source_glosry.md) in [ABAP SQL](abenabap_sql_glosry.md) whose rows contain the content of the [hierarchy nodes](abenhierarchy_node_glosry.md) of a [parent-child hierarchy](abenpcr_hierarchy_glosry.md). An ABAP SQL hierarchy is either a [parent-child-based hierarchy](abenpc_based_hiera_glosry.md) or a [level-based hierarchy](abenlevel_based_hiera_glosry.md). Special [hierarchy columns](abenhierarchy_column_glosry.md) contain [hierarchy attributes](abenhierarchy_attribute_glosry.md) of the individual hierarchy nodes in the SQL hierarchy. SQL hierarchies are either created using a [hierarchy generator](abenhierarchy_generator_glosry.md), an existing [CDS hierarchy](abencds_hierarchy_glosry.md), or a [CTE hierarchy](abencte_hierarchy_glosry.md). SQL hierarchies can be used in the [`FROM`](../abap-programming-language/abap-database-access/abapfrom_clause.md) clause and as the source of special [hierarchy navigators](abenhierarchy_navigator_glosry.md).
