# RAP interface behavior definition

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Interface BDEF for short. A component of a [RAP BO interface](abenrap_bo_interface_glosry.md). It defines the behavior that is included in the interface. A RAP BO interface behavior definition is represented by a [RAP behavior definition](abencds_behavior_definition_glosry.md) with the [BDEF implementation type](abencds_bdef_impl_type_glosry.md) `interface`.
