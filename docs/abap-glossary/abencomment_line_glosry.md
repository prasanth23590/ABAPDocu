# comment line

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [General](abenabap_glossary.md)

## Definition

Line in a program that contains nothing but a [comment](abencomment_glosry.md). A comment line is either completely identified as a comment by an asterisk `*` in the first position or is a line that contains nothing except a comment introduced by `"` in any position.
