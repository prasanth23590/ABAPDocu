# RAP behavior definition

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

RAP BDEF or BDEF for short. A RAP behavior definition describes a [RAP business object (RAP BO)](abenrap_bo_glosry.md) by defining its behavior for all its [BO entities](abenrap_bo_entity_glosry.md). A BDEF is written in [BDL source code](abenbdl_source_code_glosry.md) using language elements in [RAP BDL](abencds_bdl_glosry.md).
