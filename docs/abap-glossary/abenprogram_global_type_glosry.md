# program global type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) or [object type](abenobject_type_glosry.md) that is defined in an [ABAP program](abenabap_program_glosry.md) and is known in the entire program behind its declaration.
