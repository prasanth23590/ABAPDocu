# table key

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Columns of an [internal table](abeninternal_table_glosry.md) or [DDIC database table](abenddic_db_table_glosry.md) whose content identifies table lines. For internal tables, distinction is made between [primary table keys](abenprimary_table_key_glosry.md) and [secondary table keys](abensecondary_table_key_glosry.md), which are [technical type properties](abentechnical_type_prpt_glosry.md) of the [table type](abentable_type_glosry.md).
