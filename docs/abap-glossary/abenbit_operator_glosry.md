# bit operator

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Is applied to an [operand](abenoperand_glosry.md) or combines two operands of a [bit expression](abenbit_expression_glosry.md). The possible bit operators are [`BIT-NOT`](../abap-programming-language/abap-processing-internal-data/abenbit_operators.md), [`BIT-AND`](../abap-programming-language/abap-processing-internal-data/abenbit_operators.md), [`BIT-OR`](../abap-programming-language/abap-processing-internal-data/abenbit_operators.md), and [`BIT-XOR`](../abap-programming-language/abap-processing-internal-data/abenbit_operators.md).
