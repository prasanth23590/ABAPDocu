# write-only position

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Write position](abenwrite_position_glosry.md) in which the [operand](abenabap_operand_glosry.md) is only written to but not read-accessed. See [declaration position](abendeclaration_position_glosry.md).
