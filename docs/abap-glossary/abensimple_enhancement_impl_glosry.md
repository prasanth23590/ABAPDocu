# simple enhancement implementation

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Semantically interrelated enhancement of a [repository object](abenrepository_object_glosry.md). A simple enhancement implementation manages one or more [enhancement implementation elements](abenenhancement_impl_elem_glosry.md). A simple enhancement implementation can occur independently or as a component of a [composite enhancement implementation](abencomp_enhancement_impl_glosry.md).
