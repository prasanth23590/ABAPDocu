# database field

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md) [General](abenabap_glossary.md)

## Definition

Smallest logical unit of the [structure](abenstructure_glosry.md) of a [database table](abendatabase_table_glosry.md). The properties of a database field of a [DDIC database table](abenddic_db_table_glosry.md) in the [ABAP Dictionary](abenabap_dictionary_glosry.md) are defined by a [DDIC data element](abendata_element_glosry.md).
