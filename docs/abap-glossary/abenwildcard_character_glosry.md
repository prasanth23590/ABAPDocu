# wildcard character

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Character that substitutes other content. In [relational expressions](abencomparison_expression_glosry.md) with the operators [`CP`](../abap-programming-language/abap-program-flow-logic/abenlogexp_strings.md) and [`NP`](../abap-programming-language/abap-program-flow-logic/abenlogexp_strings.md), `*` usually stands for any [string](abencharacter_string_glosry.md) and `+` for any individual character. In [SQL conditions](abensql_cond_glosry.md) with the [operator](abenoperator_glosry.md) [`LIKE`](../abap-programming-language/abap-database-access/abenwhere_logexp_like.md), `%` stands for any string and `_` for individual characters. In [regular expressions](abenregular_expression_glosry.md), an extended set of special characters is used to define patterns. The special functions of wildcard characters can be switched off using [escape characters](abenescape_character_glosry.md)
