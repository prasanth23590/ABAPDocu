# instantiation

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Creation of an [instance](abeninstance_glosry.md). [Data objects](abendata_object_glosry.md) as instances of [data types](abendata_type_glosry.md) are created implicitly when a [context](abenobj_context_glosry.md) is loaded, or explicitly using [`NEW`](../abap-programming-language/abap-creating-objects-and-values/abenconstructor_expression_new.md). [Objects](abenobject_glosry.md) as an instance of [classes](abenclass_glosry.md) are only created explicitly using [`NEW`](../abap-programming-language/abap-creating-objects-and-values/abenconstructor_expression_new.md).
