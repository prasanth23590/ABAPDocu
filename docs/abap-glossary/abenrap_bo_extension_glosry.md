# RAP BO extension

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [repository object](abenrepository_object_glosry.md) that extends a [RAP BO](abenrap_bo_glosry.md). The following types of RAP BO extensions exist:

- [DDIC extensions](abenddic_extension_glosry.md) defined in [DDIC DDL](abenddic_dcl_glosry.md)

- [CDS entity extension](abencds_entity_extend_glosry.md) in [CDS DDL](abencds_ddl_glosry.md).

- [BDEF extensions](abenrap_extension_glosry.md) in [RAP BDL](abencds_bdl_glosry.md).

- [Service definition extensions](abencds_service_def_ext_glosry.md) in [CDS SDL](abencds_sdl_glosry.md).
