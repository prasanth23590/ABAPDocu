# RAP query

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A consumption option in RAP that provides read-only consumption of data defined in [CDS entities](abencds_entity_glosry.md). A RAP query is executed by the [RAP query engine](abenrap_query_engine_glosry.md).
