# RAP edit draft instance

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [draft instance](abenrap_draft_instance_glosry.md) that is produced by the [draft action](abenrap_bo_draft_action_glosry.md) `Edit`. For an edit draft instance, there exists a corresponding active instance in parallel.

See also: [RAP new draft instance](abenrap_new_draft_inst_glosry.md)
