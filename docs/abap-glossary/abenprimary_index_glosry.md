# primary index

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Unique [index](abenindex_glosry.md) of a [DDIC database table](abenddic_db_table_glosry.md) defined in [ABAP Dictionary](abenabap_dictionary_glosry.md). The index is assembled from the [key fields](abenkey_field_glosry.md) of the [primary key](abenprimary_key_glosry.md). When a table is activated in the ABAP Dictionary, the primary index is created automatically using the primary key fields of the table. Certain [internal tables](abeninternal_table_glosry.md) have a [primary table index](abenprimary_table_index_glosry.md).
