# index table

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

General term for [internal tables](abeninternal_table_glosry.md) that are managed using a [primary table index](abenprimary_table_index_glosry.md) ([standard tables](abenstandard_table_glosry.md) and [sorted tables](abensorted_table_glosry.md)). A [secondary table key](abensecondary_table_key_glosry.md) can be assigned to enable access using a [hash algorithm](abenhash_algorithm_glosry.md). The corresponding [generic data type](abengeneric_data_type_glosry.md) is [`index table`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
