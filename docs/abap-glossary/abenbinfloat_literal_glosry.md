# binary floating point literal

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [numeric literal](abennumeric_literal_glosry.md) that has the [binary floating point data type](abenbinfloat_glosry.md) [`f`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_numeric.md) or [`FLTP`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md).

- Not available in general ABAP.

- In [ABAP SQL](abenabap_sql_glosry.md) and [ABAP CDS](abenabap_cds_glosry.md), binary floating point literals are available as [typed literals](abentyped_literal_glosry.md).
