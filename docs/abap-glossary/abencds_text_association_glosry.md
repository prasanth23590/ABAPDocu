# CDS text association

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A regular [CDS association](abencds_association_glosry.md) whose [association target](abenassociation_target_glosry.md) is a [CDS text provider view](abencds_text_provider_glosry.md). The [target cardinality](abentarget_cardinality_glosry.md) of a CDS text association is `TO MANY`. CDS text associations are used for defining [CDS localized fields](abencds_localized_field_glosry.md).
