# CDS simple type

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS user-defined type](abencds_user_defined_type_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md) that defines an [elementary data type](abenelementary_data_type_glosry.md). A CDS simple type is defined using the statement [`DEFINE TYPE`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_simple_type.md).
