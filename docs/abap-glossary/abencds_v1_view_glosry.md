# CDS DDIC-based view

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An obsolete type of [CDS view](abencds_view_glosry.md) that is technically based on a [CDS-managed DDIC view (obsolete)](abencds_mngdddic_view_glosry.md) in the [ABAP Dictionary](abenabap_dictionary_glosry.md). A CDS DDIC-based view (obsolete) is defined with the [CDS DDL](abencds_ddl_glosry.md) statement [`DEFINE VIEW ddic_based_view`](../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_define_view_v1.md).
