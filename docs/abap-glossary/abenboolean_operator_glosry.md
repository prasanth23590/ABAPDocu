# Boolean operator

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

Negates or combines [logical expressions](abenlogical_expression_glosry.md). Boolean operators belong to the [logical operators](abenlogical_operator_glosry.md) that are used in [logical expressions](abenlogical_expression_glosry.md).

- In ABAP, the possible Boolean operators are [`NOT`](../abap-programming-language/abap-program-flow-logic/abenlogexp_not.md), [`AND`](../abap-programming-language/abap-program-flow-logic/abenlogexp_and.md), [`OR`](../abap-programming-language/abap-program-flow-logic/abenlogexp_or.md), and [`EQUIV`](../abap-programming-language/abap-program-flow-logic/abenlogexp_equiv.md).

- In ABAP SQL, the possible Boolean operators are `NOT`, `AND`, `OR`. For further details, see the topic [`sql_cond` - `AND`, `OR`, `NOT`, `( )`](../abap-programming-language/abap-database-access/abenwhere_logexp_andornot.md).

- In ABAP CDS, the possible Boolean operators are `NOT`, `AND`, `OR`. For further details, see the topic [CDS DDL - CDS View Entity, `cds_cond`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_conditional_expression_v2.md).
