# namespace

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

A namespace is a set of unique names that identify a set of objects. In ABAP, we can distinguish [namespaces for program-internal objects](../abap-programming-language/abap-syntax-elements-of-an-abap-program/abennaming_conventions.md) and a namespace for [repository objects](abenrepository_object_glosry.md). The latter can be divided into a [SAP namespace](abensap_namespace_glosry.md), a [customer namespace](abencustomer_namespace_glosry.md), a [partner namespace](abenpartner_namespace_glosry.md) and [prefix namespaces](abenprefix_name_space_glosry.md).
