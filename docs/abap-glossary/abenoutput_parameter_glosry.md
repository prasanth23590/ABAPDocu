# output parameter

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Formal parameter](abenformal_parameter_glosry.md) whose value is set during the call and is made available in the [actual parameter](abenactual_parameter_glosry.md) after the call.
