# variable

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Named data object](abennamed_data_object_glosry.md) whose value can be changed during the runtime of an [ABAP program](abenabap_program_glosry.md). See also [immutable variable](abenimmutable_variable_glosry.md).
