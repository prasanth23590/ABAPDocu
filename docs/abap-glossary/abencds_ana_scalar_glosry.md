# analytical scalar function

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS scalar function](abencds_scalar_function_glosry.md) that is evaluated by an analytical runtime environment. Analytical scalar functions can be used in [analytical projection views](abencds_analytical_pv_glosry.md) in operand positions that expect a scalar value.

Analytical scalar functions are [system functions](abencds_system_func_glosry.md). They can only be defined and implemented internally by SAP. They are available for internal and external use in [CDS analytical queries](abencds_analytic_query_glosry.md).

For a list of analytical scalar functions delivered by SAP, see [ABAP CDS - Analytical Scalar Functions](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_ana_scalar_function.md).
