# SAP HANA Smart Data Access

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Software that enables the [SAP HANA database](abenhana_database_glosry.md) to access and query data from other (remote) enterprise data stores based on a [data federation](abendata_federation_glosry.md) approach. This technology is included in the SAP HANA platform. SAP HANA Smart Data Access uses the [ODBC](abenodbc_glosry.md) protocol for external communication.
