# aggregate expression

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

In [ABAP SQL](abenabap_sql_glosry.md) or in [CDS DDL](abencds_ddl_glosry.md), an aggregate expression uses an [aggregate function](abenaggregate_function_glosry.md) to determine a value from the values of a column of the result set of a [query](abenasql_query_glosry.md).
