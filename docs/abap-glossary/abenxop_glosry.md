# XOP

[General](abenabap_glossary.md)

## Definition

Short for XML-binary Optimized Packaging (see <http://www.w3.org/TR/xop10/>). Representation of [XML](abenxml_glosry.md) data in which any binary raw data is stored separately from the data represented by characters. In ABAP, XOP is supported by a [format](../abap-programming-language/abap-data-interchange-formats/abenabap_sxml_lib_formats.md) of the [sXML Library](../abap-programming-language/abap-data-interchange-formats/abenabap_sxml_lib.md).
