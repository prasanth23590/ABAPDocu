# RAP draft indicator

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [BDEF derived type](abenrap_derived_type_glosry.md) component that is used to indicate whether a [RAP BO instance](abenrap_bo_instance_glosry.md) is a [draft instance](abenrap_draft_instance_glosry.md) or an [active instance](abenrap_active_instance_glosry.md). It is contained in the component group [`%tky`](../abap-rap-business-objects/abap-for-rap-business-objects/abapderived_types_tky.md) as [`%is_draft`](../abap-rap-business-objects/abap-for-rap-business-objects/abapderived_types_is_draft.md).
