# CDS source code

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

The [source code](abensource_code_glosry.md) for the definition of a [CDS object](abencds_object_glosry.md). There are different kinds of CDS source code, such as

- [DDL source code](abenddl_source_code_glosry.md) for [CDS data definitions](abencds_data_definition_glosry.md)

- [DDLA source code](abenddla_source_code_glosry.md) for [CDS annotation definitions](abencds_anno_definition_glosry.md)

- [DDLX source code](abenddlx_source_code_glosry.md) for [CDS metadata extensions](abencds_metadata_extension_glosry.md)

- [DCL source code](abendcl_source_code_glosry.md) for [CDS roles](abencds_role_glosry.md)

- [SDL source code](abensdl_source_code_glosry.md) for [CDS service definitions](abencds_service_definition_glosry.md)

The different types of source code have different editors in [ADT](abenadt_glosry.md), which are documented there. The CDS objects defined in CDS source code are transported using the source code.
