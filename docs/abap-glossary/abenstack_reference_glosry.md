# stack reference

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Reference](abenreference_glosry.md) to an [object](abenobject_glosry.md) or part of an object in the [stack](abenstack_glosry.md). A stack reference does not keep an object alive. See also [heap reference](abenheap_reference_glosry.md).
