# mesh node

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Component of a [mesh](abenmesh_glosry.md). Mesh nodes are always [internal tables](abeninternal_table_glosry.md) with a structured [line type](abenrow_type_glosry.md). Mesh nodes can have [mesh associations](abenmesh_association_glosry.md) that they can address in [mesh paths](abenmesh_path_glosry.md).
