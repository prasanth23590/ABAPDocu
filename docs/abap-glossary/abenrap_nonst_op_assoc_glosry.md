# RAP nonstandard operation for associations

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An [operation for associations](abenrap_operation_assoc_glosry.md) that provides noncanonical behavior along an [association path](abencds_association_path_glosry.md) from an [association source](abenassociation_source_glosry.md) to an [association target](abenassociation_target_glosry.md). For example, the [link action](abenrap_link_action_glosry.md), the [unlink action](abenrap_unlink_action_glosry.md), the [reorder action](abenrap_reorder_action_glosry.md), and the [inverse function](abenrap_inverse_function_glosry.md) are predefined nonstandard operations for associations.
