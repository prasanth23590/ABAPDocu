# message

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Text that can be accessed using the statement [`MESSAGE`](../abap-programming-language/abap-text-repositories/abapmessage.md). Messages are always displayed in the [logon language](abenlogon_language_glosry.md), which cannot be changed during a [user session](abenuser_session_glosry.md). Message texts are organized into [message classes](abenmessage_class_glosry.md) and [message numbers](abenmessage_number_glosry.md). Messages are also used as exception texts of [exception classes](abenexception_class_glosry.md).
