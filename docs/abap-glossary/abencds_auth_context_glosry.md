# RAP authorization context for disable

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP authorization context](abencds_auth_con_glosry.md) that lists [authorization objects](abenauthorization_object_glosry.md) which can be skipped if the authorization context for disable in question is activated.
