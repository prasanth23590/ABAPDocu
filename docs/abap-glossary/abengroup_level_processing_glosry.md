# group level processing

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

The evaluation of [group levels](abengroup_level_glosry.md) in [internal tables](abeninternal_table_glosry.md). Group level processing takes place in [`LOOP`](../abap-programming-language/abap-processing-internal-data/abaploop_at_itab.md)-[loops](abenloop_glosry.md) using [control structures](abencontrol_structure_glosry.md) defined using the keyword [`AT`](../abap-programming-language/abap-processing-internal-data/abapat_itab.md).
