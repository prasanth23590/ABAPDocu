# abstract

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Term in [ABAP Objects](abenabap_objects_glosry.md). An abstract [class](abenclass_glosry.md) cannot be instantiated. An abstract [method](abenmethod_glosry.md) can only be implemented in [subclasses](abensubclass_glosry.md) of its class. A non-abstract class or method is [concrete](abenconcrete_glosry.md).
