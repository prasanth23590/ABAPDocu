# logon

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Time at which an [ABAP user](abenabap_user_glosry.md) logs on to the [AS ABAP](abenas_abap_glosry.md) by specifying the [client ID](abenclient_identifier_glosry.md), [user name](abenuser_name_glosry.md), [password](abenpassword_glosry.md), and the [logon language](abenlogon_language_glosry.md). Each logon starts a [user session](abenuser_session_glosry.md).
