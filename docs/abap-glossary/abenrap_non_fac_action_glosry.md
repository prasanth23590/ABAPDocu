# RAP non-factory action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP action](abenrap_action_glosry.md) that is not a factory action. In contrast to factory actions, the [BDEF derived type](abenrap_derived_type_glosry.md) of a non-factory action does not contain a [`%cid`](../abap-rap-business-objects/abap-for-rap-business-objects/abapderived_types_cid.md) component.
