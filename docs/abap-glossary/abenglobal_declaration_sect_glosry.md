# global declaration part

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Area following the opening statement of an [ABAP program](abenabap_program_glosry.md) in which [interfaces](abenoo_intf_glosry.md), [data types](abendata_type_glosry.md), [classes](abenclass_glosry.md) and [data objects](abendata_object_glosry.md) that are visible in the whole program can be declared.
