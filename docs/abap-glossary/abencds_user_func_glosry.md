# CDS user-defined function

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Custom function in [ABAP CDS](abenabap_cds_glosry.md) that allows developers to define and implement their own custom logic and reuse it in operand positions of [CDS entities](abencds_entity_glosry.md). [SQL-based scalar functions](abencds_sql_scalar_glosry.md) are the only type of CDS user-defined functions available.
