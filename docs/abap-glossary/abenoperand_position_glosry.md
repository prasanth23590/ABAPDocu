# operand position

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [General](abenabap_glossary.md)

## Definition

Position of an [ABAP statement](abenabap_statement_glosry.md) or of a [CDS data definition](abencds_data_definition_glosry.md) at which an [operand](abenoperand_glosry.md) is listed. There are [read](abenread_position_glosry.md) and [write positions](abenwrite_position_glosry.md). In an ABAP statement, such an operand position is typed with an [operand type](abenoperand_type_glosry.md) and appropriate [data objects](abendata_object_glosry.md) or [expressions](abenexpression_glosry.md) can be specified. The operand positions for the latter are [expression positions](abenexpression_position_glosry.md). Besides that there are other operand positions, where types, callable units or other external resources such as [CDS entities](abencds_entity_glosry.md) or [DDIC database tables](abenddic_db_table_glosry.md) can be specified as operands.
