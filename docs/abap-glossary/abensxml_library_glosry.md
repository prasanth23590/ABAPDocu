# sXML library

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Global [interfaces](abenglobal_interface_glosry.md) and [classes](abenglobal_class_glosry.md) for handling [XML](abenxml_glosry.md) data in different [formats](../abap-programming-language/abap-data-interchange-formats/abenabap_sxml_lib_formats.md). The *serial* XML Library provides XML readers and XML writers for various sources and targets. The classes and interfaces in sXML Library start with the prefixes `CL_SXML` or `IF_SXML`.
