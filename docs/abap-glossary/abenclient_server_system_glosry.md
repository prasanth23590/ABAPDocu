# client-server system

[General](abenabap_glossary.md)

## Definition

Software system that consists of multiple software layers. These are usually the [presentation layer](abenpresentation_layer_glosry.md), the [application layer](abenapplication_layer_glosry.md), and the [database layer](abendatabase_layer_glosry.md). [AS ABAP](abenas_abap_glosry.md) represents the application layer of a client-server system ([ABAP system](abenabap_system_glosry.md)) in which [ABAP programs](abenabap_program_glosry.md) are executed.
