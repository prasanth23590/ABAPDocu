# system program

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP program](abenabap_program_glosry.md) that is part of the [AS ABAP](abenas_abap_glosry.md) infrastructure. System programs generally work with data from client-independent [system tables](abensystem_table_glosry.md), but also with data of special [clients](abenclient_glosry.md).
