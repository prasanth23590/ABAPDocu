# RAP extension layering

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

It is possible to extend a [BDEF extension](abenrap_extension_glosry.md) with further BDEF extensions. This is referred to as extension layering. Before a BDEF extension can be extended, extensions must be technically enabled by means of [RAP extensibility enablement](abenrap_ext_enablement_glosry.md). Technically, a BDEF extension that extends another extension is a regular extension and the rules for BDEF extensions apply.
