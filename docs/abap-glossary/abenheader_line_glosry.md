# header line

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Obsolete [work area](abenwork_area_glosry.md) of an [internal table](abeninternal_table_glosry.md) whose type is the [line type](abenrow_type_glosry.md) and has the same name as the internal table. When an internal table with a header line is used in an [operand position](abenoperand_position_glosry.md), the header line is usually addressed. To force access to the [table body](abentable_body_glosry.md), square brackets `[]` can be specified after the table name.
