# database function

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[SQLScript function](abensql_script_function_glosry.md) in the [SAP HANA database](abenhana_database_glosry.md). Database functions must have a return value defined with `RETURN`. There are [table functions](abentable_function_glosry.md) with a tabular return value and [scalar functions](abenscalar_function_glosry.md) with a scalar return value. Unlike [database procedures](abendatabase_procedure_glosry.md), database functions cannot be called using `CALL`, but can be used directly in read positions of statements. Database functions can be managed as [AMDP functions](abenamdp_function_glosry.md) in the [ABAP Managed Database Procedures](abenabap_managed_db_proc_glosry.md) (AMDP).
