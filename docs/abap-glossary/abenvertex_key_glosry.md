# vertex key

[General](abenabap_glossary.md)

## Definition

A vertex key represents one [vertex](abenvertex_glosry.md) attribute or a set of [vertex attributes](abenvertex_attr_glosry.md) that must uniquely identify vertices. If the vertex key consists of multiple [attributes](abenvertex_attr_glosry.md), then the [edge table's](abenedge_table_glosry.md) source and target must consist of a corresponding set of attributes.
