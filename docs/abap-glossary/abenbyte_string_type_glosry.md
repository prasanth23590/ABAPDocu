# byte string type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Byte-like data type](abenbyte_like_data_typ_glosry.md) for storing [byte chains](abenbyte_chain_glosry.md) of variable length. The associated [built-in ABAP type](abenbuiltin_abap_type_glosry.md) is [`xstring`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_byte.md). The [built-in DDIC type](abenbuiltin_ddic_type_glosry.md) is [`RAWSTRING`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md). Internal administration takes place using an internal [reference](abenreference_glosry.md) and the data type is [deep](abendeep_glosry.md). A [data object](abendata_object_glosry.md) of a byte field type is a [byte string](abenbyte_string_glosry.md).
