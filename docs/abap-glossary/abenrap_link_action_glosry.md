# RAP link action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP non-standard operation for associations](abenrap_nonst_op_assoc_glosry.md) that associates a [RAP BO entity instance](abenrap_bo_entity_inst_glosry.md) to another RAP BO entity instance by setting the [foreign key](abenforeign_key_glosry.md). The link action can be defined for [intra-BO associations](abencds_intra_bo_assoc_glosry.md) and for [cross-BO associations](abencds_cross_bo_assoc_glosry.md).

See also: [RAP unlink action](abenrap_unlink_action_glosry.md)
