# authorization

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Entry in the [user master record](abenuser_master_record_glosry.md). An authorization consists of complete or generic values for the [authorization fields](abenauthorization_field_glosry.md) of an [authorization object](abenauthorization_object_glosry.md). The combination specifies which activities an [ABAP user](abenabap_user_glosry.md) can use to access which data.
