# CDS projection view

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A special [CDS view entity](abencds_v2_view_glosry.md) that is based on another [CDS view entity](abencds_v2_view_glosry.md) (called [projected entity](abencds_pv_projected_entity_glosry.md)). CDS projection views adapt a CDS data model for service-specific use cases. A CDS projection view is defined with the [CDS DDL](abencds_ddl_glosry.md) statement `DEFINE [TRANSIENT] VIEW ENTITY AS PROJECTION`.

The following types of CDS projection views are available:

- [CDS transactional queries](abencds_transactional_pv_glosry.md)

- [CDS transactional interfaces](abencds_trans_interface_glosry.md)

- [CDS analytical projection views](abencds_analytical_pv_glosry.md)
