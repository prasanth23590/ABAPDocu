# runtime warning

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A runtime warning indicates critical situations that may cause a [runtime error](abenruntime_error_glosry.md) during program execution, such as high memory consumption. A runtime warning creates a [short dump](abenshort_dump_glosry.md), but does not terminate the current program.
