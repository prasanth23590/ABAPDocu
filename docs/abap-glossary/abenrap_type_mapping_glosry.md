# RAP type mapping

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Mapping between data types of the data model that is defined in CDS for a [RAP business object](abenrap_bo_glosry.md) to other data types that do not match a [BDEF derived type](abenrap_derived_type_glosry.md) component pattern.

For example, it is used in the behavior definition to map database field names to CDS element names.
