# HANA tuning object

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

A [tuning object](abentuning_object_glosry.md) that defines technical settings for an ABAP Dictionary object on the [SAP HANA database](abenhana_database_glosry.md). HANA tuning objects are defined in the [ABAP Dictionary](abenabap_dictionary_glosry.md) in [DDIC DDL](abenddic_dcl_glosry.md) and they are a wrapper for settings on the [SAP HANA database](abenhana_database_glosry.md). Currently, there are the following HANA tuning objects:

- [DDIC dependency rules](abendependency_rule_glosry.md)

- [DDIC dynamic caches](abendynamic_cache_glosry.md)
