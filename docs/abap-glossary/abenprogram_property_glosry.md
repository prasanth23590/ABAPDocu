# program property

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Property of an [ABAP program](abenabap_program_glosry.md). Program properties are used to administrate the program and affect how it is handled in [syntax checks](abensyntax_check_glosry.md) and in the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md).
