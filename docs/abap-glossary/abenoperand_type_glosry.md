# operand type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) with which an [operand position](abenoperand_position_glosry.md) is typed. The operand type can be complete or generic. An [operand](abenoperand_glosry.md) must match the operand type. Depending on the statement, [type conversions](abentype_conversion_glosry.md) or [castings](abencast_casting_glosry.md) take place for incompatible operands. In [inline declarations](abeninline_declaration_glosry.md), the operand types determine the declared data type. For [constructor expressions](abenconstructor_expression_glosry.md), the operand type can be used to infer the type of the result.
