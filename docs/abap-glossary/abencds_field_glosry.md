# CDS source field

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A field of a data source of a [CDS entity](abencds_entity_glosry.md) that can be used as a [CDS element](abencds_element_glosry.md) and at different operand positions of that CDS entity.
