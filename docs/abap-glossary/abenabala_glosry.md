# ABAP language

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

The ABAP language or [ABAP programming language](abenabap_programming_langu_glosry.md) or [ABAP](abenabap_glosry.md) for short is the main programming language of the [ABAP development environment (ABAP DE)](abenabap_dev_envir_glosry.md). It is used as the programming interface of an [Application Server ABAP](abenas_abap_glosry.md) (AS ABAP) of an [ABAP system](abenabap_system_glosry.md). Depending on the program paradigm [ABAP Cloud](abenabap_cloud_glosry.md) or [classic ABAP](abenclassic_abap_glosry.md), different [ABAP language versions](abenabap_version_glosry.md) can be used.
