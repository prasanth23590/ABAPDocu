# developer extensibility

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

An extensibility approach that allows ABAP developers to create upgrade-stable custom ABAP code in cloud and on-premise environments. It delivers flexibility beyond key user extensibility and can be done directly on the software stack using the [ABAP development tools for Eclipse](abenadt_glosry.md) (ADT) via local [released APIs](abenreleased_api_glosry.md).

One use case for developer extensibility is [RAP extensibility](abenrap_extensibility_glosry.md). Using [ABAP for Cloud Development](abenabap_for_cloud_dev_glosry.md), a RAP application can be extended from the database to the service definition directly in ADT with custom ABAP code.
