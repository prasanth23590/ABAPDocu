# Business Object Processing Framework

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[BOPF](abenbopf_glosry.md) for short. An ABAP-based framework that provides a set of generic services and functionalities to create [business objects](abenbusiness_object_glosry.md) (BOs), such as [CDS-based BOPF BOs](abencds_bopf_bo_glosry.md).
