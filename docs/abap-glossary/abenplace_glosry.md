# place in a decimal number

[General](abenabap_glossary.md)

## Definition

Place in a [decimal number](abendecimal_number_glosry.md). These can be the integer digits of a number or digits in the [fractional portion](abendecimal_place_glosry.md). In general, only those places in the fractional portion are referred to as [decimal places](abenfract_digit_glosry.md).
