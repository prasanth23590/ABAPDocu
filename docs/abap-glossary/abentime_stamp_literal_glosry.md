# time stamp literal

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [General](abenabap_glossary.md)

## Definition

A [literal](abenabap_literal_glosry.md) of the data type [`UTCLONG`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md).

- Not available in general ABAP.

- In [ABAP SQL](abenabap_sql_glosry.md) and [ABAP CDS](abenabap_cds_glosry.md), time stamp literals are available as [typed literals](abentyped_literal_glosry.md).
