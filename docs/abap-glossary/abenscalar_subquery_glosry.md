# scalar subquery

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

[Subquery](abensubquery_glosry.md) with a single-column result set. The [`SELECT` list](../abap-programming-language/abap-database-access/abapselect_list.md) of the subquery contains one element only.
