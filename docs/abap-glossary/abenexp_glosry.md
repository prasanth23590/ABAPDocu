# expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Also [expression syntax](abenexpression_syntax_glosry.md). An expression is a syntax that can be used at [operand positions](abenoperand_position_glosry.md) of statements. When a statement is processed, its expressions are evaluated and the results are used as [operands](abenoperand_glosry.md). See also:

- [ABAP expression](abenexpression_glosry.md)

- [SQL expression](abensql_expression_glosry.md)

- [CDS DDL expression](abencds_expression_glosry.md)
