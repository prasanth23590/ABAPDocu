# CDS element

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An element in a [CDS entity](abencds_entity_glosry.md). A CDS element is defined in an element list of a [CDS data definition](abencds_data_definition_glosry.md) and is a [structure component](abenstructure_component_glosry.md) of the [structured type](abenstructured_type_glosry.md) defined by the CDS entity. CDS elements can be, for example, [CDS source fields](abencds_field_glosry.md), [CDS literals](abencds_literal_glosry.md), or [CDS DDL expressions](abencds_expression_glosry.md).
