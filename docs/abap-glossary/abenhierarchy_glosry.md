# hierarchy

[General](abenabap_glossary.md)

## Definition

An arrangement of objects in hierarchical structures. The objects of a hierarchy are [hierarchy nodes](abenhierarchy_node_glosry.md) that are linked to each other using [hierarchy edges](abenhierarchy_edge_glosry.md). In [ABAP SQL](abenabap_sql_glosry.md) and [ABAP CDS](abenabap_cds_glosry.md), hierarchical data can be handled with [ABAP SQL hierarchies](abensql_hierarchy_glosry.md) and [CDS hierarchies](abencds_hierarchy_glosry.md).
