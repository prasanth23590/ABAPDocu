# CDS DDIC-based view extension

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS entity extension](abencds_entity_extend_glosry.md) of a [CDS DDIC-based view](abencds_v1_view_glosry.md). A CDS DDIC-based view extension can be used to add elements and/or clauses to a view without making any modifications to the original view. It is defined using the statement [`EXTEND VIEW`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_extend_view.md).
