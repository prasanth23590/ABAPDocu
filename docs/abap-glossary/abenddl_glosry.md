# DDL

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Short for Data Definition Language. A subset of [SQL](abensql_glosry.md). The statements in the DDL create and delete the objects of a [relational database](abenrelational_database_glosry.md). In an ABAP system, [ABAP-managed database objects](abenabap_managed_db_object_glosry.md) are edited using tools and frameworks in [AS ABAP](abenas_abap_glosry.md), such as [ABAP Dictionary](abenabap_dictionary_glosry.md), [ABAP CDS](abenabap_cds_glosry.md), and [AMDP](abenamdp_glosry.md), where [DDIC DDL](abenddic_dcl_glosry.md), [CDS DDL](abencds_ddl_glosry.md) are used. [ABAP SQL](abenabap_sql_glosry.md) does not support DDL.
