# ABAP contract checks

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

ABAP contract checks summarize the following checks:

- [RAP BO contract](abenrap_bo_contract_glosry.md) checks: Check for violations of [RAP BO consumer](abenrap_bo_consumer_glosry.md) and [RAP BO provider](abenrap_bo_provider_glosry.md) implementations.

- [Transactional contract](abentransactional_contract_glosry.md) checks: Are implemented in the [controlled SAP LUW](abencontrolled_sap_luw_glosry.md) concept. Check for transactional consistency violations in a [transactional phase](abentr_phase_glosry.md).
