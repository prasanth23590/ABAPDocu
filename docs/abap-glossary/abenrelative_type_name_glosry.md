# relative type name

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Type name](abentype_name_glosry.md) specified when defining a [data type](abendata_type_glosry.md), a [class](abenclass_glosry.md), or an [interface](abenoo_intf_glosry.md). The identity of the actual [type](abentype_glosry.md) described by a relative type name depends on the [context](abenobj_context_glosry.md) because local definitions hide global definitions. See also [absolute type name](abenabsolute_typename_glosry.md).
