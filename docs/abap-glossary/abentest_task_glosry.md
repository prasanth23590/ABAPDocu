# test task

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Combination of tests of one or more ABAP programs in [ABAP Unit](abenabap_unit_glosry.md) for which a [test run](abentest_run_glosry.md) can be executed.
