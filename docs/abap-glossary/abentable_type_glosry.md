# table type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) of an [internal table](abeninternal_table_glosry.md). Defines the [line type](abenrow_type_glosry.md), [table category](abentable_category_glosry.md), and [table key](abentable_key_glosry.md) of an internal table, as well as an [initial memory requirement](abeninitial_mem_req_glosry.md). The table type can be [generic](abengeneric_data_type_glosry.md) with regard to the key. A table type can either be defined in [ABAP programs](abenabap_program_glosry.md) using the addition [`TABLE OF`](../abap-programming-language/abap-declarations/abaptypes_itab.md) or as a [DDIC table type](../abap-dictionary-ddic/ddic-data-types/abenddic_table_types.md) in the [ABAP Dictionary](abenabap_dictionary_glosry.md).
