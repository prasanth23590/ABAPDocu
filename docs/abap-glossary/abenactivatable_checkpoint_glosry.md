# activatable checkpoint

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Checkpoint](abencheckpoint_glosry.md) that is assigned to a [checkpoint group](abencheckpoint_group_glosry.md) using the addition `ID` of the statements [`ASSERT`](../abap-programming-language/abap-program-maintenance/abapassert.md), `BREAK-POINT`, or `LOG-POINT`. The behavior of an activatable checkpoint is controlled by either group-specific or program-specific activation settings, where program-specific settings apply to all activatable checkpoints of a program and overwrite the settings of the relevant checkpoint group.
