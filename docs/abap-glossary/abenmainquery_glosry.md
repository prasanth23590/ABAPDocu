# main query

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

[ABAP SQL query](abenasql_query_glosry.md) that is implemented in an [ABAP SQL](abenabap_sql_glosry.md) as a standalone [`SELECT`](../abap-programming-language/abap-database-access/abapselect.md) statement, a closing `SELECT` statement of a [`WITH`](../abap-programming-language/abap-database-access/abapwith.md) statement, or a closing `SELECT` statement of an `OPEN` `CURSOR` statement.
