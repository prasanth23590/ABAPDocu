# interface component

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Component](abencomponent_glosry.md) of an [interface](abenoo_intf_glosry.md). Declared in the [declaration part](abendeclaration_part_glosry.md) of an interface. Possible interface components are: [Attributes](abenattribute_glosry.md), [methods](abenmethod_glosry.md), and [events](abenevent_glosry.md).
