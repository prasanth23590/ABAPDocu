# JSON library

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Global [interfaces](abenglobal_interface_glosry.md) and [classes](abenglobal_class_glosry.md) for handling [JSON](abenjson_glosry.md) data. The classes and interfaces in the JSON library start with the prefixes `CL_JSON` or `IF_JSON`.
