# CDS analytical cube view

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS view entity](abencds_v2_view_glosry.md) or [CDS DDIC-based view (obsolete)](abencds_v1_view_glosry.md) annotated with [`@Analytics.dataCategory: #CUBE`](../abap-core-data-services-abap-cds/abap-cds-annotations/abencds_annotations_frmwrk_tables.md). Serves as a data source for [CDS analytical projection views](abencds_analytical_pv_glosry.md).
