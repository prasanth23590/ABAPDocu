# RAP operation for associations

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO operation](abenrap_bo_operation_glosry.md) that operates along an [association path](abencds_association_path_glosry.md) and affects the [association target](abenassociation_target_glosry.md). They are defined in the [RAP behavior definition](abencds_behavior_definition_glosry.md) for the association. There are [standard operations for associations](abenrap_standard_op_assoc_glosry.md) and [non-standard operations for associations](abenrap_nonst_op_assoc_glosry.md).
