# heap

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Also referred to as free or dynamic memory. Part of the [program memory](abenroll_area_glosry.md), where [anonymous data objects](abenanonymous_data_object_glosry.md) created dynamically using [`CREATE DATA`](../abap-programming-language/abap-creating-objects-and-values/abapcreate_data.md), [`CREATE OBJECT`](../abap-programming-language/abap-creating-objects-and-values/abapcreate_object.md), or [`NEW`](../abap-programming-language/abap-creating-objects-and-values/abenconstructor_expression_new.md) or [instances](abeninstance_glosry.md) of [classes](abenclass_glosry.md) are stored. The occupied memory can be released again by the [garbage collector](abengarbage_collector_glosry.md). See also [stack](abenstack_glosry.md).
