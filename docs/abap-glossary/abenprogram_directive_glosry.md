# program directive

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A program directive is a special construct in [ABAP source code](abenabap_source_code_glosry.md) that modifies the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) rather than affecting the program flow directly.
