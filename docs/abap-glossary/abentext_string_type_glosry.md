# text string type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Character-like data type](abencharlike_data_type_glosry.md) for storing [character strings](abencharacter_string_glosry.md) of variable length. The associated [built-in ABAP type](abenbuiltin_abap_type_glosry.md) is [`string`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_character.md). The [built-in DDIC types](abenbuiltin_ddic_type_glosry.md) are [`STRING`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md) and [`SSTRING`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md). The internal representation takes place in the [character representation](abenchar_representation_glosry.md) of the current [code page](abencodepage_glosry.md). Internal administration takes place using an internal [reference](abenreference_glosry.md) and the data type is [deep](abendeep_glosry.md). A [data object](abendata_object_glosry.md) of a text field type is a [text string](abentext_string_glosry.md).
