# temperature column

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Column of a [database table](abendatabase_table_glosry.md) called `_DATAAGING`. On an [SAP HANA database](abenhana_database_glosry.md), the values in this column determine whether [data aging](abendata_aging_glosry.md) data is current or obsolete.
