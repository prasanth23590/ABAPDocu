# target-resolved association

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Also known as [reverse foreign key association](abenreverse_fk_assoc_glosry.md). An [association](abencds_association_glosry.md) relationship in which the [foreign key](abenforeign_key_glosry.md) is stored in the [association target](abenassociation_target_glosry.md) entity.
