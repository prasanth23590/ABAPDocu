# RAP exclusive draft

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A type of [RAP draft handling](abenrap_draft_handling_glosry.md) where [draft instances](abenrap_draft_instance_glosry.md) are exclusively locked or reserved for a single user. When a user creates a draft instance, they have exclusive modify access to it, preventing other users from editing the same draft concurrently. The creator of the draft instance is the sole draft instance owner. Only the draft instance owner is allowed to modify, activate, or discard the draft instance.
