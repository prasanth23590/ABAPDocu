# conversion exit

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

A conversion exit defines rules that overwrite standard conversions that take place when values are passed as input from user interfaces to ABAP or as output from ABAP to user interfaces. Version exits can be linked to UI elements in different ways.
