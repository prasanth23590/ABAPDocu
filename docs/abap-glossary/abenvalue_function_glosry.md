# value function

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

A [window function](abenwindow_function_glosry.md) that determines a value from a different row of the window for a row of a [window](abenwindow_glosry.md) in the result set of a [query](abenasql_query_glosry.md) in [ABAP SQL](abenabap_sql_glosry.md). The calculation is executed in the [database system](abendatabase_system_glosry.md).
