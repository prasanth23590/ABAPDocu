# RAP reorder action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP hierarchy action](abenrap_hierarchy_action_glosry.md) that moves a [hierarchy node](abenhierarchy_node_glosry.md) to a dedicated position among its siblings in editable [treeview scenarios](abenrap_treeview_glosry.md) by recalculating the hierarchy index fields of all sibling instances. The reorder action can be managed or unmanaged.
