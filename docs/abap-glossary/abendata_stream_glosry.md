# data stream

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Stream](abenstream_glosry.md) that is either directly connected to a [streaming data source](abenstreaming_data_source_glosry.md) as a [reader stream](abenreader_stream_glosry.md) or as a [writer stream](abenwriter_stream_glosry.md) directly with a [streaming data sink](abenstreaming_data_sink_glosry.md).
