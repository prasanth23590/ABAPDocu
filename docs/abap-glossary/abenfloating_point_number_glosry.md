# floating point number

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Either a [decimal floating point number](abendecfloat_glosry.md) or a [binary floating point number](abenbinfloat_glosry.md). In floating point numbers, the number of [decimal places](abendecimal_place_glosry.md) is part of the value and not part of the data type, as is the case in [packed numbers](abenpacked_number_glosry.md). [Floating point arithmetic](abenfloating_point_arith_glosry.md) is used for calculations with floating point numbers.
