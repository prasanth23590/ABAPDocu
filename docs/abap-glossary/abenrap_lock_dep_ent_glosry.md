# RAP lock dependent entity

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO entity](abenrap_bo_entity_glosry.md) whose locking requests are delegated to the [lock master entity](abenrap_lock_ma_ent_glosry.md). Defined using the keyword [`lock dependent by _Assoc`](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_locking.md).
