# RAP ETag

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

ETag is short for entity tag. A RAP ETag field is a field of a [RAP BO entity](abenrap_bo_entity_glosry.md) that is used to describe the state of the instance as an entity tag for [optimistic concurrency control](abenoptimistic_conc_control_glosry.md). It is updated on every change of the [RAP BO entity instance](abenrap_bo_entity_inst_glosry.md).
