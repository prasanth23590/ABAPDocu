# search help

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

A [repository object](abenrepository_object_glosry.md) maintained in the [ABAP Dictionary](abenabap_dictionary_glosry.md) to create value lists. Search helps can be linked in the ABAP Dictionary with [structure components](abenstructure_component_glosry.md), [DDIC data elements](abendata_element_glosry.md), and [check tables](abencheck_table_glosry.md). A search help enables searches for input values using associated data, without the need to know the exact spelling of the value.
