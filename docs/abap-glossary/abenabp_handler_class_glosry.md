# RAP handler class

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [local class](abenlocal_class_glosry.md) in a [CCIMP include](abenccimp_glosry.md) of an [ABAP behavior pool (ABP)](abenbehavior_pool_glosry.md) for implementing [RAP handler methods](abenabp_handler_method_glosry.md) that is executed during the [RAP interaction phase](abenrap_int_phase_glosry.md).
