# object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Instance](abeninstance_glosry.md) of a [type](abentype_glosry.md). Either an instance of a [class](abenclass_glosry.md) or, as a [data object](abendata_object_glosry.md), an instance of a [data type](abendata_type_glosry.md). Exists in the [internal session](abeninternal_session_glosry.md) of an [ABAP program](abenabap_program_glosry.md).
