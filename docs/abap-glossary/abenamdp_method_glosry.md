# AMDP method

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [AMDP](../abap-programming-language/abap-database-access/abenamdp_glossary.md)

## Definition

[Method](abenmethod_glosry.md) of an [AMDP class](abenamdp_class_glosry.md) that is flagged as an [AMDP procedure implementation](abenamdp_procedure_method_glosry.md) using [`BY DATABASE PROCEDURE`](../abap-programming-language/abap-database-access/abapmethod_by_db_proc.md) or as an [AMDP function implementation](abenamdp_function_method_glosry.md) using [`BY DATABASE FUNCTION`](../abap-programming-language/abap-database-access/abapmethod_by_db_proc.md) in the [implementation part](abenimplementation_part_glosry.md) of the class.
