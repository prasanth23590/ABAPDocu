# static component

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Superordinate term for [static attribute](abenstatic_attribute_glosry.md), [static event](abenstatic_event_glosry.md), and [static method](abenstatic_method_glosry.md). The static components of a [class](abenclass_glosry.md) can be addressed using the name of the class. A class that only contains static components is referred to as a [static class](abenstatic_class_glosry.md).
