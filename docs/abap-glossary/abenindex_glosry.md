# index

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md) [General](abenabap_glossary.md)

## Definition

Selected columns of a [database table](abendatabase_table_glosry.md) that are sorted in order and stored as a copy in the [database system](abendatabase_system_glosry.md), and which point to the actual rows. For the database tables of an [AS ABAP](abenas_abap_glosry.md) that are defined in the [ABAP Dictionary](abenabap_dictionary_glosry.md), there is always a [primary index](abenprimary_index_glosry.md), and additional [secondary indexes](abensecondary_index_glosry.md) can also be created. In [internal tables](abeninternal_table_glosry.md) there may be one or more [table indexes](abentable_index_glosry.md).
