# locator

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

Pointer to substrings of [LOBs](abenlob_glosry.md) in a [database](abendatabase_glosry.md). In ABAP, locators are [LOB handles](abenlob_handle_glosry.md) and are implemented using [instances](abeninstance_glosry.md) of the corresponding [system classes](abensystem_class_glosry.md). Locators can be linked with the database in question in [ABAP SQL statements with LOBs](abenabap_sql_glosry.md). Different [locator types](abenlocator_type_glosry.md) are provided for [BLOBs](abenblob_glosry.md) and [CLOBs](abenclob_glosry.md).
