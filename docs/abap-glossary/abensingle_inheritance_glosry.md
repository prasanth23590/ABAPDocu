# single inheritance

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Inheritance](abeninheritance_glosry.md) method where, unlike multiple inheritance, a [class](abenclass_glosry.md) can have multiple [subclasses](abensubclass_glosry.md) but only one direct [superclass](abensuperclass_glosry.md). See also [inheritance hierarchy](abeninheritance_hierarchy_glosry.md).
