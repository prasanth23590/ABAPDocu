# coalesce function

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [built-in function](abenbuiltin_function_glosry.md) that returns the first non-zero expression in a list of expressions. Available in [ABAP CDS](abenabap_cds_glosry.md) and [ABAP SQL](abenabap_sql_glosry.md).
