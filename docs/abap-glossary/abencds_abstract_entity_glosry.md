# CDS abstract entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS transient entity](abencds_non_sql_entity_glosry.md) defined using [`DEFINE ABSTRACT ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_f1_define_abstract_entity.md) in a [CDS data definition](abencds_data_definition_glosry.md). A CDS abstract entity defines the type properties of a [CDS entity](abencds_entity_glosry.md) without defining a database object.
