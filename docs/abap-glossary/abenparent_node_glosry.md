# parent node

[General](abenabap_glossary.md)

## Definition

A [hierarchy node](abenhierarchy_node_glosry.md) from which a [parent-child relationship](abenpcr_glosry.md) to a [child node](abenchild_node_glosry.md) originates. A parent node can have multiple child nodes. A parent node is an [ancestor node](abenancestor_node_glosry.md) of its child nodes, their child nodes, and so on.
