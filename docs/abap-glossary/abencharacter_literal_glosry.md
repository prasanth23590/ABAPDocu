# character literal

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Also referred to as text literal. A [literal](abenabap_literal_glosry.md) with a [character-like data type](abencharlike_data_type_glosry.md) whose value is a [character string](abencharacter_string_glosry.md).

- In general ABAP, character literals are [untyped literals](abenuntyped_literal_glosry.md).

- In [ABAP SQL](abenabap_sql_glosry.md) and [ABAP CDS](abenabap_cds_glosry.md), character literals can be [typed literals](abentyped_literal_glosry.md) or [untyped literals](abenuntyped_literal_glosry.md).
