# technical type property

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Property of a [data type](abendata_type_glosry.md) that is important for the [compatibility](abencompatible_glosry.md) with other data types except [reference types](abenreference_type_glosry.md). For [elementary data types](abenelementary_data_type_glosry.md), this concerns the [built-in ABAP type](abenbuiltin_abap_type_glosry.md), the length of the [fraction portion](abendecimal_place_glosry.md) and the number of decimal places. For [structured types](abenstructured_type_glosry.md), this concerns how the type is constructed from [substructures](abensubstructure_glosry.md) and elementary data types. For [table types](abentable_type_glosry.md), this concerns the [table category](abentable_category_glosry.md), the [line type](abenrow_type_glosry.md), and the [table key](abentable_key_glosry.md). For [mesh types](abenmesh_type_glosry.md), this concerns the layout of components and their [mesh associations](abenmesh_association_glosry.md).
