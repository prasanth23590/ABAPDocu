# password

[General](abenabap_glossary.md)

## Definition

A sequence of characters that is only known to a specific [ABAP user](abenabap_user_glosry.md) and is required from this user to [log on](abenlogon_glosry.md) to [AS ABAP](abenas_abap_glosry.md). Used together with the [user name](abenuser_name_glosry.md), the password enables authorized use of an AS ABAP.
