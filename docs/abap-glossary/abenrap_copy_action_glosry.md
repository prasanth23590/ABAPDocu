# RAP copy action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP hierarchy action](abenrap_hierarchy_action_glosry.md) that determines how a hierarchy node can be duplicated in an editable [treeview](abenrap_treeview_glosry.md) scenario. It is useful for creating new hierarchy nodes based on an existing one in an editable treeview scenario. Copy actions are [factory actions](abenrap_factory_action_glosry.md), i.e. they offer [`%cid`](../abap-rap-business-objects/abap-for-rap-business-objects/abapderived_types_cid.md) handling for the result instance. Copy actions are user-implemented.
