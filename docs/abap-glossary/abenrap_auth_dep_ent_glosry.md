# RAP authorization dependent entity

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO entity](abenrap_bo_entity_glosry.md) that uses the [authorization control](abenrap_auth_control_glosry.md) that is defined on its [authorization master entity](abenrap_auth_ma_ent_glosry.md). It delegates authorization requests to the implementation of the [authorization master entity](abenrap_auth_ma_ent_glosry.md).&#x00A0;
