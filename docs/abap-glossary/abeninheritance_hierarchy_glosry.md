# inheritance hierarchy

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Hierarchical relationship between [superclasses](abensuperclass_glosry.md) and [subclasses](abensubclass_glosry.md) in [inheritance](abeninheritance_glosry.md) functions. When [single inheritance](abensingle_inheritance_glosry.md) is used, the inheritance hierarchy forms an [inheritance tree](abeninheritance_tree_glosry.md).
