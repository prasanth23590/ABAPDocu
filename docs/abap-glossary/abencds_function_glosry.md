# CDS function

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Function in [ABAP CDS](abenabap_cds_glosry.md) that can be used in operand positions of [CDS entities](abencds_entity_glosry.md). A CDS function can be a [user-defined function](abencds_user_func_glosry.md), a [built-in function](abencds_builtin_func_glosry.md), or a [system function](abencds_system_func_glosry.md).
