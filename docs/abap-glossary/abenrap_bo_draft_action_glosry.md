# RAP BO draft action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP action](abenrap_action_glosry.md) that is invoked during the lifecycle of a [draft-enabled RAP BO](abendraft_rap_bo_glosry.md) to manage the state of [draft](abenrap_draft_instance_glosry.md) and [active instances](abenrap_active_instance_glosry.md). The implementation is provided by the [RAP managed draft provider](abenrap_man_draft_provider_glosry.md).
