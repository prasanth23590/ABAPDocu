# primary key

[General](abenabap_glossary.md)

## Definition

[Table key](abentable_key_glosry.md) that is determined when a [database table](abendatabase_table_glosry.md) is defined and which uniquely identifies a table row. In [internal tables](abeninternal_table_glosry.md), there is a [primary table key](abenprimary_table_key_glosry.md).
