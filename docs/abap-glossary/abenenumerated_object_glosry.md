# enumerated object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data object](abendata_object_glosry.md) with an [enumerated type](abenenum_type_glosry.md). An enumerated object can only contain the [enumerated values](abenenumerated_value_glosry.md) of the enumerated type. The data type of an enumerated object is the enumerated type. The technical data type of the content is the [base type](abenbase_type_glosry.md) of the enumerated type. [Enumerated variables](abenenumerated_variable_glosry.md) are variable enumerated objects that can only contain the associated enumerated values. [Enumerated constants](abenenumerated_constant_glosry.md) and components of [enumerated structures](abenenumerated_structure_glosry.md) are special enumerated objects that define the value set of an enumerated type.
