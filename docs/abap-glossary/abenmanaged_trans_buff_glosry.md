# managed transactional buffer

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The [transactional buffer](abentransactional_buffer_glosry.md) of a [managed RAP BO](abenmanaged_rap_bo_glosry.md) that is provided by the [managed RAP BO provider](abenmanaged_rap_bo_prov_glosry.md). A managed transactional buffer can be accessed in [ABAP programs](abenabap_program_glosry.md) by [ABAP EML](abenabap_eml_glosry.md) only.
