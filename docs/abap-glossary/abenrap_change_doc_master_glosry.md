# RAP change documents master entity

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [change documents-enabled RAP BO entity](abenrap_change_doc_enabled_glosry.md) that has its own [change document object](abenchange_document_obj_glosry.md) for logging changes to persisted data.
