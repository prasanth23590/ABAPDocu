# RAP hierarchy action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP action](abenrap_action_glosry.md) that can be used in the context of editable [treeviews](abenrap_treeview_glosry.md) for performing operations on hierarchical data.

The following types of RAP hierarchy actions are available:

- [RAP copy action](abenrap_copy_action_glosry.md)

- [RAP reorder action](abenrap_reorder_action_glosry.md)
