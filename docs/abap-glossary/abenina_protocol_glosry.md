# Information Access protocol

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[InA](abenina_glosry.md) for short. InA is a standardized protocol for defining and consuming multidimensional analytical queries. InA can be specified as a type of [service binding](abenservice_binding_glosry.md) and it is interpreted by the [ABAP Analytical Engine](abenabap_ae_glosry.md).
