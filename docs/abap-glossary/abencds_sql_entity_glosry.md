# CDS persistent entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS entity](abencds_entity_glosry.md) for which an artifact is created on the database and which can be used as a data source in [ABAP SQL](abenabap_sql_glosry.md), such as a [CDS view entity](abencds_v2_view_glosry.md) or a [CDS table function](abencds_table_function_glosry.md).

See also: [CDS transient entity](abencds_non_sql_entity_glosry.md)
