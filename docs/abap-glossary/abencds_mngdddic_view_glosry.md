# CDS-managed DDIC view

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An obsolete [DDIC database view](abendatabase_view_glosry.md) of the [ABAP Dictionary](abenabap_dictionary_glosry.md) that is created in addition to the [CDS entity](abencds_entity_glosry.md) when a [CDS DDIC-based view (obsolete)](abencds_v1_view_glosry.md) is activated. CDS-managed DDIC views are used as technical foundations for a CDS view of this type, but should not be used directly in ABAP or ABAP CDS.
