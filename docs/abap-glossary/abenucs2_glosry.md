# UCS-2

[General](abenabap_glossary.md)

## Definition

Two byte [Unicode character representation](abenunicode_char_represent_glosry.md). In this representation, all characters are represented by two bytes (16 bits). In UCS-2, 65536 different characters can be encoded, that correspond to the so called Basic Multilingual Plane (BMP) of the Unicode standard. In contrast to [UTF-16](abenutf16_glosry.md), UCS-2 does not support characters from the [surrogate area](abensurrogate_area_glosry.md). The ABAP programming language supports UCS-2 in [Unicode systems](abenunicode_system_glosry.md) and therefore no [surrogates](abensurrogates_glosry.md).
