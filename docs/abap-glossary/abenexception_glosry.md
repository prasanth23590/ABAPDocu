# exception

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Error situation during execution of an [ABAP program](abenabap_program_glosry.md). Exceptions are [catchable](abencatchable_exception_glosry.md) (statements [`TRY`](../abap-programming-language/abap-program-flow-logic/abaptry.md), [`CATCH`](../abap-programming-language/abap-program-flow-logic/abapcatch_try.md)) or [uncatchable](abenuncatchable_exception_glosry.md). Uncaught exceptions result in a [runtime error](abenruntime_error_glosry.md).
