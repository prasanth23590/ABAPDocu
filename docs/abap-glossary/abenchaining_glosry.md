# chaining

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Composite specification of an [ABAP operand](abenabap_operand_glosry.md) in an [operand position](abenoperand_position_glosry.md) in which the individual components are chained using [component selectors](abencomponent_selector_glosry.md). Examples of possible chainings are [chained identifiers](abenchained_name_glosry.md), [chained method calls](abenchained_method_call_glosry.md), [chained attribute accesses](abenchained_attribute_acc_glosry.md), chainings of [table expressions](abentable_expression_glosry.md), and various combinations of all four.
