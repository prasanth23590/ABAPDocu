# comparison type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Property of [comparison expressions](abencomparison_expression_glosry.md) whose [operands](abenoperand_glosry.md) have [elementary data types](abenelementary_data_type_glosry.md), including [calculation expressions](abencalculation_expression_glosry.md). The comparison type is determined from the operands and defines how the comparison is executed. The comparison type can be of any [built-in ABAP type](abenbuiltin_abap_type_glosry.md). Operands of another type are converted to the comparison type before the comparison.
