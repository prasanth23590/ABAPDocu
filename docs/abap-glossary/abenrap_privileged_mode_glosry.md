# BDEF privileged mode

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

With BDEF privileged mode, [RAP BO consumers](abenrap_bo_consumer_glosry.md) can circumvent [authorization checks](abenauthorization_check_glosry.md), such as&#x00A0; [RAP authorization control](abenrap_auth_control_glosry.md). BDEF privileged mode is prerequisite to use the addition [`PRIVILEGED`](../abap-rap-business-objects/abap-for-rap-business-objects/abapeml_privileged.md) in [EML](abeneml_glosry.md) when consuming the [RAP BO](abenrap_bo_glosry.md).&#x00A0;&#x00A0;
