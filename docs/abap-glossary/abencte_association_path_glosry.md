# CTE association path

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

A sequence of [CTE associations](abencte_association_glosry.md) that link [common table expressions](abencommon_table_expression_glosry.md) with [association targets](abenassociation_target_glosry.md). CTE association paths can be specified in the form of [SQL path expressions](abensql_path_expression_glosry.md) in [ABAP SQL](abenabap_sql_glosry.md).
