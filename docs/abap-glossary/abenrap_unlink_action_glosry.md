# RAP unlink action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP non-standard operation for associations](abenrap_nonst_op_assoc_glosry.md) that disconnects two associated [RAP BO entity instances](abenrap_bo_entity_inst_glosry.md) by removing the value of the [foreign key](abenforeign_key_glosry.md) field. The unlink action can be defined for [intra-BO associations](abencds_intra_bo_assoc_glosry.md) and for [cross-BO associations](abencds_cross_bo_assoc_glosry.md).

See also: [RAP link action](abenrap_link_action_glosry.md)
