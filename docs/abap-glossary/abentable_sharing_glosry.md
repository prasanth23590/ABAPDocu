# table sharing

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Sharing](abensharing_glosry.md) of [internal tables](abeninternal_table_glosry.md) in [assignments](abenassignment_glosry.md) and [pass by value](abenpass_by_value_glosry.md). Table sharing only occurs between similar tables if their [line types](abenrow_type_glosry.md) do not themselves contain any [table types](abentable_type_glosry.md).
