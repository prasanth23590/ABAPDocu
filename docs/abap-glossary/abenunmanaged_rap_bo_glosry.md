# unmanaged RAP business object

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Unmanaged RAP BO for short. Provisioning type of the [business object behavior](abenrap_bo_behavior_glosry.md) of a [RAP BO](abenrap_bo_glosry.md). The [transactional buffer](abentransactional_buffer_glosry.md) of an unmanaged RAP BO is provided by an [ABAP behavior implementation](abenbehavior_implement_glosry.md). The implementation of an unmanaged RAP BO is fully provided by the [unmanaged RAP BO provider](abenunmanaged_rap_bo_prov_glosry.md) in an [ABAP behavior pool](abenbehavior_pool_glosry.md).
