# exception class

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Special [class](abenclass_glosry.md) that is the basis for [catchable](abencatchable_exception_glosry.md) exceptions. If an [exception](abenexception_glosry.md) is raised, an [object](abenobject_glosry.md) of an exception class is created. There are predefined exception classes for exceptions of the runtime framework, and user-defined exception classes for custom applications. The superclasses for all exception classes are `CX_STATIC_CHECK`, `CX_DYNAMIC_CHECK`, or `CX_NO_CHECK`, through which exceptions are divided into [exception categories](abenexception_category_glosry.md).
