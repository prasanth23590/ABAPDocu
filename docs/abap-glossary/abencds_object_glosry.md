# CDS object

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [repository object](abenrepository_object_glosry.md) of [ABAP CDS](abenabap_cds_glosry.md). CDS objects are, for example, [CDS entities](abencds_entity_glosry.md), [CDS annotation definitions](abencds_anno_definition_glosry.md), [CDS metadata extensions](abencds_metadata_extension_glosry.md), [CDS roles](abencds_role_glosry.md), [CDS user-defined types](abencds_user_defined_type_glosry.md), [CDS functions](abencds_function_glosry.md), and [ABAP tuning objects](abenabap_tuning_object_glosry.md).
