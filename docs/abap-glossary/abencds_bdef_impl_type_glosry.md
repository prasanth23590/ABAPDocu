# BDEF implementation type

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Type of [RAP behavior definition](abencds_behavior_definition_glosry.md). There are five different implementation types of behavior definitions:

- [managed](abenmanaged_rap_bo_glosry.md)

- [unmanaged](abenunmanaged_rap_bo_glosry.md)

- [interface](abencds_interface_bdef_glosry.md)

- [projection](abenrap_projection_bo_glosry.md)

- [abstract](abencds_abstract_bdef_glosry.md)

The differences are, for example, the type of underlying [CDS entity](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_view_entity.md) and the degree of standardized vs. customized behavior implementation.
