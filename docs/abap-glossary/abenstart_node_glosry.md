# start node

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

- In a [ABAP SQL hierarchy](abensql_hierarchy_glosry.md), a [hierarchy node](abenhierarchy_node_glosry.md) from which a [hierarchy node navigator](abenhierarchy_node_navi_glosry.md) determines further hierarchy nodes and adds them to its result set.

- In a [mesh](abenmesh_glosry.md), a [mesh node](abenmesh_node_glosry.md) for which a [mesh association](abenmesh_association_glosry.md) is defined is the association's start node.
