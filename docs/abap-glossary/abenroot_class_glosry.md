# root class

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Superclass](abensuperclass_glosry.md) shared by all [subclasses](abensubclass_glosry.md) of an [inheritance tree](abeninheritance_tree_glosry.md) in [single inheritance](abensingle_inheritance_glosry.md). In [ABAP Objects](abenabap_objects_glosry.md), all [classes](abenclass_glosry.md) are subclasses of the predefined [abstract](abenabstract_glosry.md) root class [`object`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
