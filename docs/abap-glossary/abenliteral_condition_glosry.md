# CDS literal condition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Part of an [access condition](abenaccess_condition_glosry.md) in a [CDS role](abencds_role_glosry.md) that associates an element of a [CDS entity](abencds_entity_glosry.md) with a literal value.
