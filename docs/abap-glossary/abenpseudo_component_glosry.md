# pseudo component

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Expression `table_line` that can be specified in accesses to [internal tables](abeninternal_table_glosry.md) instead of a [structure component](abenstructure_component_glosry.md). The entire line of the internal table is then interpreted as the only component. The name `table_line` is a reserved name. In ABAP and in [ABAP Dictionary](../abap-dictionary-ddic/abenabap_dictionary.md), no structure components called `table_line` can be defined or created.
