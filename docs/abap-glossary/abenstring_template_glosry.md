# character string template

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

String template for short. A character string template creates a [character string](abencharacter_string_glosry.md) from literal text, embedded expressions, and [control characters](abencontrol_character_glosry.md) in a [string expression](abenstring_expression_glosry.md).
