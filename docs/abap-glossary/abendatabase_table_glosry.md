# database table

[General](abenabap_glossary.md)

## Definition

[Database object](abendb_object_glosry.md) of a [relational database](abenrelational_database_glosry.md) in which the data is structured as a table in rows and columns. The database tables of an [AS ABAP](abenas_abap_glosry.md) are defined as [DDIC database tables](abenddic_db_table_glosry.md) or as [CDS table entities](abencds_table_entity_glosry.md).
