# RAP feature control

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An access restriction that enables or disables [RAP BO operations](abenrap_bo_operation_glosry.md) or defines field attributes dynamically for [RAP BO consumers](abenrap_bo_consumer_glosry.md). Feature control can be static or dynamic, [instance-based](abenrap_ins_feature_control_glosry.md) or [global](abenrap_glo_feature_control_glosry.md).
