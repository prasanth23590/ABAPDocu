# DDL object

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

A [database](abendatabase_glosry.md) artifact that is not managed by the [ABAP Dictionary](abenabap_dictionary_glosry.md). It can be used in the context of [AMDP](abenamdp_glosry.md). Currently, the following DDL objects can be used with AMDP:

- [Views](abenview_glosry.md)

- L libraries

- [Graph workspaces](abengraph_workspace_glosry.md)

DDL objects can be consumed by other [AMDP methods](abenamdp_method_glosry.md).
