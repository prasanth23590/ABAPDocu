# SAP BTP ABAP environment

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[ABAP system](abenabap_system_glosry.md) (aka [Steampunk](abensteampunk_glosry.md)) in [SAP BTP](abensap_btp_glosry.md) that provides the [ABAP technology](abenabap_techno_glosry.md) as a service to customers and partners. ABAP development is governed by the restricted rules of [ABAP Cloud](abenabap_cloud_glosry.md).
