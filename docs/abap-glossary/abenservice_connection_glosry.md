# service connection

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Additional [database connection](abendatabase_connection_glosry.md) from an [AS ABAP](abenas_abap_glosry.md) to the [standard database](abenstandard_db_glosry.md). In addition to the [standard connection](abenstandard_db_connection_glosry.md), service connections to the standard database called `R/3*name` can be opened for a [work process](abenwork_process_glosry.md) to access the [ABAP database schema](abenabap_db_schema_glosry.md).
