# type pool

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP program](abenabap_program_glosry.md), administrated by the [ABAP Dictionary](abenabap_dictionary_glosry.md), that is introduced by the statement `TYPE-POOL` and which contains the definitions of globally visible [data types](abendata_type_glosry.md), [constants](abenconstant_glosry.md). A type pool is loaded the first time its data types and constants are used.
