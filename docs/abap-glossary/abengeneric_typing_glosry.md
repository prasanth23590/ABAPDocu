# generic typing

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Typing](abentyping_glosry.md) in which the [data type](abendata_type_glosry.md) of a [formal parameter](abenformal_parameter_glosry.md) or [field symbol](abenfield_symbol_glosry.md) is not fully specified. The actual data type is copied at runtime from the assigned [actual parameter](abenactual_parameter_glosry.md) or memory area. During a dynamic access to a generically typed formal parameter or field symbol, the properties of the actual parameter apply. During static access, the properties of the actual parameter determined by the typing apply.
