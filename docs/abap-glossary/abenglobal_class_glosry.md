# global class

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Class](abenclass_glosry.md) that is defined as a [global type](abenglobal_type_glosry.md). Global classes are declared in [class pools](abenclass_pool_glosry.md) and are marked as such there using the addition [`PUBLIC`](../abap-programming-language/abap-declarations/abapclass_options.md) of the statement [`CLASS`](../abap-programming-language/abap-declarations/abapclass.md). A class pool can only contain one global class.
