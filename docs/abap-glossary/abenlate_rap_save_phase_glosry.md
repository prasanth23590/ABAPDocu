# RAP late save phase

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The phase of the [RAP save sequence](abenrap_save_seq_glosry.md) that covers the [RAP saver methods](abenabp_saver_method_glosry.md) [`adjust_numbers`](../abap-rap-business-objects/abap-for-rap-business-objects/abensaver_adjust_numbers.md) and [`save`](../abap-rap-business-objects/abap-for-rap-business-objects/abensaver_method_save.md) (or [`save_modified`](../abap-rap-business-objects/abap-for-rap-business-objects/abaprap_saver_meth_save_modified.md) respectively). The [`cleanup`](../abap-rap-business-objects/abap-for-rap-business-objects/abensaver_method_cleanup.md) method is called following a successful save.
