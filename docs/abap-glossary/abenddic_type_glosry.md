# DDIC type

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Data type](abendata_type_glosry.md) defined as a [global type](abenglobal_type_glosry.md) in the [ABAP Dictionary](abenabap_dictionary_glosry.md). DDIC types are always data types, while global [object types](abenobject_type_glosry.md) are defined in the [class library](abenclass_library_glosry.md). In particular [DDIC database tables](abenddic_db_table_glosry.md) can be used as DDIC types in ABAP programs.
