# character-like operand position

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Read position](abenread_position_glosry.md) with character-like [operand type](abenoperand_type_glosry.md) in which a [character-like data object](abencharlike_data_object_glosry.md) that can be converted into the operand type can be specified. See also [character-like expression position](abencharlike_expr_position_glosry.md).
