# boxed component

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Structured [component](abencomponent_glosry.md) of a [structure](abenstructure_glosry.md) or a [class](abenclass_glosry.md) or [interface](abenoo_intf_glosry.md) that is not stored at the location of the definition but is [deep](abendeep_glosry.md), meaning it is managed by an internal reference. Boxed components are a mixture of [static](abenstatic_data_object_glosry.md) and [dynamic data objects](abendynamic_data_object_glosry.md). Currently, [static boxes](abenstatic_box_glosry.md) are supported as boxed components.
