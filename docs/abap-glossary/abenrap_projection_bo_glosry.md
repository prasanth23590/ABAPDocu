# RAP projection business object

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP business object](abenrap_bo_glosry.md) that is defined in a [RAP projection behavior definition](abencds_proj_bdef_glosry.md). It has a [CDS projection view](abencds_projection_view_glosry.md) as [root view](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_view_as_projection.md).
