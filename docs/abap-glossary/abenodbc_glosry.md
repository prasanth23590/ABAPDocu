# ODBC

[General](abenabap_glossary.md)

## Definition

Short for Open Database Connectivity.

A standard software API specification used for accessing database management systems in the network. ODBC is independent of the programming language, database management system, and operating system. ODBC is based on the Call Level Interface Specifications from SQL, X/Open, and ISO/IEC.

Communication between the [SAP HANA database](abenhana_database_glosry.md) and external systems via a [SAP HANA remote source](abensap_hana_remote_source_glosry.md) is based on the ODBC protocol. The [SQL services](abenabap_sql_services_glosry.md), which provide an access mechanism to [AS ABAP](abenas_abap_glosry.md) for external consumers, is also based on ODBC.
