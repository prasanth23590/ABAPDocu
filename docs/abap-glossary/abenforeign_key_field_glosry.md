# foreign key field

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Field in a [DDIC database table](abenddic_db_table_glosry.md) to which a [check table](abencheck_table_glosry.md) is assigned. Part of the [foreign key](abenforeign_key_glosry.md) of a [foreign key table](abenforeign_key_table_glosry.md).
