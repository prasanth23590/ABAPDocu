# entity behavior characteristics

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A part of an [entity behavior definition](abencds_entity_bdef_glosry.md) that stand after `define behavior for` and before the curly brackets. The entity behavior characteristics define additional properties of a behavior definition on entity level.
