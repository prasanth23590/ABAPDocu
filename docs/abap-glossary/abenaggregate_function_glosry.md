# aggregate function

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A function that processes multiple values together and returns a single value as a result. The calculation is done in the [database system](abendatabase_system_glosry.md). An aggregate function can be used in an [aggregate expression](abenaggregate_expression_glosry.md). In [ABAP SQL](abenabap_sql_glosry.md), it can also be used as a [window function](abenwindow_function_glosry.md) in a [window expression](abenwindow_expression_glosry.md), and in a [hierarchy aggregate navigator](abenhierarchy_agg_navi_glosry.md).
