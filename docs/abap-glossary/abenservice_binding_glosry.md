# service binding

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

SB for short. A service binding is a [repository object](abenrepository_object_glosry.md) that binds a [CDS service definition](abencds_service_definition_glosry.md) to a communication protocol and publishes it as a [business service](abenbs_glosry.md) of [AS ABAP](abenas_abap_glosry.md).
