# data cluster

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Grouping of [data objects](abendata_object_glosry.md) for transient and persistent storage in a storage medium. A data cluster can be processed using the statements [`IMPORT`](../abap-programming-language/abap-data-cluster/abapimport_data_cluster.md), [`EXPORT`](../abap-programming-language/abap-data-cluster/abapexport_data_cluster.md), and `DELETE FROM`.
