# common table expression

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

CTE for short. Common table expressions are defined in the [ABAP SQL](abenabap_sql_glosry.md) statement [`WITH`](../abap-programming-language/abap-database-access/abapwith.md) via [subqueries](abensubquery_glosry.md). The [main query](abenmainquery_glosry.md) of the `WITH` statement accesses its common table expressions.
