# language setting

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Part of the [language environment](abenlanguage_environment_glosry.md). The language setting of an ABAP program comprises the [logon language](abenlogon_language_glosry.md) and the [text environment language](abentext_env_langu_glosry.md) of the [text environment](abentext_environment_glosry.md).
