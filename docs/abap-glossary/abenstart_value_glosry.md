# start value

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Value specified when a [data object](abendata_object_glosry.md) is declared. The data object is filled with this value when it is created. The start value is set using the [`VALUE`](../abap-programming-language/abap-declarations/abapdata_options.md) addition of the [`DATA`](../abap-programming-language/abap-declarations/abapdata.md) statement. If the `VALUE` addition is not used, the system uses the type-specific [initial value](abeninitial_value_glosry.md).
