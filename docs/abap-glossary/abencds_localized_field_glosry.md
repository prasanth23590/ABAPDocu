# CDS localized field

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [SQL path target field](abensql_target_field_glosry.md) in a [CDS entity](abencds_entity_glosry.md) whose original data source is a [CDS text provider view](abencds_text_provider_glosry.md) and that is automatically displayed in the user's logon language. Defined using the keyword [`LOCALIZED`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_localized.md). Currently available in [CDS projection views](abencds_projection_view_glosry.md) only.
