# ABAP literal

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

An [unnamed data object](abenunnamed_data_object_glosry.md) defined by textual specification of a value in the [ABAP source code](abenabap_source_code_glosry.md) of an [ABAP program](abenabap_program_glosry.md). In the general ABAP language, untyped [numeric literals](abennumeric_literal_glosry.md) and untyped [character literals](abencharacter_literal_glosry.md) are available. A [literal operator](abenliteral_operator_glosry.md) enables the linking of multiple literals. See also:

- [anonymous data object](abenanonymous_data_object_glosry.md)

- [named data object](abennamed_data_object_glosry.md)

- [literal](abenliteral_glosry.md)

- [ABAP SQL literal](abenabap_sql_literal_glosry.md)
