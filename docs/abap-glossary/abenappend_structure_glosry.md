# append structure

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Structure](abenstructure_glosry.md) of the [ABAP Dictionary](abenabap_dictionary_glosry.md) that is appended to a different DDIC structure or [DDIC database table](abenddic_db_table_glosry.md) thus adding its [structure components](abenstructure_component_glosry.md) to them. Append structures and database tables can be used to add components to structures and database tables delivered by SAP without making modifications to them.
