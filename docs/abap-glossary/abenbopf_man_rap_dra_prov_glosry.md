# BOPF-managed RAP draft provider

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The draft provider of [BOPF-based RAP BOs](abenrap_bopf_bo_glosry.md) with BOPF-managed draft. The [draft handling](abenrap_draft_handling_glosry.md) is managed by the [Business Object Processing Framework](abenbo_processing_fw_glosry.md) (BOPF).
