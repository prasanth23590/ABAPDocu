# entity behavior body

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A part of an [entity behavior definition](abencds_entity_bdef_glosry.md) that is defined within curly brackets. The entity behavior body can include [RAP BO operations](abenrap_bo_operation_glosry.md), [validations](abenrap_validation_glosry.md), [determinations](abenrap_determination_glosry.md), and other elements.
