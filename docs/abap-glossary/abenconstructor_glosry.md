# constructor

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A special [method](abenmethod_glosry.md) in a [class](abenclass_glosry.md) that sets a defined initial value for the status ([attributes](abenattribute_glosry.md)) of the class or its [objects](abenobject_glosry.md). There is an [instance constructor](abeninstance_constructor_glosry.md) for [instance attributes](abeninstance_attribute_glosry.md) and a [static constructor](abenstatic_constructor_glosry.md) for [static attributes](abenstatic_attribute_glosry.md). The constructors always exist implicitly but nevertheless must be declared explicitly for separate implementations. Special [constructor expressions](abenconstructor_expression_glosry.md) also exist.
