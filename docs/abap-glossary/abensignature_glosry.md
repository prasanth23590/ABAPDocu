# signature

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

For a [procedure](abenprocedure_glosry.md), the name, all the [formal parameters](abenformal_parameter_glosry.md) of the [parameter interface](abenparameter_interface_glosry.md), and its other properties.
