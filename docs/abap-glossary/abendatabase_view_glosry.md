# DDIC database view

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

General view in [ABAP Dictionary](abenabap_dictionary_glosry.md) for multiple [DDIC database tables](abenddic_db_table_glosry.md). The instance of a DDIC database view as an [ABAP-managed database object](abenabap_managed_db_object_glosry.md) is an [SQL view](abensql_view_glosry.md) in the [ABAP database schema](abenabap_db_schema_glosry.md) of the [standard database](abenstandard_db_glosry.md).
