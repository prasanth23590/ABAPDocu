# CDS propagated buffer (obsolete)

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS entity buffer](abencds_entity_buffer_glosry.md) that defines [SQL path target fields](abensql_target_field_glosry.md) for [buffer propagation](abencds_buffer_propagation_glosry.md). Defined using the syntax [`PROPAGATE VIEW ENTITY BUFFER`](../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_propagate_buffer.md).
