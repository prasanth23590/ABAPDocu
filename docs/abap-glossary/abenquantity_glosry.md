# quantity field

[General](abenabap_glossary.md)

## Definition

A quantity field is linked to a [unit key](abenunit_glosry.md) and it is used for entering a quantity in a particular unit. Quantity fields are available in [ABAP Dictionary](abenabap_dictionary_glosry.md) (DDIC) and in [ABAP CDS](abenabap_cds_glosry.md), but the possible data types and handling differs.
