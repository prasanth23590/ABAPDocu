# data aging

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

A [SAP HANA database](abenhana_database_glosry.md) concept where current data is distinguished from outdated data by entries in a [temperature column](abentemperature_column_glosry.md). Only current data exists in the memory.
