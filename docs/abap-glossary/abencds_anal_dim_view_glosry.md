# CDS analytical dimension view

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS view entity](abencds_v2_view_glosry.md) or [CDS DDIC-based view (obsolete)](abencds_v1_view_glosry.md) annotated with [`@Analytics.dataCategory: #DIMENSION`](../abap-core-data-services-abap-cds/abap-cds-annotations/abencds_annotations_frmwrk_tables.md). Can serve as a data source for CDS analytical projection views.
