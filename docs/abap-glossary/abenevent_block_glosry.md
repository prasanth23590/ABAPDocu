# event block

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Processing block](abenprocessing_block_glosry.md) An event block is processed when the corresponding [event](abenevent_glosry.md) of the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) is raised. It starts with an [event keyword](abenevent_keyword_glosry.md) and ends at the start of the next processing block.
