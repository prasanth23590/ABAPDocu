# function pool

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

The only kind of [ABAP program](abenabap_program_glosry.md) that can contain [function modules](abenfunction_module_glosry.md); usually loaded by calling one of its function modules. A function pool can currently contain a maximum of 99 function modules.
