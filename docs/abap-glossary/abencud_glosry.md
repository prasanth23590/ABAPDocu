# CUD operations

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An acronym for Create, Update, and Delete operations, which are part of the four basic [CRUD](abencrud_glosry.md) operations for persistent data storage.

- In [SQL](abensql_glosry.md), the three operations are implemented by the [DML](abendml_glosry.md) statements `INSERT`, `UPDATE`, and `DELETE`.

- In the [ABAP RESTful Application Programming Model (RAP)](abenarap_glosry.md), the three operations are represented by the [RAP modify operations](abenrap_modify_operation_glosry.md) [Create](abenrap_create_operation_glosry.md), [update](abenrap_update_operation_glosry.md), and [delete](abenrap_delete_operation_glosry.md) in [RAP BOs](abenrap_bo_glosry.md).
