# RAP behavior definition header

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

BDEF header short. A BDEF header is the part of a [RAP behavior definition](abencds_behavior_definition_glosry.md) that defines the [implementation type](abencds_bdef_impl_type_glosry.md) and some global attributes that apply to the complete [business object](abenbusiness_object_glosry.md). It is the topmost part and includes all statements that are listed before the [entity behavior definition](abencds_entity_bdef_glosry.md), `define behavior for`.
