# mandatory RAP BO field

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [field](abenrap_bo_field_glosry.md) in a [RAP BO](abenrap_bo_glosry.md) that is defined as mandatory in the [behavior definition](abencds_behavior_definition_glosry.md). A non-initial value must be passed to this field in every create request and it cannot be initialized in a [modify operation](abenrap_modify_operation_glosry.md).
