# application server instance

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

AS instance for short. Component of an [AS ABAP](abenas_abap_glosry.md). An AS ABAP can be implemented using one or more AS instances, which are usually instantiated on different [host computers](abenhost_computer_glosry.md). However, multiple AS instances of one or more AS ABAP can also be instantiated on the same host computer. Each AS instance has [work processes](abenwork_process_glosry.md) to execute [ABAP programs](abenabap_program_glosry.md).
