# dynamic type

[General](abenabap_glossary.md)

## Definition

For a [reference variable](abenreference_variable_glosry.md), the [data type](abendata_type_glosry.md) or the [class](abenclass_glosry.md) of the [object](abenobject_glosry.md), to which the reference variable points. The dynamic type is always more special than or equal to the [static type](abenstatic_type_glosry.md).
