# CTE hierarchy

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

[Common table expression](abencommon_table_expression_glosry.md) ([CTE](abencte_glosry.md)) that can be used as an [ABAP SQL hierarchy](abensql_hierarchy_glosry.md) in the subsequent [queries](abenasql_query_glosry.md) of its [`WITH`](../abap-programming-language/abap-database-access/abapwith.md) statement. A CTE hierarchy is created when the common table expression is defined using the addition [`WITH HIERARCHY`](../abap-programming-language/abap-database-access/abapwith_hierarchy.md).
