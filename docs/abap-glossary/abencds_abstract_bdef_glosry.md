# RAP abstract behavior definition

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

RAP abstract BDEF or abstract BDEF for short. A RAP abstract behavior definition is a [RAP behavior definition](abencds_behavior_definition_glosry.md) of [implementation type](abencds_bdef_impl_type_glosry.md) abstract. It is based on a [CDS abstract entity](abencds_abstract_entity_glosry.md) and it mainly serves as typing mechanism for deep action or function parameters.
