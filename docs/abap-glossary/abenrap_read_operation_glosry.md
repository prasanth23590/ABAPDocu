# RAP read operation

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

[RAP BO operation](abenrap_bo_operation_glosry.md) that retrieves data of a [RAP BO entity instance](abenrap_bo_entity_inst_glosry.md) from the [RAP transactional buffer](abentransactional_buffer_glosry.md) or from the database table if the instance in not available in the transactional buffer.

See also: [CRUD operations](abencrud_glosry.md)
