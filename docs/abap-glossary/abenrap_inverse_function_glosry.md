# RAP inverse function

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP non-standard operation for associations](abenrap_standard_op_assoc_glosry.md) that receives the values of the [foreign key fields](abenforeign_key_field_glosry.md) of the [association target](abenassociation_target_glosry.md) instances as input and provides the corresponding [association source](abenassociation_source_glosry.md) instances as result. It can be used, for example, to enable [read-by-association operations](abenrap_rba_operation_glosry.md) in a [cross-BO](abencds_cross_bo_assoc_glosry.md) scenario.
