# constant

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

In ABAP, a [named data object](abennamed_data_object_glosry.md) whose value cannot be changed during the runtime of an [ABAP program](abenabap_program_glosry.md) or a [procedure](abenprocedure_glosry.md). In [ABAP CDS](abenabap_cds_glosry.md), constants appear as components of [CDS enumerated types](abencds_enum_type_glosry.md).
