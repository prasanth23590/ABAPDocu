# chained statement

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Abbreviated way of writing multiple [ABAP statements](abenabap_statement_glosry.md) with the same initial part. The identical initial part is specified once and closed using a colon (`:`). This is followed by the remaining parts separated by commas.
