# POSIX time stamp

[General](abenabap_glossary.md)

## Definition

[UTC time stamp](abenutc_timestamp_glosry.md) where each day has 86400 seconds in accordance with the standard [POSIX](https://en.wikipedia.org/wiki/POSIX) 1:2001 and [leap seconds](abenleap_second_glosry.md) are not supported. A time stamp that is created during a leap second 23:59:60 is rounded to a valid time.
