# CDS DDLX

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS DDL](abencds_ddl_glosry.md) dialect that contains language elements for [CDS metadata extensions](abencds_metadata_extension_glosry.md) in [DDLX source code](abenddlx_source_code_glosry.md).
