# RAP handler method

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A method in a [RAP handler class](abenabp_handler_class_glosry.md) of an [ABAP behavior pool](abenbehavior_pool_glosry.md) that is called during the [RAP interaction phase](abenrap_int_phase_glosry.md). The names of handler methods can be freely chosen except for [draft actions](abenrap_bo_draft_action_glosry.md) and [augmentation](abenrap_bo_augmentation_glosry.md).
