# interface (ABAP Objects)

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Template for the [public](abenpublic_glosry.md) [interface](abenintf_gen_glosry.md) of [classes](abenclass_glosry.md) in [ABAP Objects](abenabap_objects_glosry.md). Defined with [`INTERFACE - ENDINTERFACE`](../abap-programming-language/abap-declarations/abapinterface.md), either as a [global interface](abenglobal_interface_glosry.md) in an [interface pool](abeninterface_pool_glosry.md) or as a [local interface](abenlocal_interface_glosry.md) in another [ABAP program](abenabap_program_glosry.md). An interface contains the declaration of [interface components](abeninterface_component_glosry.md) but does not contain method implementations. Can be implemented in classes using [`INTERFACES`](../abap-programming-language/abap-declarations/abapinterfaces.md), which enhances the external interface of the class by adding interface components. OO interfaces are generally referred to as interfaces, unless the distinction to [general interfaces](abenintf_gen_glosry.md) needs to be made.
