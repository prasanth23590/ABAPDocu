# entry node

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A [mesh node](abenmesh_node_glosry.md) from which the evaluation of a [mesh association](abenmesh_association_glosry.md) starts. The entry node is not always the [start node](abenstart_node_glosry.md) of the association.
