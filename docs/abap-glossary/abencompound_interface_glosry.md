# compound interface

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Interface in which at least one [component interface](abencomponent_interface_glosry.md) is included in its declaration with [`INTERFACES`](../abap-programming-language/abap-declarations/abapinterfaces_ifac.md). Also referred to as a nested interface.
