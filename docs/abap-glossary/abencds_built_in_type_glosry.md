# CDS built-in type

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[Built-in](abenbuiltin_data_type_glosry.md) [elementary](abenelementary_data_type_glosry.md) [CDS type](abencds_type_glosry.md). CDS built-in types are based on the [built-in Dictionary types](abenbuiltin_ddic_type_glosry.md) and the same rules apply as to the corresponding built-in ABAP Dictionary types. CDS built-in types can be used for the typing of [CDS elements](abencds_element_glosry.md), [CDS parameters](abencds_parameter_glosry.md), and [CDS simple types](abencds_simple_type_glosry.md), and for casting in ABAP CDS.
