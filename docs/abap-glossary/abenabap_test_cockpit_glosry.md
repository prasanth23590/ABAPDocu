# ABAP Test Cockpit

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

ATC for short. Framework for executing and evaluating various tests for [repository objects](abenrepository_object_glosry.md) integrated into [ABAP development tools for Eclipse (ADT)](abenadt_glosry.md) and the [Change and Transport System (CTS)](abencts_glosry.md).
