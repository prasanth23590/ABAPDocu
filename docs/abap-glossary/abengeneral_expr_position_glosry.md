# general expression position

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Operand position](abenread_position_glosry.md) in which not only a suitable [data object](abendata_object_glosry.md) can be specified, but also a [constructor expression](abenconstructor_expression_glosry.md), a [table expression](abentable_expression_glosry.md), a [calculation expression](abencalculation_expression_glosry.md), a [built-in function](abenbuiltin_function_glosry.md), a [functional method](abenfunctional_method_glosry.md), or a [method chaining](abenmethod_chaining_glosry.md).
