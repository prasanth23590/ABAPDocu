# assignment operator

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Operator](abenoperator_glosry.md) for assigning the content of a [data object](abendata_object_glosry.md) to a [variable](abenvariable_glosry.md). The general assignment operator in ABAP is the equal sign ([`=`](../abap-programming-language/abap-processing-internal-data/abenequals_operator.md)). The [casting operator](abencasting_operator_glosry.md) ([`?=`](../abap-programming-language/abap-processing-internal-data/abapmove_cast.md)) is a special assignment operator. Furthermore, there is the [addition assignment operator](abenadd_assignment_op_glosry.md) ([`+=`](../abap-programming-language/abap-processing-internal-data/abencalculation_assignments.md)), the [subtraction assignment operator](abensub_assignment_op_glosry.md) ([`-=`](../abap-programming-language/abap-processing-internal-data/abencalculation_assignments.md)), the [multiplication assignment operator](abenmult_assignment_op_glosry.md) ([`*=`](../abap-programming-language/abap-processing-internal-data/abencalculation_assignments.md)), the [division assignment operator](abendiv_assignment_op_glosry.md) ([`/=`](../abap-programming-language/abap-processing-internal-data/abencalculation_assignments.md)), and the [concatenation assignment operator](abenconcat_assignment_op_glosry.md) ([`**=`](../abap-programming-language/abap-processing-internal-data/abencalculation_assignment_string.md)) for [calculation assignments](abencalculation_assignment_glosry.md).
