# internal session

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Instance within an [ABAP session](abenabap_session_glosry.md) with its own [program memory](abenroll_area_glosry.md) in which the data and [objects](abenobject_glosry.md) of an [ABAP program](abenabap_program_glosry.md) are stored during its execution. An internal session is created when an ABAP program is called in the [shared memory](abenshared_memory_glosry.md).
