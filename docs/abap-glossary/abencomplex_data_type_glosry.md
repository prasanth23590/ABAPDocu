# complex data type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A [data type](abendata_type_glosry.md) that is made up of other data types. A complex data type is either a [structured data type](abenstructured_type_glosry.md), a [table type](abentable_type_glosry.md), or a [mesh type](abenmesh_type_glosry.md).
