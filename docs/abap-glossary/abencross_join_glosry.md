# cross join

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [join type](abenjoin_type_glosry.md) for which the rows of the result set are determined by a cross product of the result sets of both [SQL data sources](abensql_data_source_glosry.md). The result set contains all possible combinations of rows.
