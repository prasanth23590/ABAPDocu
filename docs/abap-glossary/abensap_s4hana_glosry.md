# SAP S/4HANA

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

SAP's on-premise business suite that is based on a [ABAP Platform](abenabap_platform_glosry.md) and runs on [SAP HANA](abensap_hana_glosry.md). See also [SAP S/4HANA Cloud Public Edition](abensap_s4hana_cpub_glosry.md) and [SAP S/4HANA Cloud Private Edition](abensap_s4hana_cpriv_glosry.md).
