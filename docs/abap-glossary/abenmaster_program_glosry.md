# master program

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Compilation unit](abencompilation_unit_glosry.md) that is modularized into different [processing blocks](abenprocessing_block_glosry.md) which are distributed over several [include programs](abeninclude_program_glosry.md). Typical master programs are [class](abenclass_pool_glosry.md) and [function pools](abenfunction_pool_glosry.md), that are created implicitly by the development tools. The [ABAP Unit](abenabap_unit_glosry.md) tests for the units in the include programs are usually created in the [test include](abentest_include_glosry.md) of the master program.
