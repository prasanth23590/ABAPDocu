# reuse expression

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS element](abencds_element_glosry.md) that reuses an expression from the `SELECT` list of the same entity using the syntax [`$projection`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_reusable_expression_v2.md).
