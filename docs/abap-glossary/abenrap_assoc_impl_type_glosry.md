# association implementation type

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Defines the [RAP BO provider](abenrap_bo_provider_glosry.md) that implements the [operations for associations](abenrap_operation_assoc_glosry.md). The association implementation types available are `managed` and `unmanaged`.
