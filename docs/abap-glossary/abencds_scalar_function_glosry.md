# CDS scalar function

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS function](abencds_function_glosry.md) that operates on a single input data set and returns a scalar (that means [elementary](abenelementary_data_type_glosry.md)) return value as result. A CDS scalar function is defined using [`DEFINE SCALAR FUNCTION`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_scalar_function.md) in a [CDS data definition](abencds_data_definition_glosry.md). CDS scalar functions can be [user-defined functions](abencds_user_func_glosry.md) or [system functions](abencds_system_func_glosry.md).

There are [analytical scalar functions](abencds_ana_scalar_glosry.md) and [SQL-based scalar functions](abencds_sql_scalar_glosry.md).

A scalar function can have one or more [scalar function implementation references](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_scalar_func_impl_ref.md) that bind it to implementations in different environments, such as an SQL environment or the [ABAP Analytical Engine](abenabap_ae_glosry.md).
