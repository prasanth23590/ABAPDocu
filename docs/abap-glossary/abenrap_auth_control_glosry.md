# RAP authorization control

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An access restriction that protects a [RAP BO](abenrap_bo_glosry.md) against unauthorized access to data. It limits access to data or the permission to perform [operations](abenrap_bo_operation_glosry.md). Authorization control can be global or instance or both.

- Global authorization is independent of individual [instances](abenrap_bo_instance_glosry.md).

- Instance authorization is dependent on the state of an [entity instance](abenrap_bo_entity_inst_glosry.md).
