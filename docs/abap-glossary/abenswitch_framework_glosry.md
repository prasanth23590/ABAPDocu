# Switch Framework

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

`SFW` for short. Framework for the externally controlling the visibility of [repository objects](abenrepository_object_glosry.md), their components, or [enhancements](abenenhancement_glosry.md) using [switches](abenswitch_glosry.md).
