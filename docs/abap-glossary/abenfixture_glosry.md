# fixture

[General](abenabap_glossary.md)

## Definition

Test configuration that produces unique test behavior. A fixture comprises test data, test objects, resources, and connections. A fixture is implemented in the methods `[class_]setup` and `[class_]teardown` of [test classes](abentest_class_glosry.md) in [ABAP Unit](abenabap_unit_glosry.md).
