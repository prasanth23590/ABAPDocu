# RAP BO interface

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP business object](abenrap_bo_glosry.md) that serves as interface for stable consumption. A RAP BO interface consists of a [CDS transactional interface](abencds_trans_interface_glosry.md) and a [RAP interface behavior definition](abencds_interface_bdef_glosry.md). A RAP BO interface does not have a runtime handler and cannot specify an implementation class for [ABAP behavior implementation](abenbehavior_implement_glosry.md). A RAP BO interface can only project behavior from the underlying RAP BO.
