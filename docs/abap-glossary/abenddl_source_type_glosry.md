# CDS source type

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Denotes the type of [CDS data definition](abencds_data_definition_glosry.md). The following categories are available:

- [CDS view entities](abencds_v2_view_glosry.md)

- [CDS projection views](abencds_projection_view_glosry.md)

- [CDS table functions](abencds_table_function_glosry.md)

- [CDS table entities](abencds_table_entity_glosry.md)

- [CDS hierarchies](abencds_hierarchy_glosry.md)

- [CDS custom entities](abencds_custom_entity_glosry.md)

- [CDS abstract entities](abencds_abstract_entity_glosry.md)

- [CDS DDIC-based views (obsolete)](abencds_v1_view_glosry.md)

- [CDS DDIC-based view extension](abencds_view_extend_glosry.md)

- [CDS view entity extension](abencds_view_entity_extend_glosry.md)

All available CDS source types are listed in the domain `DDDDLSRCTYPE`.
