# RAP save action

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

[RAP action](abenrap_action_glosry.md) that can only be executed during the [RAP save sequence](abenrap_save_seq_glosry.md). Any attempt to execute a RAP save action during the [RAP interaction phase](abenrap_int_phase_glosry.md) results in a [short dump](abenshort_dump_glosry.md).
