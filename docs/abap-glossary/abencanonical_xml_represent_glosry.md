# canonical XML representation

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Format of [XML](abenxml_glosry.md) data that is created during the [serialization](abenserialization_glosry.md) of ABAP data with the [identity transformation](abenid_trafo_glosry.md) and that is a prerequisite for a [deserialization](abendeserialization_glosry.md) using identity transformations and is used as an intermediate format when using [XSLT](abenxslt_glosry.md) to access ABAP data. The short name is [asXML](abenasxml_glosry.md); see also [basXML](abenbasxml_glosry.md)
