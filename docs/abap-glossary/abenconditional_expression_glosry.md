# conditional expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Constructor expression](abenconstructor_expression_glosry.md) with a [conditional operator](abenconditional_operator_glosry.md) that creates a value or raises a [class-based exception](abenclass_based_exception_glosry.md) depending on a [logical expression](abenlogical_expression_glosry.md) or a [case distinction](abencase_distinction_glosry.md).
