# application program

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP program](abenabap_program_glosry.md) that is part of the business applications executed on [AS ABAP](abenas_abap_glosry.md). Application programs generally only work with the data of the current [application client](abenapplication_client_glosry.md) that is stored in [application tables](abenapplication_table_glosry.md).
