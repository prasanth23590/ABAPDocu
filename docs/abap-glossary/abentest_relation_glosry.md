# test relation

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Relation between a [test class](abentest_class_glosry.md) or a [test method](abentest_method_glosry.md) and another [repository object](abenrepository_object_glosry.md). A test relation is defined by the special [ABAP Doc comment](abenabap_doc_comment_glosry.md) [`"! @testing`](../abap-programming-language/abap-program-maintenance/abentest_relations.md) and allows repository objects to be tested with [ABAP Unit](abenabap_unit_glosry.md) in [ADT](abenadt_glosry.md) that do not support test classes themselves.
