# table category

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Technical type property](abentechnical_type_prpt_glosry.md) of a [table type](abentable_type_glosry.md) that specifies the storage and primary access method. Table categories include [standard tables](abenstandard_table_glosry.md), [sorted tables](abensorted_table_glosry.md), and [hashed tables](abenhashed_table_glosry.md).
