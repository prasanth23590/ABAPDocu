# ABAP function

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

A [function](abenfunction_glosry.md) in ABAP can either be predefined as a [built-in function](abenbuiltin_function_glosry.md) or can be defined as a [functional method](abenfunctional_method_glosry.md). In an [ABAP program](abenabap_program_glosry.md), an ABAP function can be called by an [expression](abenexpression_glosry.md) by using its name at an [operand position](abenoperand_position_glosry.md). During the evaluation of the expression, the function is called and its result is used as an [operand](abenoperand_glosry.md).
