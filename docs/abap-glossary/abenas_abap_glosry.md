# Application Server ABAP

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

AS ABAP for short. AS ABAP represents the [application layer](abenapplication_layer_glosry.md) of an [ABAP system](abenabap_system_glosry.md) in which [ABAP programs](abenabap_program_glosry.md) are executed.
