# intra-BO association

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [CDS association](abencds_association_glosry.md) that is part of a [RAP business object's](abenrap_bo_glosry.md) [composition tree](abencds_composition_tree_glosry.md) and has an [association target](abenassociation_target_glosry.md) from the same RAP BO. The opposite of an intra-BO association is a [cross-BO association](abencds_cross_bo_assoc_glosry.md).
