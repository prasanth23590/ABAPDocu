# logon language

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Language that an [ABAP user](abenabap_user_glosry.md) specifies when logging on to an [AS ABAP](abenas_abap_glosry.md). The logon language is persistent for the entire [user session](abenuser_session_glosry.md). The logon language affects [messages](abenmessage_glosry.md), [text elements](abentext_element_glosry.md), and the [text environment](abentext_environment_glosry.md).
