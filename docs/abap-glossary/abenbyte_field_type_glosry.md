# byte field type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Byte-like data type](abenbyte_like_data_typ_glosry.md) for storing [byte strings](abenbyte_string_glosry.md) of fixed length. The associated [built-in ABAP type](abenbuiltin_abap_type_glosry.md) is [`x`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_byte.md). The [built-in DDIC types](abenbuiltin_ddic_type_glosry.md) are [`RAW`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md) and [`LRAW`](../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md). A [data object](abendata_object_glosry.md) of a byte field type is a [byte field](abenbyte_field_glosry.md).
