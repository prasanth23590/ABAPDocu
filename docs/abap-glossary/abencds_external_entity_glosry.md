# CDS external entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS persistent entity](abencds_sql_entity_glosry.md) defined using [`DEFINE EXTERNAL ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_external_entity.md) in a [CDS data definition](abencds_data_definition_glosry.md). A CDS external entity can be used to access data from external database systems within the [AS ABAP](abenas_abap_glosry.md). The external systems can be other [SAP HANA](abenhana_database_glosry.md) or non-SAP HANA database systems. The properties of the connection between an external entity and the external system are configured using a [logical external schema](abencds_logical_schema_glosry.md). The connection is managed using [SAP HANA Smart Data Access](abensap_hana_sda_glosry.md). The following types of external entities are available:

- [dynamic external entities](abencds_dynamic_ee_glosry.md)

- [static external entities](abencds_static_ee_glosry.md)

- [writable external entities](abenwritable_ee_glosry.md)
