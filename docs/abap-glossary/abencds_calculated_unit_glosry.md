# CDS calculated unit

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A component of a [CDS view entity](abencds_v2_view_glosry.md) of data type `CHAR` that specifies a user-defined unit which is not contained in any list of predefined values. A CDS calculated unit can be linked with a [CDS calculated quantity](../abap-core-data-services-abap-cds/abap-cds-data-types/abencds_calculated_quantity.md) of the same CDS view entity.
