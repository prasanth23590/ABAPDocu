# CDS analytical dimension field

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An analytical dimension field is an element of an [analytical cube view](abencds_analytical_cube_glosry.md) that describes a characteristic of the view's subject and that can be used for [grouping](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_group_by_v2.md) or filtering. For example if a view describes a sales order, the following columns can be dimensions: customer, date, region.
