# processing block

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Indivisible and non-nestable modularization unit of an [ABAP program](abenabap_program_glosry.md). They contain statements that are structured into [statement blocks](abenstatement_block_glosry.md) by [control structures](abencontrol_structure_glosry.md). Each non-declarative statement in an ABAP program is part of a processing block.
