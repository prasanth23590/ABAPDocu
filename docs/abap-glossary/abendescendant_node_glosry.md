# descendant node

[General](abenabap_glossary.md)

## Definition

The descendant nodes of a [parent node](abenparent_node_glosry.md) of a [hierarchy](abenhierarchy_glosry.md) are its [child nodes](abenchild_node_glosry.md), their child nodes, and so on.
