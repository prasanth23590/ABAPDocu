# structure

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data object](abendata_object_glosry.md) with a [structured type](abenstructured_type_glosry.md) that consists of [structure components](abenstructure_component_glosry.md). In [ABAP programs](abenabap_program_glosry.md), whole structures or just components of structures can be accessed. Structures that contain only [character-like](abencharlike_data_object_glosry.md), [flat](abenflat_glosry.md) [components](abenstructure_component_glosry.md) can also be handled like [elementary data objects](abenelementary_data_object_glosry.md).
