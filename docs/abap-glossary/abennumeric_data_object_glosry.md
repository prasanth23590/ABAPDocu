# numeric data object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Data object](abendata_object_glosry.md) that can be interpreted numerically if the content is appropriate. In addition to data objects with [numeric data types](abennumeric_data_type_glosry.md), [byte-like](abenbyte_like_data_object_glosry.md) and [character-like data objects](abencharlike_data_object_glosry.md) can also be numeric.
