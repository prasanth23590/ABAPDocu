# RAP query engine

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A part of the [RAP runtime engine](abenrap_runtime_engine_glosry.md) that handles the non-transactional consumption of [RAP BOs](abenrap_bo_glosry.md). The RAP query engine is provided by the [RAP framework](abenrap_framework_glosry.md) but can be adapted by implementing an [unmanaged query](abenrap_unmanged_query_glosry.md).
