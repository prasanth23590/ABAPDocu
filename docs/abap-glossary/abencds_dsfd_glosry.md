# CDS scalar function definition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS object](abencds_object_glosry.md) that defines a [CDS scalar function](abencds_scalar_function_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md). A CDS scalar function definition is defined using the statement [`DEFINE SCALAR FUNCTION`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_define_scalar_function.md).
