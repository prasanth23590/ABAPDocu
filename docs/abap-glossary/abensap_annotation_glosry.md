# SAP annotation

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS annotation](abencds_annotation_glosry.md) delivered by SAP as a [CDS annotation definition](abencds_anno_definition_glosry.md). There are the following categories of SAP annotations:

- [ABAP annotations](abenabap_annotation_glosry.md), which are evaluated by the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) for every [CDS object](abencds_object_glosry.md).

- [Framework-specific annotations](abenfrmwrk_annotation_glosry.md), which are evaluated by the frameworks of other software components.
