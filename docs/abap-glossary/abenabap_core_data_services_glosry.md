# ABAP Core Data Services

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

ABAP CDS for short. An infrastructure for defining and consuming semantically rich data models on [AS ABAP](abenas_abap_glosry.md). ABAP CDS provides different languages for defining metadata realized as [CDS objects](abencds_object_glosry.md). ABAP CDS is based on SQL but provides more features and sublanguages than SQL.
