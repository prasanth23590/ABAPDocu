# database user name

[General](abenabap_glossary.md)

## Definition

Identity used by a [database user](abendatabase_user_glosry.md) to log on to a [database system](abendatabase_system_glosry.md). A database user name is assigned a [database schema](abendatabase_schema_glosry.md), whose objects can be accessed by the database user implicitly or as an unqualified user.
