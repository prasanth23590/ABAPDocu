# annotation value

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A value specified for a [CDS annotation](abencds_annotation_glosry.md) in the [CDS annotation syntax](abencds_annotation_syntax_glosry.md). The possible values can be specified in the [CDS annotation definition](abencds_anno_definition_glosry.md) using a type specification, enumeration symbols, and a default value.
