# branch

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Also referred to as selection. [Control structure](abencontrol_structure_glosry.md) that can consist of multiple [statement blocks](abenstatement_block_glosry.md) that are defined using the keywords [`IF` - `ELSEIF` - `ELSE` - `ENDIF`](../abap-programming-language/abap-program-flow-logic/abapif.md), [`CASE` - `WHEN` - `ENDCASE`](../abap-programming-language/abap-program-flow-logic/abapcase.md), [`TRY` - `CATCH` - `CLEANUP` - `ENDTRY`](../abap-programming-language/abap-program-flow-logic/abaptry.md) and are executed depending on conditions. Branches can be implemented in [operand positions](abenoperand_position_glosry.md) using [conditional expressions](abenconditional_expression_glosry.md).
