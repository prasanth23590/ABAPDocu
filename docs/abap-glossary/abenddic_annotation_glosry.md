# DDIC annotation

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

A DDIC annotation adds metadata to a DDIC object. It can be used, for example, to add technical or semantic properties to a [DDIC database table](abenddic_db_table_glosry.md) or a [DDIC structure](abenddic_structure_glosry.md).
