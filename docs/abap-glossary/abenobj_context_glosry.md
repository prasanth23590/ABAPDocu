# object context

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Environment of an [object](abenobject_glosry.md). Determines its visibility and lifetime. Possible contexts are [procedures](abenprocedure_glosry.md), [instances](abeninstance_glosry.md) of [classes](abenclass_glosry.md), classes, and [programs](abenabap_program_glosry.md).
