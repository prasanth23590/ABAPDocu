# RAP field characteristic

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A property of a [RAP BO field](abenrap_bo_field_glosry.md) that restricts access to the field in question. Field characteristics can be [static](abenrap_static_field_char_glosry.md) or [dynamic](abenrap_dyn_field_char_glosry.md).
