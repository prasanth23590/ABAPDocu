# SQL function

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Built-in database platform function that can be used in [SQL](abensql_glosry.md). In [ABAP SQL](../abap-programming-language/abap-database-access/abenabap_sql_functions.md) and in the [CDS DDL](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_builtin_functions_v2.md) in [ABAP CDS](abenabap_cds_glosry.md), a set of SQL functions can be accessed platform-independently.
