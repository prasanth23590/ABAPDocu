# CDS parent entity

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [CDS entity](abencds_entity_glosry.md) of a [CDS composition tree](abencds_composition_tree_glosry.md) that uses a [to-child association](abento_child_association_glosry.md) to define a [child entity](abenchild_entity_glosry.md). A parent entity can have multiple child entities. Each child entity must define and expose a [to-parent association](abento_parent_association_glosry.md) to its parent entity.
