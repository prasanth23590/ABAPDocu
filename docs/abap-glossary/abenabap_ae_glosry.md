# ABAP Analytical Engine

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

The ABAP Analytical Engine implements the [OLAP](abenolap_glosry.md) concept on [AS ABAP](abenas_abap_glosry.md). It processes multidimensional data models to be consumed by analytical clients such as SAP Analytics Cloud. Clients communicate with the ABAP Analytical Engine using protocols such as the [InA](abenina_glosry.md) protocol. The ABAP Analytical Engine performs calculations either on the [SAP HANA database](abenhana_database_glosry.md) or in the [ABAP language](abenabala_glosry.md).
