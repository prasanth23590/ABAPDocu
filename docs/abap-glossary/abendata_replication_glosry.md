# data replication

[General](abenabap_glossary.md)

## Definition

An approach to [data integration](abendata_integration_glosry.md) where data is copied from a source to a consumer system or application. As a result, the data is available for use in the consumer as well as the source. Data is continuously replicated to the consumer for a close to real-time consumption. All requests are executed on the replicated data in the consumer system.

See also: [Data federation](abendata_federation_glosry.md)
