# graph procedure

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [AMDP](../abap-programming-language/abap-database-access/abenamdp_glossary.md)

## Definition

A graph procedure is an [ABAP Managed Database Procedure](abenabap_managed_db_proc_glosry.md). It refers to [graph workspace](abengraph_workspace_glosry.md) and operates on [graph](abengraph_glosry.md) models. It is a read-only procedure that is written in [GraphScript](abengraphscript_glosry.md).
