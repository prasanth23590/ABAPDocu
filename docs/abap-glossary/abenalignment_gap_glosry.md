# alignment gap

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Bytes within a [structure](abenstructure_glosry.md) that are inserted either before [structure components](abenstructure_component_glosry.md) with alignment requirements or before the end of the structure to provide the necessary [alignment](abenalignment_glosry.md). Alignment gaps contribute to the length of a structure. The binary content of alignment gaps is not defined and must not be evaluated.
