# ABAP SQL engine

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

Part of the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md) that processes [ABAP SQL](abenabap_sql_glosry.md) statements. ABAP SQL statements are either processed by the [ABAP SQL interface](abenabap_sql_interface_glosry.md) and passed to the [standard database](abenstandard_db_glosry.md) of the [AS ABAP](abenas_abap_glosry.md) or by the [ABAP SQL in-memory engine](abenabap_sql_inmemeng_glosry.md).
