# hierarchy function

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

In [ABAP SQL](abenabap_sql_glosry.md), a special [table function](abentable_function_glosry.md) for processing [ABAP SQL hierarchies](abensql_hierarchy_glosry.md). A [hierarchy generator](abenhierarchy_generator_glosry.md), for example, is used to create SQL hierarchies, whereas [hierarchy navigators](abenhierarchy_navigator_glosry.md) are used to access them. In the [SAP HANA database](abenhana_database_glosry.md), there are built-in hierarchy functions that are wrapped by ABAP SQL and [ABAP CDS](abenabap_cds_glosry.md).
