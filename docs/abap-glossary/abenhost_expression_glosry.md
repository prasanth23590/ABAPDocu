# host expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

ABAP-[expression](abenexpression_glosry.md) specified in an operand position of an [ABAP SQL](../abap-programming-language/abap-database-access/abenabap_sql_host_expressions.md) statement. Host expressions are always specified in parentheses preceded by the [escape character](abenescape_character_glosry.md) `@`: `@( ... )`.
