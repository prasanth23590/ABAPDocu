# DDIC quantity field

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Component of a [DDIC structure](abenddic_structure_glosry.md), or [DDIC database table](abenddic_db_table_glosry.md) of type `QUAN` defined in the [ABAP Dictionary](abenabap_dictionary_glosry.md). A quantity field must be linked to a [unit key](abenunit_glosry.md) of a structure, database table, or view. This key determines the unit of the quantity field.
