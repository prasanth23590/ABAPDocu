# RAP default values function

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO operation addition](../abap-rap-business-objects/rap-behavior-definitions/abenbdl_operations_additions.md) that defaults field values or input parameters for [RAP BO operations](abenrap_bo_operation_glosry.md) on the user interface. A RAP default values function must be implemented by an [ABP handler method](abenabp_handler_method_glosry.md).
