# hashed table

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Table category](abentable_category_glosry.md) of an [internal table](abeninternal_table_glosry.md) whose lines are stored internally using a [hash algorithm](abenhash_algorithm_glosry.md) and can be accessed using a unique [hash key](abenhash_key_glosry.md). A hashed table does not have a [primary table index](abenprimary_table_index_glosry.md), but it can be assigned a [secondary table index](abensecondary_table_index_glosry.md) using a [secondary table key](abensecondary_table_key_glosry.md). The corresponding [generic data type](abengeneric_data_type_glosry.md) is [`hashed table`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md).
