# character-like expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Represents a [string](abencharacter_string_glosry.md). A character-like expression is a [constructor expression](abenconstructor_glosry.md), a [string expression](abenstring_expression_glosry.md), a [table expression](abentable_expression_glosry.md), or a [function](abenfunction_glosry.md), the return value of which has a [character-like data type](abencharlike_data_type_glosry.md).
