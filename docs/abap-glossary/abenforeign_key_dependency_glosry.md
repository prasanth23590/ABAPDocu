# foreign key dependency

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Relationship between a [foreign key table](abenforeign_key_table_glosry.md) and a [check table](abencheck_table_glosry.md). A foreign key table usually only contains entries for which the content of the [foreign key](abenforeign_key_glosry.md) also occurs as content of the [primary key](abenprimary_key_glosry.md) in the check table.
