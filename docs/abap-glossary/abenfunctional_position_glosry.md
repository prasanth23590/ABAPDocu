# functional operand position

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Read position](abenread_position_glosry.md) with any [operand type](abenoperand_type_glosry.md), in which not only a suitable [data object](abendata_object_glosry.md) but also a [functional method call](abenfunctional_method_call_glosry.md) or [method chainings](abenmethod_chaining_glosry.md), a [constructor expression](abenconstructor_expression_glosry.md), or a [table expression](abentable_expression_glosry.md) can be specified, the [return value](abenreturn_value_glosry.md) or result of which has the suitable [data type](abendata_type_glosry.md).
