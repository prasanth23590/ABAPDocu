# class-based exception

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Catchable exception](abencatchable_exception_glosry.md), which is represented by an [exception object](abenexception_object_glosry.md) of an [exception class](abenexception_class_glosry.md). A class-based exception can either terminate the current context or be a [resumable exception](abenresumable_exception_glosry.md).
