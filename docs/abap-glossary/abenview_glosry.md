# database view

[General](abenabap_glossary.md)

## Definition

Grouping of columns from one or more [database tables](abendatabase_table_glosry.md) or other [database objects](abendb_object_glosry.md). In an [AS ABAP](abenas_abap_glosry.md), views are defined in [ABAP CDS](abenabap_cds_glosry.md) as [CDS views](abencds_view_glosry.md). Both can be referenced as [data types](abendata_type_glosry.md) in ABAP programs and represent [flat structures](abenflat_structure_glosry.md) there. Views can be used like database tables in reading [ABAP SQL](abenabap_sql_glosry.md) statements.
