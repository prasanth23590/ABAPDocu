# ABAP keyword

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP word](abenabap_word_glosry.md) that introduces an [ABAP statement](abenabap_statement_glosry.md). In combination with other ABAP words or [ABAP operands](abenabap_operand_glosry.md), it defines an [ABAP language element](abenabap_language_element_glosry.md).
