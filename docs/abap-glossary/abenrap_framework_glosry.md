# RAP framework

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

The framework for the [ABAP RESTful Application Programming Model (RAP)](abenrap_glosry.md) on [AS ABAP](abenas_abap_glosry.md). It consists of the [RAP runtime engine](abenrap_runtime_engine_glosry.md) and the RAP development environment.
