# class component

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Component](abencomponent_glosry.md) of a [class](abenclass_glosry.md). Declared in the [declaration part](abendeclaration_part_glosry.md) of the class. Possible class components are: [Attributes](abenattribute_glosry.md), [methods](abenmethod_glosry.md), and [events](abenevent_glosry.md).
