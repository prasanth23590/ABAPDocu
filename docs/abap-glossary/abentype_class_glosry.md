# type description class

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[System class](abensystem_class_glosry.md) of the [runtime type services](abenrun_time_type_services_glosry.md). The [static methods](abenstatic_method_glosry.md) of a type description classes create [type description objects](abentype_object_glosry.md) from existing types or construct new types.
