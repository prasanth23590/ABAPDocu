# CDS view entity extension

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

[CDS entity extension](abencds_entity_extend_glosry.md) of a [CDS view entity](abencds_v2_view_glosry.md) or a [CDS projection view](abencds_projection_view_glosry.md). A CDS view entity extension can be used to add elements and/or clauses to a view without making any modifications to the original view. It is defined using the statement [`EXTEND VIEW ENTITY`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_extend_view_entity.md).
