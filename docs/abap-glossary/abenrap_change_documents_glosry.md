# RAP change documents

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

An optional part of an [entity behavior definition](abencds_entity_bdef_glosry.md) that enables change logging of persisted RAP BO data for a [change documents-enabled RAP BO entity](abenrap_change_doc_enabled_glosry.md). When enabled, changes are written to a [change document object](abenchange_document_obj_glosry.md). RAP change documents are a [RAP reuse service](abenrap_reuse_service_glosry.md).
