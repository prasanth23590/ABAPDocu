# static box

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Boxed component](abenboxed_component_glosry.md) for supporting [initial value sharing](abeninitial_value_sharing_glosry.md) when the initial value exists only once on the [AS instance](abenas_instance_glosry.md). A static box is declared using the `BOXED` addition when defining [substructures](abensubstructure_glosry.md) using [`TYPES`](../abap-programming-language/abap-declarations/abaptypes_boxed.md) or when declaring structured [attributes](abenattribute_glosry.md) of [classes](abenclass_glosry.md) or [interfaces](abenoo_intf_glosry.md) using [`DATA`](../abap-programming-language/abap-declarations/abapdata_boxed.md).
