# left outer join

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [join type](abenjoin_type_glosry.md) that determines the same rows as an [inner join](abeninner_join_glosry.md) and an additional row for each row of the left [SQL data source](abensql_data_source_glosry.md) that is not included by the [join conditions](abenjoin_condition_glosry.md). In these rows, the columns coming from the right data source contain [null values](abennull_value_glosry.md).
