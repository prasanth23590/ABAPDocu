# application table

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[DDIC database table](abenddic_db_table_glosry.md) with [client column](abenclient_column_glosry.md). An application table contains [client-dependent](abenclient_dependent_glosry.md) data that is processed by [application programs](abenapplication_program_glosry.md).
