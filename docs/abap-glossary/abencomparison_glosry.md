# comparison

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Relational expression](abenrelational_expression_glosry.md) that compares one or more [operands](abenoperand_glosry.md). Implemented in ABAP using [comparison expressions](abencomparison_expression_glosry.md).
