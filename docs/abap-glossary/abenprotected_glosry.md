# protected

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Term in [ABAP Objects](abenabap_objects_glosry.md). A protected [component](abenclass_component_glosry.md) of a [class](abenclass_glosry.md) can be accessed only by the class itself or by its subclasses. Only the class itself and its subclasses can create [objects](abenobject_glosry.md) in the case of a protected instantiation. Here, [friends](abenfriend_glosry.md) of the class have the same rights as the class itself. The protected [visibility section](abenvisibility_section_glosry.md) of a class is declared in the statement [`PROTECTED SECTION`](../abap-programming-language/abap-declarations/abapprotected.md) in the [declaration section](abendeclaration_part_glosry.md).
