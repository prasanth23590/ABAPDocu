# complete typing

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Typing](abentyping_glosry.md) in which the [data type](abendata_type_glosry.md) of a [formal parameter](abenformal_parameter_glosry.md) or a [field symbol](abenfield_symbol_glosry.md) is completely defined, and which is valid for dynamic access as well as static access.
