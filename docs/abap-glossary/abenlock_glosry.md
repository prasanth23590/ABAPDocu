# lock

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [General](abenabap_glossary.md)

## Definition

Locks control the access to data by multiple users. Regarding access to [database tables](abendatabase_table_glosry.md), there are [shared locks](abenshared_lock_glosry.md) or [exclusive locks](abenexclusive_lock_glosry.md).
