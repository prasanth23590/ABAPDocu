# user name

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Name of an [ABAP user](abenabap_user_glosry.md) that is required for logging on to a [user session](abenuser_session_glosry.md) in the [AS ABAP](abenas_abap_glosry.md). Together with the [password](abenpassword_glosry.md), the user name allows authorized use of an AS ABAP.
