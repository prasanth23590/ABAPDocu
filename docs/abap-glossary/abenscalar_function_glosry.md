# scalar function

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

In the [SAP HANA database](abenhana_database_glosry.md), a [database function](abendatabase_function_glosry.md) with a scalar or elementary return value. In [SQLScript](abensql_script_glosry.md), scalar functions can be used as operands in the same places as elementary variables or columns of database tables or views. A scalar function can be managed as an [AMDP function](abenamdp_function_glosry.md) in an [AMDP class](abenamdp_class_glosry.md).
