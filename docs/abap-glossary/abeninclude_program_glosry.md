# include program

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[ABAP program](abenabap_program_glosry.md) that cannot be compiled independently but must be included in another ABAP program using the statement `INCLUDE`. To be able to be compiled, an include program must be part of a [compilation unit](abencompilation_unit_glosry.md). An include program should only be assigned to a single compilation unit.
