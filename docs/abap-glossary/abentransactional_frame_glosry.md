# RAP transactional framework

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

Part of the [RAP framework](abenrap_framework_glosry.md) that consists of the [RAP transactional engine](abenrap_transac_engine_glosry.md) and the development environment for [RAP business objects](abenrap_bo_glosry.md).
