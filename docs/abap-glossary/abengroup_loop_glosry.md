# group loop

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Loop across the groups of an [internal table](abeninternal_table_glosry.md) formed by the addition [`GROUP BY`](../abap-programming-language/abap-processing-internal-data/abaploop_at_itab_group_by.md) of the statement [`LOOP AT`](../abap-programming-language/abap-processing-internal-data/abaploop_at_itab_variants.md). A group loop can contain [member loops](abenmember_loop_glosry.md) for the evaluation of the groups.
