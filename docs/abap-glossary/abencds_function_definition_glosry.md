# CDS function definition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A [CDS object](abencds_object_glosry.md) that defines a [CDS function](abencds_function_glosry.md) in [ABAP CDS](abenabap_cds_glosry.md). Currently, [CDS scalar function definitions](abencds_dsfd_glosry.md) are the only type of CDS function definition available.
