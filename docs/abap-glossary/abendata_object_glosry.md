# data object

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Instance](abeninstance_glosry.md) of a [data type](abendata_type_glosry.md). Exists in the [internal session](abeninternal_session_glosry.md) of an [ABAP program](abenabap_program_glosry.md). Is either created as a [named](abennamed_data_object_glosry.md), statically declared data object (statement [`DATA`](../abap-programming-language/abap-declarations/abapdata.md) and similar) when a program or [procedure](abenprocedure_glosry.md) is loaded, or dynamically as an [anonymous data object](abenanonymous_data_object_glosry.md) at runtime ( [instance operator](abeninstance_operator_glosry.md) [`NEW`](../abap-programming-language/abap-creating-objects-and-values/abenconstructor_expression_new.md)). In addition, the [literals](abenabap_literal_glosry.md) defined as part of the source code are also handled as data objects. The data type of a data object is always complete (not [generic](abengeneric_data_type_glosry.md)) and can be [bound](abenbound_data_type_glosry.md) or [standalone](abenstand-alone_data_type_glosry.md). See also [static data object](abenstatic_data_object_glosry.md) and [dynamic data object](abendynamic_data_object_glosry.md).
