# DDIC dependency rule

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Database object](abendb_object_glosry.md) of the [SAP HANA database](abenhana_database_glosry.md). A dependency rule can be defined for [DDIC database tables](abenddic_db_table_glosry.md) and derives additional conditions from a selection condition, used by the optimizer of the [database system](abendatabase_system_glosry.md) to extend the read access to these database tables.
