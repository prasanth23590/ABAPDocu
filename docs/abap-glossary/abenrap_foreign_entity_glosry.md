# RAP foreign entity

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO entity](abenrap_bo_entity_glosry.md) which is not part of the [BO composition tree](abencds_composition_tree_glosry.md) for which it is defined. Defining a foreign entity in the [behavior definition](abencds_behavior_definition_glosry.md) enables cross-BO message mapping between the two [BOs](abenrap_bo_glosry.md).
