# stack

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Part of the [program memory](abenroll_area_glosry.md) in which [named data objects](abennamed_data_object_glosry.md) of programs and [procedures](abenprocedure_glosry.md) are stacked. The memory used by a procedure is released again once the procedure ends. See also [heap](abenheap_glosry.md).
