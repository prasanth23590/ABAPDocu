# Runtime Type Creation

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

RTTC for short. Creation of [data types](abendata_type_glosry.md) during program runtime. Implemented using methods of the [type description classes](abentype_class_glosry.md) of [RTTS](abenrun_time_type_services_glosry.md).
