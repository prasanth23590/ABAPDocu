# component selector

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Syntax that can be used to address [components](abencomponent_glosry.md) of higher units. There is the [structure component selector](abenstructure_component_sel_glosry.md) (`-`), the [class component selector](abenclass_component_select_glosry.md) (`=>`), the [interface component selector](abeninterface_comp_selector_glosry.md) (`~`), and the [object component selector](abenobject_component_select_glosry.md) (`->`). [ABAP SQL](abenabap_sql_glosry.md) provides the additional [column selector](abentable_comp_selector_glosry.md) `~`.
