# CDS DDL

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

The data definition language of [ABAP CDS](abenabap_cds_glosry.md). Besides CDS DDL for [CDS data definitions](abencds_data_definition_glosry.md), there two further dialects, namely [CDS DDLA](abencds_ddla_glosry.md) and [CDS DDLX](abencds_ddlx_glosry.md).
