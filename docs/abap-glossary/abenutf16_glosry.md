# UTF-16

[General](abenabap_glossary.md)

## Definition

16-bit [Unicode character representation](abenunicode_char_represent_glosry.md). In this representation, all characters are represented using 2 bytes or 4 bytes. UTF-16 is the [system code page](abensystem_codepage_glosry.md) of a [Unicode system](abenunicode_system_glosry.md). UTF-16 uses the same 2-byte encoding as [UCS-2](abenucs2_glosry.md) for the Basic Multilingual Plane (BMP) of the Unicode standard and a 4-byte encoding for the other Unicode planes in the [surrogate area](abensurrogate_area_glosry.md) that are addressed by [surrogates](abensurrogates_glosry.md). The ABAP programming language supports UCS-2 as a subset of UTF-16 without surrogates.
