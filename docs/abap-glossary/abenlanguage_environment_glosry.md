# language environment

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Language-dependent settings for [ABAP programs](abenabap_program_glosry.md). The language environment includes both [language settings](abenlanguage_setting_glosry.md) and [format settings](abenformat_setting_glosry.md).
