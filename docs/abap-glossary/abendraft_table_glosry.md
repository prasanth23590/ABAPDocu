# RAP draft table

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [DDIC database table](abenddic_db_table_glosry.md) that is generated for a [draft-enabled RAP business object](abendraft_rap_bo_glosry.md). It contains draft administrative data that is used for [RAP draft handling](abenrap_draft_handling_glosry.md). A draft table should be accessed by the [RAP framework](abenrap_framework_glosry.md) only.
