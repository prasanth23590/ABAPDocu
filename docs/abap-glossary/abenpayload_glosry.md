# payload

[General](abenabap_glossary.md) [RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

In communications technology, *payload* is the term used to describe the data that is transported in a data packet during communication between two partners that does not contain any control or protocol information. Payload data includes voice, text, characters, images, and sounds.

In the context of [RAP business events](abenrap_entity_event_glosry.md), the payload is the data that is passed from the sender to the event consumers. The payload of a RAP business event is defined using an [output parameter](abenoutput_parameter_glosry.md).
