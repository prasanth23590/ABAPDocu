# static attribute

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Attribute](abenattribute_glosry.md) of a [class](abenclass_glosry.md) declared using [`CLASS-DATA`](../abap-programming-language/abap-declarations/abapclass-data.md) that is valid independent of the class [instance](abeninstance_glosry.md). The content of the static attributes determines the instance-dependent state of a class.
