# procedure

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Processing block](abenprocessing_block_glosry.md) that can be called using an [ABAP statement](abenabap_statement_glosry.md). After ending a procedure, processing continues behind the call position in the ABAP program. A procedure has a [parameter interface](abenparameter_interface_glosry.md) and a local [data area](abendata_area_glosry.md). Possible procedures are [methods](abenmethod_glosry.md).
