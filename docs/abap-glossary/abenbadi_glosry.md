# BAdI

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Business Add-In, template for [BAdI objects](abenbadi_object_glosry.md). A BAdI consists of a [BAdI interface](abenbadi_interface_glosry.md), a set of filters, and various settings. BAdIs are the basis for [enhancements](abenenhancement_glosry.md), for which [BAdI methods](abenbadi_method_glosry.md) in [object plug-ins](abenobject_plugin_glosry.md) can be called in ABAP programs, whereby the caller can control which [BAdI implementations](abenbadi_implementation_glosry.md) are used by specifying the filter values.
