# time zone

[General](abenabap_glossary.md)

## Definition

Geographical area in which the same [local time](abenlocal_time_glosry.md) and [local date](abenlocal_date_glosry.md) apply based on a set of [time zone rules](../abap-programming-language/abap-processing-internal-data/abentime_zone_rules.md) at a given time.
