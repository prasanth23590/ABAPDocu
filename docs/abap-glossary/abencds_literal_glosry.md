# CDS literal

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An elementary [CDS operand](abencds_operand_glosry.md) defined by the textual specification of a value in a [CDS object](abencds_object_glosry.md). ABAP CDS provides [typed literals](abentyped_literal_glosry.md) and [untyped literals](abenuntyped_literal_glosry.md).
