# CDS DDL aspect binding

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

An optional component of a [CDS data definition](abencds_data_definition_glosry.md), specified in front of the [`SELECT`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_select_statement_v2.md) list. With a CDS aspect binding, a [CDS aspect](abencds_aspect_glosry.md) is bound to a CDS data definition using the syntax [`BIND ASPECT`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_bind_aspect.md). This makes the elements of the aspect available for use in an operand position of the data definition, using the syntax [`INCLUDE`](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_include_aspect.md).
