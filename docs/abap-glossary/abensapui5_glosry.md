# SAPUI5

[General](abenabap_glossary.md)

## Definition

SAPUI5 is a tool set for developing user interfaces for Web applications in HTML5. SAPUI5 supports the Model View Controller (MVC) approach and is based on the user interface elements delivered in JavaScript and CSS libraries. The data connection to the application server is established using the data formats [XML](abenxml_glosry.md), [JSON](abenjson_glosry.md) or OData. Interfaces developed with SAPUI5 can be connected to SAP and non-SAP platforms. In particular, SAPUI5 user interfaces can be developed for ABAP applications in [AS ABAP](abenas_abap_glosry.md).
