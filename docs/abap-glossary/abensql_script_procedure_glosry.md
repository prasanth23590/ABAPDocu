# SQLScript procedure

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

A [database procedure](abendatabase_procedure_glosry.md) of the [SAP HANA database](abenhana_database_glosry.md) programmed in the language [SQLScript](abensql_script_glosry.md). [ABAP Managed Database Procedures (AMDP)](abenabap_managed_db_proc_glosry.md) enable SQLScript procedures to be implemented in [AMDP procedure implementations](abenamdp_procedure_method_glosry.md) of [AMDP classes](abenamdp_class_glosry.md). See also [SQLScript Function](abensql_script_function_glosry.md).
