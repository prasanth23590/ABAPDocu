# CDS access condition

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Condition in a [CDS role](abencds_role_glosry.md) defined in an [access rule](abenaccess_rule_glosry.md) of the statement [`DEFINE ROLE`](../abap-core-data-services-abap-cds/abap-cds-access-control/abencds_f1_define_role.md) for a [CDS entity](abencds_entity_glosry.md). [CDS access control](abencds_access_control_glosry.md) evaluates the access conditions of a CDS entity by default when [ABAP SQL](abenabap_sql_glosry.md) is used to access objects. Access conditions can include for example [PFCG conditions](abenpfcg_condition_glosry.md), [literal conditions](abenliteral_condition_glosry.md), [user conditions](abenuser_condition_glosry.md), and other conditions.
