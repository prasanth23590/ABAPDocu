# predicate method

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Functional method](abenfunctional_method_glosry.md) whose [return value](abenreturn_value_glosry.md) has the type `abap_bool` from the [type pool](abentype_pool_glosry.md) `ABAP`. A predicate method is particularly well suited for [predicative method calls](abenpredicative_method_call_glosry.md), but is not a prerequisite.
