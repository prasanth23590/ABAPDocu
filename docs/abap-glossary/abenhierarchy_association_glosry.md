# hierarchy association

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

A [CDS association](abencds_association_glosry.md) or [CTE association](abencte_association_glosry.md) used to define the [parent-child relationships](abenpcr_glosry.md) of a [ABAP SQL hierarchy](abensql_hierarchy_glosry.md) or [CDS hierarchy](abencds_hierarchy_glosry.md). A hierarchy association is always a [self-association](abenself_association_glosry.md).
