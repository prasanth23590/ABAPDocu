# SQL path expression

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Specifies a [CDS association path](abencds_association_path_glosry.md), a [CTE association path](abencte_association_path_glosry.md), or a [CDS/CTE association path](abencds_cte_assoc_path_glosry.md) in [ABAP SQL](abenabap_sql_glosry.md) or [ABAP CDS](abenabap_cds_glosry.md). A SQL path expression can be used as a data source, or for specifying a [SQL path target field](abensql_target_field_glosry.md) in an operand position. For this, [CDS associations](abencds_association_glosry.md) and [CTE associations](abencte_association_glosry.md) are implicitly transformed into [joins](abenjoin_glosry.md). See

- [Path Expression in CDS](../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_path_expression_v2.md)

- [Path Expression in ABAP SQL](../abap-programming-language/abap-database-access/abenabap_sql_path.md).
