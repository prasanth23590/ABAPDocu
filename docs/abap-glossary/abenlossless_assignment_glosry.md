# lossless assignment

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Assignment](abenassignment_glosry.md) between two non-[compatible](abencompatible_glosry.md) [data objects](abendata_object_glosry.md), where the source field contains a valid value, the [conversion](abenconversion_glosry.md) is lossless, and the target field contains a valid value after the assignment. The [lossless operator](abenlossless_operator_glosry.md) [`EXACT`](../abap-programming-language/abap-processing-internal-data/abenconstructor_expression_exact.md) [assignment](abenassignment_glosry.md) can be used to check whether an assignment is lossless.
