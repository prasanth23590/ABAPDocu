# serialization

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Transformation of ABAP data into [XML](abenxml_glosry.md) data or [JSON](abenjson_glosry.md) data. Performed either by calling an [XSLT program](abenxsl_transformation_glosry.md) or a [Simple Transformation](abensimple_transformation_glosry.md). If [XSLT](abenxslt_glosry.md) is used, the system first creates a [canonical XML representation](abencanonical_xml_represent_glosry.md) ([asXML](abenxml_glosry.md)).
