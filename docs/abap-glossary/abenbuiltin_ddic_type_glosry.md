# built-in DDIC type

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

[Built-in](abenbuiltin_data_type_glosry.md) [elementary data type](abenelementary_data_type_glosry.md) of the [ABAP Dictionary](abenabap_dictionary_glosry.md). Built-in DDIC types can be used to define types in ABAP Dictionary and [ABAP CDS](abenabap_cds_glosry.md) but cannot be used in [ABAP programs](abenabap_program_glosry.md) directly.
