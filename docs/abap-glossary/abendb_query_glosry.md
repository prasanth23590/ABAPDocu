# database query

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Query for short. A database query is used to retrieve data from [database tables](abendatabase_table_glosry.md). In [SQL](abensql_glosry.md), queries are generally expressed in its subset [DQL](abendql_glosry.md) (Data Query Language). In [ABAP SQL](abenabap_sql_glosry.md) a query is called [ABAP SQL Query](abenasql_query_glosry.md). In [ABAP CDS](abenabap_cds_glosry.md), queries appear in the SQL-part of the definitions of [CDS views](abencds_view_glosry.md).
