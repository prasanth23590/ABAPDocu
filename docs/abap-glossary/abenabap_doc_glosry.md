# ABAP Doc

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

ABAP Doc is a documentation tool that enables documentation files to be created automatically in HTML format from [ABAP source code](abenabap_source_code_glosry.md). ABAP Doc is based on special [ABAP Doc comments](abenabap_doc_comment_glosry.md).
