# Unicode check

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Syntax check](abensyntax_check_glosry.md) for [ABAP programs](abenabap_program_glosry.md) that are to be executed in a [Unicode system](abenunicode_system_glosry.md). The Unicode check is carried out for [ABAP language versions](abenabap_version_glosry.md) [Standard ABAP](abenstandard_abap_glosry.md) or higher.
