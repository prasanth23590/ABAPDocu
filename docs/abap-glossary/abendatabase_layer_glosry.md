# database layer

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md) [General](abenabap_glossary.md)

## Definition

Software layer of a [client-server system](abenclient_server_system_glosry.md) in which [persistent data](abenrap_persistent_data_glosry.md) is stored and managed. The [AS ABAP](abenas_abap_glosry.md) of an [ABAP system](abenabap_system_glosry.md) is always connected to a database layer in the form of a [database server](abendatabase_server_glosry.md) that contains a [database system](abendatabase_system_glosry.md) with the [standard AS ABAP database](abenstandard_db_glosry.md).
