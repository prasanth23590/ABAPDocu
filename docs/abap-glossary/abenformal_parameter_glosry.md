# formal parameter

[General](abenabap_glossary.md)

## Definition

In the [ABAP language](abenabala_glosry.md):

- An [input parameter](abeninput_parameter_glosry.md), [output parameter](abenoutput_parameter_glosry.md), [input/output parameter](abeninput_output_parameter_glosry.md), or [returning parameter](abenreturning_parameter_glosry.md).

- A [parameter](abenparameter_glosry.md) of the [parameter interface](abenparameter_interface_glosry.md) of a [procedure](abenprocedure_glosry.md) or [event](abenevent_glosry.md), see [Parameter Interface of Procedures](../abap-programming-language/abap-program-structure/abenformal_parameters_oview.md).

- A parameter of a [built-in function](abenbuiltin_function_glosry.md). Can be a named or an unnamed parameter.

In [ABAP CDS](abenabap_cds_glosry.md):

- A [CDS parameter](abencds_parameter_glosry.md) of a [CDS entity](abencds_entity_glosry.md).

- An [input parameter](abeninput_parameter_glosry.md) of a [CDS built-in function](abencds_builtin_func_glosry.md).

- An input parameter of a [CDS scalar function](abencds_scalar_function_glosry.md).

In [RAP](abenabap_rap_glosry.md):

- An input or output parameter of a [RAP action](abenrap_action_glosry.md), [RAP function](abenrap_function_glosry.md), or a [RAP business event](abenrap_entity_event_glosry.md).

In transformations:

- An input parameter of a [XSL transformation](abenxslt_glosry.md) or a [Simple Transformation](abensimple_transformation_glosry.md).
