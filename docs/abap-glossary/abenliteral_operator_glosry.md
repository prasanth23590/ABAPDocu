# literal operator

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

The literal operator `&` joins two [text field literals](abentext_field_literal_glosry.md) or two [text string literals](abentext_string_literal_glosry.md) as a single literal or two [string templates](abenstring_template_glosry.md) as a single string template. The literal operator is supported in [ABAP literals](abenabap_literal_glosry.md) and in [ABAP SQL literals](abenabap_sql_literal_glosry.md), but not in [CDS literals](abencds_literal_glosry.md).
