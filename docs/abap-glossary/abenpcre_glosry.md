# Perl Compatible Regular Expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md) [General](abenabap_glossary.md)

## Definition

PCRE for short. [Regular expressions](abenregular_expression_glosry.md) using the same syntax and semantics as [Perl 5](https://www.perl.org/). In general, ABAP supports [PCRE syntax](../abap-programming-language/abap-processing-internal-data/abenregex_pcre_syntax.md) for regular expressions by implementing the [PCRE2 library](https://www.pcre.org/) in the [ABAP kernel](abenkernel_glosry.md). [ABAP SQL](abenabap_sql_glosry.md) supports PCRE by using the PCRE1 library implemented in the [SAP HANA database](abenhana_database_glosry.md).
