# client

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

Organizational unit of an [AS ABAP](abenas_abap_glosry.md). For each [logon](abenlogon_glosry.md) to AS ABAP, a [client ID](abenclient_identifier_glosry.md) must be specified. This ID enables a logon to a specific client. The different clients of an AS ABAP have their own [user master records](abenuser_master_record_glosry.md) with specific [authorizations](abenauthorization_glosry.md). [Client-dependent](abenclient_dependent_glosry.md) data is kept separate using the [client column](abenclient_column_glosry.md) in [application tables](abenapplication_table_glosry.md).
