# value table

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Semantic property of a [DDIC domain](abendomain_glosry.md) in the [ABAP Dictionary](abenabap_dictionary_glosry.md). The value table is the default value for the [check table](abencheck_table_glosry.md) of table fields defined with reference to the domain.
