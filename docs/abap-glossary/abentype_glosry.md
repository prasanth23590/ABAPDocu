# type

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Abstract description of an [object](abenobject_glosry.md). Either a [data type](abendata_type_glosry.md) for a [data object](abendata_object_glosry.md) or an [object type](abenobject_type_glosry.md) for an object in [ABAP Objects](abenabap_objects_glosry.md). The associated [generic data type](abengeneric_data_type_glosry.md) is [`any`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuilt_in_types_generic.md). All types share the same [namespace](../abap-programming-language/abap-syntax-elements-of-an-abap-program/abennaming_conventions.md).
