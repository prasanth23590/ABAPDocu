# tuning object

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

A [repository object](abenrepository_object_glosry.md) that defines technical settings for certain repository objects. A tuning object can be defined and transported separately from the repository object for which it is defined. The following types of tuning objects are currently available:

- [HANA tuning objects](abenhana_tuning_object_glosry.md) defined in the [ABAP Dictionary](abenabap_dictionary_glosry.md) in [DDIC DDL](abenddic_dcl_glosry.md).

- [ABAP tuning objects](abenabap_tuning_object_glosry.md) defined as [CDS objects](abencds_object_glosry.md) in [CDS DDL](abencds_ddl_glosry.md).
