# secondary table key

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Up to 15 secondary [table keys](abentable_key_glosry.md) can be created for each [internal table](abeninternal_table_glosry.md). Possible secondary table keys are [sorted keys](abensorted_key_glosry.md) and [hash keys](abenhash_key_glosry.md). A [secondary table index](abensecondary_table_index_glosry.md) is created internally for each sorted secondary key. When internal tables are accessed, the table key to be used must be specified.
