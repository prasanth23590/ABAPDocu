# UTF

[General](abenabap_glossary.md)

## Definition

Short for Universal Transformation Format. Different representations of the [Unicode](abenunicode_glosry.md) [character set](abencharacter_set_glosry.md). All UTF character representations objectively refer to the characters defined in Unicode and can be transformed into each other. The representations differ only in the type of addressing. See [UTF-8](abenutf8_glosry.md), [UTF-16](abenutf16_glosry.md), and [UTF-32](abenutf32_glosry.md) plus [UCS-2](abenucs2_glosry.md).
