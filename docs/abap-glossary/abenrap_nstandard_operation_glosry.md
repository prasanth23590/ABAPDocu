# RAP BO non-standard operation

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [RAP BO operation](abenrap_bo_operation_glosry.md) that does not provide canonical transactional behavior for a [RAP BO](abenrap_bo_glosry.md), for example [actions](abenrap_action_glosry.md) and [functions](abenrap_function_glosry.md). Most non-standard operations must be implemented in the [ABAP behavior pool](abenbehavior_pool_glosry.md).
