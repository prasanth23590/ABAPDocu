# Unicode

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Language-independent [character set](abencharacter_set_glosry.md) for international data processing ([www.unicode.org](http://www.unicode.org)). Subset of the [`UCS`](abenucs_glosry.md) character set according to ISO-10646. Unicode can represent 1114111 different characters numbered hexadecimally from `U+0000` to `U+10FFFF`. The Unicode character set is normally accessed using a [UTF](abenutf_glosry.md) or [`UCS`](abenucs2_glosry.md) [character representation](abenchar_representation_glosry.md).
