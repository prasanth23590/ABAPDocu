# hierarchy source

[ABAP SQL](../abap-programming-language/abap-database-access/abensql_glossary.md)

## Definition

A [SQL data source](abensql_data_source_glosry.md) that exposes a [hierarchy association](abenhierarchy_association_glosry.md) and can be used as a source of a [CDS hierarchy](abencds_hierarchy_glosry.md) or the [hierarchy generator](abenhierarchy_generator_glosry.md) of [ABAP SQL](abenabap_sql_glosry.md).
