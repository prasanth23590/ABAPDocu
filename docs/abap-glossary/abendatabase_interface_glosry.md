# database interface

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Interface](abenintf_gen_glosry.md) of an [AS ABAP](abenas_abap_glosry.md) to its [database](abendatabase_glosry.md) that is integrated into the [ABAP runtime framework](abenabap_runtime_frmwk_glosry.md). Statements in [ABAP SQL](abenabap_sql_glosry.md) access the database using the database interface. The database interface is responsible for data transport between the AS ABAP and the [database system](abendatabase_system_glosry.md), implicit [client handling](abenclient_handling_glosry.md), and [table buffering](abentable_buffering_glosry.md). The database interface can also be involved in maintaining [ABAP-managed database objects](abenabap_managed_db_object_glosry.md).
