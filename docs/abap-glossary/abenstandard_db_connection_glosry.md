# standard connection

[ABAP](../abap-programming-language/abap-overview/abentechno_glossary.md)

## Definition

[Database connection](abendatabase_connection_glosry.md) between an [AS ABAP](abenas_abap_glosry.md) and its [standard database](abenstandard_db_glosry.md). A standard connection is always opened for each [work process](abenwork_process_glosry.md) of an AS ABAP. The [ABAP database schema](abendatabase_user_glosry.md) is assigned to the [database user](abenabap_db_schema_glosry.md) of the standard connection.
