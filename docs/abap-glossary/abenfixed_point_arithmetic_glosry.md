# fixed point arithmetic

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Calculation with [packed numbers](abenpacked_number_glosry.md) ([data type](abendata_type_glosry.md) [`p`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_numeric.md)). Is calculated with an internal accuracy of 31 or (if not sufficient) 63 [places](abenplace_glosry.md). [Decimal places](abendecimal_place_glosry.md) are rounded arithmetically, if necessary. Places before the [decimal point](abendecimal_point_separat_glosry.md) are never lost if a calculation is completed successfully.
