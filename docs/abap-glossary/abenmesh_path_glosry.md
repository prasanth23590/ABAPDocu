# mesh path

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

Chaining of multiple [mesh nodes](abenmesh_node_glosry.md) using their [mesh associations](abenmesh_association_glosry.md). A mesh path describes a set of lines in its final path node. These lines are accessed when a mesh path is used.
