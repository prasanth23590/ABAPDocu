# character string expression

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

String expression for short. Formulation of an operation with character-like operands in a [calculation expression](abencalculation_expression_glosry.md), the result of which is a [character string](abencharacter_string_glosry.md).
