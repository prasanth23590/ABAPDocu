# value range

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Set of valid values for a [data object](abendata_object_glosry.md). The values that are valid for a data object are determined by its [data type](abendata_type_glosry.md). In [ABAP Dictionary](abenabap_dictionary_glosry.md), the term value range indicates a [semantic property](../abap-dictionary-ddic/ddic-data-types/abenddic_domains_sema.md) of a [DDIC domain](abendomain_glosry.md).
