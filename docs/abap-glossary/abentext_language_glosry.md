# text language

[DDIC](../abap-dictionary-ddic/abenddic_glossary.md)

## Definition

Semantic property of a [DDIC database table](abenddic_db_table_glosry.md) that affects data transport between non-Unicode and [Unicode systems](abenunicode_system_glosry.md).
