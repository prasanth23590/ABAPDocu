# base type

[ABAP Language](../abap-programming-language/abenabala_glossary.md) [CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

Technical storage type of [enumerated constants](abenenumerated_constant_glosry.md), [enumerated variables](abenenumerated_variable_glosry.md), and [CDS enumerated elements](abencds_enum_element_glosry.md). In ABAP CDS, the base type of an [enumerated type](abenenum_type_glosry.md) is also used for compatibility checks in cast expressions and in comparisons. In ABAP, the base type of an enumerated type can be used in special conversions using [`CONV`](../abap-programming-language/abap-processing-internal-data/abenconv_constructor_enum.md). A base type is [flat](abenflat_glosry.md), [elementary](abenelementary_data_type_glosry.md), and has a maximum length of 16 bytes.
