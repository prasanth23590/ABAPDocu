# date field

[General](abenabap_glossary.md)

## Definition

[Data object](abendata_object_glosry.md) of the [date type](abendate_type_glosry.md) [`d`](../abap-programming-language/abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_date_time.md) for storing a character-like [calendar date](abencalendar_date_glosry.md). Valid values have the format *yyyymmdd*. The internal representation takes place in the [character representation](abenchar_representation_glosry.md) of the current [code page](abencodepage_glosry.md). When assignments are made to data objects of [numeric data types](abennumeric_data_type_glosry.md) and in calculations, valid values are converted to the number of days since 01.01.0001.
