# test seam

[ABAP Language](../abap-programming-language/abenabala_glossary.md)

## Definition

[Seam](abenseam_glosry.md) enclosed by the statements [`TEST-SEAM`](../abap-programming-language/abap-program-maintenance/abaptest-seam.md) and [`END-TEST-SEAM`](../abap-programming-language/abap-program-maintenance/abapend-test-seam.md) in production code and replaced by an [injection](abeninjection_glosry.md) when [unit tests](abenunit_test_glosry.md) are executed.
