# CDS association path

[CDS](../abap-core-data-services-abap-cds/abencds_glossary.md)

## Definition

A sequence of [CDS associations](abencds_association_glosry.md). CDS association paths can be specified in the form of [SQL path expressions](abensql_path_expression_glosry.md) in [ABAP SQL](abenabap_sql_glosry.md) and in [ABAP CDS](abenabap_cds_glosry.md).
