# RAP change documents dependent entity

[RAP](../abap-rap-business-objects/abenrap_glossary.md)

## Definition

A [change documents-enabled RAP BO entity](abenrap_change_doc_enabled_glosry.md) that uses the [change document object](abenchange_document_obj_glosry.md) that is defined in its [change documents master entity](abenrap_change_doc_master_glosry.md) to log changes to persisted data.
