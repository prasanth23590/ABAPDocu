# News for ABAP Release 7.75

The kernel release for ABAP release 7.75 is 7.75.

## ABAP SQL

| Modification                                                   | Description                                                                                                                                                                                                                                                                             |
|----------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Window Expressions**                                         | Window expressions defined using [`OVER`](../../abap-programming-language/abap-database-access/abapselect_over.md) can now be used in the [`SELECT` list](../../abap-programming-language/abap-database-access/abapselect_list.md) of a query. Window expressions define windows as a subset of the result set and apply [window functions](../../abap-glossary/abenwindow_function_glosry.md) to them.         |
| **New Aggregate Function `STRING_AGG`**                        | The new aggregate function [`STRING_AGG`](../../abap-programming-language/abap-database-access/abapselect_aggregate.md) can be used to chain character-like results of the rows of the result set of a query or of the current group as a string.                                                                                          |
| **Addition `DISTINCT` Optional in Aggregate Function `COUNT`** | The aggregate function [`COUNT( sql_exp )`](../../abap-programming-language/abap-database-access/abapselect_aggregate.md) can now be used without the addition `DISTINCT`. In this case, it counts all rows in which the value of the argument is not the [null value](../../abap-glossary/abennull_value_glosry.md).                                        |
| **Hierarchy Navigators**                                       | The new [hierarchy navigator](../../abap-glossary/abenhierarchy_navigator_glosry.md) [`HIERARCHY_DESCENDANTS_AGGREGATE`](../../abap-programming-language/abap-database-access/abenselect_hierarchy_agg_navis.md) can be used to calculate [aggregate functions](../../abap-glossary/abenaggregate_function_glosry.md) for [descendant nodes](../../abap-glossary/abendescendant_node_glosry.md). |

## ABAP CDS

| Modification                    | Description                                                                                                                                                                                                                                                                                                                                                                                                                  |
|---------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Temporal Hierarchies**        | The new addition `PERIOD` of the statement [`DEFINE HIERARCHY`](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_f1_define_hierarchy.md) can now be used to create [temporal SQL hierarchies](../../abap-glossary/abentemporal_hierarchy_glosry.md) in which the hierarchy nodes are limited by time intervals.                                                                                                                                                                       |
| **CDS Custom Entities**         | A new type of [CDS entity](../../abap-glossary/abencds_entity_glosry.md) is available: the [CDS custom entity](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_custom_entities.md). CDS custom entities are used in the [RAP framework](../../abap-glossary/abenrap_framework_glosry.md) to implement ABAP queries in CDS.                                                                                                                                                                             |
| **Root Nodes and Compositions** | The new addition `ROOT` is available for CDS entities to mark an entity as a [CDS root entity](../../abap-glossary/abenroot_entity_glosry.md). In addition, [CDS associations](../../abap-glossary/abencds_association_glosry.md) can be declared as `COMPOSITION` or `TO PARENT`. In this way, a [CDS composition tree](../../abap-glossary/abencds_composition_tree_glosry.md) can be modeled for use in the [ABAP RESTful Application Programming Model](../../abap-glossary/abenarap_glosry.md). |

## AMDP

| Modification                              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|-------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Specifying CDS Entities After `USING`** | In the implementation of the AMDP method, the name of the [CDS entity](../../abap-glossary/abencds_entity_glosry.md) can now be specified after the [`USING`](../../abap-programming-language/abap-database-access/abapmethod_by_db_proc.md) addition for [CDS views](../../abap-glossary/abencds_view_glosry.md), [CDS table functions](../../abap-glossary/abencds_table_function_glosry.md), and [CDS hierarchies](../../abap-glossary/abencds_hierarchy_glosry.md). The name of the [CDS-managed DDIC view (obsolete)](../../abap-glossary/abencds_mngdddic_view_glosry.md) of a CDS view or of the [AMDP function](../../abap-glossary/abenamdp_function_glosry.md) of a CDS table function can still be specified, but is best replaced by specifying CDS entities. If a CDS entity is specified, all other database objects of CDS entities must be also be specified using this entity. |
