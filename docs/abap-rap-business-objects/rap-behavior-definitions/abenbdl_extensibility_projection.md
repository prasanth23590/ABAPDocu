# RAP - BDEF Projection Extension

A [BDEF projection extension](../../abap-glossary/abenrap_projec_bdef_ext_glosry.md) is a repository object that extends a [RAP projection behavior definition](../../abap-glossary/abencds_proj_bdef_glosry.md) using the statement [`extension for projection`](abenbdl_extension_for_projection.md).

As a prerequisite, the respective projection BDEF must explicitly allow extensions as described in topic [RAP - Extensibility Enabling for Projection BDEFs](abenbdl_ext_enabling_projection.md).
