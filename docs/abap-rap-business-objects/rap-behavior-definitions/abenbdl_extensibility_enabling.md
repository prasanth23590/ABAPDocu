# RAP - BDEF Extension, Extensibility Enabling

RAP behavior definitions must be explicitly enabled to allow for behavior extensibility. They must fulfill technical requirements and define extension points. Otherwise, no BDEF extensions are possible. The following sections describe how to enable RAP behavior definitions of type [managed](../../abap-glossary/abenmanaged_rap_bo_glosry.md), [unmanaged](../../abap-glossary/abenunmanaged_rap_bo_glosry.md), [interface](../../abap-glossary/abenrap_bo_interface_glosry.md), [projection](../../abap-glossary/abencds_proj_bdef_glosry.md), and [abstract](../../abap-glossary/abencds_abstract_bdef_glosry.md) for behavior extensibility. It also describes how to enable a BDEF extension for extensibility to allow for [extension layering](../../abap-glossary/abenrap_ext_layering_glosry.md).

- [RAP - Extensibility Enabling for Base BOs](abenbdl_extensibility_enabling_m_u.md)

- [RAP - Extensibility Enabling for RAP BO Interfaces](abenbdl_extensibility_enablng_intf.md)

- [RAP - Extensibility Enabling for Projection BDEFs](abenbdl_ext_enabling_projection.md)

- [RAP - Extensibility Enabling for Abstract BDEFs](abenbdl_ext_enabling_abstract.md)
