# RAP - Extensibility Enabling for BDEF Extensions

It is possible to extend a [BDEF extension](../../abap-glossary/abenrap_extension_glosry.md) with further BDEF extensions. This is referred to as [extension layering](../../abap-glossary/abenrap_ext_layering_glosry.md). As a prerequisite, a BDEF extension must be explicitly enabled for extensibility. It must fulfill technical requirements and define extension points.

The following topics describe how to enable [base BDEF extensions](../../abap-glossary/abenrap_base_bdef_ext_glosry.md), [BDEF projection extensions](../../abap-glossary/abenrap_projec_bdef_ext_glosry.md), and [abstract BDEF extensions](../../abap-glossary/abenrap_abs_bdef_ext_glosry.md) for extensibility.

- [RAP - Extensibility Enabling for Base BDEF Extensions](abenbdl_ext_enabl_ext_base.md)

- [RAP - Extensibility Enabling for Projection BDEF Extensions](abenbdl_ext_enabl_ext_proj.md)

- [RAP - Extensibility Enabling for Abstract BDEF Extensions](abenbdl_ext_enabl_ext_abs.md)

The general rules for extension layering are described in the topic [RAP - Extension Layering](abenbdl_extension_layering.md).
