# RAP - Non-Standard Operations

[Non-standard operations](../../abap-glossary/abenrap_nstandard_operation_glosry.md) are [RAP BO operations](../../abap-glossary/abenrap_bo_operation_glosry.md) that provide transactional behavior and that are user-implemented. There are two kinds of non-standard operations available:

- [Actions](abenbdl_action.md): User-implemented operations that change the data of a BO instance.

- [Functions](abenbdl_function.md): User-implemented operations that return information without any side effects.
