# RAP - ExtensionBody

## Syntax

``` abap
... 
  [Adding Elements] 
  [Extending Elements] 
  ...  
```

[`Adding Elements`](abenbdl_new_elem_ext.md) · [`Extending Elements`](abenbdl_ext_elem_ext.md)

## Description

Defines the [behavior extension body](../../abap-glossary/abenrap_behavior_ext_body_glosry.md) to extend an existing [RAP BO entity](../../abap-glossary/abenrap_bo_entity_glosry.md) in the [RAP BDL](../../abap-glossary/abencds_bdl_glosry.md).

- [`Adding Elements`](abenbdl_new_elem_ext.md): Elements can be added to an existing [entity behavior definition](../../abap-glossary/abencds_entity_bdef_glosry.md).

- [`Extending Elements`](abenbdl_ext_elem_ext.md): Existing elements of existing entity behavior definitions can be extended.
