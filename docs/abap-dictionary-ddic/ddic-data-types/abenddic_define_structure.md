# DDIC - Dictionary DDL for Structure Definitions

A structure can be displayed and modified using [dictionary DDL](../../abap-glossary/abendictionary_ddl_glosry.md) in the [ABAP development tools for Eclipse (ADT)](../../abap-glossary/abenadt_glosry.md). The source code of a structure is not stored and transported. Instead, the source code of an existing structure is generated from the metadata of the associated system tables. When saved, the metadata is derived directly from the source code and stored in the system tables.
