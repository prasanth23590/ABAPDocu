# DDIC - Naming Rules for Structures

Besides the general naming rules for [DDIC data types](abenddic_data_types.md), [DDIC structures](../../abap-glossary/abenddic_structure_glosry.md) and also [DDIC database tables](../../abap-glossary/abenddic_db_table_glosry.md) must comply with the following additional naming rules:

- A name must not end with an underscore (`_`).

- A name must not start with `QCM`.

- A name must not contain an underscore (`_`) at the second or third position if it does not start with `J`.

- A name must not be a reserved name from the DDIC database table `TRESE`.
