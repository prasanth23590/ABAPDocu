# DDIC - Tuning Objects

A [tuning object](../../abap-glossary/abentuning_object_glosry.md) is a [repository object](../../abap-glossary/abenrepository_object_glosry.md) that defines technical settings or tunings for another repository object. A tuning object can be defined and transported separately from the repository object for which it is defined. ABAP Dictionary provides the following [HANA tuning objects](../../abap-glossary/abenhana_tuning_object_glosry.md) to define tunings for dictionary objects:

- [DDIC - Dynamic Caches](abenddic_dynamic_caches.md)
