# DDIC - Conversion Functions

The following table shows the conversion functions that can be used by [ABAP CDS](../../abap-glossary/abenabap_cds_glosry.md) and [ABAP SQL](../../abap-glossary/abenabap_sql_glosry.md). The last three columns indicate where a function can be used.

| **SQL Function**          | **Result**                                                                                                                                                                                                                  | **ABAP CDS, DDIC-Based Views**           | **ABAP CDS, View Entities**              | **ABAP SQL**                          |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------|------------------------------------------|---------------------------------------|
| `AS_GEO_JSON`             | Converts an argument of type ` GEOM_EWKB` to JSON format.                                                                                                                                                                   | \-                                       | \-                                       | [x](../../abap-programming-language/abap-database-access/abensql_geo_conv_func.md)       |
| `BINTOHEX`                | Converts an argument of the type `RAW` to a string of the type `CHAR`.                                                                                                                                                      | [x](../../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_conv_func_types_v1.md)     | [x](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_conv_func_types_v2.md)     | [x](../../abap-programming-language/abap-database-access/abensql_type_conv_func.md)      |
| `CURRENCY_CONVERSION`     | Conversion of currencies.                                                                                                                                                                                                   | [x](../../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_conv_func_unit_curr_v1.md) | [x](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_conv_func_unit_curr_v2.md) | [x](../../abap-programming-language/abap-database-access/abensql_curr_unit_conv_func.md) |
| `CURR_TO_DECFLOAT_AMOUNT` | Converts a currency field of data type `CURR` into a currency field of data type `DECFLOAT34`.                                                                                                                              | \-                                       | [x](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_conv_func_unit_curr_v2.md) | \-                                    |
| `DECIMAL_SHIFT`           | Sets the decimal separator of an argument in accordance with a currency.                                                                                                                                                    | [x](../../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_conv_func_unit_curr_v1.md) | \-                                       | \-                                    |
| `FLTP_TO_DEC`             | Converts an argument of type `FLTP` to a packed number.                                                                                                                                                                     | [x](../../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_conv_func_types_v1.md)     | [x](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_conv_func_types_v2.md)     | \-                                    |
| `GET_NUMERIC_VALUE`       | Converts a [CDS amount field](../../abap-glossary/abencds_amount_field_glosry.md) or a [CDS quantity field](../../abap-glossary/abencds_quantity_glosry.md) into a regular field of data type `DECFLOAT34`. The reference to a unit or currency key is removed. | \-                                       | [x](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_conv_func_unit_curr_v2.md) | \-                                    |
| `HEXTOBIN`                | Converts an argument of the type `CHAR` or `NUMC` to a byte string of the type `RAW`.                                                                                                                                       | [x](../../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_conv_func_types_v1.md)     | [x](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_conv_func_types_v2.md)     | [x](../../abap-programming-language/abap-database-access/abensql_type_conv_func.md)      |
| `TO_BLOB`                 | Converts an argument of the type `RAW` to a byte string (BLOB) of the type `RAWSTRING`.                                                                                                                                     | \-                                       | \-                                       | [x](../../abap-programming-language/abap-database-access/abensql_type_conv_func.md)      |
| `TO_CLOB`                 | Converts an argument of the type `SSTRING` to a CLOB of the type `STRING`.                                                                                                                                                  | \-                                       | \-                                       | [x](../../abap-programming-language/abap-database-access/abensql_type_conv_func.md)      |
| `UNIT_CONVERSION`         | Conversion of units.                                                                                                                                                                                                        | [x](../../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_conv_func_unit_curr_v1.md) | [x](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_conv_func_unit_curr_v2.md) | [x](../../abap-programming-language/abap-database-access/abensql_curr_unit_conv_func.md) |

The possible operands and data types as well as the exact functionality is described in the corresponding documentation for [ABAP CDS, DDIC-Based Views](../../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_conversion_functions_v1.md), [ABAP CDS, View Entities](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_conversion_functions_v2.md), and [ABAP SQL](../../abap-programming-language/abap-database-access/abenabap_sql_conversion_functions.md).
