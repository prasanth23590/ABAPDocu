# DDIC - SQL Functions for Strings

The following table shows the SQL functions for strings that can be used by [ABAP CDS](../../abap-glossary/abenabap_cds_glosry.md) and [ABAP SQL](../../abap-glossary/abenabap_sql_glosry.md). The columns **CDS DDIC-Based Views**, **CDS View Entities** and **ABAP SQL** indicate where a function can be used. The **ABAP SQL In-Memory Engine** column indicates whether the function can be executed in the [ABAP SQL in-memory engine](../../abap-glossary/abenabap_sql_inmemeng_glosry.md).

| `CONCAT_WITH_SPACE`    | Concatenates strings with a specified number of blanks in between.                                                                                                                          | [x](../../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_sql_functions_character_v1.md) | [x](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_sql_functions_character_v2.md) | [x](../../abap-programming-language/abap-database-access/abensql_string_func.md) | [x](../../abap-programming-language/abap-database-access/abensql_engine_expr.md) |
