# DDIC - Built-In Functions

The following sections summarize the built-in database functions managed by ABAP Dictionary. They can be used by [ABAP CDS](../../abap-glossary/abenabap_cds_glosry.md) and [ABAP SQL](../../abap-glossary/abenabap_sql_glosry.md). They are divided in two categories:

- [SQL functions](abensql_functions.md). These functions are generally available in SQL.

- [Special functions](abenddic_special_functions.md). These functions are SAP-specific functions.

The possible operands and data types are described in the corresponding documentation for [ABAP CDS, DDIC-Based Views](../../abap-core-data-services-abap-cds/abap-cds-obsolete-language-elements/abencds_builtin_functions_v1.md), [ABAP CDS, View Entities](../../abap-core-data-services-abap-cds/abap-cds-data-definitions/abencds_builtin_functions_v2.md) and [ABAP SQL](../../abap-programming-language/abap-database-access/abenabap_sql_builtin_functions.md).
