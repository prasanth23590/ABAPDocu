# DDIC - Dictionary Objects for Cloud Development

In [SAP BTP ABAP environment](../abap-glossary/abensap_btp_abap_env_glosry.md) and [SAP S/4HANA Cloud ABAP environment](../abap-glossary/abens4_hana_cloud_abap_env_glosry.md), customers and partners can define DDIC data elements, DDIC structures, and DDIC database tables in ADT. The restriction applies to these dictionary objects that only repository objects [released as API](../abap-glossary/abenreleased_api_glosry.md) for [ABAP language version](../abap-glossary/abenabap_version_glosry.md) [ABAP for Cloud Development](../abap-glossary/abenabap_for_cloud_dev_glosry.md) or objects in the same software component can be used.

## Hint

See [Released APIs](../abap-apis/released-apis/abenreleased_apis.md) for a list of repository objects that are released as APIs in the current system.
