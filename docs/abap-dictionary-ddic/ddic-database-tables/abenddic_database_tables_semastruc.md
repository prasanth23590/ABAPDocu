# DDIC - Structure-Specific Semantic Properties of Database Tables

The following semantic properties are the same as those of a [DDIC structure](../ddic-data-types/abenddic_structures_sema.md):

- Short text

- Documentation

- Short text of table fields

- Output style of table fields

- Reference field for components of the [built-in data types](../ddic-built-in-data-types/abenddic_builtin_types.md) `CURR` and `QUAN`. If a field in a DDIC database table is used as a reference field in a different table, the field cannot be deleted.

- Search help
