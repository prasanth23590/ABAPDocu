# DDIC - Foreign Key Dependencies

A foreign key dependency is a semantic dependency between two DDIC database tables, namely a [foreign key table](../../abap-glossary/abenforeign_key_table_glosry.md) and a [check table](../../abap-glossary/abencheck_table_glosry.md).

The definition of a foreign key dependency is done in the foreign key table. By assigning check tables to table fields, the table fields become [foreign keys](../../abap-glossary/abenforeign_key_glosry.md).
