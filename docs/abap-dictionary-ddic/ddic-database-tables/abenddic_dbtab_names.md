# DDIC - Naming Rules for Database Tables

The name of a database table defined in the ABAP Dictionary must adhere to the following rules:

- It can have a maximum of 16 characters.

- It must follow the [naming rules for DDIC types](../ddic-data-types/abenddic_types_names.md).

- It must follow the special [naming rules for DDIC structures](../ddic-data-types/abenddic_structures_names.md).

- It is in the namespace of [DDIC data types](../ddic-data-types/abenddic_data_types.md) and hence in the namespace of all [global types](../../abap-glossary/abenglobal_type_glosry.md) of an AS ABAP.
