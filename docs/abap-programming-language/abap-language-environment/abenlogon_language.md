# Logon Language

The [logon language](../../abap-glossary/abenlogon_language_glosry.md) is defined when an [ABAP user](../../abap-glossary/abenabap_user_glosry.md) [logs on](../../abap-glossary/abenlogon_glosry.md) to an AS ABAP for the entire [user session](../../abap-glossary/abenuser_session_glosry.md) and can no longer be changed.

The logon language affects the selection of the following texts:

- Texts of [messages](../../abap-glossary/abenmessage_glosry.md)

- Texts from [text pools](../../abap-glossary/abentext_pool_glosry.md)
