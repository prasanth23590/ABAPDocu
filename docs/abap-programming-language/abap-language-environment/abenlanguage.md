# ABAP - Language Environment

The language environment of an ABAP program is part of the ABAP runtime framework and includes the following:

- [Language settings](abenlanguage_settings.md)

  The language settings defined by the [logon language](../../abap-glossary/abenlogon_language_glosry.md) and a [text environment language](../../abap-glossary/abentext_env_langu_glosry.md) control all language-dependent behavior of an ABAP program.

- [Format settings](abencountry.md)

  Country-specific formatting settings determine, for example, the format of numbers, dates, times, and time stamps.
