# Inline Declarations

An inline declaration is performed using a [declaration operator](../../abap-glossary/abendeclaration_operator_glosry.md) in a [declaration expression](../../abap-glossary/abendeclaration_expression_glosry.md) in a [declaration position](../../abap-glossary/abendeclaration_position_glosry.md). The result of the declaration is used in the current operand position, is visible statically as of the current position and is valid in the current context.

- [`DATA`, Inline Declaration for Variables](abendata_inline.md)

- [`FINAL`, Inline Declaration for Immutable Variables](abenfinal_inline.md)

- [`FIELD-SYMBOL`, Inline Declaration for Field Symbols](abenfield-symbol_inline.md)
