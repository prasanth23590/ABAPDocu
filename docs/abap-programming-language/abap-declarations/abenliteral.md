# Literals

In addition to the [named data objects](../../abap-glossary/abennamed_data_object_glosry.md) that can be addressed by their names in ABAP programs (this includes the text symbols) and the [anonymous data objects](../../abap-glossary/abenanonymous_data_object_glosry.md) that are created by the statement [`CREATE DATA`](../abap-creating-objects-and-values/abapcreate_data.md), there are also [literals](../../abap-glossary/abenabap_literal_glosry.md) that are defined in the source code of a program by specifying a string that represents a value. Possible literals are:

- [Numeric literals](abenuntyped_number_literals.md)

- [Character literals](abenuntyped_character_literals.md)

The [literal operator](abenliteral_operator.md) `&` can be used to link multiple literals of the same type to a literal.

## Hint

In general ABAP, only [untyped literals](../../abap-glossary/abenuntyped_literal_glosry.md) are available. In [ABAP SQL](../../abap-glossary/abenabap_sql_glosry.md) [typed literals](../../abap-glossary/abentyped_literal_glosry.md) can and should be used as well.
