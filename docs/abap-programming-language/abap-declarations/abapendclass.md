# ENDCLASS

## Syntax

``` abap
ENDCLASS.  
```

## Description

``` abap
The statement `ENDCLASS` closes a class declaration introduced using: 
 
  `CLASS class DEFINITION` 
 
or a class implementation introduced using: 
 
  `CLASS class IMPLEMENTATION` 
 
 
```
