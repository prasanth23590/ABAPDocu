# Built-In Functions

ABAP provides a set of built-in functions. A built-in function returns a return value for one or more [arguments](../../abap-glossary/abenargument_glosry.md) passed to the function. There are functions with exactly one unnamed [formal parameter](../../abap-glossary/abenformal_parameter_glosry.md) and functions with one or more named formal parameters.

Built-in functions can be called functionally in [certain operand positions](../abap-operands/abenoperands_expressions.md). When a built-in function is called in an [operand position](../abap-syntax-elements-of-an-abap-program/abenexpression_positions.md), the function is executed before the operand is used and the return value of the built-in function is used as the operand, in accordance with its data type.
