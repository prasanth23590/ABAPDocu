# Built-In Data Types

The following [built-in data types](../../abap-glossary/abenbuiltin_data_type_glosry.md) are used in ABAP programs:

- [Built-In ABAP Types](abenbuilt_in_types_complete.md)

- [Generic ABAP Types](abenbuilt_in_types_generic.md)

[ABAP Dictionary](../../abap-glossary/abenabap_dictionary_glosry.md) has its own set of [built-in types](../../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md), which are used to define global data types but which cannot be addressed directly in ABAP programs.
