# ABAP - Text Repositories

The following persistent texts can be accessed in ABAP programs:

- [Text pools](abentext_pool.md)

- [Messages](abenabap_messages.md)

These texts can be translated into different languages. By default, a program accesses the texts in the [logon language](../../abap-glossary/abenlogon_language_glosry.md).

## Hint

Another central repository for texts is Online Text Repository (OTR), which can be accessed using the transaction `SOTR_EDIT`. In ABAP, OTR is important for [exception texts](../abap-program-flow-logic/abenexception_texts.md) and is also used by other frameworks.
