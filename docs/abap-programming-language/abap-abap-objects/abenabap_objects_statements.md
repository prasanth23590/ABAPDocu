# ABAP Objects - Statements in ABAP Objects

The statements in ABAP Objects can be differentiated as follows:

- [Statements for defining classes and interfaces](abendefining_classes_interfaces.md)

  These statements define classes and interfaces and their components. They can be used for local and global classes or interfaces.

- [Statements for implementing methods](abendefining_methods.md)

  These statements implement the functions of classes in methods.

- [Statements in class pools and interface pools](abenclass_interace_pools.md)

  In addition to the statements for defining the global class, statements for local declarations and implementations can also be used in [class pools](../../abap-glossary/abenclass_pool_glosry.md). In [interface pools](../../abap-glossary/abeninterface_pool_glosry.md), only the global interface can be declared.
