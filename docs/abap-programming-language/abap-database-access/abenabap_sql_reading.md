# ABAP SQL - Read Access with DQL

The following ABAP SQL statements implement the [DQL](../../abap-glossary/abendql_glosry.md) part of [SQL](../../abap-glossary/abensql_glosry.md) in the ABAP language for performing reads on the database:

- [`SELECT`](abapselect.md)

- [`WITH`](abapwith.md)

  - `FETCH NEXT CURSOR`

  - `CLOSE CURSOR`

- [`UNION`](abapunion.md), [`INTERSECT`](abapunion.md), [`EXCEPT`](abapunion.md)
