# Database Access Using Database Connections

The following additions can be used to use a database connection other than the [standard connection](../../abap-glossary/abenstandard_db_connection_glosry.md) in ABAP SQL:

- The addition [`CONNECTION`](abapselect_connection.md) for DQL statements

- The identical addition [`CONNECTION`](abapiumd_conn.md) for DML statements

Here, a service connection can be specified by using an [ABAP SQL connection object](../../abap-glossary/abenabap_sql_conn_obj_glosry.md).
