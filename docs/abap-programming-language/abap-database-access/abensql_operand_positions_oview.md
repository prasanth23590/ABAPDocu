# ABAP SQL - SQL Operand Positions

The following table provides a general overview of important operand positions in ABAP SQL and which operands can be used.

| **Operand Position**                                                                                                                                              | **Operands**                                                                                                                                           | **Arguments of SQL Expressions**                                                                                                              |
|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| Column specification [`col_spec`](abapselect_clause_col_spec.md) in a [`SELECT` list](abapselect_list.md)                                                     | [SQL expressions](abapsql_expr.md)                                                                                                                   | [SQL expressions](abapsql_expr.md)                                                                                                          |
| Left side of a relational expression [`rel_exp`](abenabap_sql_stmt_logexp.md) in [`WHERE` clauses](abapwhere.md) and [`ON` conditions](abapselect_join.md)  | [SQL expressions](abapsql_expr.md) except [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md)          | [SQL expressions](abapsql_expr.md) except [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md) |
| Right side of a relational expression [`rel_exp`](abenabap_sql_stmt_logexp.md) in [`WHERE` clauses](abapwhere.md) and [`ON` conditions](abapselect_join.md) | Elementary [SQL operands](abensql_operands.md), no [SQL expressions](abapsql_expr.md)                                                              | \-                                                                                                                                            |
| Left side of a relational expression [`rel_exp`](abenabap_sql_stmt_logexp.md) in [`HAVING` clauses](abaphaving_clause.md)                                     | [SQL expressions](abapsql_expr.md) except [window expressions](abapselect_over.md)                                                                 | [SQL expressions](abapsql_expr.md) except [window expressions](abapselect_over.md)                                                        |
| Right side of a relational expression [`rel_exp`](abenabap_sql_stmt_logexp.md) in [`HAVING` clauses](abaphaving_clause.md)                                    | Elementary [SQL operands](abensql_operands.md) and [aggregate expressions](abapselect_aggregate.md), no other [SQL expressions](abapsql_expr.md) | \-                                                                                                                                            |
| Left side of a relational expression [`rel_exp`](abenabap_sql_expr_logexp.md) for expressions                                                                   | [SQL expressions](abapsql_expr.md) except [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md)          | [SQL expressions](abapsql_expr.md) except [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md) |
| Right side of a relational expression [`rel_exp`](abenabap_sql_expr_logexp.md) for expressions                                                                  | [SQL expressions](abapsql_expr.md) except [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md)          | [SQL expressions](abapsql_expr.md) except [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md) |
| Grouping criterion after [`GROUP BY`](abapgroupby_clause.md)                                                                                                    | [SQL expressions](abapsql_expr.md) except [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md)          | [SQL expressions](abapsql_expr.md) except [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md) |
| Window criterion after [`PARTITION BY`](abapselect_over.md)                                                                                                     | [SQL expressions](abapsql_expr.md) except [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md)          | [SQL expressions](abapsql_expr.md) except [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md) |
| Sort criterion after [`ORDER BY`](abaporderby_clause.md)                                                                                                        | [Columns](abenabap_sql_columns.md) and alias names for [SQL expressions](abapsql_expr.md) defined using [`AS`](abapselect_list.md)               | \-                                                                                                                                            |

- The arguments of [aggregate expressions](abapselect_aggregate.md) can be [SQL expressions](abapsql_expr.md) with the exception of [aggregate expressions](abapselect_aggregate.md) and [window expressions](abapselect_over.md).

- The arguments of [window expressions](abapselect_over.md) can be [SQL expressions](abapsql_expr.md) with the exception of [window expressions](abapselect_over.md).

Certain operand positions are subject to further restrictions and these are documented where appropriate.
