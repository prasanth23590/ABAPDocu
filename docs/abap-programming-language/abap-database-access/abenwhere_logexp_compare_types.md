# sql_cond - Comparable Types

The following table shows which [built-in data types](../../abap-dictionary-ddic/ddic-built-in-data-types/abenddic_builtin_types.md) in the ABAP Dictionary can be compared with each other. The table applies to the following:

- [Comparisons](abenwhere_logexp_compare.md) of a [`WHERE`](abapwhere.md) condition or [`HAVING`](abaphaving_clause.md) condition in which SQL expressions are specified on the left side (`lhs`) and columns are specified on the right side (`rhs`).

- Comparisons of an [`ON`](abapselect_join.md) condition.

- Comparisons in [expressions](abenabap_sql_expr_logexp.md).

Invalid comparisons produce a syntax error.

- There are no restrictions for combinations using *x*.

- Combinations with *y* cannot be used in [conditions in an expression](abenabap_sql_expr_logexp.md).

- In combinations with *z*, the lengths and decimal places must match in the compared columns or expressions in [conditions in an expression](abenabap_sql_expr_logexp.md).

- Combinations with *e* can only be used in [conditions in an expression](abenabap_sql_expr_logexp.md) and cannot be used in [conditions for a statement](abenabap_sql_stmt_logexp.md).

- In combinations with *l*, the lengths of the compared columns or expressions must match.

- In [conditions in an expression](abenabap_sql_expr_logexp.md), combinations with *=* can only be compared for equality.

The comparability of dictionary types is significant for comparisons with [columns](abenabap_sql_columns.md) or [SQL expressions](abapsql_expr.md) on the right side or for [comparisons in SQL expressions](abenabap_sql_expr_logexp.md). This applies in particular to [literals](abenabap_sql_literals.md), [host variables](abenabap_sql_host_variables.md), and [host expressions](abenabap_sql_host_expressions.md) when handled as [elementary SQL expressions](abensql_elem.md). These elements are mapped to a dictionary type and comparability is identified for the dictionary type in question.

## Hints

- Any [literals](abenabap_sql_literals.md), [host variables](abenabap_sql_host_variables.md), and [host expressions](abenabap_sql_host_expressions.md) that are not handled as [elementary SQL expressions](abensql_elem.md) are usually converted to the matching dictionary type instead of being mapped to a dictionary type. For example, it may be possible to compare a host variable as the right side of a [relational expression](abenabap_sql_stmt_logexp.md) for statements with more dictionary types than in a [relational expression for SQL expressions](abenabap_sql_expr_logexp.md).

  - SQL expressions of the types `DF16_DEC` or `DF34_DEC` are compared with other numeric types other than themselves.

  - SQL expressions of the type `SSTRING` are compared with types other than themselves in a [`CASE` expression](abensql_case.md).
