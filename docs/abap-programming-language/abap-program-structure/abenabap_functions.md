# Function Modules

Function modules are reusable cross-program [procedures](../../abap-glossary/abenprocedure_glosry.md) that are organized into [function pools](../../abap-glossary/abenfunction_pool_glosry.md) and whose functionality is implemented between the following statements:

``` abap
`FUNCTION` 
  ... 
`ENDFUNCTION`
```

Function modules and their [interfaces](abenfunction.md) are created in the [ABAP development tools for Eclipse (ADT)](../../abap-glossary/abenadt_glosry.md).

## Hint

Function modules in function pools are the predecessor technology of public [methods](../../abap-glossary/abenmethod_glosry.md) in global classes.
