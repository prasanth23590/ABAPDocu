# Modularization Statements

Each ABAP program is modularized by [processing blocks](../../abap-glossary/abenprocessing_block_glosry.md). Each accessible statement of an ABAP program that does not belong to the global declaration part of the program belongs to a [processing block](../../abap-glossary/abenprocessing_block_glosry.md).

The possible processing blocks are:

- [Procedures](abenabap_language_procedures.md)

  ABAP statements are used to process procedures. Possible [procedures](../../abap-glossary/abenprocedure_glosry.md) are: [Methods](../../abap-glossary/abenmethod_glosry.md)
