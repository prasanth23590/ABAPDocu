# Methods

Methods are the [procedures](../../abap-glossary/abenprocedure_glosry.md) of a class whose functionality is implemented between the following statements:

``` abap
`METHOD` 
`  ...` 
`ENDMETHOD`
```

The statement `METHOD` does not usually have any additions. Exceptions to this rule are:

- Methods used to implement [ABAP Managed Database Procedures](../abap-database-access/abenamdp.md) (AMDP)
