# ABAP Language Versions

Each ABAP program has the [program property](../../abap-glossary/abenprogram_property_glosry.md) [ABAP language version](../../abap-glossary/abenabap_version_glosry.md), which is defined internally by a version ID. The version of a program determines which language elements and which [repository objects](../../abap-glossary/abenrepository_object_glosry.md) can be used in the program and which syntax rules apply. The following versions are currently available:

| **Language Version**                                             | **Meaning**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | **Version ID** |
|------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------|
| [Standard ABAP](../../abap-glossary/abenstandard_abap_glosry.md)                   | This version of ABAP is an [unrestricted ABAP language version](../../abap-glossary/abenunrestricted_version_glosry.md) for [classic ABAP](../../abap-glossary/abenclassic_abap_glosry.md). It covers the entire language scope of ABAP that can be used in [Unicode systems](../../abap-glossary/abenunicode_system_glosry.md) and apart from the static [package concept](../../abap-glossary/abenpackage_concept_glosry.md), access to all other repository objects is allowed. The [syntax check](../../abap-glossary/abensyntax_check_glosry.md) for Standard ABAP is performed as [Unicode check](../../abap-glossary/abenunicode_check_glosry.md), which is the minimum requirement for a [Unicode system](../../abap-glossary/abenunicode_system_glosry.md). The documentation of this version describes all ABAP language elements.                                                                                                                                                                                                                                                                                                                                                 | ` X`           |
| [ABAP for Cloud Development](../../abap-glossary/abenabap_for_cloud_dev_glosry.md) | This version of ABAP is a [restricted ABAP language version](../../abap-glossary/abenrestricted_version_glosry.md) for [ABAP Cloud](../../abap-glossary/abenabap_cloud_glosry.md). The general rules for [Standard ABAP](../../abap-glossary/abenstandard_abap_glosry.md) apply but only a very restricted set of language elements is supported and access to [repository objects](../../abap-glossary/abenrepository_object_glosry.md) is restricted as [described here](../../abap-apis/abenabap_versions_and_apis.md). Furthermore, most developments can be implemented in methods only, where the stricter syntax rules of classes automatically apply. Almost no [obsolete language elements](../abap-obsolete-language-elements/abenabap_obsolete.md) are allowed. For [ABAP SQL](../../abap-glossary/abenabap_sql_glosry.md), the most strict syntax check mode currently available is applied. [Client isolation](../../abap-glossary/abenclient_isolation_glosry.md) is enforced. The documentation for ABAP for Cloud Development is a restricted version of the full documentation.                                                                                                                          | ` 5`           |
| [ABAP for Key Users](../../abap-glossary/abenabap_for_key_users_glosry.md)         | This version of ABAP is intended for the secure implementation of enhancements by key users within the scope of enhancement options provided by SAP. ABAP for Key Users is a [restricted ABAP language version](../../abap-glossary/abenrestricted_version_glosry.md) where the general rules for [Standard ABAP](../../abap-glossary/abenstandard_abap_glosry.md) apply but only a very restricted set of language elements is supported and access to [repository objects](../../abap-glossary/abenrepository_object_glosry.md) is restricted as [described here](../../abap-apis/abenabap_versions_and_apis.md). Furthermore, enhancements can be implemented in methods only, where the stricter syntax rules for classes automatically apply and no [obsolete language elements](../abap-obsolete-language-elements/abenabap_obsolete.md) are allowed. ABAP for Key Users is not supported by the ABAP keyword documentation. Only ABAP syntax diagrams with a short explanation are shown. For more information, see [Key User Extensibility](https://help.sap.com/docs/ABAP_PLATFORM_NEW/0f69f8fb28ac4bf48d2b57b9637e81fa/3ccb50e724b045508fea8b2cf1774b2b). | ` 2`           |

## Hints

- If a program has a version ID that is not listed in the table above, it is handled in the same way as a version that does not support any language elements.

- The topic [Released APIs](../../abap-apis/released-apis/abenreleased_apis.md) provides an overview of APIs that are released for the [restricted ABAP language versions](../../abap-glossary/abenrestricted_version_glosry.md) in the current system.

- Besides ABAP programs, other repository objects can also have a property named ABAP language version.

- For an overview, see also [ABAP APIs](../../abap-apis/abenabap_versions_and_apis.md).
