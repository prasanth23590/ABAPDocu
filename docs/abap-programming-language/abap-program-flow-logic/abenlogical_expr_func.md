# Expressions and Functions for Conditions

The flow control of a program is performed using [control structures](../../abap-glossary/abencontrol_structure_glosry.md) that are generally controlled by logical expressions. The following options exist for the formulation and evaluation of conditions:

- [Logical expressions](abenlogexp.md)

- [Logical functions](abenlogic_functions.md)

In addition to control structures, logical expressions and functions can also be listed in other statements.
