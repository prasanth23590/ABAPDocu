# Conditional Expressions

A conditional expression is a [constructor expression](../abap-built-in-types-data-objects-functions-and-constructors/abenconstructor_expressions.md) that creates a value or raises a class-based exception depending on a logical expression or a case distinction. Conditional expressions are constructed using the following conditional operators:

- [`COND`](abenconditional_expression_cond.md)

- [`SWITCH`](abenconditional_expression_switch.md)
