# ENDCASE

## Syntax

``` abap
ENDCASE.  
```

## Description

The statement `ENDCASE` closes a [case distinction](../../abap-glossary/abencase_distinction_glosry.md) introduced using [`CASE`](abapcase.md) or [`CASE TYPE OF`](abapcase_type.md).
