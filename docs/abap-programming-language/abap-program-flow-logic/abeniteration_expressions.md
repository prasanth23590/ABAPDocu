# Iteration Expressions

An iteration expression is a subexpression of specific [constructor expressions](../../abap-glossary/abenconstructor_expression_glosry.md) introduced using the iteration operator `FOR` and executes an iteration in these expressions. In addition to its optional use for creating lines in internal tables with the corresponding variants of the instance operator [`NEW`](../abap-creating-objects-and-values/abennew_constructor_params_itab.md) and the value operator [`VALUE`](../abap-creating-objects-and-values/abenvalue_constructor_params_itab.md), there is a special reduction operator `REDUCE` that is based entirely on iteration expressions.

- [`REDUCE` - Reduction Operator](abenconstructor_expression_reduce.md)
