# Branches

This section describes the branches defined using the following:

- [`IF`](abapif.md)

- [`CASE`](abapcase.md)

- [`CASE TYPE OF`](abapcase_type.md)

## Hint

The [conditional operators](../../abap-glossary/abenconditional_operator_glosry.md) [`COND`](abenconditional_expression_cond.md) and [`SWITCH`](abenconditional_expression_switch.md) can be used to implement branches in operand positions.
