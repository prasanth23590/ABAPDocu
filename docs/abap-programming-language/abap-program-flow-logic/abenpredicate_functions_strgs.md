# rel_exp - Predicate Functions for Character-Like Arguments

The following predicate functions exist for character-like arguments:

- [`contains, contains_...`](abencontains_functions.md)

- [`matches`](abenmatches_functions.md)

## Hint

The predicate functions shown here can be used instead of [comparison operators](abenchar_comp_op_vs_funct.md).
