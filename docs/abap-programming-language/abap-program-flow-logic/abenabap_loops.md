# Loops

This section describes the loops defined using the following:

- [`DO` - `ENDDO`](abapdo.md)

- [`WHILE` - `ENDWHILE`](abapwhile.md)

Further keywords for defining loops are:

- [`LOOP` - `ENDLOOP`](../abap-processing-internal-data/abaploop_at_itab.md)

- [`SELECT` - `ENDSELECT`](../abap-database-access/abapselect.md) for loops across the result set of a database access.
