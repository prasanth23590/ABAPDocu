# ABAP - Enhancements

[ABAP source code](../../abap-glossary/abenabap_source_code_glosry.md) can be enhanced without modifications using [BAdIs](../../abap-glossary/abenbadi_glosry.md), as part of the ABAP Enhancement Framework.

- [Enhancements Using BAdIs](abenbadi_enhancement.md)

For more information and further enhancement options, see [Enhancement Framework](https://help.sap.com/docs/ABAP_PLATFORM_NEW/46a2cfc13d25463b8b9a3d2a3c3ba0d9/949cdc40132a8531e10000000a1550b0) in the SAP Help Portal.
