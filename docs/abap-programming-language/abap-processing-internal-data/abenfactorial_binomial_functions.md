# num_func - factorial, binomial

## Syntax

``` abap
... factorial( n ) ...  

... binomial( n = i k = j ) ...  
```

## Description

The [built-in function](../../abap-glossary/abenbuiltin_function_glosry.md) `factorial` computes the factorial of positive integer values. The `binomial` function computes the binomial coefficient.

- [`num_func` - `factorial`](abenfactorial_functions.md)

- [`num_func` - `binomial`](abenbinomial_functions.md)
