# Time Stamp Functions (ts_func)

The following [built-in functions](../../abap-glossary/abenbuiltin_function_glosry.md) for processing UTC time stamps in time stamp fields are available:

- [`utclong_current`](abenutclong_current.md) creates a current time stamp

- [`utclong_add`](abenutclong_add.md) adds values to a time stamp

- [`utclong_diff`](abenutclong_diff.md) determines the difference between two time stamps
