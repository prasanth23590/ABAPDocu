# Conversion Statements for Time Stamp Fields

The following statements convert UTC time stamps in time stamp fields to date fields and time fields and back again.

- [`CONVERT UTCLONG`](abapconvert_utclong.md)

- [`CONVERT INTO UTCLONG`](abapconvert_date_utclong.md)
