# cstring_func - Common Parameters

- [`cstring_func` - `case`](abenstring_functions_case.md)

- [`cstring_func` - `occ`](abenstring_functions_occ.md)

- [`cstring_func` - `off, len`](abenstring_functions_off_len.md)

- [`cstring_func` - `pcre`, `xpath`](abenstring_functions_regex.md)

- [`cstring_func` - `sub`](abenstring_functions_sub.md)

- [`cstring_func` - `val`](abenstring_functions_val.md)
