# Assigning Structure Components

The following special language constructs are used to assign components from structures or columns of internal tables:

- [`MOVE-CORRESPONDING`](abapmove-corresponding.md) for the assignment of identically named components.

- Component operator [`CORRESPONDING`](abenconstructor_expr_corresponding.md) for the assignment of components using identical names or a static mapping rule.

- System class [`CL_ABAP_CORRESPONDING`](abencl_abap_corresponding.md) for dynamic mapping rules.
