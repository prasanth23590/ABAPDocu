# Date Fields and Time Fields

The ABAP types [`d`](../abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_date_time.md) and [`t`](../abap-built-in-types-data-objects-functions-and-constructors/abenbuiltin_types_date_time.md) are built-in types for data objects that specify dates and times. The date type `d` describes a character-like local date in the format *yyyymmdd*. The date type `t` describes a character-like local time in the format ` hhmmss`.
