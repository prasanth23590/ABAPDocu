# Numeric Calculations

Numeric calculations are executed mainly using [arithmetic expressions](../../abap-glossary/abenarithmetic_expression_glosry.md) that can be used in operand positions and, in particular, on the right side of the [assignment operator`=`](abenequals_operator.md). [Numeric data objects](../../abap-glossary/abennumeric_data_object_glosry.md), that is, data objects that can be converted to [numeric data types](../../abap-glossary/abennumeric_data_type_glosry.md), and [numeric functions](../../abap-glossary/abenmathematical_funktion_glosry.md) that have a numeric return value can be used as operands of an arithmetic expression. Some [system classes](../../abap-glossary/abensystem_class_glosry.md) complement the numeric functions with additional functions. Finally, there are four standalone assignment operators that can be used for the basic arithmetic operations.

- [Numeric Data Types](abennumber_types.md)

- [Arithmetic Expressions (`arith_exp`)](abapcompute_arith.md)

- [Numeric Functions (`num_func`)](abenmathematical_functions.md)

- [System Classes for Numbers](abencl_abap_math.md)

- [`+=`, `-=`, `*=`, `/=`, Calculation Assignments](abencalculation_assignments.md)
