# Streaming for Data Objects

The abstract superclasses for [streaming](../../abap-glossary/abenstreaming_glosry.md) for data objects are:

- `CL_ABAP_MEMORY_C_READER`

- `CL_ABAP_MEMORY_C_WRITER`

- `CL_ABAP_MEMORY_X_READER`

- `CL_ABAP_MEMORY_X_WRITER`

Streaming is possible for strings and internal tables:

- [Streaming for Strings](abenstring_streams.md)

- [Streaming for Internal Tables](abenitab_streams.md)

## Hint

Another important application for streaming is when using [ABAP SQL](../abap-database-access/abenabap_sql_streaming.md) to access [LOBs](../../abap-glossary/abenlob_glosry.md) in database tables.
