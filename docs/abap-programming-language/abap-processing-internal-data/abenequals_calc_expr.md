# =, Assign Calculation Expressions

[Calculation expressions](../../abap-glossary/abencalculation_expression_glosry.md) are [arithmetic expressions](../../abap-glossary/abenarithmetic_expression_glosry.md), [string expressions](../../abap-glossary/abenstring_expression_glosry.md), and [bit expressions](../../abap-glossary/abenbit_expression_glosry.md). Any calculation expression can be located on the right side of the [assignment operator `=`](abenequals_operator.md).
