# CL_ABAP_CORRESPONDING, System Class

The system class `CL_ABAP_CORRESPONDING` enables assignments of components between structures or between internal tables with dynamically specified mapping rules. Methods are available for simple assignments, assignments of default values, and for using a lookup table.

- [`CL_ABAP_CORRESPONDING` - Simple Assignment](abencl_abap_corresponding_1.md)

- [`CL_ABAP_CORRESPONDING` - Assignment of Default Values](abencl_abap_corresponding_3.md)

- [`CL_ABAP_CORRESPONDING` - Lookup Table](abencl_abap_corresponding_2.md)
