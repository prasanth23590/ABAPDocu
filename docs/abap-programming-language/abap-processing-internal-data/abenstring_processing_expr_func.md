# Expressions and Functions for Character String Processing

Expressions and functions for character string processing can be listed at many [operand positions](../abap-syntax-elements-of-an-abap-program/abenexpression_positions.md).

- [String Expressions (`string_exp`)](abapcompute_string.md)

- [Character String Functions (`cstring_func`)](abenstring_functions.md)

- [Regular Expressions (regex)](abenregular_expressions.md)

## Hint

An advantage of the expressions and functions for string processing over the [statements for character and byte string processing](abenstring_processing_statements.md) is that expressions can be specified for all operands, which is only possible to a very limited extent in the statements.
