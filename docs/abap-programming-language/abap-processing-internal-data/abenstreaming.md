# Streaming

Streaming describes how [streams](../../abap-glossary/abenstream_glosry.md) are passed. Streams are represented by instances of special classes. The transfer of streams takes place by calling the relevant methods of the object.

## Properties of Streams

Streams are classified by the following properties:

- Stream kind

  [Data streams](../../abap-glossary/abendata_stream_glosry.md)

- Stream direction

  [Reader streams](../../abap-glossary/abenreader_stream_glosry.md) and [writer streams](../../abap-glossary/abenwriter_stream_glosry.md)

- Stream type

  [Binary streams](../../abap-glossary/abenbinary_stream_glosry.md) and [character streams](../../abap-glossary/abencharacter_stream_glosry.md)
