# XSL Transformations

An XSL transformation is a program in the [repository](../../abap-glossary/abenrepository_glosry.md) that is written in [XSLT](../../abap-glossary/abenxslt_glosry.md) (XSLT program) and used for the transformation of XML data. A set of rules is defined to express how an XML input tree is transformed to an XML output tree. The following use cases are available:

- Transformation of XML to HTML or any other text-based document format

- Transformation of XML to XML

- Mapping of XML and ABAP data structures

Existing XSLT programs in the repository can be called using the statement [`CALL TRANSFORMATION`](abapcall_transformation.md).
