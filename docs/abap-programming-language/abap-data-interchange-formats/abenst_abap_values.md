# ST - Transformation of ABAP Values

The following ST statements are used for transformations of ABAP values:

- [`tt:value`](abenst_tt_value_elementary.md) for elementary data objects

- [`tt:value`](abenst_tt_value_structure.md) for structures

- [`tt:loop`](abenst_tt_loop.md) for internal tables

- [`tt:copy`](abenst_tt_copy.md) for the asXML format
