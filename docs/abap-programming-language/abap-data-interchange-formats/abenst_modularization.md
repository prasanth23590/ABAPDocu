# ST - Modularization with Subtemplates

An ST program can contain any number of templates that are defined with `tt:template`. All templates but the [main template](abenst_tt_template_main.md) are subtemplates that can be called in the main template.

- [`tt:template`, `tt:context`, Create Subtemplate](abenst_tt_template_sub.md)

- [`tt:apply`, Call Subtemplate](abenst_tt_apply.md)
