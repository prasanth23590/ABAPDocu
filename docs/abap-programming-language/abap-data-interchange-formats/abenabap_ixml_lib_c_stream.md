# iXML - Streams

The iXML Library interfaces for handling streams are:

``` abap
 
IF_IXML_STREAM_FACTORY_CORE 
 
IF_IXML_STREAM_CORE 
  | 
  |--IF_IXML_ISTREAM_CORE 
  | 
  |-- IF_IXML_OSTREAM_CORE
```
