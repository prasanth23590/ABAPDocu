# XSL - Serialization from and Deserialization to ABAP

The source and result of a general XSL transformation are [XML](../../abap-glossary/abenxml_glosry.md) data. When an XSL transformation is called using the statement `CALL TRANSFORMATION`, however, ABAP data can also be transformed directly to XML and vice versa. For this purpose, a [serialization](../../abap-glossary/abenserialization_glosry.md) or [deserialization](../../abap-glossary/abendeserialization_glosry.md) is performed implicitly, with [asXML](../../abap-glossary/abenasxml_glosry.md) as an intermediate format.
