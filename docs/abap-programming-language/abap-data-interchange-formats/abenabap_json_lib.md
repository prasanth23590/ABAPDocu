# JSON Library

The JSON library provides an API consisting of [classes and interfaces](abenabap_json_lib_object_types.md) for reading (validating parses) and rendering (validating writes) of JSON data in different formats and from different sources or to different targets.

The JSON reader and JSON writer can be specified as JSON source or JSON target in the statement [`CALL TRANSFORMATION`](abapcall_transformation.md).
