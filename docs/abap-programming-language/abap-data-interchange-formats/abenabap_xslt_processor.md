# XSL - XSLT Processor

The [ABAP runtime framework](../../abap-glossary/abenabap_runtime_frmwk_glosry.md) contains an [SAP XSLT processor](../../abap-glossary/abenxslt_processor_glosry.md) for executing the transformations. It supports almost all XSLT statements and implements enhancements (extension instructions and extension functions) such as calling ABAP methods from XSLT programs.
